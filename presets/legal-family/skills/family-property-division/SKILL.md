# 财产分割方案编排入口（property-division）

> **迁移说明**：本技能为全新创建的财产分割方案主技能，包含四个可独立触发的子技能：
> - `community-property-identification`（共同财产认定）
> - `special-asset-division`（特殊财产分割）
> - `division-principles-care`（分割原则与照顾）
> - `concealed-asset-remedy`（隐藏转移财产救济）
>
> 各子技能可由本入口顺序编排，也可**单独触发**（`/family-legal:<子技能名>`）。
>
> **与 divorce-agreement/property-division-clauses 的分工**：
> - **本技能（property-division）**：侧重复杂财产的**法律性质认定**（共同财产 vs 个人财产）、**估值方法与分割方案设计**、照顾原则与补偿请求权分析、隐匿转移财产救济路径
> - **divorce-agreement/property-division-clauses**：侧重将认定结果落实为**离婚协议具体条款文本**（条款语言、补偿数额约定、过户安排等）
> - 典型使用路径：先调用本技能认定与分析，再调用 property-division-clauses 起草协议条款

---

## 目的

作为财产分割方案的主技能编排入口，为律师/法务/当事人提供离婚财产分割的**完整分析流程**：

1. **共同财产认定** → 识别夫妻共同财产范围与个人财产边界、约定财产制效力
2. **特殊财产分割** → 房产（按揭增值/父母出资/加名）、股权与公司份额、知识产权收益、投资性资产、养老金保险
3. **分割原则与照顾** → 照顾子女/女方/无过错方原则（第1087条）、家务劳动补偿（第1088条）、经济帮助（第1090条）、损害赔偿（第1091条）
4. **隐藏转移财产救济** → 少分不分（第1092条）、离婚后再次分割、财产保全与举证

## 当事人情绪护栏

> **贯穿全程，凌驾于代理立场之上。**

- 输出措辞**中立、克制、非煽动**：不替当事人作情绪化判断，不描述对方的主观动机
- **不激化对立**：财产纠纷往往情绪激烈，避免「对方居心叵测」等加剧冲突的语言
- **识别情绪危机信号**：当事人表达自我伤害、极度绝望等信号，**暂停法律分析**，提示专业心理支持（心理援助热线 400-161-9995 或当地援助热线）

> **贯穿全程，凌驾于代理立场之上。**


### 2. 代理立场对共同财产认定的影响

**代理立场是分析侧重的核心变量**：

| 代理立场 | 认定侧重方向 |
|---------|-----------|
| **离婚一方侧（主张方）** | 尽量扩大共同财产范围：婚后取得的财产推定为共同财产；婚后增值主张转化为共同财产或要求补偿；约定财产制效力审慎核查（对方是否真正知悉）；婚前出资记录有瑕疵时主张共同性 |
| **离婚一方侧（被主张方）** | 尽量剥离个人财产：举证婚前来源（房产/存款出资时间线/父母赠与协议）；主张自然增值属个人；约定财产制有效对抗主张方；争取个人专用生活用品单独列示 |
| **中立审查** | 依法律规则客观认定，双向识别争议点，平衡呈现双方可能主张 |

**不得被立场覆盖的护栏**：涉及未成年子女的财产安排以最有利于未成年子女为首要原则；家暴情形下强制升级，不因立场影响。

### 步骤二：按财产性质认定分类

**2.1 夫妻共同财产认定（民法典第1062条，建议复核）**

以下财产为夫妻共同财产：

| 来源类别 | 典型财产 | 认定要点 | 争议点 |
|---------|---------|---------|------|
| 工资、奖金、劳务报酬 | 婚后工资/年终奖/绩效/劳务费 | 婚姻关系存续期间取得即为共同财产，无需另行证明 | 婚前应得但婚后发放的奖金（应以取得时间还是应得时间认定）`[待验证]` |
| 生产、经营、投资收益 | 婚后开办公司/个体经营/投资股票基金所得 | 婚后收益归共同所有，婚前个人经营收益属个人 | 婚前投入、婚后获得收益的投资（见步骤三婚后增值部分） |
| 知识产权收益 | 婚后版权稿酬/专利许可费/商标许可费 | 注意：是「收益」而非「知识产权本身」，婚姻关系存续期间实现的收益为共同财产 | 婚前创作、婚后取得的著作权收益（司法解释描述规则，`[待验证]`） |
| 继承或受赠所得 | 婚后继承的遗产、婚后受赠的财产 | 遗嘱或赠与合同明确只归一方的除外；未明确时为共同财产 | 父母出资赠与的房产：是赠与双方还是只赠一方（须看赠与合同或明示表述） |
| 其他应归共同所有 | 婚后共同贷款所得、共同事业积累 | 兜底条款 | — |

**核查清单（共同财产认定）**：

- [ ] 财产取得时间是否确为婚姻关系存续期间
- [ ] 是否有遗嘱/赠与合同明确说明只归一方（如有则不属共同财产）
- [ ] 知识产权的「收益」与「权利本身」是否已区分
- [ ] 婚后工资/奖金的金融账户是否清晰（混同账户须清分）
- [ ] 经营实体（公司/个体户）的收益分配记录是否完整

**2.2 夫妻个人财产认定（民法典第1063条，建议复核）**

以下财产为一方个人财产：

| 类别 | 典型财产 | 认定要点 | 举证方向 |
|-----|---------|---------|---------|
| 婚前财产 | 婚前购买的房产、婚前存款、婚前车辆 | 婚姻登记前取得，婚后增值问题另行处理 | 购房合同/首付时间/存款开户时间/交付凭证 |
| 人身损害赔偿/补偿 | 交通事故/工伤/人身侵权赔偿金 | 无论婚前婚后取得，均为个人财产（与人身相关） | 判决书/调解书/银行入账记录 |
| 遗嘱/赠与合同明确归一方的财产 | 父母立遗嘱明确留给本方的遗产；赠与合同明确只归一方的赠与 | 须有书面遗嘱或赠与合同明确记载 | 遗嘱/赠与合同原件 |
| 一方专用生活用品 | 婚后购买的一方专用衣物/日常用品（价值较低） | 仅限一方专用、价值较小；高价值奢侈品不适用 | — |
| 其他应归一方 | 兜底条款 | 须有法律依据 | — |

**核查清单（个人财产认定）**：

- [ ] 婚前财产有无足够时间线证据（合同/首付时间/付款记录）
- [ ] 人身损害赔偿金是否与精神损害抚慰金一并归一方（确认）
- [ ] 父母赠与或遗嘱是否有书面记载明确只归一方
- [ ] 「专用生活用品」是否仅限低价值日常用品（高价值奢侈品须核查）

**2.3 约定财产制认定（民法典第1065条，建议复核）**

约定财产制须满足以下要件：

| 要件 | 内容 | 核查重点 |
|-----|------|---------|
| 书面形式 | 约定须采用书面形式（口头约定无效） | 核查是否有书面婚前/婚内财产协议 |
| 约定内容明确 | 约定各自所有 / 共同所有 / 部分各自部分共同（三种模式之一） | 约定内容是否覆盖争议财产类型 |
| 双方均知悉 | 约定对双方有约束力；对第三人须证明第三人知道该约定 | 核查第三人是否知情（影响对外债务清偿） |
| 意思表示真实 | 约定须为双方真实意思表示（无欺诈/胁迫/重大误解） | 若存在意思表示瑕疵，约定可被主张撤销（合同编参照结构，`[待验证]`） |

约定财产制有效时的效力分析：

- **对内效力**：双方受约定约束，不适用第1062/1063条默认规则
- **对外效力**：债权人仅在知道该约定的情形下，方可以夫或妻一方的个人财产主张清偿
- **约定的边界**：约定不得规避法律强制性规定（如不得约定免除赡养义务、不得损害债权人利益）

### 步骤三：婚前财产婚后增值的性质判断

**自然增值 vs 主动增值的区分**（司法解释规则，描述规则，`[待验证]`）：

| 增值类型 | 典型例子 | 性质认定 | 说明 |
|---------|---------|---------|-----|
| **自然增值** | 婚前购房因市场行情上涨；婚前存款利息；婚前债权到期实现 | 通常认定为一方**个人财产**（增值属于原物的自然延伸） | 无需配偶任何投入，仅因市场或时间自然产生 |
| **主动经营增值** | 婚前购房婚后共同装修/还贷/增值；婚前公司婚后双方共同经营获利 | 增值部分**可能转化为共同财产或产生补偿权** | 共同劳务投入、共同资金投入是转化的关键因素 |
| **混合型** | 婚前存款婚后用于共同投资，收益与本金混同 | 须依账务记录清分 | 混同时举证责任对主张方有利 |

**房产婚前购买婚后增值**（最典型争议）：

最高法婚姻家庭编司法解释(一)规定（描述规则，条号 `[待验证]`）：一方婚前以个人财产购买、登记为其名下的房产，婚后双方共同还贷的，离婚时归产权登记方，但婚后共同还贷的数额及对应房产增值部分，由产权登记方对另一方进行补偿。

具体分析见 `本文档「子技能：special-asset-division」章节`（房产专项）。

**知识产权婚前创作婚后取得收益**（司法解释规则，描述规则，`[待验证]`）：

最高法婚姻家庭编司法解释(一)规定（描述规则）：婚姻关系存续期间，实际取得或者明确可以取得的知识产权收益属于夫妻共同财产。婚前创作婚后取得的收益是否属于共同财产，须结合取得时间认定。

## 边界条件

| 情形 | 处理方式 |
|-----|---------|
| 父母出资购房（全额出资） | 核查是否有书面赠与合同/公证；明确赠与一方还是双方还是借款——三种性质法律结果完全不同；无书面记录时存在争议 `[待验证]` |
| 父母出资购房（部分出资/首付）| 部分出资是赠与一方还是双方须有书面证明；剩余部分为婚后共同还贷（婚后还贷增值见 special-asset-division） |
| 公积金与养老金 | 公积金余额通常认定为夫妻共同财产（婚后缴存部分）；养老金在婚姻关系存续期间的积累部分属共同财产——具体认定须核实当地实践 `[待验证]` `[地方 flagged]` |
| 约定财产制对抗债权人 | 第三人不知道约定时，债权人可向夫妻双方追索；知道时按约定处理 |
| 知识产权收益婚前创作 | 婚前创作婚后持续取得的版税等收益，以收益实际取得时间为准（司法解释，描述规则，`[待验证]`） |
| 财产来源无法证明 | 无法证明来源时，推定为夫妻共同财产（举证责任在主张个人财产一方） |
| 婚姻无效/可撤销情形 | 婚姻被确认无效或撤销时，财产处理另有规则，不适用共同财产分割（须单独分析） |
| 涉外财产 | 涉及境外财产/跨境投资，准据法认定与财产调查路径须核实 `[待验证]` |

## 详细步骤

### 一、房产分割

房产是离婚财产分割中争议最大的类别，须逐情形分析。

**房产基本信息采集**：

| 字段 | 内容 |
|-----|------|
| 产权登记情况 | 一方名下 / 双方共有 / 父母名下 |
| 购房时间 | 婚前 / 婚后 |
| 首付资金来源 | 一方婚前存款 / 婚后共同存款 / 一方父母出资 / 双方父母共同出资 |
| 贷款情况 | 无贷款（全款）/ 有按揭（婚前/婚后还贷） |
| 贷款还款方式 | 婚前一人还款 / 婚后共同还款 / 婚后一方独自还款 |
| 房产现值估计 | [市场评估价 / 网签备案价 / 鉴定评估价] |
| 婚后增值情况 | 估计增值额 |

**房产分割决策表**（依据最高法婚姻家庭编司法解释(一)，描述规则，`[待验证]`）：

| 情形 | 房产归属 | 补偿计算方向 | 主要争议点 |
|-----|---------|-----------|----------|
| **婚前一方全款购买，登记在一方名下** | 个人财产（第1063条，建议复核）；归产权登记方 | 无补偿（纯个人财产） | 婚后装修/翻新支出是否应补偿（较小） |
| **婚前一方购房，婚后双方共同还贷** | 产权归登记方（司法解释规则，`[待验证]`）；但婚后共同还贷本金+对应增值须补偿另一方 | 补偿额 = 婚后共同还贷本金 × 2 ÷ 2 + 增值部分 × （婚后还贷/总贷款比例）× 1/2，具体计算公式须司法实践确认 `[待验证]` | 增值比例计算方法；还贷来源证明（是否真正共同还贷） |
| **婚前一方父母全额出资，产权登记在子女名下** | 视为对该子女的个人赠与（司法解释，描述规则，`[待验证]`）；个人财产 | 无补偿（个人财产） | 是否有书面赠与合同；登记情况（登记在双方名下则不同） |
| **婚前一方父母部分出资（首付），子女婚后还贷** | 父母出资部分视为赠与一方（个人财产基础）；婚后还贷+增值须补偿 | 父母出资=个人财产；婚后还贷增值部分按共同财产处理 `[待验证]` | 父母出资是赠与还是借款须书面证明 |
| **婚后双方父母共同出资** | 若有书面说明各自赠与比例，按比例认定；无书面记录通常视为赠与双方 `[待验证]` | 依赠与比例认定各自份额 | 父母出资性质（赠与/借款）及各方份额比例 |
| **婚后共同出资购房，登记在一方名下** | 属夫妻共同财产，登记仅是形式（第1062条，建议复核）；分割时各占50%或按约定 | 产权登记方取得房产须向另一方支付折价补偿 | 折价补偿额（市场价还是评估价）；剩余贷款承担方式 |
| **婚后加名（原个人财产加另一方名）** | 婚后加名通常视为赠与（转变为共同共有）`[待验证]` | 加名后按共同财产分割 | 加名时是否有附带条件；赠与是否可撤销 |
| **婚后共同购房，登记在双方名下** | 共同财产，按份共有或共同共有依登记情况 | 各持份额或各50% | 剩余贷款承担比例 |

**按揭房产剩余贷款处理**：

- 离婚时剩余贷款通常随取得房产方承担；另一方已还本金须获得补偿
- 银行贷款变更需银行同意（实践中银行审批可能有限制）
- 如不能变更贷款，须约定内部分担责任并设置违约责任条款

**房产估值路径**：

| 方法 | 适用场景 | 优缺点 |
|-----|---------|------|
| 协议约定房价 | 双方自愿协商 | 简便，但可能一方不满意 |
| 委托评估机构出具评估报告 | 争议较大时 | 客观，有成本；评估基准日影响结果 |
| 参考近期同小区成交价 | 市场信息透明时 | 便捷，争议时对方可能不认可 |
| 申请法院委托评估 | 诉讼程序中 | 权威，诉讼成本较高 |

### 二、股权与公司份额分割

**有限责任公司股权分割**：

股权分割面临双重障碍：夫妻财产分割规则（民法典）与公司法对股东变更的限制。

**股权性质认定**：

| 情形 | 股权性质 | 分割路径 |
|-----|---------|---------|
| 婚前持有股权 | 股权本身为个人财产（第1063条）；婚后股权增值/分红可能为共同财产 | 认定婚后增值/收益性质 |
| 婚后出资设立公司 | 出资资金来源于共同财产时，股权属共同财产（第1062条，建议复核） | 分割股权或折价补偿 |
| 婚后以个人财产出资 | 个人财产出资，股权属个人财产（须举证出资来源） | 举证出资来源 |

**股权分割的三条路径**：

| 路径 | 内容 | 适用条件 | 利弊 |
|-----|------|---------|-----|
| **折价补偿** | 一方取得股权，向另一方支付相当于股权价值半数的补偿款 | 另一方不适合持股或双方同意 | 保持公司控制权完整；须确定公允股权价值 |
| **股权转让给非配偶** | 一方将共同财产部分股权转让给第三方，获得对价后分割对价 | 其他股东同意行使优先购买权放弃后 | 需其他股东配合；公司法对有限公司股权转让有规定 `[待验证]` |
| **强制分割股权** | 法院判决将配偶列为股东 | 其他股东不行使优先购买权时 | 干扰公司治理；实践中其他股东通常反对 |

**股权估值**：

| 方法 | 适用场景 | 注意事项 |
|-----|---------|---------|
| 净资产法 | 账面净资产清晰 | 不反映未来盈利能力和商誉 |
| 收益法（市盈率） | 盈利稳定 | 预测假设敏感 |
| 市场比较法 | 有可比公司 | 非上市公司难找可比对象 |
| 司法评估 | 争议较大，诉讼程序中 | 委托具有资质的司法鉴定机构 |

**其他注意事项**：

- **未实缴出资**：认缴未实缴的出资，实际价值与认缴值有差异，须区分认缴额与实际出资额
- **公司控制权**：大股东一方分割后可能影响公司经营决策，折价补偿是更常见选择
- **竞业限制与商业秘密**：分割股权后，前配偶成为小股东可能涉及公司商业秘密保护问题

### 三、知识产权收益分割

**知识产权本身 vs 知识产权收益**（重要区分）：

| 类别 | 性质 | 分割规则 |
|-----|------|---------|
| **知识产权本身（著作权/专利权/商标权）** | 与权利人人身密切相关，通常不分割权利本身 | 不强制分割权利归属 |
| **知识产权收益（版税/专利许可费/商标许可费）** | 婚姻关系存续期间实际取得的收益为共同财产（第1062条，建议复核） | 已实现收益按共同财产分割 |
| **尚未取得的预期收益（未到期版税/待实现专利许可费）** | 性质认定有争议（司法解释，描述规则，`[待验证]`） | 可约定未来实现时支付补偿；或折现现值分割 |

**知识产权收益认定的实务要点**：

- 收益已入账：有银行流水、合同对账单 → 认定为共同财产，可直接分割
- 收益未到账但合同已签：可约定将来实现时支付；须注意对方可能主张折现分割
- 持续性创作（作者婚后继续创作获得收益）：婚后创作对应的婚后收益为共同财产

### 四、股票、基金等投资性资产

| 资产类型 | 分割要点 | 估值时点 | 注意事项 |
|---------|---------|---------|---------|
| **股票（A股）** | 婚后买入的股票为共同财产；婚前持有的婚后增值可能涉及性质认定 | 离婚时市值；注意市值波动对公平性的影响 | 账户挂账的股票须明确持仓数量；停牌股票估值困难 |
| **基金（公募/私募）** | 婚后投入资金对应份额为共同财产 | 净值日估值 | 私募基金流动性差，赎回有限制；锁定期内分割须协商 |
| **债券/大额存单** | 婚后购入为共同财产 | 按面值或市场价 | 到期兑付时间影响现金流 |
| **互联网理财产品** | 婚后投入为共同财产 | 账面余额 | 注意关联账户归属 |

**估值时点的争议**：应以离婚诉讼立案时、庭审时还是判决时为准，各地实践不同 `[地方 flagged — 需核实地方裁判口径]`。

### 五、养老金与保险现金价值

**养老金（职工基本养老保险）**：

最高法婚姻家庭编司法解释(一)（描述规则，`[待验证]`）：婚姻关系存续期间缴交的养老保险费对应的权益属夫妻共同财产，离婚时一方可主张分割婚内缴交部分对应的养老金账户价值；具体分割方式因各地社保实践差异较大  `[地方 flagged — 需核实地方社保实践]`。

**人身保险现金价值**：

- 整存式两全保险/终身寿险的现金价值，婚后缴交保费对应的现金价值属共同财产
- 保险权益须注意受益人变更与保单归属
- 分红型保险的分红收益（婚后取得）为共同财产

## 边界条件

| 情形 | 处理方式 |
|-----|---------|
| 父母出资性质争议（赠与 vs 借款） | 有书面借条且有还款记录的倾向认定为借款（共同债务）；无书面凭证的赠与认定须举证 `[待验证]` |
| 公司经营连续性 | 法院通常倾向折价补偿而非强制分割股权，以保护公司正常经营 |
| 跨境资产（境外房产/境外账户） | 准据法、资产调查、评估与执行路径均有特殊性，须专业律师介入 `[待验证]` |
| 房产被查封/限制交易 | 须先解除查封方可分割，诉讼保全可能影响分割程序 |
| 股票处于跌停/停牌 | 估值困难；可约定于正常交易日按收盘价分割或折算 |
| 期权/限制性股票（上市公司） | 未行权期权的现值认定有争议；已行权部分按收益认定 `[待验证]` |

| 错误/敏感情形 | 识别信号 | 处理方式 |
|------------|---------|---------|
| 对方隐匿股权/公司 | 财产清单中缺少明知的公司股权；工商查询显示对方持股但未申报 | 🔴 调用 `「子技能：concealed-asset-remedy」章节（见本文档）`；申请工商调查令 |

| 涉刑情形（职务侵占/挪用） | 疑似公司财产来源不明 | 🔴 强制升级刑事律师 |

## 详细步骤

### 一、离婚财产分割照顾原则（第1087条，建议复核）

**基本规则**：离婚时，夫妻共同财产由双方协议；协议不成时，由法院根据财产具体情况，按照照顾子女、女方和无过错方权益的原则判决。

**照顾原则的适用分析**：

| 照顾情形 | 构成要件 | 实践中的影响程度 | 举证方向 |
|---------|---------|------------|---------|
| **照顾子女** | 直接抚养未成年子女一方，因承担日常抚育支出、子女有稳定居住需求 | 较大——通常倾向将有子女居住的房产判给抚养方，或优先考虑抚养方的居住需求 | 提供直接抚养证据（照顾记录/学校接送/医疗记录）；子女居住稳定性说明 |
| **照顾女方** | 女性一方处于明显不利地位（如家庭主妇/经济来源单一/年龄较大再就业困难） | 中等——具体比例酌定，不是硬性50%以上 | 收入差距证明；年龄与再就业困难说明；家庭贡献记录 |
| **照顾无过错方** | 另一方存在法定过错（重婚/同居/家暴/虐待遗弃/其他重大过错=第1091条法定情形）且导致离婚 | 中等——可影响分割比例（酌情增加无过错方份额），但具体比例由法院裁量 | 过错情形的证据（见损害赔偿章节举证清单） |

**照顾原则与损害赔偿的关系**：

- 照顾原则（第1087条）和损害赔偿（第1091条）是**两个独立请求权**，可同时主张
- 照顾分割影响的是共同财产分割比例（不均等分割）
- 损害赔偿是单独的赔偿请求权（可另行主张物质损害和精神损害抚慰金）

**核查清单（照顾原则）**：

- [ ] 是否有直接抚养未成年子女（照顾子女情形）
- [ ] 女方经济状况与男方是否有较大差距（照顾女方情形）
- [ ] 对方是否存在第1091条法定过错情形（照顾无过错方）
- [ ] 照顾原则主张的比例增加是否合理（须法院最终裁量，无法保证具体比例）

### 二、家务劳动补偿请求权（第1088条，建议复核）

**基本规则**：夫妻一方因抚育子女、照料老年人、协助另一方工作等负担较多义务的，离婚时有权向另一方请求补偿，另一方应当给予补偿。

**民法典修订说明**：民法典修订后，家务劳动补偿请求权**不再限于约定分别财产制**，所有夫妻均可主张（取消了原婚姻法司法解释的前提条件限制）。

**家务劳动补偿请求权分析**：

| 分析维度 | 内容 | 核查要点 |
|---------|------|---------|
| **「负担较多义务」的认定** | 须证明一方实际承担了远超另一方的家务劳动（抚育子女/照料老人/协助另一方工作） | 家务承担比例；是否为家庭主妇/主夫；照料老人的记录；协助另一方事业的具体贡献 |
| **补偿数额的计算基础** | 无明确计算公式（司法解释和司法实践中数额差异较大，`[待验证]`）；参考因素：家务年限、市场家政价格、工资损失、家庭规模 | 收集婚姻年限/家务承担年数/当地家政市场价格参考；法院最终酌定 |
| **举证方式** | 家务承担证据（证人证言/照片/医疗记录/学校接送记录/老人护理记录） | 证据碎片化，须系统收集 |
| **补偿时机** | 离婚时主张；协议离婚和诉讼离婚均可主张 | 注意：协议中如未约定，离婚后主张是否有时效问题须核实 `[待验证]` |

**家务补偿数额考量因素（实践参考，非法定标准）**：

| 因素 | 说明 |
|-----|------|
| 婚姻年限 | 婚龄越长，家务贡献积累越大 |
| 家务承担比例 | 主要承担全部家务 vs 承担部分家务，比例影响数额 |
| 对方收入水平 | 法院通常参考对方因获得支持而节省的成本 |
| 市场价格参考 | 当地家政服务市场价格（`[地方 flagged — 需核实地方价格水平]`） |
| 子女/老人数量 | 照料对象越多，负担越重 |
| 牺牲的职业发展机会 | 为家庭放弃职业发展的量化较难 |

### 三、经济帮助请求权（第1090条，建议复核）

**基本规则**：离婚时，如果一方生活困难，有负担能力的另一方应当给予适当帮助。

**请求权构成要件**：

| 要件 | 说明 | 举证要点 |
|-----|------|---------|
| **「一方生活困难」** | 须证明离婚后确实面临基本生活困难（无住房/无收入/重大疾病等），而非一般经济差距 | 收入证明/住房情况/健康状况/就业能力证明 |
| **「另一方有负担能力」** | 另一方须有实际经济能力给予帮助 | 另一方收入证明/财产状况 |
| **「适当帮助」** | 帮助程度以解决基本生活困难为限，不是无限制的扶养 | 法院酌定，无固定标准 |

**帮助方式**：

| 方式 | 说明 |
|-----|------|
| 住房方面 | 允许困难方在共同房产中居住一段时间，或给予其他住房安排 |
| 金钱帮助 | 一次性支付或定期支付（具体期限由双方协议或法院裁量） |
| 其他适当形式 | 由当事人协议或法院酌定 |

### 四、离婚损害赔偿（第1091条，建议复核）

**基本规则**：有下列情形之一导致离婚的，无过错方有权请求损害赔偿：（一）重婚；（二）与他人同居；（三）实施家庭暴力；（四）虐待、遗弃家庭成员；（五）有其他重大过错。

**⚠️ 家暴情形特别提示**：本条第三项涉及家庭暴力。识别到家暴情形时，**立即触发强制升级**（见前置章节），损害赔偿数额分析须在安全环境与律师指导下进行。

**各过错情形的认定与举证**：

| 过错情形 | 认定标准（描述规则，`[待验证]`） | 举证清单 | 举证难度 |
|---------|---------|---------|---------|
| **重婚** | 有配偶者与他人登记结婚 | 婚姻登记记录；公安户籍证明 | 相对明确（有登记记录） |
| **与他人同居** | 最高法司法解释认定：有配偶者与他人持续稳定地共同居住（描述规则，`[待验证]`）；非偶发性 | 同居地址证明；物业/门卫证人；通讯记录；照片/视频；共同消费记录 | 较高——须证明持续稳定性 |
| **实施家庭暴力** | 反家庭暴力法对家庭暴力的定义（描述规则，`[待验证]`）；包括身体暴力、精神控制等 | 医院伤情鉴定/诊断记录；报警记录/派出所处理记录；人身安全保护令申请记录；证人证言；伤情照片；通讯记录（威胁内容） | 较高——受害方往往因恐惧而未及时保留证据 |
| **虐待、遗弃家庭成员** | 持续性伤害行为（虐待）或拒绝履行扶养义务（遗弃） | 诊断记录；生活记录（对方未承担家庭责任的证明）；证人证言 | 较高 |
| **其他重大过错** | 由法院认定；实践中包括：长期赌博挥霍家庭财产、吸毒、刑事犯罪等 | 证据视具体情形而定 | 视情形 |

**损害赔偿的范围与数额**：

- 损害赔偿包括**物质损害赔偿**（财产损失）和**精神损害抚慰金**
- 精神损害抚慰金数额由法院酌定，无明确计算公式
- 实践中数额差异较大，受地方法院裁判口径影响  `[地方 flagged — 需核实地方裁判口径]`

**损害赔偿与照顾原则的关系（再强调）**：两个请求权独立，可并行主张；照顾原则影响共同财产比例，损害赔偿是独立赔偿金。

**损害赔偿的程序要点**：

- 提起时机：（1）提起离婚诉讼时一并主张；（2）离婚后在一定期限内单独主张（具体期限须核实 `[待验证]`）
- 诉讼形式：通常附随离婚诉讼提起，也可单独起诉
- 举证责任：无过错方须举证证明过错情形存在

**家暴情形的完整救济路径（强制升级后律师处理）**：

| 路径 | 内容 | 注意事项 |
|-----|------|---------|
| 人身安全保护令 | 向法院申请禁止被申请人实施家暴（反家庭暴力法，具体程序 `[待验证]`） | 紧急情况下优先申请；须提供家暴证据 |
| 离婚损害赔偿 | 第1091条第三项，家暴是法定请求权基础 | 须与离婚诉讼同时提起或离婚后一定期限内主张 |
| 刑事追责 | 家暴致人重伤/死亡构成故意伤害罪/故意杀人罪；持续性虐待可能构成虐待罪 | 须刑事律师介入 |

## 详细步骤

### 一、隐匿转移财产的情形识别

**第1092条规定的五种不法行为**（建议复核）：

| 行为类型 | 常见手段 | 典型识别信号 |
|---------|---------|-----------|
| **隐藏** | 隐瞒财产存在（不申报存款账户/股权/贵重物品）；将财产转移至父母兄弟名下但实际控制 | 申报财产明显少于已知生活水平；工商查询显示隐性股权；社交媒体显示高消费但申报收入低 |
| **转移** | 将共同财产赠与或低价转让给第三人（父母/情人/朋友）；资金大额转出无说明；不动产无对价转让 | 离婚前夕大额转账给亲属；不动产突然过户；银行流水有大额出金无说明 |
| **变卖** | 低价处置共同财产（不动产/车辆/贵重物品）并截留价款 | 财产明显低价处置（明显低于市价）；短期内多项资产「消失」 |
| **毁损** | 故意损毁共同财产（车辆/贵重物品/生产设备） | 财产在离婚期间突然毁损/报废 |
| **挥霍** | 将共同财产用于赌博/吸毒/包养情人等挥霍行为 | 银行流水显示大额现金支取/博彩/娱乐；资产快速减少 |
| **伪造共同债务** | 伪造借条/虚构债务与亲属勾结（「夫妻共同债务」名义） | 离婚前突然出现大额债务；债主为亲友；无正当用途说明 |

**识别信号汇总表**：

| 信号类别 | 具体信号 | 紧急程度 |
|---------|---------|---------|
| 财产账目异常 | 银行流水有无法解释的大额转出/现金支取；账户余额与收入明显不符 | 🔴 高 |
| 资产快速消失 | 已知的房产/车辆/股权在离婚前夕突然「不见了」 | 🔴 高 |
| 关联方交易 | 大量资金流向亲属/朋友；资产以明显低价转让给熟人 | 🔴 高 |
| 突然新增债务 | 离婚前夕突然出现大额借款/债务，债主为亲友 | 🔴 高 |
| 工商信息变化 | 工商登记显示隐性股权/公司；或股权在离婚前被转走 | 🟠 较高 |
| 申报财产与生活水平明显不符 | 申报财产偏少但实际有明显高消费迹象 | 🟠 较高 |
| 涉赌博/吸毒/包养 | 银行流水有大额博彩/娱乐支出 | 🟠 较高 |

### 二、举证策略

**举证原则**：主张隐匿转移一方（通常为受损方）承担举证责任，但司法解释中有举证责任减轻规则（描述规则，`[待验证]`）——对方隐匿财产的证据明显难以获取时，法院可要求对方说明。

**举证路径**：

| 证据来源 | 可获取信息 | 获取方式 |
|---------|---------|---------|
| **银行流水** | 全部账户交易记录、大额出账方向、现金支取记录 | 申请法院调查令或当事人自行申请（部分银行支持），律师协助申请更有效 |
| **工商登记信息** | 对方名下公司/股权/任职情况（含隐性股权） | 通过国家企业信用信息公示系统查询；如信息不全，申请调查令 |
| **不动产登记信息** | 对方名下房产情况（含可能的低价转让/抵押记录） | 通过当地不动产登记中心查询；离婚诉讼立案后可申请法院调查 |
| **税务记录** | 对方收入（工资/经营收入/股权转让）缴税情况 | 法院调查令（需立案后） |
| **车辆登记** | 对方名下车辆及转让情况 | 公安交管信息查询；律师调查令 |
| **社保缴纳记录** | 对方真实收入水平 | 本人申请或律师调查令 |
| **第三方证人** | 亲属/朋友关于财产处置的知情证言 | 当事人收集；公证录音/录像（须合法取证） |
| **社交媒体/消费记录** | 高消费证据（奢侈品/出行/娱乐）与申报不符 | 截图保存；注意取证合法性 |

**调查令申请**：

离婚诉讼立案后，当事人可申请法院向金融机构/工商部门/不动产登记机构等发出调查令，获取对方财产信息。调查令是应对财产隐匿的重要工具，建议尽早申请。

**紧急举证措施**：在提起诉讼前，对已发现的可疑处置行为及时保全证据（截图/公证/拍照），避免证据灭失。

### 三、少分或不分救济（第1092条前半段，建议复核）

**规则**：一方隐藏、转移、变卖、毁损、挥霍夫妻共同财产，或伪造夫妻共同债务企图侵占另一方财产的，在离婚分割夫妻共同财产时，对该方可以少分或者不分。

**救济路径**：

| 路径 | 说明 | 适用条件 |
|-----|------|---------|
| **少分** | 降低过错方在共同财产中的分割比例（如30%而非50%）| 已有证据证明不法行为，但程度较轻 |
| **不分** | 过错方在某项财产上不获分配 | 不法行为严重，证据确凿 |
| **恢复价值折算** | 对已变卖/毁损的财产，按市场价格计算后在其他财产中扣除 | 财产已被处置无法恢复 |
| **伪造债务不认定** | 伪造的夫妻共同债务不予认定为共同债务 | 有证据证明债务系伪造 |

**证明标准**：少分不分须达到证明隐匿转移行为存在的标准；法院综合证据认定。

### 四、离婚后再次分割（第1092条后半段，描述规则）

最高法婚姻家庭编相关规则（描述规则，条号 `[待验证]`）：

> 离婚后，另一方发现有隐藏、转移、变卖、毁损、挥霍共同财产或伪造共同债务的行为的，可以向人民法院提起诉讼，请求再次分割夫妻共同财产。

**再次分割的重要注意事项**：

| 事项 | 说明 |
|-----|------|
| **诉讼时效** | 具体诉讼时效期限须核实（一般民事诉讼时效为3年，自知道或应当知道权利受损之日起算；但具体适用须核实 `[待验证]`） |
| **举证重点** | 须证明：（1）有隐匿转移不法行为；（2）该行为在离婚时未被发现/未被处理；（3）损失数额 |
| **适用范围** | 仅适用于不法行为（第1092条规定的情形）；不适用于正当财产处置 |
| **程序** | 重新起诉，属独立诉讼；非申请执行已生效判决 |

**协议离婚后再次分割**：

协议离婚后发现对方隐匿财产，同样可以依据第1092条主张再次分割，不因协议离婚程序的完成而丧失权利。

### 五、诉前/诉中财产保全

**财产保全的重要性**：财产保全是防止对方在诉讼期间继续转移财产、保障判决可执行性的关键措施。

**保全类型**：

| 类型 | 适用时机 | 主要条件 |
|-----|---------|---------|
| **诉前财产保全** | 尚未提起诉讼，但紧急情况下需保全 | 须缴纳担保金（一般为保全金额的一定比例）；须在保全后30日内提起诉讼 `[待验证]` |
| **诉中财产保全** | 离婚诉讼立案后提出 | 相对较易，可随时申请；提供担保后法院较快裁定 |
| **行为保全** | 需要禁止特定行为（如禁止转让不动产） | 须证明行为会造成难以弥补的损害 |

**保全对象**：

| 财产类型 | 保全方式 |
|---------|---------|
| 银行存款 | 冻结账户（法院向银行发出冻结令） |
| 不动产 | 查封/限制处分登记（法院向不动产登记机构发出协助执行通知） |
| 股权 | 冻结股权/禁止转让（法院向工商登记机构发出协助执行通知） |
| 车辆 | 扣押或限制转让（通过公安交管配合） |
| 到期债权 | 由法院通知第三方（借款人/承租人）向法院支付 |

**保全申请要点**：

1. 提交申请书（说明被保全财产、保全理由、担保安排）
2. 提供担保（现金/担保公司保函）
3. 法院裁定后立即执行（紧急情况下48小时内）`[待验证]`

## 边界条件

| 情形 | 处理方式 |
|-----|---------|
| **正常生活消费与挥霍的界限** | 正常合理的日常消费（餐饮/衣物/旅游）不构成挥霍；须证明支出明显超出正常生活水平或用于不正当目的 |
| **再次分割的诉讼时效** | 具体期限须核实（民事诉讼时效一般3年，从知道或应当知道权利受损之日起算，具体适用须核实）`[待验证]` |
| **虚构债务的认定** | 须区分真实债务与虚构债务；有借条但无资金流向的债务存疑；债主为亲属且无合理说明的存疑 |
| **善意第三人受让** | 对方转让给不知情第三人的财产，第三人受保护（物权法规则）；受损方只能主张转让价款的分配 |
| **保全损失赔偿** | 申请保全错误（对方财产系正当处置）须赔偿对方保全期间损失；申请前须充分评估证据强度 |
| **境外财产取证** | 境外银行账户/资产调查路径特殊，须借助司法协助或境外律师，时间成本高 `[待验证]` |

## 错误处理

| 错误/敏感情形 | 识别信号 | 处理方式 |
|------------|---------|---------|
| **财产隐匿与家暴同时存在** | 当事人描述在胁迫下不敢调查财产；财产信息完全被对方控制 | 🔴 **强制升级**——优先人身安全；家暴情形须律师主导，财产保全路径在安全环境下推进 |
| **虚构债务涉嫌刑事** | 伪造证据（假借条/虚假公证）；涉嫌诈骗/合同诈骗 | 🔴 **强制升级刑事律师**；保全证据避免灭失 |
| **当事人情绪危机** | 因财产损失导致极度绝望/危机信号 | **暂停分析**——提示心理援助；标注 `[暂停 — 情绪危机]` |
| **紧急转移进行中** | 对方正在过户/大额转账中 | 🔴 **立即申请诉前财产保全**——须律师主导，最快48小时内申请 |
| **举证严重不足** | 仅有怀疑无任何证据 | 告知举证责任风险；规划调查令申请计划；不基于无证据主张出具风险报告 |
