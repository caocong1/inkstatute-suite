### 当事人情绪护栏（丧亲）

婚姻家事继承案件中，当事人处于丧亲悲痛中是普遍情形。全程须：

- **中立、克制**：不在分析中激化继承人之间的对立情绪
- **非煽动**：不替当事人作情绪化判断，不使用加剧冲突的语言

- **尊重丧失**：在涉及被继承人时，以尊重的措辞呈现

## 详细步骤

### 步骤一：遗产范围正向认定

#### 1.1 遗产的基本定义（民法典第1122条，建议复核）

> **遗产是自然人死亡时遗留的个人合法财产。**
> 依照法律规定或者根据其性质不得继承的财产，不得作为遗产。

核心判断要素：

| 要素 | 说明 |
|------|------|
| **「自然人死亡时」** | 继承开始时间点（自然死亡或宣告死亡的特定时间）——此后新增的财产不属于遗产 |
| **「个人合法财产」** | 须属于被继承人个人所有（夫妻共同财产须先析产），且合法取得 |
| **「不得继承的财产」** | 专属人身性权利（如肖像权本身）、法律规定不得转让的权利，不得作为遗产 |

#### 1.2 属于遗产的财产范围

| 财产类型 | 说明 | 注意事项 |
|---------|------|---------|
| **不动产（房产/土地使用权）** | 登记在被继承人名下的个人份额（若为共同共有须析产） | 析产后被继承人个人部分方为遗产 |
| **银行存款/现金** | 被继承人名下个人账户余额 | 共同账户须析产；大额存款来源须核实合法性 |
| **车辆/动产** | 登记或实际属于被继承人的动产 | |
| **股权/公司份额** | 被继承人持有的有限公司股权、合伙份额（转让限制须审查） | 股权继承须核查公司章程和合伙协议的限制 |
| **股票/基金/证券投资** | 被继承人证券账户内的金融资产 | |
| **债权/借款债权** | 被继承人对他人的借款、合同债权 | 须有证明文件（借条/合同） |
| **知识产权中的财产性权利** | 著作权中的财产权（使用权/收益权）、专利权的财产权、商标权 | **知识产权中的人身权（署名权）不属于遗产**；财产权可继承 |
| **已获赔偿但未实际支付的债权** | 如人身损害赔偿判决已生效但未实际收到的款项 | 赔偿金以被继承人为权利人的部分属遗产 |
| **经营资产** | 个体工商户的营业资产、农村承包经营权中的财产性利益 | |

#### 1.3 继承开始前须清缴税款和债务

注意：遗产分配前须**先清偿**被继承人依法应缴纳的税款和债务（见步骤三），剩余部分才是可分配遗产。

---

### 步骤二：遗产范围反向排除（不属于遗产的财产）

以下财产**不属于遗产**，须从遗产清单中排除：

| 财产类型 | 不属于遗产的理由 | 归属 |
|---------|--------------|------|
| **夫妻共同财产中属配偶的一半** | 须先析产，配偶应得份额不属于遗产 | 归配偶所有 |
| **其他共有财产中属共有人的份额** | 如合伙财产中他人份额 | 归其他共有人 |
| **指定受益人的人身保险金** | 有指定受益人时，保险金直接归受益人，不进入遗产 | 归指定受益人 |
| **依法不得转让的权利** | 如劳动报酬请求权（部分）、人身损害赔偿中的精神损害抚慰金（专属性）——存在争议 | 归权利主体本人 |
| **养老金/工龄补偿等个人权利** | 依社会保障法规定属于个人专属权益的部分（描述规则，`[待验证]`） | 依法处理 |
| **知识产权中的人身权利** | 著作权中的署名权、发表权（一定程度上可由继承人保护但本身不属遗产） | 特殊法律保护 |
| **特定用途的赔偿金** | 如残疾赔偿金、医疗费赔偿（专属人身补偿，归权利人本身，不属遗产——存在争议，`[待验证]`） | 个案处理 |

---

### 步骤三：夫妻共同财产先析产后继承

#### 3.1 析产原则

被继承人死亡时若处于婚姻关系存续状态（或存在未完成析产的财产），须按以下步骤处理：

```
被继承人死亡时全部财产
    ↓
Step 1: 识别夫妻共同财产范围（第1062条，建议复核）
    ↓
Step 2: 配偶析出一半夫妻共同财产（归配偶个人所有）
    ↓
Step 3: 其余夫妻共同财产的另一半 + 被继承人个人财产 = 被继承人遗产
    ↓
Step 4: 遗产先清偿税款和债务（第1161条）
    ↓
Step 5: 剩余遗产按遗嘱/法定继承分配
```

#### 3.2 夫妻共同财产范围确认

| 财产类型 | 共同财产认定（第1062条，建议复核） | 个人财产认定（第1063条，建议复核） |
|---------|--------------------------------|--------------------------------|
| 婚后工资收入 | ✅ 共同财产 | — |
| 婚后生产经营投资收益 | ✅ 共同财产 | — |
| 婚后知识产权收益 | ✅ 共同财产（收益部分） | — |
| 婚后继承赠与所得 | ✅ 共同财产（除非明确归一方） | ❌ 若遗嘱/赠与合同明确归一方则为个人 |
| 婚前个人财产 | — | ✅ 个人财产 |
| 婚后婚前财产的自然增值 | 描述规则，`[待验证]` | 一般倾向个人（自然增值，`[待验证]`） |
| 人身损害赔偿 | — | ✅ 个人财产 |
| 一方专用生活用品 | — | ✅ 个人财产 |

#### 3.3 析产实操注意事项

| 情形 | 处理说明 |
|------|---------|
| 房产等不动产登记为夫妻一方名下 | 不影响夫妻共同财产的认定；须审查购买时间和资金来源 |
| 约定财产制（第1065条，建议复核） | 若有书面约定财产制，按约定析产 |
| 析产争议 | 继承人与配偶对析产比例有争议，须通过诉讼解决；AI工具提示析产必要性，不独立计算 |

### 步骤四：遗产债务清偿

#### 4.1 限额清偿原则（民法典第1161条，建议复核）

> **继承人以所得遗产实际价值为限清偿被继承人依法应当缴纳的税款和债务。超过遗产实际价值部分，继承人自愿偿还的不在此限。放弃继承的，对被继承人依法应当缴纳的税款和债务可以不负清偿责任。**

核心规则：

| 规则要点 | 说明 |
|---------|------|
| **限额清偿** | 继承人的清偿义务上限 = 所得遗产实际价值（不超过、不承担超额部分） |
| **自愿超额偿还** | 继承人可自愿超额清偿，但法律不强制 |
| **放弃继承免债** | 放弃继承的，不负清偿责任（一般不能选择性继承财产、拒绝债务） |
| **不得以放弃逃债** | 虚假放弃继承逃避债务，债权人可主张撤销（描述规则，`[待验证]`） |

#### 4.2 遗产债务清偿顺序

依据司法解释（描述规则，条号 `[待验证]`）和民法典继承编规则，遗产债务清偿顺序为：

| 清偿顺序 | 内容 | 说明 |
|---------|------|------|
| 1 | 先析产（配偶析出应得份额） | 析产后方确定遗产范围 |
| 2 | 清偿被继承人应缴税款 | 税款优先（第1161条，建议复核） |
| 3 | 清偿被继承人债务 | 在遗产价值范围内按比例清偿（遗产不足则按比例） |
| 4 | 清偿遗赠扶养协议（优先于遗嘱/法定继承的受益） | 遗赠扶养协议的受益人优先 |
| 5 | 按遗嘱/法定继承分配剩余遗产 | 剩余遗产分配给遗嘱指定人或法定继承人 |

**遗产不足以清偿全部债务**：按比例清偿（同等顺序债务按各债权比例清偿）——描述规则，具体规则 `[待验证]`。

#### 4.3 继承人份额与债务分担

| 情形 | 处理方式 |
|------|---------|
| 多个继承人 | 各继承人在各自继承的遗产份额范围内清偿（限额为各自实际所得份额价值） |
| 继承人分割遗产后清偿债务 | 债权人可对各继承人主张在其所得份额内清偿 |
| 继承人代为偿还超额部分 | 须向其他继承人追偿（内部分担） |

---

### 步骤五：放弃继承与债务清偿

#### 5.1 放弃继承的法律效果

| 方面 | 放弃继承的影响 |
|------|--------------|
| 遗产继承 | 完全不继承，视为自始未参与继承 |
| 债务清偿 | 对被继承人的税款和债务**可以不负清偿责任**（第1161条，建议复核） |
| 放弃声明要求 | 须书面声明，须在遗产分割前作出（描述规则，具体要求 `[待验证]`） |

#### 5.2 虚假放弃继承逃债的处理

债权人利益保护：

- 若继承人以虚假放弃继承的方式逃避清偿被继承人债务，债权人可主张该放弃行为无效（撤销权）——描述规则，具体规则 `[待验证]`
- 法院可能认定放弃无效，要求继承人在实际所得份额内清偿
- 代理债权人时须核查继承人是否有放弃动机与财产保全的必要性

---

### 步骤六：无人继承遗产归属（民法典第1160条，建议复核）

当无人继承又无人受遗赠时：

| 被继承人身份 | 遗产归属 |
|------------|---------|
| 一般公民 | 归国家所有，用于公益事业 |
| 集体所有制组织成员 | 归所在集体所有制组织所有 |

**触发条件**：
- 无法定继承人（或全部丧失继承权/全部放弃继承）
- 无有效受遗赠人（受遗赠人放弃/先死亡）
- 无有效遗赠扶养协议

## 错误处理

| 错误情形 | 处理方式 |
|---------|---------|
| 财产清单不完整（被继承人有隐藏财产） | 提示调查路径（不动产查询/股权工商查询/银行账户查询）；代理继承人时提示向法院申请调查令 |
| 夫妻共同财产析产争议 | 提示该争议须通过析产诉讼或协商解决；AI工具不独立计算存在争议的析产比例，标注 🟠 高风险 |
| 遗产债务真实性存疑（如被继承人死后出现大额债权人） | 提示债权人须提供证明文件；标注 🟠 高风险，建议核实债务真实性再清偿 |

| 股权价值无法确定 | 提示需要专业评估机构出具评估报告；以市场公允价值为准 |
| 丧亲情绪危机 | 中立克制措辞，提示专业支持，暂缓财产争议分析 |

## 目的

审查遗嘱继承的效力，确定被继承人遗产应按遗嘱继承还是法定继承（或两者结合）处理。覆盖以下核心分析：

1. 遗嘱继承与法定继承的优先顺位确认

4. 遗赠与遗赠扶养协议优先顺位
5. 遗嘱部分无效的处理
6. 按代理立场区分举证策略

## 详细步骤

### 步骤一：继承顺位体系确认

#### 1.1 四层继承/受益优先顺位

在遗产分配前，须先确认以下四层优先顺位（从高到低）：

| 优先层级 | 内容 | 法律依据 |
|---------|------|---------|
| **第一层：遗赠扶养协议** | 扶养人依协议受遗赠，优先于遗嘱和法定继承 | 第1158条（建议复核） |
| **第二层：遗嘱继承/遗赠** | 有效遗嘱指定继承人继承；遗赠给非法定继承人 | 遗嘱优先原则 |
| **第三层：法定继承** | 无有效遗嘱，或遗嘱未涵盖的遗产 | 第1127条（建议复核） |
| **（先于所有层级）** | 清偿被继承人税款和债务（以遗产实际价值为限） | 第1161条（建议复核） |

**关键要点**：

- 遗嘱继承**优先于**法定继承——被继承人生前立有有效遗嘱的，按遗嘱分配遗嘱涵盖的遗产
- 遗嘱未覆盖的遗产（如遗嘱成立后新取得的财产、遗嘱内容无效部分）才适用法定继承
- 遗赠扶养协议效力**高于**遗嘱，须先处理遗赠扶养协议部分

#### 1.2 遗赠扶养协议核查

**什么是遗赠扶养协议**（民法典第1158条，已核实锚点，建议复核）：

自然人与继承人以外的组织或个人签订协议，由扶养方承担受扶养人的生养死葬义务，受扶养人将其遗产遗赠给扶养方。

核查要点：

| 要点 | 说明 |
|------|------|
| 协议主体 | 扶养方须为「继承人以外」的组织或个人（不能是法定继承人） |
| 义务履行 | 扶养方须实际履行生养死葬义务；未履行或部分履行的，可能影响受遗赠权利 |
| 效力优先 | 遗赠扶养协议部分须先从遗产中扣除，剩余部分再按遗嘱/法定继承处理 |
| 与遗嘱并存 | 遗嘱人同时存在遗嘱和遗赠扶养协议时，协议优先；遗嘱不得处分协议已覆盖的遗赠部分 |

**受遗赠人的接受时限**（描述规则，期限条号 `[待验证]`）：受遗赠人须在知道受遗赠后的法定期限内作出接受表示，逾期未表示的，视为放弃受遗赠。具体期限须核实民法典或司法解释现行规定 `[待验证]`。

### 步骤二：遗嘱有效要件审查

#### 2.1 遗嘱有效要件体系

有效遗嘱须同时满足：

| 要件类别 | 具体内容 | 对应子技能 |
|---------|---------|---------|
| 形式合法 | 六种法定形式之一，形式要件完整（签名/日期/见证人等） | `will-drafting` 主技能及 `will-form-selection`/`witnessing-effectiveness` 子技能（详见） |
| 能力适格 | 立遗嘱时须为完全民事行为能力人 | `testamentary-capacity-intent` 子技能（详见） |
| 意思真实 | 遗嘱须表示遗嘱人真实意思，受欺诈胁迫无效 | 第1143条（建议复核） |
| 内容合法 | 不违反法律强制性规定；须为必留份继承人保留必要份额 | `content-reserved-share` 子技能（详见） |

> 本技能对形式要件、能力与意思表示进行**概括性审查和效力认定**；详细要件核查请调用对应 `will-drafting` 子技能。

#### 2.2 遗嘱无效情形（第1143条，建议复核）

依据民法典第1143条（中度把握，建议复核）：

| 无效情形 | 说明 | 法律后果 |
|---------|------|---------|
| 无民事行为能力人所立 | 如精神障碍、认知症患者等 | 遗嘱全部无效 |
| 限制民事行为能力人所立 | 如8-18周岁未成年人 | 遗嘱全部无效 |
| 受欺诈所立 | 遗嘱人被他人虚假陈述所诱导 | 受欺诈所立的遗嘱无效 |
| 受胁迫所立 | 遗嘱人被威胁强迫 | 受胁迫所立的遗嘱无效 |
| 伪造的遗嘱 | 遗嘱并非遗嘱人所立，而是他人伪造 | 伪造的遗嘱无效 |
| 遗嘱被篡改 | 遗嘱内容被他人擅自修改 | 篡改的**内容**无效（其余内容可能仍有效） |

**部分无效的处理**：
- 遗嘱部分无效（如遗嘱被篡改，仅篡改内容无效）：有效部分按遗嘱执行，无效部分依法定继承
- 遗嘱超出遗嘱人个人财产范围（如处分夫妻共同财产的全部）：析产后超出个人份额的部分无效

### 步骤三：数份遗嘱冲突处理

#### 3.1 「最后遗嘱为准」规则（民法典重大修订）

**民法典第1142条**（中度把握，建议复核）：

立有数份遗嘱，内容相抵触的，**以最后的遗嘱为准**。

**关键修订说明**：

民法典取消了原继承法下「公证遗嘱效力优先」的规则。原继承法规定，公证遗嘱效力高于其他形式遗嘱。民法典施行后（2021年1月1日起），**公证遗嘱不再具有优先效力**，所有形式的遗嘱一律按立遗嘱时间排序，以**最后订立的**遗嘱为准，无论其形式是否为公证遗嘱。

| 规则对比 | 原继承法 | 民法典（2021年起） |
|---------|---------|-----------------|
| 数份遗嘱冲突 | 公证遗嘱优先，无公证遗嘱时以最后为准 | **一律以最后订立的遗嘱为准，无论形式** |
| 公证遗嘱地位 | 优先于其他形式遗嘱 | **与其他形式遗嘱效力相同** |

**适用时间节点**：该修订自2021年1月1日起适用。2021年1月1日前已立的遗嘱，其效力认定应适用2021年1月1日起施行的民法典规定（存在过渡期争议，描述规则，条号 `[待验证]`）。

#### 3.2 数份遗嘱顺位判定流程

```
识别全部遗嘱
    ↓
逐份审查每份遗嘱的有效性（形式+实质）
    ↓
剔除无效遗嘱
    ↓
对有效遗嘱按立遗嘱时间排序
    ↓
识别内容相抵触的条款
    ↓
以最后订立的遗嘱中的内容为准
（最后遗嘱未覆盖的财产，由更早遗嘱或法定继承处理）
```

**时间确认要点**：

| 遗嘱形式 | 时间确认方式 |
|---------|------------|
| 自书遗嘱 | 遗嘱人亲笔注明的年月日 |
| 代书遗嘱 | 遗嘱人与见证人签名注明的年月日 |
| 打印遗嘱 | 每一页上遗嘱人与见证人签名注明的年月日 |
| 录音录像遗嘱 | 录音录像中记录的年月日 |
| 口头遗嘱 | 见证人记录的年月日（危急情况消除后即失效） |
| 公证遗嘱 | 公证机构办理公证的日期 |

### 步骤四：遗嘱内容与法定继承的衔接

#### 4.1 遗嘱未覆盖遗产的处理

| 情形 | 处理方式 |
|------|---------|
| 遗嘱成立后新取得的财产 | 遗嘱未提及的，按法定继承处理 |
| 遗嘱处分他人财产（无权处分部分） | 无权处分部分无效，该部分按法定继承 |
| 遗嘱继承人先于遗嘱人死亡 | 该部分遗嘱失效，归法定继承（代位继承规则不适用于遗嘱继承——描述规则，具体规则 `[待验证]`） |
| 遗嘱继承人放弃继承 | 放弃部分归法定继承 |

#### 4.2 遗赠的特殊规则

**遗赠**（给法定继承人以外的人或组织）：

| 规则 | 说明 |
|------|------|
| 受遗赠人身份 | 须为法定继承人以外的个人或组织 |
| 接受表示时限 | 须在知道受遗赠后的法定期限内明示接受，否则视为放弃（期限条号 `[待验证]`） |
| 受遗赠人先死亡 | 受遗赠人先于遗嘱人死亡的，遗赠失效，该部分归法定继承 |

**第1142条 — 遗嘱撤回变更与数份遗嘱最后为准**
- 《中华人民共和国民法典》**第1142条** `[模型知识 — 需验证]` 中度把握，建议复核
- 遗嘱人可撤回、变更自己所立的遗嘱；立有数份遗嘱内容相抵触的，以最后的遗嘱为准
- **公证遗嘱不再具有优先效力**（与原继承法相比的重大修订）

**第1143条 — 遗嘱无效情形**
- 《中华人民共和国民法典》**第1143条** `[模型知识 — 需验证]` 中度把握，建议复核
- 无行为能力人或限制行为能力人所立遗嘱无效；受欺诈胁迫所立遗嘱无效；伪造的遗嘱无效；被篡改的内容无效

**第1158条 — 遗赠扶养协议优先**
- 《中华人民共和国民法典》**第1158条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 遗赠扶养协议效力优先于遗嘱和法定继承

**第1141条 — 必留份**
- 《中华人民共和国民法典》**第1141条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 遗嘱须为缺乏劳动能力又无生活来源的继承人保留必要遗产份额

**第1125条 — 丧失继承权（含遗嘱相关情形）**
- 《中华人民共和国民法典》**第1125条** `[模型知识 — 需验证]` 中度把握，建议复核

## 目的

在无有效遗嘱（或遗嘱无效、仅部分有效）时，依法确定法定继承人资格与继承顺序，计算各继承人应继份额，识别酌情多分或少分情形，判断丧偶儿媳女婿的第一顺序继承地位，并按代理立场调整份额主张侧重。

本技能覆盖以下核心分析：

1. 法定继承启动条件确认（无遗嘱 / 遗嘱无效 / 部分法定继承）
2. 第一顺序继承人范围核查（配偶、子女、父母的扩大定义）
3. 第二顺序继承人范围核查（仅第一顺序无人继承时启用）
4. 同顺序继承份额计算（一般均等原则 + 三类酌情情形）
5. 丧偶儿媳/女婿的第一顺序继承地位判定
6. 按代理立场区分份额主张侧重

## 详细步骤

### 步骤一：法定继承启动条件确认

#### 1.1 法定继承的适用场景

| 场景 | 说明 | 分析路径 |
|------|------|---------|
| 无遗嘱 | 被继承人未立遗嘱，全部遗产依法定继承分配 | 直接进行法定继承顺序与份额分析 |
| 遗嘱全部无效 | 遗嘱因形式或实质要件瑕疵全部无效 | 视同无遗嘱，全部法定继承 |
| 遗嘱部分无效 | 遗嘱部分有效，无效部分按法定继承分配 | 先确认遗嘱有效范围（调用 `testate-succession-validity`），再对无效部分法定继承 |
| 遗嘱继承人放弃继承 | 遗嘱指定继承人放弃，该部分按法定继承处理 | 确认放弃声明的效力，余额法定继承 |
| 无人受遗赠 | 受遗赠人放弃或先于遗嘱人死亡，遗赠财产归法定继承 | 遗赠部分按法定继承分配 |

**关键判断**：确认是否存在**遗赠扶养协议**（民法典第1158条，建议复核）。遗赠扶养协议效力优先于遗嘱和法定继承，须先扣除遗赠扶养协议部分，剩余遗产再按法定继承处理。

#### 1.2 先析产后继承原则

在进行法定继承前，须先完成遗产析产：

1. 被继承人遗产中若含夫妻共同财产，先分出配偶应得的一半
2. 被继承人遗产中若含其他共有财产（如与他人合伙财产），先完成析产
3. 析产后属于被继承人的个人部分才是法定继承的遗产

> **析产步骤**：具体遗产范围认定与析产计算见 `estate-scope-debt` 子技能。本技能以析产完成后的遗产为基础进行继承顺序与份额分析。

---

### 步骤二：第一顺序继承人核查

#### 2.1 第一顺序继承人范围

依据民法典第1127条（已核实锚点，中度把握，建议复核），第一顺序继承人包括：

**配偶**（须满足以下条件之一）：

| 资格条件 | 说明 |
|---------|------|
| 合法婚姻存续 | 被继承人死亡时，双方处于有效婚姻关系中（已登记结婚，未协议离婚/未诉讼离婚判决生效） |
| 注意：无效婚姻/可撤销婚姻 | 若婚姻被认定为无效或已被撤销，配偶继承资格丧失——须核实婚姻效力 |
| 注意：事实婚姻 | 1994年2月1日前已符合婚姻实质要件的事实婚姻，可能具有继承资格（描述规则，条号 `[待验证]`） |

**子女**（包含以下类型，均具有平等继承权）：

| 类型 | 说明 | 注意事项 |
|------|------|---------|
| 婚生子女 | 父母婚内所生 | 无特殊要求 |
| 非婚生子女 | 父母未婚所生 | 与婚生子女继承权平等，须证明亲子关系 |
| 养子女 | 依法形成收养关系的子女 | 须有合法收养手续（民政登记或法院认定） |
| 有扶养关系的继子女 | 继父母与继子女之间形成了事实扶养关系 | **须证明扶养关系**；无扶养关系的继子女不继承继父母遗产（反之亦然） |

**父母**（包含以下类型）：

| 类型 | 说明 | 注意事项 |
|------|------|---------|
| 生父母 | 亲生父母（含离婚后的父母） | 离婚不影响对子女的继承权 |
| 养父母 | 依法形成收养关系的父母 | 须有合法收养手续 |
| 有扶养关系的继父母 | 继父或继母与被继承人之间形成了事实扶养关系 | **须证明扶养关系**；无扶养关系的继父母不具备继承资格 |

> **继承资格核查清单（第一顺序）**：
>
> - [ ] 配偶：婚姻状态确认（死亡证明日期 vs 离婚证/判决书生效日期）
> - [ ] 子女：亲子关系证明（户口本/出生证明/亲子鉴定/收养手续）
> - [ ] 父母：扶养关系确认（养父母/继父母须证明扶养关系）
> - [ ] 各继承人是否存在丧失继承权情形（第1125条，建议复核，见步骤五）
> - [ ] 各继承人是否已放弃继承（须书面声明，并在遗产分割前作出）

#### 2.2 丧偶儿媳/女婿的第一顺序继承地位

依据民法典第1129条（中度把握，建议复核）：

**适用条件**：

| 条件 | 具体要求 |
|------|---------|
| 身份要求 | 丧偶儿媳（丈夫已死亡）或丧偶女婿（妻子已死亡） |
| 亲属关系 | 丧偶儿媳对公婆尽了主要赡养义务；丧偶女婿对岳父母尽了主要赡养义务 |
| 「主要赡养义务」 | 须由法院综合认定（无明确条件定义，通常考量：共同居住时间、实际照料程度、经济支持情况） |

**证明材料建议**：

- 共同居住证明（户籍同址、物业记录、邻居证言）
- 经济支持记录（生活费转账记录、购物票据）
- 医疗照料证明（医院陪护记录、护工证言）
- 其他家庭成员证言（兄弟姐妹对赡养贡献的认可声明）

**代理侧重**：
- 代理丧偶儿媳/女婿：收集上述证明，主张第一顺序地位
- 代理其他第一顺序继承人抗辩：质疑「主要」赡养义务认定，举反证（其他继承人实际尽了更多义务）

---

### 步骤三：第二顺序继承人核查

#### 3.1 第二顺序继承人范围

依据民法典第1127条（已核实锚点，中度把握，建议复核），第二顺序继承人包括：

| 类型 | 扩大定义 |
|------|---------|
| 兄弟姐妹 | 包括同父母的兄弟姐妹、同父异母或同母异父的兄弟姐妹、养兄弟姐妹、有扶养关系的继兄弟姐妹 |
| 祖父母 | 父方祖父母 |
| 外祖父母 | 母方外祖父母 |

**第二顺序启动条件**：

第二顺序继承人仅在**无第一顺序继承人**时继承。具体情形包括：

- 第一顺序继承人全部先于被继承人死亡（且无代位继承人）
- 第一顺序继承人全部丧失继承权（第1125条）
- 第一顺序继承人全部放弃继承（须书面声明）
- 被继承人无配偶、无子女、无父母（含养父母、有扶养关系继父母）

> **注意**：只要有**任何一名**有效的第一顺序继承人，第二顺序继承人即不继承。

---

### 步骤四：同顺序继承份额计算

#### 4.1 一般均等原则

依据民法典第1130条（中度把握，建议复核）：

同一顺序继承人继承遗产的份额，**一般应当均等**。

**示例**：被继承人死亡，遗产（析产后）为 120 万元，无有效遗嘱。第一顺序继承人：配偶甲、子女乙、父母丙丁，共 4 人。一般均等份额：每人 30 万元。

#### 4.2 酌情照顾多分情形

| 情形 | 法律依据 | 说明 | 举证方向 |
|------|---------|------|---------|
| 对生活有特殊困难且缺乏劳动能力的继承人 | 第1130条（建议复核） | **须同时满足**「特殊困难」和「缺乏劳动能力」两个条件；「应当予以照顾」为强制性规定 | 残疾证明、无业证明、生活困难陈述、医疗诊断书 |
| 对被继承人尽了主要扶养义务或与被继承人共同生活 | 第1130条（建议复核） | 「可以多分」为授权性规定（非强制，由继承人协商或法院裁量）；须证明「主要」扶养义务 | 共同居住证明、赡养费记录、照料证明 |

> **重要区分**：
> - 「缺乏劳动能力又有特殊困难」的照顾是**强制性**的（「应当」）
> - 「尽主要扶养义务」的多分是**授权性**的（「可以」）——可由继承人协商，协商不成由法院酌情判决

#### 4.3 酌情不分或少分情形

| 情形 | 法律依据 | 说明 |
|------|---------|------|
| 有扶养能力和有扶养条件但不尽扶养义务 | 第1130条（建议复核） | 「应当不分或者少分」为强制性规定；须同时满足「有能力」「有条件」「不尽义务」三要素 |

**认定说明**：
- 「有扶养能力」：有经济来源、劳动能力
- 「有扶养条件」：居住距离合理、无客观障碍
- 「不尽扶养义务」：长期不探视、不提供生活费、不协助医疗照料等

**代理侧重**：
- 代理尽了主要义务一方：收集多分证据，主张多分情形
- 代理被主张不尽义务一方：举反证（如客观原因导致无法尽义务、实际已尽部分义务）

#### 4.4 继承人协商一致的不均等分配

依据第1130条（建议复核），继承人协商同意的，也可以不均等分配。协商结果须在遗产分割协议中明确记载。

### 步骤五：丧失继承权审查

依据民法典第1125条（中度把握，建议复核），继承人有下列情形之一的，丧失继承权：

| 情形 | 说明 | 涉刑风险 |
|------|------|---------|
| 故意杀害被继承人 | 刑事定罪或民事法院认定 | 🔴 强制升级刑事律师 |
| 为争夺遗产杀害其他继承人 | 刑事定罪或民事认定 | 🔴 强制升级刑事律师 |
| 遗弃被继承人或虐待情节严重 | 情节严重的认定由法院裁量 | 🟠 可能涉刑，需评估 |
| 伪造、篡改、隐匿或销毁遗嘱情节严重 | 情节严重的认定由法院裁量 | 🟠 高风险 |
| 以欺诈胁迫手段迫使或妨碍被继承人设立、变更或撤回遗嘱情节严重 | 情节严重由法院裁量 | 🟠 高风险 |

**丧失继承权的恢复**：被继承人对上述部分情形（如虐待后有悔改表现）可予宽恕，须被继承人明示宽恕（建议在遗嘱中体现）；被继承人死后不得宽恕。

**程序说明**：丧失继承权不由继承人自行主张，须通过法院诉讼程序认定。AI 工具不得自行宣布某继承人丧失继承权，仅提供风险提示，**强制升级给律师**后由律师决定是否提起相关诉讼。

## 错误处理

| 错误情形 | 处理方式 |
|---------|---------|
| 继承人资格文件不齐全（如无出生证明、无收养手续） | 提示需要补充的材料清单；核实前在结论中标注 `⚠️ 资格未经完整文件确认` |
| 被继承人婚姻状态不明确（如疑似事实婚姻、离婚协议真实性存疑） | 暂停继承份额计算，提示须先通过法院确认婚姻效力；标注 🟠 高风险 |
| 发现涉刑情形（故意杀害被继承人等） | **立即暂停**所有继承份额分析，标注 🔴 关键，**强制升级刑事律师** |
| 丧失继承权争议（如有人主张某继承人应丧失继承权） | 提示丧失继承权须经法院认定程序，AI工具不得自行认定；标注 🟠 高风险，升级律师处理诉讼 |
| 无法确定遗产范围（析产尚未完成） | 先触发 `estate-scope-debt` 子技能完成析产，再回到本技能进行继承分析 |
| 继承人情绪危机（丧亲悲痛，无法冷静分析） | 以中立克制措辞呈现，暂停分析复杂争议情形，提示寻求专业支持（法律援助/心理支持） |
| 多份遗嘱并存且效力不明 | 先触发 `testate-succession-validity` 子技能确认遗嘱效力范围，再确定法定继承的启动范围 |

## 目的

在被继承人的继承人（子女或兄弟姐妹）先于被继承人死亡或在遗产分割前死亡时，准确判断代位继承或转继承是否适用、范围如何、份额多少，防止因概念混淆导致继承份额错误。同时审查继承人丧失继承权的情形，为代位/转继承人的份额主张提供法律依据。

覆盖核心分析：

1. 代位继承的触发条件与范围（被继承人子女/兄弟姐妹先死）
2. 代位继承的份额计算（代位继承被代位人有权继承的份额）
3. 转继承的触发条件与范围（继承人在遗产分割前死亡）
4. 代位继承与转继承的本质区别（时间点/主体/份额/性质）
5. 丧失继承权的情形认定（第1125条）
6. 按代理立场区分份额主张侧重

### 2. 代理立场区分

| 立场 | 审查侧重 |
|------|---------|
| **代理代位继承人** | 关注代位资格确立（被代位人先于被继承人死亡 + 晚辈直系血亲关系）、被代位份额的确认、丧失继承权情形排除（被代位人是否有丧失继承权情形）、代位人数量与份额分配 |
| **代理转继承人** | 关注转继承人资格（继承人在遗产分割前死亡且未放弃继承）、转继承时应继份的确认、转继承人的继承人范围 |
| **代理其他法定继承人（抗辩代位/转继承人份额）** | 质疑代位资格（如亲属关系存疑）或转继承有效性，主张丧失继承权情形 |
| **中立** | 双向列示代位/转继承适用情形与各方份额 |

### 3. 敏感情形检查

- 涉及丧失继承权争议（如被代位人曾故意伤害被继承人）：标注 🟠 高风险，提示须通过法院程序认定，强制升级律师
- 涉刑情形（故意杀害）：标注 🔴 关键，强制升级刑事律师

## 详细步骤

### 步骤一：代位继承分析

#### 1.1 代位继承的触发条件（民法典第1128条，建议复核）

代位继承须同时满足以下条件：

| 条件 | 具体说明 |
|------|---------|
| **时间要件** | 被代位继承人**先于被继承人死亡**（在被继承人死亡前已死亡） |
| **身份要件** | 被代位继承人须为：(1) 被继承人的子女，或 (2) 被继承人的兄弟姐妹 |
| **代位人身份** | (1) 子女先死：由子女的**晚辈直系血亲**代位；(2) 兄弟姐妹先死：由兄弟姐妹的**子女**代位 |
| **份额限制** | 代位继承人只能继承被代位继承人**有权继承**的遗产份额（不能超过被代位人应继份） |

#### 1.2 代位继承的适用场景

| 情形 | 是否触发代位继承 |
|------|--------------|
| 被继承人子女先于被继承人死亡 | ✅ 是 — 由该子女的晚辈直系血亲（孙子女/外孙子女等）代位 |
| 被继承人兄弟姐妹先于被继承人死亡 | ✅ 是 — 由该兄弟姐妹的子女代位（仅一代，不延伸至孙辈） |
| 被继承人父母先于被继承人死亡 | ❌ 否 — 父母先死不适用代位继承（父母的上辈无代位权） |
| 继承人先于被继承人死亡但被继承人已放弃让其继承 | ❌ 无代位份额可代位 |
| 被代位继承人丧失继承权 | ⚠️ 存在争议——主流认为丧失继承权者的晚辈直系血亲仍可代位（描述规则，`[待验证]`） |

#### 1.3 代位继承人范围与份额

**子女先死的代位继承人范围**：

- **晚辈直系血亲**：包括孙子女、外孙子女（及更低辈）
- 代位继承人可以是多人（如先死子女留有多名子女），则由多名代位继承人均等分配被代位人的应继份
- 代位继承人的子女（曾孙等）在特定情形下是否可再次代位，存在争议（描述规则，`[待验证]`）

**兄弟姐妹先死的代位继承人范围**：

- 仅限该兄弟姐妹的**子女**（一代，不延伸至孙辈）
- 民法典第1128条（建议复核）

#### 1.4 份额计算示例

**示例**：被继承人甲（无遗嘱），遗产 120 万元（析产后）。第一顺序继承人：配偶乙、父母丙丁、子女戊（戊已先于甲死亡，戊有子女己庚）。

```
法定继承人（含代位）：乙（配偶）、丙（父）、丁（母）、己（代位戊的份额）、庚（代位戊的份额）
均等顺序计算：应为 4 人（乙+丙+丁+戊代位份）均等 = 每份 30 万元
戊的应继份 30 万元由己、庚均等代位：己 15 万元 + 庚 15 万元
```

### 步骤二：转继承分析

#### 2.1 转继承的触发条件

转继承须同时满足以下条件：

| 条件 | 具体说明 |
|------|---------|
| **时间要件** | 继承人在**继承开始后**（被继承人死亡后）、**遗产分割前**死亡 |
| **态度要件** | 该继承人在死亡前**未放弃继承**（若已放弃则应继份不存在） |
| **转移主体** | 该继承人死亡时其已确定的应继份，转移给其**自身的继承人**继承（按该继承人自己的继承规则处理） |

#### 2.2 转继承的性质

转继承本质上是继承人的**「应继份」**在该继承人死亡时转为其遗产，由其继承人按该继承人自身的继承规则继承。

| 特点 | 代位继承 | 转继承 |
|------|---------|-------|
| 发生时间 | 被代位人先于被继承人死亡（被继承人死亡前） | 继承开始后（被继承人死亡后）、遗产分割前 |
| 法律基础 | 民法典第1128条（法定代位规则） | 应继份作为继承人遗产的转移（继承人的继承人） |
| 代位/转移主体 | 晚辈直系血亲（子女先死）或兄弟姐妹的子女 | 转继承人的全部继承人（法定或遗嘱） |
| 份额限制 | 代位继承被代位人有权继承的份额 | 转继承人的应继份全额转移（不限于晚辈） |
| 遗嘱的影响 | 代位不受遗嘱影响（代位法定规则，除非遗嘱排除） | 转继承按转继承人自身的继承规则（可有遗嘱） |

### 步骤三：代位继承与转继承对比表

| 维度 | 代位继承 | 转继承 |
|------|---------|-------|
| **触发时间** | 被代位人先于被继承人死亡 | 继承人在被继承人死亡后、遗产分割前死亡 |
| **法律条文** | 第1128条（建议复核） | 无专门条文（描述规则，`[待验证]`） |
| **代位/转移主体** | 晚辈直系血亲（子女）；兄弟姐妹的子女 | 转继承人的全体继承人（法定或遗嘱指定） |
| **份额** | 限于被代位人有权继承的份额 | 转继承人的全部应继份 |
| **放弃的影响** | 被代位人的放弃不影响代位继承（仅在生前放弃有争议，`[待验证]`） | 转继承人在继承开始后死亡前放弃的，无转继承份额 |
| **适用范围** | 法定继承（遗嘱继承一般不适用，`[待验证]`） | 法定继承与遗嘱继承均可适用 |

### 步骤四：丧失继承权审查（民法典第1125条，建议复核）

#### 4.1 丧失继承权的情形

| 情形 | 认定难度 | 涉刑风险 | 处理方式 |
|------|---------|---------|---------|
| 故意杀害被继承人 | 刑事判决或民事认定 | 🔴 极高 — 强制升级刑事律师 | 依刑事判决/民事法院认定 |
| 为争夺遗产杀害其他继承人 | 刑事判决或民事认定 | 🔴 极高 — 强制升级刑事律师 | 依刑事判决/民事法院认定 |
| 遗弃/虐待被继承人情节严重 | 情节严重由法院裁量 | 🟠 可能涉刑（遗弃罪/虐待罪） | 须通过法院诉讼认定 |
| 伪造/篡改/隐匿/销毁遗嘱情节严重 | 情节严重由法院裁量 | 🟠 高风险 | 须通过法院诉讼认定 |
| 欺诈胁迫影响遗嘱情节严重 | 情节严重由法院裁量 | 🟠 高风险 | 须通过法院诉讼认定 |

#### 4.2 丧失继承权的法律后果

| 后果 | 说明 |
|------|------|
| 丧失继承权的继承人不参与继承 | 视为自始不具有继承资格 |
| 其晚辈直系血亲是否可代位 | 主流观点：丧失继承权不影响代位继承（描述规则，`[待验证]`）——晚辈直系血亲仍可代位 |
| 宽恕后恢复继承权 | 被继承人可对虐待/遗弃（情节较轻者）明示宽恕，须在遗嘱中体现；死后不得宽恕 |

#### 4.3 丧失继承权的程序

**重要程序说明**：

> **丧失继承权须经法院诉讼认定程序**。AI 工具不得自行宣布某继承人丧失继承权，仅提供风险提示。识别到疑似丧失继承权情形时，**必须标注并强制升级给律师**，由律师决定是否通过诉讼程序主张。

程序路径：

1. 有争议的继承人提起确认继承权（或否认继承权）之诉
2. 或在遗产分割纠纷诉讼中作为附属争议处理
3. 法院认定后出具判决，明确该继承人的继承地位


## 边界条件

| 边界情形 | 处理方式 | 风险等级 |
|---------|---------|---------|
| 双重代位（代位继承人也先于被继承人死亡） | 子女先死的代位继承人自身是否可再代位存在争议（描述规则，`[待验证]`）；兄弟姐妹的子女代位仅限一代 | 🟡 中等 |
| 被代位人丧失继承权 | 主流观点其晚辈直系血亲仍可代位，但具体规则须核实（`[待验证]`） | 🟡 中等 |
| 被代位人生前自愿放弃继承 | 主流观点认为若被代位人生前主动放弃，代位继承是否仍适用存在争议（`[待验证]`） | 🟡 中等 |
| 转继承人在被继承人死亡前放弃继承 | 继承开始前放弃的视为不继承（无转继承份额）；须区分「放弃时间」——死亡前放弃有效 | 🟡 中等 |
| 继承人与被继承人同时死亡（共同事故） | 无法确定死亡先后顺序时，推定互不继承（描述规则，条号 `[待验证]`） | 🟠 高 |
| 代位人认定关系存疑（如亲子关系不明） | 须通过亲子鉴定或法院认定；标注 🟠 高风险 | 🟠 高 |
| 遗嘱继承是否适用代位继承 | 主流观点遗嘱继承不适用代位继承（遗嘱指定的继承人先死，该遗嘱条款失效）——描述规则，`[待验证]` | 🟡 中等 |

## 错误处理

| 错误情形 | 处理方式 |
|---------|---------|
| 先死亡继承人的死亡时间不明确 | 提示须取得死亡证明（医院记录/民政局死亡登记），明确死亡时间是判断代位还是转继承的关键 |
| 代位继承人身份关系证明不足 | 提示须取得亲属关系证明（户口本/出生证明/遗嘱等）；核实前标注 `⚠️ 亲属关系未经完整文件确认` |
| 涉刑情形（故意杀害） | 立即标注 🔴 关键，停止继承份额分析，强制升级刑事律师 |
| 丧失继承权争议（无法院认定） | 提示须通过法院诉讼认定程序；在认定完成前，争议继承人暂时保留继承候选人地位 |
| 转继承人自身也存在多重继承关系 | 按转继承人自身的继承规则处理其应继份；可能涉及多层继承，提示须律师梳理 |
| 丧亲情绪危机（多名亲属相继死亡） | 特别注意情绪护栏，以中立克制措辞呈现，避免在悲伤气氛中推动复杂份额争议 |

**第1128条 — 代位继承**

### 司法解释（描述规则，条号待验证）

**关于代位继承范围的司法解释规则**（最高法继承编司法解释(一)）
- 规则描述：代位继承人只能代位继承被代位继承人有权继承的遗产份额，不能超过被代位继承人本应继承的份额 `[模型知识 — 需验证]` `[待验证]`

**关于转继承的规则**（描述规则）
- 规则描述：继承人在继承开始后遗产分割前死亡且未放弃继承的，其应继份作为其遗产，由其继承人按其继承规则继承——民法典继承编无专门条文，以继承法理与司法解释规则处理，条号 `[待验证]` `[模型知识 — 需验证]`

**关于丧失继承权者的晚辈直系血亲代位的规则**（描述规则）
- 规则描述：丧失继承权不影响其晚辈直系血亲的代位继承权（主流观点），具体规则须核实 `[模型知识 — 需验证]` `[待验证]`

**关于同时死亡推定规则**（描述规则）
- 规则描述：自然人同时发生死亡且无法确定死亡先后顺序的，推定同时死亡，互不继承各自遗产；具体规则须核实 `[待验证]` `[模型知识 — 需验证]`
