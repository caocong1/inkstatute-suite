## 目的

遗嘱起草是遗嘱人将其遗产分配意愿以符合法律形式的方式固定下来的过程。本技能以**遗嘱人侧**为核心立场，确保遗嘱在形式上合法有效、在内容上符合遗嘱人真实意愿、在必留份要求上符合法律强制性规定，并安排妥当的见证与保管。

**主要法律框架**：民法典继承编（第1119-1163条），特别是第1134-1145条（遗嘱各形式要件、见证人资格、必留份、附义务、遗产管理人），及最高法继承编司法解释(一)（具体条号 `[待验证]`）。

## 入口级护栏

### 文书风格加载

遗嘱文书须符合以下风格标准：

| 要素 | 要求 |
|------|------|
| **严谨准确** | 财产描述须精确（含不动产权证书号/银行账户等）；受益人身份须明确（姓名/身份证号）|
| **无歧义** | 避免模糊表述（如「我的孩子们」「其余财产」等）；每项财产归属须单独列明 |
| **形式要件明确** | 遗嘱形式选择须在文本中体现（如「本遗嘱为自书遗嘱，系本人亲笔书写」）|
| **语言克制** | 不含对继承人的情绪化评价；不含可能引发纠纷的人身攻击性内容 |

### 遗嘱能力与真实意思核查提示（强制优先）

在进入具体子技能前，须做以下核查：

| 核查项 | 触发护栏 |
|--------|---------|
| 立遗嘱人年龄是否满18周岁（或16周岁以劳动收入为主）| 未满足：🔴 关键，须升级律师评估 |
| 是否有认知障碍/精神疾病/近期手术麻醉等能力疑虑 | 有疑虑：🔴 关键，**强制升级律师**，建议医疗机构出具能力证明 |
| 是否有家庭成员全程陪同且控制沟通的迹象（胁迫嫌疑）| 有迹象：🔴 关键，**强制升级律师**，须创造独立沟通条件 |
| 遗嘱内容是否与立遗嘱人平时表达的意愿明显不符 | 明显偏差：🟠 高风险，须独立核实 |

**遗嘱能力与意思真实是遗嘱有效性的根本要件**。识别到任何能力存疑或受胁迫信号，须**立即暂停遗嘱起草，强制升级律师**，不得继续推进形式起草。

### 必留份与处分范围提示

在起草遗嘱内容前，须提示：

1. **先析产**：遗嘱只能处分遗嘱人的个人财产（含夫妻共同财产中属其的一半），不得处分配偶或他人财产
2. **必留份**：若继承人中有「缺乏劳动能力又无生活来源」者，遗嘱须为其保留必要份额（民法典第1141条，建议复核）；违反必留份的部分无效

### 公证路径提示

根据遗嘱人情况，提示以下公证路径（不强制，但建议考虑）：

| 情形 | 公证路径建议 |
|------|------------|
| 财产复杂（多处房产/股权/海外资产） | 建议办理公证遗嘱，由公证机构留档，减少继承争议 |
| 担心遗嘱能力事后被质疑 | 立遗嘱时同步办理公证，公证员可记录立遗嘱时的精神状态 |
| 遗嘱内容重要且不希望更改 | 公证遗嘱可提供强有力的留痕，但注意民法典下公证遗嘱**不再优先**，仍可通过其他形式修改 |

**公证遗嘱不再优先的重要提示**：民法典取消公证遗嘱效力优先规则，数份遗嘱以**最后订立的**为准（民法典第1142条，建议复核），与是否公证无关。

### 目的地与特权检查

- **非律师角色（当事人本人）**：遗嘱定稿前须暂停并升级律师确认形式与内容合规性

## 详细步骤

### 步骤一：遗嘱能力要件

#### 1.1 遗嘱能力的法律要求

依据民法典第1143条（中度把握，建议复核）：

| 要件 | 具体要求 |
|------|---------|
| **完全民事行为能力人** | 须为完全民事行为能力人（年满18周岁且精神状态正常，或年满16周岁且以自己劳动收入为主要生活来源） |
| **无民事行为能力人** | 所立遗嘱无效（如：无行为能力的精神病患者、未满8周岁的未成年人） |
| **限制民事行为能力人** | 所立遗嘱无效（如：8-18周岁未成年人、精神状态时好时坏的间歇性精神病患者处于发作状态时） |

#### 1.2 能力的时间节点

**关键原则**：遗嘱能力在**立遗嘱时**判断，不以立遗嘱后的状态推算。

| 时间节点情形 | 处理规则 |
|------------|---------|
| 立遗嘱时有完全民事行为能力，其后丧失 | **不影响遗嘱效力**——遗嘱仍有效 |
| 立遗嘱时无完全民事行为能力（如发作期间），其后恢复 | **遗嘱仍无效**——效力以立遗嘱时为准 |
| 间歇性精神障碍者在清醒期（缓解期）立遗嘱 | **遗嘱可能有效**——须证明立遗嘱时处于完全行为能力状态（医疗证明+见证人证词） |

#### 1.3 高龄遗嘱人的能力核查

高龄遗嘱人（特别是70岁以上，或有认知症迹象者）须额外关注：

| 核查方面 | 具体措施 |
|---------|---------|
| 认知状态评估 | 建议在立遗嘱前进行认知功能评估（可由医院神经内科或老年科出具意见） |
| 独立沟通测试 | 在无家庭成员陪同的情况下，与遗嘱人独立沟通，验证其对遗嘱内容的理解与意愿 |
| 医疗记录留痕 | 取得近期医院诊疗记录，证明立遗嘱时的精神状态 |
| 录音录像辅证 | 对高龄遗嘱人，建议采用录音录像遗嘱或录音录像记录立遗嘱过程，以备将来争议时使用 |

### 步骤二：真实意思表示保障

#### 2.1 意思真实的法律要求

依据民法典第1143条（中度把握，建议复核）：遗嘱必须表示遗嘱人的**真实意思**，受欺诈、胁迫所立的遗嘱无效。

| 要件 | 具体含义 |
|------|---------|
| **自主意思** | 遗嘱内容完全按遗嘱人本人意愿表达，不受他人不当干预 |
| **无欺诈** | 无他人通过虚假陈述诱使遗嘱人作出不真实的意思表示 |
| **无胁迫** | 无他人通过威胁或强迫手段影响遗嘱人作出违背意愿的表示 |

#### 2.2 欺诈与胁迫的识别信号

| 信号类型 | 具体表现 | 风险等级 |
|---------|---------|---------|
| **欺诈信号** | | |
| 虚假财产信息 | 他人向遗嘱人虚报某继承人的财务状况、品德，诱导遗嘱人将更多财产留给该人 | 🔴 高度可疑 |
| 遗嘱内容出现异常偏差 | 遗嘱内容与遗嘱人平时表达的意愿差异很大（如突然将全部财产留给非传统受益人） | 🟠 需关注 |
| 立遗嘱后内容不知情 | 遗嘱人不知道或不理解自己签署的遗嘱内容 | 🔴 高度可疑 |
| **胁迫信号** | | |
| 陪同控制 | 某人全程陪同立遗嘱，不允许遗嘱人独立与律师沟通 | 🔴 高度可疑 |
| 遗嘱人行为异常 | 遗嘱人在陪同者离开后表达与遗嘱内容不同的意愿 | 🔴 高度可疑 |
| 遗嘱人表达恐惧 | 遗嘱人在讨论遗嘱内容时明显紧张、顾虑、眼神求助 | 🔴 高度可疑 |

#### 2.3 保障真实意思的最佳实践

| 最佳实践 | 说明 |
|---------|------|
| **独立沟通** | 在无继承人/受遗赠人在场的情况下，律师或公证员与遗嘱人单独沟通，确认遗嘱内容符合其真实意愿 |
| **理解测试** | 请遗嘱人用自己的语言复述遗嘱的主要内容，确认遗嘱人真正理解并认可 |
| **录音录像记录** | 建议对立遗嘱过程录音录像，记录遗嘱人主动表达遗嘱内容的过程，作为意思真实的证据 |
| **见证人独立核查** | 见证人须独立判断遗嘱人的意思表示是否真实，不可成为胁迫的从犯 |
| **多次确认** | 若有能力疑虑，建议隔日或多次独立沟通确认，避免单次情绪化表达影响判断 |
| **医疗证明** | 若有能力疑虑，立遗嘱前取得当日或近日的医疗诊断证明 |

### 步骤三：伪造与篡改遗嘱

#### 3.1 伪造遗嘱的效力（第1143条，建议复核）

**伪造的遗嘱无效**。

| 伪造情形 | 法律后果 |
|---------|---------|
| 完全非遗嘱人所写的「自书遗嘱」 | 整份遗嘱无效 |
| 遗嘱人签名系伪造（非本人签名） | 整份遗嘱无效 |
| 遗嘱人死亡后伪造遗嘱 | 整份遗嘱无效；伪造者可能丧失继承权（第1125条，建议复核） |

**识别方法**：笔迹鉴定（法院委托司法鉴定机构）、公证档案比对、目击人证词。

#### 3.2 篡改遗嘱的效力（第1143条，建议复核）

**遗嘱被篡改的，篡改的内容无效。**

| 篡改情形 | 法律后果 |
|---------|---------|
| 修改了财产分配比例 | 修改部分无效，原内容仍有效（若能识别原内容） |
| 添加了非遗嘱人所写的条款 | 添加部分无效 |
| 删除了遗嘱人所写的条款 | 视具体情况，可能导致遗嘱部分无效或影响整体解释 |

#### 3.3 丧失继承权的关联

依据民法典第1125条（中度把握，建议复核）：伪造、篡改、隐匿或者销毁遗嘱，情节严重的，丧失继承权。

**程序说明**：丧失继承权须通过法院诉讼程序认定，AI 工具不得自行认定。

## 详细步骤

### 步骤一：六种法定遗嘱形式要件对照

依据民法典第1134-1139条（均已核实，建议复核）：

| 遗嘱形式 | 条号 | 核心要件 | 见证人要求 | 签名要求 | 日期要求 | 适用情形 |
|---------|------|---------|---------|---------|---------|---------|
| **自书遗嘱** | 第1134条 | 遗嘱人**亲笔书写**全文 | 无 | 遗嘱人签名 | 遗嘱人注明年月日 | 有书写能力、财产简单、希望保密 |
| **代书遗嘱** | 第1135条 | 两名以上见证人在场；其中**一人代书**；其他人见证 | 2人以上（含代书人）；见证人须签名 | 遗嘱人、代书人、见证人均须签名 | 注明年月日 | 无书写能力（残疾/文盲）；需要见证记录 |
| **打印遗嘱** | 第1136条 | 两名以上见证人在场；遗嘱人和见证人在**每一页**签名 | 2人以上；须在**每一页**签名 | 遗嘱人和每名见证人须在**每一页**签名 | 注明年月日 | 财产复杂、遗嘱内容较长、可打印修改 |
| **录音录像遗嘱** | 第1137条 | 两名以上见证人在场；遗嘱人和见证人在录音录像中**记录姓名或肖像及年月日** | 2人以上；须在录音录像中记录 | 以录音录像中记录姓名/肖像代替签名 | 在录音录像中记录年月日 | 无书写能力；希望留存遗嘱人声音/画面；辅助证明意思真实 |
| **口头遗嘱** | 第1138条 | **危急情况**下；两名以上见证人在场 | 2人以上 | — | 见证人记录年月日 | 仅限危急情况（生命危急、无法书写/打印/录音） |
| **公证遗嘱** | 第1139条 | 经公证机构公证办理 | 公证机构（公证员） | 在公证机构办理 | 公证机构记录 | 财产复杂、希望减少争议、有充分时间办理 |

> **重要提示：口头遗嘱失效条件**（第1138条，建议复核）：危急情况消除后，遗嘱人能以书面或录音录像形式立遗嘱的，此前所立的口头遗嘱无效。

---

### 步骤二：公证遗嘱不再优先——民法典重大修订

**这是实践中最容易混淆的重要修订，必须向立遗嘱人明确说明：**

| 规则对比 | 原继承法（已废止） | 民法典（2021年起） |
|---------|-----------------|-----------------|
| 数份遗嘱效力 | 公证遗嘱效力优先于其他形式 | **一律以最后订立的遗嘱为准，无论形式** |
| 公证遗嘱地位 | 可用公证遗嘱锁定效力 | 与其他形式遗嘱效力相同 |
| 修改灵活性 | 若立了公证遗嘱，须通过公证机构修改方可覆盖 | 最后订立的合法遗嘱有效，可通过任何合法形式修改/撤回 |

**实践影响**：

1. 民法典施行后，立遗嘱人**可以通过自书遗嘱或其他合法形式**撤回或修改此前立的公证遗嘱，只需确保最后立的遗嘱是有效的
2. 公证遗嘱仍有价值：公证提供的**留痕与专业性**有助于减少继承争议（即使效力不再优先）
3. 旧的公证遗嘱（2021年前立的）过渡期效力认定存在争议（描述规则，`[待验证]`）

### 步骤三：形式选择决策表

根据立遗嘱人情况推荐形式：

| 情形 | 推荐形式 | 理由 |
|------|---------|------|
| 有书写能力、财产简单、希望保密 | **自书遗嘱** | 简单灵活，无需他人协助，保密性强；须亲笔书写全文 |
| 有书写能力、财产较复杂 | **打印遗嘱** 或 **公证遗嘱** | 打印遗嘱内容清晰，但须每页签名；公证有专业留痕 |
| 无书写能力（残疾/文盲）但能表达意思 | **代书遗嘱** 或 **录音录像遗嘱** | 代书须可信非利害关系见证人；录音录像保留声音/画面辅证意思真实 |
| 无书写能力且表达困难（如重症失语）| 评估完全民事行为能力后谨慎处理 | 能力存疑时立遗嘱风险极高，建议升级律师评估 |
| 财产复杂（多处不动产/股权/海外资产） | **公证遗嘱**（为主）+ 自书遗嘱（补充后期更新） | 公证遗嘱专业性高，减少继承人对遗嘱内容的质疑；后期修改可用其他形式 |
| 希望保留最终修改灵活性 | **自书遗嘱** 或 **打印遗嘱**（最后立的为准） | 民法典下任何形式均可，以最后立的为准 |
| 危急情况（生命危急） | **口头遗嘱**（限危急情形）/ **录音录像遗嘱** | 危急时口头遗嘱须两名见证人；危急解除后须书面/录音录像跟进，否则口头遗嘱无效 |

### 步骤四：各形式常见无效陷阱

| 遗嘱形式 | 常见无效陷阱 | 防范建议 |
|---------|-----------|---------|
| **自书遗嘱** | 部分文字非亲笔书写（如用打印纸填入日期）；无签名；无日期（仅年月无日）；日期晚于实际立遗嘱时间 | 全文亲笔书写；签名在最末；年月日完整 |
| **代书遗嘱** | 代书人同时是继承人或受遗赠人；见证人不足两人；遗嘱人未签名（仅按手印有争议）；代书人未签名 | 代书人须非利害关系人；见证人须独立签名 |
| **打印遗嘱** | 某页未签名（如仅第一页和最后一页签）；见证人未在每页签名；打印后补签日期 | **每一页**遗嘱人与见证人均须签名；日期注明时遗嘱已完成 |
| **录音录像遗嘱** | 录制中遗嘱人或见证人未说出姓名；日期未在录音录像中说明；见证人仅在录像外纸面签名 | 录音录像开头遗嘱人说出自己姓名和日期；见证人在录像中说出姓名 |
| **口头遗嘱** | 危急情况消除后仍依口头遗嘱（无效）；见证人只有一人；见证人为继承人/受遗赠人 | 危急解除后立即办理书面/录音录像遗嘱；见证人须两名且非利害关系 |
| **公证遗嘱** | 2021年前立的公证遗嘱过渡期效力争议；遗嘱人立遗嘱后通过其他形式修改了遗嘱但未告知继承人（致继承争议）| 定期告知可信赖的人遗嘱最新版本的存在；修改遗嘱后告知公证机构 |

### 步骤五：多份遗嘱的管理建议

当立遗嘱人已立有多份遗嘱或计划修改遗嘱时：

| 事项 | 建议 |
|------|------|
| 撤销旧遗嘱 | 在新遗嘱中明确说明「撤销 [日期] 立的全部遗嘱/本遗嘱内容」 |
| 实施与遗嘱内容相反的民事行为 | 视为对遗嘱相关内容的撤回（民法典第1142条，建议复核）——故须谨慎处分遗嘱中的财产 |
| 保管原件 | 自书遗嘱妥善保管原件（避免原件丢失导致难以证明内容）；建议告知至少一名受信任的人保管地点 |
| 公证机构档案 | 公证遗嘱由公证机构存档，有据可查，但可通过其他形式最后遗嘱覆盖 |

| 错误情形 | 处理方式 |
|---------|---------|
| 遗嘱人无书写能力且无合格见证人 | 提示须找到两名合格见证人（非利害关系），若实在无法找到见证人，提示公证遗嘱路径（公证员可作见证） |

## 法律依据

### 法条（来源：民法典继承编，中度把握锚点）

**第1134条 — 自书遗嘱**
- 《中华人民共和国民法典》**第1134条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 自书遗嘱由遗嘱人亲笔书写，签名，注明年、月、日

**第1135条 — 代书遗嘱**
- 《中华人民共和国民法典》**第1135条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 代书遗嘱须有两个以上见证人在场见证，由其中一人代书，注明年月日，并由代书人、其他见证人和遗嘱人签名

**第1136条 — 打印遗嘱**
- 《中华人民共和国民法典》**第1136条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 打印遗嘱须有两个以上见证人在场见证，遗嘱人和见证人应当在**遗嘱每一页**上签名，注明年月日

**第1137条 — 录音录像遗嘱**
- 《中华人民共和国民法典》**第1137条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 录音录像遗嘱须有两个以上见证人在场见证，遗嘱人和见证人应当在录音录像中记录其姓名或者肖像，以及年月日

**第1138条 — 口头遗嘱**
- 《中华人民共和国民法典》**第1138条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 口头遗嘱须在危急情况下，须有两个以上见证人在场见证；危急情况消除后，遗嘱人能够以书面或者录音录像形式立遗嘱的，所立的口头遗嘱无效

**第1139条 — 公证遗嘱**
- 《中华人民共和国民法典》**第1139条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 公证遗嘱由遗嘱人经公证机构公证办理；**民法典取消公证遗嘱优先效力**

**第1142条 — 最后遗嘱为准**
- 《中华人民共和国民法典》**第1142条** `[模型知识 — 需验证]` 中度把握，建议复核
- 立有数份遗嘱内容相抵触的，以最后的遗嘱为准（无论形式）

**第1140条 — 见证人资格**
- 《中华人民共和国民法典》**第1140条** `[模型知识 — 需验证]` 中度把握，建议复核
- 继承人、受遗赠人及与其有利害关系的人不能作为见证人

## 详细步骤

### 步骤一：遗嘱处分范围核查

#### 1.1 先析产后确定可处分范围

遗嘱只能处分遗嘱人的**个人合法财产**。若遗嘱人有配偶，须先析产：

```
遗嘱人的全部财产（含共同财产）
    ↓
Step 1: 识别夫妻共同财产范围（民法典第1062条，建议复核）
    ↓
Step 2: 夫妻共同财产中属遗嘱人的一半 = 可通过遗嘱处分的共同财产部分
    ↓
Step 3: 遗嘱人个人财产（民法典第1063条，建议复核）= 可通过遗嘱处分的个人财产
    ↓
Step 4: 遗嘱可处分范围 = Step 2 + Step 3
```

#### 1.2 遗嘱处分范围核查表

| 财产类型 | 可通过遗嘱处分 | 不可通过遗嘱处分 | 备注 |
|---------|-------------|--------------|------|
| **遗嘱人婚前个人财产** | ✅ 全部可处分 | — | 须能证明属个人财产 |
| **婚后夫妻共同财产** | ✅ 遗嘱人应得的**一半** | ❌ 配偶应得的一半 | 须先析产 |
| **约定为遗嘱人所有的财产**（书面约定财产制） | ✅ 可处分 | — | 须有书面约定 |
| **遗嘱或赠与明确归遗嘱人的财产** | ✅ 可处分 | — | 须有遗嘱/赠与合同证明 |
| **配偶的个人财产** | ❌ 不可处分 | — | 遗嘱处分他人财产无效 |
| **共有人共有财产中他人份额** | ❌ 不可处分 | — | 超出个人份额部分无效 |
| **专属人身性权利** | ❌ 不可处分 | — | 如肖像权本身、人身损害请求权未实现部分 |

> **实践提示**：遗嘱处分范围超出遗嘱人个人财产时，**超出部分无效**，不影响遗嘱在合法范围内的效力（即遗嘱部分有效）。

### 步骤二：必留份的判定与计算

#### 2.1 必留份的法律规定（第1141条，建议复核）

> **遗嘱应当为缺乏劳动能力又没有生活来源的继承人保留必要的遗产份额。**

必留份是对遗嘱自由的法律限制，保护弱势继承人的基本生活保障。

#### 2.2 必留份的适用要件

须同时满足**两个条件**：

| 条件 | 判断要点 |
|------|---------|
| **缺乏劳动能力** | 因年龄（如幼年/高龄）、身体残疾、疾病等客观原因**无法通过劳动获得收入**；单纯失业或懒惰不构成「缺乏劳动能力」 |
| **没有生活来源** | 没有其他可维持基本生活的收入、财产或保障；如有养老金、社保、其他遗产可维持生活，则可能不满足此要件 |

**仅满足其中一个条件，不适用必留份**（如：有养老金的老人不一定须留必留份；有劳动能力但暂时失业者不适用）。

#### 2.3 典型必留份受益人

| 典型情形 | 是否通常满足两要件 | 注意事项 |
|---------|----------------|---------|
| 年幼子女（如未成年子女，尤其是丧失劳动能力的） | ✅ 通常满足 | 须评估是否有其他生活来源 |
| 丧失劳动能力的成年子女（如重度残疾） | ✅ 通常满足 | 须评估劳动能力认定标准 |
| 依靠遗嘱人赡养的高龄无收入父母 | ✅ 通常满足 | 须评估是否有退休金/其他积蓄 |
| 一般健康的成年子女 | ❌ 通常不满足（有劳动能力） | — |
| 有退休金的老年父母 | ⚠️ 可能不满足（有生活来源） | 须评估退休金是否足以维持基本生活 |

#### 2.4 必留份的计算方式

必留份的具体数额**没有统一的比例标准**，由法院或当事人协商根据以下因素确定（描述规则，具体计算方法须司法解释细化，`[待验证]`）：

| 考量因素 | 说明 |
|---------|------|
| 受益人的基本生活需要 | 当地生活水平下的基本生活所需（食住医等） |
| 遗产实际情况 | 遗产总价值决定可保留的份额上限 |
| 其他生活来源 | 受益人是否有其他收入来源（影响最终数额） |

> **实践建议**：在遗嘱中明确为满足必留份的继承人保留的份额，并说明该份额的计算依据，减少继承纠纷。

#### 2.5 违反必留份的后果

| 情形 | 法律后果 |
|------|---------|
| 遗嘱完全剥夺必留份受益人的继承权 | 遗嘱剥夺必留份部分**无效**；实际分配时须先留出必留份 |
| 遗嘱给予必留份受益人的份额不足 | 不足部分从遗嘱其他受益人的份额中补足 |

**处理顺序**：先满足必留份 → 再按遗嘱其余内容分配剩余遗产。

---

### 步骤三：附义务遗嘱

#### 3.1 附义务遗嘱的法律规定（第1144条，建议复核）

> **遗嘱继承或者遗赠附有义务的，继承人或者受遗赠人应当履行义务。没有正当理由不履行义务的，经有关单位或者个人请求，人民法院可以取消其接受附义务部分遗产的权利。**

#### 3.2 附义务遗嘱的典型条款

| 义务类型 | 示例条款 | 注意事项 |
|---------|---------|---------|
| **赡养义务** | 「受遗嘱人须在获得遗产后，以月均不少于 X 元的方式赡养遗嘱人之 [亲属]，直至 [亲属] 死亡」 | 义务须具体可执行（金额/方式/期限） |
| **照料义务** | 「受遗嘱人须将 [房产] 提供给 [亲属] 居住至 [亲属] 死亡或再婚」 | 明确居住条件，避免歧义 |
| **用途限制** | 「遗嘱财产须专用于 [子女] 的教育费用，不得挪作他用」 | 限制条款须合法，不得违反公序良俗 |
| **维持原状** | 「受遗嘱人须保留 [房产] 中 [亲属] 的居住权，不得出售或出租」 | 须符合居住权法律规定 `[待验证]` |

**条款起草要点**：

1. 义务须明确、可执行——「适当赡养」等模糊表述争议多
2. 明确不履行义务的后果（法院可取消接受附义务财产的权利）
3. 须指定监督人或受益方（有资格向法院请求取消权利的「有关单位或个人」）
4. 义务须合法，不得违反法律强制性规定

---

### 步骤四：遗赠与遗嘱继承的区分

| 对比维度 | 遗嘱继承 | 遗赠 |
|---------|---------|------|
| **受益人身份** | 法定继承人（配偶/子女/父母/兄弟姐妹等） | 法定继承人**以外**的个人或组织 |
| **接受方式** | 继承人可默认接受；放弃须书面 | 受遗赠人须**明示接受**，否则视为放弃（须在知道受遗赠后的法定期限内，具体期限 `[待验证]`） |
| **遗产税/继承费用** | 依法定规则 | 相同（须核实 `[待验证]`） |
| **内容区分** | 遗嘱指定法定继承人获得遗产 | 遗嘱指定继承人以外的人/组织获得遗产 |

**实践建议**：在遗嘱中明确区分遗嘱继承部分（给法定继承人）与遗赠部分（给法定继承人以外的人），分别列示，避免混淆。

## 错误处理

| 错误情形 | 处理方式 |
|---------|---------|
| 遗嘱未为必留份受益人保留份额 | 标注 🔴 关键，须修改遗嘱内容为其保留必要份额；提示违反第1141条的遗嘱该部分无效 |
| 遗嘱处分了配偶/他人的财产 | 标注 🟠 高风险，提示超出部分无效；建议修改遗嘱明确处分范围为遗嘱人个人部分 |
| 附义务内容模糊无法执行 | 提示须将义务具体化（金额/方式/期限/监督人），否则履行义务认定困难 |
| 受遗赠人是法定继承人 | 提示其身份定性为「遗嘱继承」而非「遗赠」，接受方式不同（无需明示接受） |
| 财产描述不准确（如房产地址不完整） | 提示须补充准确描述（房产证编号/不动产权证书编号/地址），避免过户争议 |

## 详细步骤

### 步骤一：见证人资格排除清单

依据民法典第1140条（中度把握，建议复核）：

**以下人员不能作为遗嘱见证人：**

| 排除类型 | 具体情形 | 原因 |
|---------|---------|------|
| **无民事行为能力人** | 未满8周岁的未成年人；无行为能力的精神障碍患者 | 无见证能力 |
| **限制民事行为能力人** | 8-18周岁未成年人；精神障碍处于发作状态 | 见证能力受限 |
| **其他不具有见证能力的人** | 视听障碍等导致无法有效见证（描述规则，具体认定 `[待验证]`） | 无法有效见证 |
| **继承人** | 遗嘱指定的继承人（无论其最终是否获益） | 利益冲突 |
| **受遗赠人** | 遗嘱指定的遗赠受益人 | 利益冲突 |
| **与继承人有利害关系的人** | 继承人/受遗赠人的配偶、父母、子女、兄弟姐妹等近亲属 | 间接利益冲突 |
| **与受遗赠人有利害关系的人** | 受遗赠人的近亲属等 | 间接利益冲突 |

> **「利害关系」的范围**：以「与继承人或受遗赠人有共同利益关系」为判断标准，具体认定由法院裁量（描述规则，条号 `[待验证]`）。实践中，继承人/受遗赠人的配偶及直系亲属通常被认定为有利害关系。

#### 合格见证人的正向标准

| 合格条件 | 说明 |
|---------|------|
| 完全民事行为能力 | 年满18周岁且精神状态正常（或年满16周岁以自己劳动收入为主） |
| 与继承/受遗赠人无利害关系 | 最好选择与遗嘱人家庭无关联的社区成员、同事、朋友等 |
| 了解立遗嘱过程 | 全程在场，亲眼见证遗嘱人的立遗嘱行为 |

### 步骤二：各遗嘱形式见证与生效要件核对表

| 遗嘱形式 | 见证人数 | 见证方式 | 遗嘱人签名 | 见证人签名 | 日期要求 | 其他要件 |
|---------|---------|---------|---------|---------|---------|---------|
| **自书遗嘱** | 无需见证人 | — | 遗嘱人亲笔签名 | — | 遗嘱人注明年、月、日 | 全文须亲笔书写 |
| **代书遗嘱** | ≥2人（含代书人） | 全程在场见证 | 遗嘱人签名 | 代书人+全部见证人均须签名 | 注明年月日 | 一人代书，见证人须独立见证（不可仅代书人完成所有步骤） |
| **打印遗嘱** | ≥2人 | 全程在场见证 | **每一页**遗嘱人签名 | **每一页**全部见证人签名 | 注明年月日（每页须有） | 见证人须独立签名（非仅在末页） |
| **录音录像遗嘱** | ≥2人 | 在录音录像中记录 | 录音录像中遗嘱人说出/展示姓名 | 录音录像中见证人说出/展示姓名或肖像 | 录音录像中记录年月日 | 见证人须在录音录像中记录其姓名或肖像；录制时间须明确 |
| **口头遗嘱** | ≥2人 | 全程在场见证 | — | 见证人记录并签名（以书面方式记录） | 见证人记录立遗嘱日期 | **仅限危急情况**；危急解除后失效 |
| **公证遗嘱** | 公证员（代替见证人） | 公证机构办理 | 在公证机构签名 | 公证员签署 | 公证机构记录 | 无需额外见证人；公证机构存档 |

> **关键提示——打印遗嘱「每一页」签名**：第1136条要求遗嘱人和见证人在遗嘱**每一页**上签名。遗嘱共3页则须3页均有签名，不得仅在末页签名。这是打印遗嘱最常见的无效陷阱之一。

### 步骤三：「在场见证」要件解析

#### 3.1 「在场见证」的含义

「两名以上见证人在场见证」不仅指见证人在同一场所，还要求见证人：

| 要求 | 说明 |
|------|------|
| **全程在场** | 从遗嘱人开始代书/打印/录音录像/口头表达，到完成签名/日期注明，须全程在场 |
| **亲眼见证** | 见证人须实际目击遗嘱人表达遗嘱内容的过程及签名行为 |
| **独立见证** | 见证人须独立判断，不得仅凭代书人/律师事后告知而签名确认 |

#### 3.2 远程见证的争议

目前司法实践对**视频远程见证**（如视频通话方式的见证）是否满足「在场见证」要求存在争议（描述规则，`[待验证]`）。建议谨慎对待远程见证方式，优先选择同一场所的现场见证。

---

### 步骤四：遗嘱执行人与遗产管理人

#### 4.1 遗嘱执行人

遗嘱人可在遗嘱中**指定遗嘱执行人**（无法律强制要求，但指定可减少继承争议）。

| 方面 | 说明 |
|------|------|
| 指定方式 | 在遗嘱中明确指定姓名及联系方式 |
| 职责 | 执行遗嘱内容：管理遗产、分配遗产给继承人/受遗赠人、处理遗产债务 |
| 身份限制 | 无法律限制（可以是继承人本人，但可能有利益冲突风险） |
| 未指定时 | 由继承人推选遗产管理人，或由继承人共同担任 |

**遗嘱中指定遗嘱执行人的建议条款**：

```
遗嘱执行人：本人指定 [姓名]（身份证号：[XXXXXXXXXX]，联系方式：[XXXXXXXXXX]）
为本遗嘱的遗嘱执行人，授权其依照本遗嘱内容管理和分配本人遗产。
```

#### 4.2 遗产管理人（民法典第1145条，建议复核）

遗产管理人与遗嘱执行人的区别：

| 对比维度 | 遗嘱执行人 | 遗产管理人 |
|---------|---------|---------|
| **产生方式** | 遗嘱人指定 | 继承人推选（无遗嘱执行人时）；或由法定来源产生 |
| **适用情形** | 有指定遗嘱执行人的情形 | 无遗嘱执行人时（继承人推选、共同担任、民政部门/村委会） |
| **法律地位** | 第1145条：遗嘱执行人为遗产管理人（即遗嘱执行人同时履行遗产管理人职责） | 有遗嘱执行人时，其为遗产管理人；无时，按继承人推选规则 |
| **职责** | 执行遗嘱内容 | 管理遗产、清偿债务、分配遗产 |

依据民法典第1145条（中度把握，建议复核）：

> 继承开始后，遗嘱执行人为遗产管理人；没有遗嘱执行人的，继承人应当及时推选遗产管理人；继承人未能推选的，由继承人共同担任遗产管理人；没有继承人或者继承人均放弃继承的，由被继承人生前住所地的民政部门或者村民委员会担任遗产管理人。

### 步骤五：遗嘱保管与生效

#### 5.1 遗嘱生效时间

**遗嘱在遗嘱人死亡时生效**——遗嘱的法律效力在遗嘱人死亡时才发生，遗嘱人生前可随时撤回或修改。

| 规则 | 说明 |
|------|------|
| 生效时间 | 遗嘱人死亡时生效 |
| 有效期 | 遗嘱无有效期（只要未被撤回/修改，自立遗嘱时起均有效） |
| 撤回修改 | 遗嘱人生前任何时候可撤回或修改遗嘱（民法典第1142条，建议复核） |

#### 5.2 遗嘱原件保管建议

| 保管方式 | 说明 | 优缺点 |
|---------|------|-------|
| **遗嘱人自行保管** | 存放于保险箱/私人存储 | 优：保密；缺：死亡后可能难以找到 |
| **律师/律所保管** | 委托律师保管原件 | 优：专业、死亡后可及时通知；缺：律所关闭风险 |
| **公证机构存档** | 公证遗嘱由公证机构档案存档 | 优：可核查；缺：修改须通过公证机构 |
| **告知受信任的人** | 告知至少一名受信任的人遗嘱原件存放位置 | 重要：防止原件无法找到 |
| **多份副本** | 多份副本存放不同地点 | 注意：副本须与原件内容完全一致 |

## 边界条件

| 边界情形 | 处理方式 | 风险等级 |
|---------|---------|---------|
| 见证人临时回避（立遗嘱中途离开又返回） | 须全程在场，中途离开可能影响「在场见证」要件认定，建议重新完成见证 | 🟠 高 |
| 远程见证效力存疑（视频见证） | 建议谨慎，远程见证「在场」要件不明确，可能被质疑无效 `[待验证]` | 🟠 高 |
| 遗嘱原件丢失（仅有副本） | 遗嘱效力认定困难，须通过其他证据证明内容；无原件时遗嘱继承执行难度大 | 🟠 高 |
| 见证人签名为手印而非书写签名 | 各形式要件中均要求「签名」，手印是否等同于签名存在争议（描述规则，`[待验证]`）；建议优先使用书写签名 | 🟡 中等 |
| 见证人死亡（无法作证） | 见证人在遗嘱生效前死亡，应通过其他方式（录音录像/留存见证记录）证明见证事实 | 🟡 中等 |

## 错误处理

| 错误情形 | 处理方式 |
|---------|---------|
| 见证人为继承人/受遗赠人 | **立即标注 🔴 关键**，该见证人不适格，须更换合格的见证人重新见证；不合格见证人参与的遗嘱形式要件不满足 |
| 打印遗嘱某页漏签 | **立即标注 🔴 关键**，须在遗嘱人和全部见证人在场时补签，或重新立遗嘱（补签是否有效存争议，建议重新立）|
| 口头遗嘱危急情况已解除但未转书面 | **立即标注 🔴 关键**，提示口头遗嘱已无效，须立即安排书面/录音录像形式立遗嘱 |
| 见证人只有一名（不足两名） | 标注 🔴 关键，须增加至少一名合格见证人重新见证 |
| 未注明完整日期（仅年月无日） | 标注 🟠 高风险，日期不完整的遗嘱可能被认定为形式要件不满足；建议补注日（可通过重新立遗嘱确保） |
| 见证人不确定是否与利害关系人相关 | 提示核实见证人与各继承人/受遗赠人的关系，不确定时建议更换无疑虑的见证人 |

## 法律依据

### 法条（来源：民法典继承编，中度把握锚点）

**第1140条 — 见证人资格限制**
- 《中华人民共和国民法典》**第1140条** `[模型知识 — 需验证]` 中度把握，建议复核
- 无民事行为能力人、限制民事行为能力人及不具有见证能力的人不能作见证人；继承人、受遗赠人不能作见证人；与继承人、受遗赠人有利害关系的人不能作见证人

**第1145条 — 遗产管理人**
- 《中华人民共和国民法典》**第1145条** `[模型知识 — 需验证]` 中度把握，建议复核
- 遗嘱执行人为遗产管理人；无遗嘱执行人时，继承人推选或共同担任；无继承人时，民政部门或村委会担任

**第1134-1139条 — 各遗嘱形式生效要件**
- 《中华人民共和国民法典》**第1134-1139条** `[模型知识 — 需验证]` 已核实锚点（中度把握），建议复核
- 自书遗嘱、代书遗嘱、打印遗嘱、录音录像遗嘱、口头遗嘱、公证遗嘱各自的见证与签名日期要件（参见 will-form-selection 详细要件表）

**第1142条 — 遗嘱撤回变更（生效相关）**
- 《中华人民共和国民法典》**第1142条** `[模型知识 — 需验证]` 中度把握，建议复核
- 遗嘱人可撤回、变更遗嘱；最后遗嘱为准

### 司法解释（描述规则，条号待验证）

**关于「利害关系」认定的司法解释规则**（继承编司法解释，描述规则）
- 规则描述：「与继承人或受遗赠人有利害关系」的范围由法院综合考量，通常包括继承人/受遗赠人的配偶、父母、子女等近亲属 `[模型知识 — 需验证]` `[待验证]`
