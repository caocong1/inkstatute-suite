## 当事人情绪护栏

> **贯穿全程，凌驾于代理立场之上。**

- 输出措辞**中立、克制、非煽动**：不替当事人作情绪化判断，不描述对方的主观动机
- **不激化对立**：不使用「对方在利用你」「对方心怀不轨」等加剧冲突的语言
- **识别情绪危机信号**：如当事人表达自我伤害、极度绝望等信号，**暂停法律分析**，提示专业心理支持（如拨打心理援助热线 400-161-9995 或当地援助热线）
- **不判断对错**：提供法律分析而非道德评判

## 未成年人利益最大化护栏

> **贯穿子女抚养与探望子技能，凌驾于代理立场之上。**

- 以「最有利于未成年子女」为首要原则（民法典第1084条，建议复核）
- 子女有独立利益主体地位，不等于父母任何一方的利益
- 8周岁以上子女须尊重其真实意愿
- 涉未成年人重大利益（主要抚养权/子女生活保障）须强制升级

详细护栏内容见：`family-legal/CLAUDE.md ## 共享护栏 ### 未成年人利益最大化护栏` 与子技能 `本文档「子技能：child-custody-visitation」章节`。

## 协议不成转诉讼提示

如双方就协议条款无法达成一致（特别是财产分割或子女抚养存在重大分歧），提示：

1. 可聘请**家事调解机构**协助调解（成本低于诉讼，基层法院或社会组织提供）
2. 如调解失败，一方可向**基层人民法院家事审判庭**提起**诉讼离婚**（民法典第1079条，建议复核）
3. 诉讼离婚**无冷静期**，法院调解后如感情确已破裂可判决离婚并直接裁决财产/子女安排
4. 家暴/虐待/遗弃/分居满两年等情形为法定准予诉讼离婚情形（第1079条，建议复核）

## 详细步骤

### 步骤一：财产清单梳理

**1.1 夫妻共同财产清单**（依据民法典第1062条，建议复核）

引导当事人逐类梳理：

| 财产类型 | 典型示例 | 权属性质判断要点 | 证明材料 |
|---------|---------|----------------|---------|
| 不动产（房产） | 婚后购买的房产 | 购买时间（婚前/婚后）、出资来源（个人/共同/父母）、登记名称 | 房产证/不动产权证/购房合同/网签备案/还贷记录 |
| 银行存款 | 婚后共同账户存款 | 工资及经营收入一般为共同财产 | 银行流水（婚后开始）/定期存款证明 |
| 车辆 | 婚后购买的机动车 | 购买时间（婚前/婚后）、出资来源 | 行驶证/购车发票/登记证书 |
| 股权与公司份额 | 婚后出资设立或增资的公司股权 | 出资来源（婚前/婚后）、股权评估价值 `[待评估]` | 工商登记信息/出资证明/审计报告 |
| 股票/基金/债券 | 婚后购买的证券投资 | 购买时间与资金来源 | 证券账户/基金账户截图（日期确认） |
| 知识产权收益 | 婚后取得的著作权/专利许可费 | **注意**：知识产权本身可能为个人，但婚后收益归共同财产 | 合同/许可协议/收款记录 |
| 保险现金价值 | 婚后缴费的寿险/年金保险 | 婚后缴纳部分的现金价值 | 保险合同/缴费记录/现金价值证明 |
| 对他人债权 | 婚后共同借出的款项 | 出借时间与资金来源 | 借条/转账记录/法院判决 |

**1.2 夫妻个人财产清单**（依据民法典第1063条，建议复核）

| 财产类型 | 认定要点 | 证明材料 |
|---------|---------|---------|
| 婚前房产 | 购买于婚前，或婚前签订合同/付款、婚后取得登记 | 房产证（登记日期）/购房合同（签订日期）/付款记录 |
| 婚前存款 | 明确为婚前积累的存款 | 银行流水（婚前开始，金额对应） |
| 人身损害赔偿 | 一方因人身损害获得的赔偿/补偿（含残疾赔偿金/医疗费/精神损害抚慰金） | 法院判决/调解协议/赔偿协议 |
| 遗嘱/赠与明确归一方 | 遗嘱或赠与合同明确只归一方的财产 | 遗嘱文件/赠与合同（明确「只归一方」） |
| 一方专用生活用品 | 个人日常使用的生活用品（手表/首饰等一般不超过个人日常消费范围） | 购买凭证 |

**特别注意——婚前房产婚后增值**：婚前个人购买，婚后价值增长，增值部分性质存在争议。司法实践中，自然增值（市场行情增长）一般仍属个人财产，主动增值（婚后共同装修/改扩建）部分可能涉及补偿。具体处理须结合司法解释（**描述规则，具体条号 `[待验证]`**）和当地裁判口径（`[地方 flagged — 需核实当地裁判口径]`）。

### 步骤二：各类财产分割条款拟定

**2.1 房产分割条款要点**

| 场景 | 分割方案选项 | 条款要点 |
|------|------------|---------|
| 共同购买，双方都想要 | 折价补偿（一方支付另一方市值一半） | 评估价值确定方式（双方协议/评估机构）、补偿金额、支付期限、过户时间 |
| 共同购买，一方不想要 | 直接归属（归一方，支付折价） | 同上 |
| 一方婚前购买，婚后共同还贷 | 归产权方，另一方获还贷补偿 | 婚后还贷总额、增值分摊（描述规则，条号 `[待验证]`），补偿金额须明确计算依据 |
| 父母出资 | 按出资性质（赠与/借款）确定 | 须明确父母出资属于对哪方的赠与，或双方均等赠与，影响共同财产认定 |

**房产分割条款模板结构**：
```
第X条 [房产描述（地址、不动产权证号）] 归 [甲/乙] 方所有，
[甲/乙] 方于本协议生效后 [X] 个工作日内协助办理产权过户手续，
过户所需税费由 [甲/乙/双方按比例] 承担。
[另一方] 在 [日期] 前一次性支付 [金额] 元作为折价补偿。
房产上现有抵押贷款余额由 [甲/乙/双方] 负责还清。
```

**2.2 存款分割条款要点**

- 明确分割的账户（银行+账号后四位）和金额
- 注意：婚后共同积累的存款为共同财产，婚前存款须提供证明
- 条款须写明划转方式（转账/提现）和时间

**2.3 股权/公司份额分割条款要点**

- 股权价值须通过评估确定（`[待评估]`，建议聘请评估机构），不得单方低价定价
- 分割方式：折价补偿（股权归一方，支付等值补偿）或股权转让（须公司章程/其他股东审查）
- **注意**：公司股权分割须防止影响公司正常经营，条款须明确过渡安排

**2.4 投资类资产分割条款（股票/基金/债券）**

- 以协议签署日或约定日期的市值为准（明确取值时间点防争议）
- 证券账户直接归属的，明确账户归属与转移方式
- 不能直接分割的，一方折价补偿另一方

**2.5 知识产权收益分割**

- 婚后已发生的收益归共同财产，须列明
- **注意**：知识产权本身如专利/著作权，如系婚后取得但具有人身属性，归属处理须谨慎
- 婚后尚未支付但已到期的许可费、版税，确认归属

### 步骤三：隐瞒财产救济保留条款

**强烈建议在协议中加入以下救济保留条款**（依据民法典第1092条，建议复核）：

```
第X条（财产如实申报与后续救济）
双方承诺本协议所列财产清单系夫妻共同财产与个人财产的完整申报，
未存在隐藏、转移、变卖、毁损或挥霍夫妻共同财产，
也未伪造共同债务的行为。

如一方日后发现另一方在协议签署前存在上述行为，
受损害方保留向人民法院提起诉讼、请求再次分割的权利，
不受本协议财产分割条款约束。
（法律依据：民法典第1092条，建议复核）
```

**主张方重点**：此条款保障日后发现隐匿财产时可再次主张；建议同时在协议中写入「对方有如实申报义务，如日后发现隐瞒财产，按隐瞒价值的一定比例赔偿」（具体约定，须律师审核合法性）。

**被主张方重点**：如对方声称发现未申报财产，须有书面证据支持，不能凭口头主张撤销已签协议；协议中明确确认「本协议为双方真实意思表示，对财产清单已充分知情」以防对方事后滥用第1092条。

- **整体代理立场**：离婚一方侧（主张抚养方/被主张方）/ 中立审查
- **涉未成年子女事项**（`## 敏感度校准`）：是否有涉未成年人特殊情形
- **家暴识别等级**：是否有家暴或虐待子女情形

如果配置缺失，以临时模式继续，**敏感度默认最高，未成年人利益最大化护栏强制开启**。

### 2. 未成年人利益最大化护栏（贯穿全程）

> **本护栏不得被任何代理立场覆盖。**

无论代理哪方，以下原则须始终贯穿：

- 子女有独立的利益主体地位，其利益不等同于父母任何一方的利益
- 任何抚养权安排须以「最有利于未成年子女的生活成长」为判断标准，不是以「父母哪方更强势」为判断标准
- 已满8周岁子女的真实意愿须被尊重，不得替代子女表达意见
- 即使为被代理方，若某安排损害子女利益，须明确标注并建议调整

### 3. 代理立场区分

| 立场 | 审查侧重 |
|------|---------|
| **主张抚养方（争取抚养权一方）** | 关注抚养权归属论证（年龄/生活环境/抚养能力）、抚养费标准不低于合理水平、探望权安排合理不过度 |
| **被主张方（可能失去抚养权一方）** | 关注探望权充分保障、探望时间/地点/方式明确不受阻挠、抚养费标准合理 |
| **中立审查** | 双向识别：双方能力综合评估、子女意愿、探望安排可执行性 |

### 4. 敏感情形识别

- **家庭暴力/虐待子女**（🔴关键）：若一方有对子女实施暴力/虐待的情形，须**强制升级**，家暴情形下不宜将抚养权判给施暴方
- **抢夺藏匿子女**（🔴关键）：识别到一方在离婚过程中擅自带走/藏匿子女，标注 🔴 关键，**强制升级律师**，提示申请人身安全保护令及扣押子女令
- **当事人情绪极度激动**（🟠高）：确保分析不激化对立，措辞中立克制

## 详细步骤

### 步骤一：子女基本情况核查

收集以下信息：

| 信息项 | 内容 | 对抚养权判断的影响 |
|--------|------|-----------------|
| 子女年龄 | 出生年月 | 不满2周岁：母亲原则；2-8周岁：综合考量；8周岁以上：参考子女意愿 |
| 就读情况 | 学校/幼儿园/所在城市 | 影响抚养权归属（通常以不变动子女生活学习环境为佳） |
| 与父母同住情况 | 目前随哪方生活 | 已稳定同住的一方通常有优势 |
| 子女健康状况 | 有无特殊疾病/残障/心理状况 | 特殊需求可能要求特定医疗资源或照护能力 |
| 子女意愿（8周岁以上） | 子女希望跟谁生活 | 须尊重（第1084条），但不等于绝对服从；须核实意愿的真实性与稳定性 |

### 步骤二：抚养权归属分析

**2.1 法定抚养权原则**（依据民法典第1084条，建议复核）

| 子女年龄段 | 法定原则 |
|-----------|---------|
| 不满2周岁 | 以由**母亲直接抚养为原则**；但母亲有重大疾病/不利于子女成长的特殊情形除外（具体情形描述规则，条号 `[待验证]`） |
| 2-8周岁 | 按**最有利于未成年子女的原则**判定，综合考量双方条件 |
| 8周岁以上 | 应**尊重子女的真实意愿** |

**2.2 抚养权归属综合考量因素**

| 考量因素 | 说明 |
|---------|------|
| 稳定的生活成长环境 | 哪方能为子女提供稳定住所、学校不变化 |
| 抚养能力与日常照料 | 哪方实际承担日常照料（接送上学/辅导作业/医疗护理） |
| 经济条件 | 哪方能提供充足的经济保障（注意：经济条件不是唯一因素） |
| 品德与教育能力 | 双方的品行、教育理念与子女的契合度 |
| 工作时间与陪伴能力 | 哪方有更多时间陪伴子女 |
| 与子女的感情基础 | 子女与哪方的感情更深厚（注意家暴/虐待情形须过滤） |
| **家庭暴力情形** | 有家暴/虐待记录的一方通常不应获得直接抚养权 |
| 是否有意阻断另一方与子女联系 | 抢夺藏匿子女、阻止探望的一方抚养能力存疑 |

**2.3 主要抚养权协议条款拟定**

```
第X条（子女抚养权）
[子女姓名]（出生日期：[日期]），离婚后由[甲/乙]方直接抚养。
[对方]仍享有探望权，双方均有继续履行对子女抚养、教育、保护的义务。
```

**注意**：「直接抚养」（与子女同住、日常照料）与「法定监护权」（父母双方均自然享有）须区分，离婚不改变父母均为监护人的法律地位。

### 步骤三：抚养费标准与支付安排

**3.1 抚养费标准参考**（司法实践惯例，具体数字须核实当地裁判口径）

司法实践中一般参考月均收入比例确定，常见标准（**描述规则，具体比例须核实现行当地裁判口径 `[地方 flagged — 需核实当地裁判口径]`**）：

- 一个子女：月均收入的一定比例（各地惯例有差异）
- 多个子女：按子女数量适当调整比例
- 固定收入参考工资流水；非固定收入（经营/自由职业）参考年均收入核算月均

**3.2 抚养费支付条款要素**

| 条款要素 | 说明 |
|---------|------|
| 支付金额 | 明确每月金额（如约定调整机制也须明确触发条件） |
| 支付方式 | 银行转账到指定账户（保留流水）；避免现金以防争议 |
| 支付时间 | 每月X日前到账 |
| 支付期限 | 至子女年满18周岁（或完成大学教育，须明确上限） |
| 大额费用分担 | 教育（择校费/学杂费）/医疗（重大疾病/手术）/其他重大支出如何分担（建议另行协商或按比例） |
| 调整机制 | 一方收入变化超过一定比例时，可申请法院变更抚养费（无需写入协议，法律已有规定，但可约定双方协商优先） |

**3.3 抚养费条款模板**：

```
第X条（抚养费）
[甲/乙]方每月向另一方支付[子女姓名]的抚养费人民币 [金额] 元，
于每月[X]日前转入[甲/乙]方名下银行账户（账号：[XXXX]）。
上述抚养费支付至[子女姓名]年满十八周岁之日止，
或在此之前完成[大学本科]教育止（以较晚者为准，双方另行协商）。

以下费用由双方各承担50%（或约定比例）：
- 每学年学杂费（学费/住宿费）超过 [金额] 元的部分
- 重大疾病（单次医疗费超过 [金额] 元）的医疗费用
其他重大支出经双方协商决定。
```

### 步骤四：探望权安排条款

**4.1 探望权的法律基础**（民法典第1086条，中度把握，建议复核）

不直接抚养方有探望权，另一方有协助义务。探望不利于子女身心健康的，可申请法院中止。

**4.2 探望权安排要素**

| 安排要素 | 常见方案示例 | 注意事项 |
|---------|------------|---------|
| 常规探望频率 | 每两周一次（周末）；或每周X、X | 须具体明确，避免「适时探望」等模糊表述 |
| 探望时长 | 每次 [X] 天（如周六上午至周日晚）| 注意学习日安排对子女的影响 |
| 探望地点 | 接送地点（如学校/约定地点）；是否可带子女过夜 | 注意异地探望的交通安排 |
| 假期探望 | 寒暑假轮流/平分；法定节假日安排 | 明确哪一年哪方优先 |
| 接送安排 | 由哪方负责接送，或自行安排 | 异地须明确交通费承担 |
| 通讯联系 | 非探望期间电话/视频联系频率 | 建议写入「每周不少于X次电话/视频」 |

**4.3 探望权条款模板**：

```
第X条（探望权）
[未直接抚养方（甲/乙）]享有探望[子女姓名]的权利，
[直接抚养方]有协助义务，不得无故阻止探望。

常规探望安排：
（一）每[两周/月]一次，时间为[周六]上午[10:00]起至[周日]晚[18:00]止；
（二）在[指定地点/学校]接送；
（三）寒暑假及法定长假期间，双方另行协商安排（原则上各一半时间）；
（四）非探望期间，[甲/乙]方可通过电话/视频与子女保持联系，每周不少于[X]次。

如上述探望安排因子女升学、工作变动等重大情况需要调整，
双方协商一致后可变更，如协商不成可申请法院调整。
```

**未成年人保护提示**：探望安排须以子女的生活秩序和心理健康为首要考量；如探望方有家暴或虐待行为，另一方可向法院申请中止探望（须证据支持）。

### 步骤五：抚养关系变更情形约定

**法律允许在以下情形变更抚养权**（条号 `[待验证]`，描述规则）：

| 变更情形 | 说明 |
|---------|------|
| 直接抚养方患重大疾病 | 无力继续抚养子女 |
| 直接抚养方虐待、放弃抚养 | 严重损害子女利益 |
| 子女已满8周岁明确表示愿与另一方生活 | 尊重子女真实意愿 |
| 直接抚养方就学/工作安排明显不利于子女成长 | 须综合评估 |

**建议在协议中加入**：

```
第X条（抚养关系变更）
双方同意，如发生以下情形之一，另一方可要求变更直接抚养关系，
双方优先协商；协商不成可申请人民法院调整：
（一）直接抚养方患重大疾病或无力继续抚养；
（二）直接抚养方虐待子女或严重损害子女身心健康；
（三）[子女姓名]年满八周岁后明确表示愿与另一方生活。
```

> **前置依赖**：读取 `family-legal/CLAUDE.md` 实践配置（代理立场·协议审查严格度·敏感度校准），引用 `../_shared/family-law-citations.md` 引用库。
> **分工说明**：本技能专注债务处理；财产分割由 `property-division-clauses` 处理；协议生效与登记由 `effectiveness-registration` 处理。
> **关键纪律**：夫妻共同债务认定规则来自司法解释，**描述规则，不写裸条号，具体条号 `[待验证]`**。

---

## 目的

分析离婚协议中的债务处理条款，覆盖夫妻共同债务与个人债务的认定、债务清单梳理、对外清偿责任与内部分担约定、债务条款的对外效力局限。确保债务处理条款合法合理，保护当事人不承担非共同债务，同时明确善意第三人（债权人）的权利边界。

---

## 前置

### 1. 读取实践配置

读取 `family-legal/CLAUDE.md`，重点检查：

- **整体代理立场**：主张方（希望将债务定性为对方个人债务）/ 被主张方（希望将债务认定为共同债务以分担）/ 中立审查
- **协议审查严格度**：保守（任何不利条款标红）/ 平衡 / 进取
- **主要痛点**（`## 我们是谁`）：是否有虚构债务/大额经营债务/担保债务等特殊情形

如果配置缺失，以临时模式继续。

### 2. 代理立场区分

| 立场 | 审查侧重 |
|------|---------|
| **主张方（希望债务定性为对方个人债务）** | 关注举证责任分配（债权人须证明该债务用于共同生活/经营）、认定为个人债务后本方无清偿义务 |
| **被主张方（对方主张本方承担共同债务）** | 关注共同债务认定要件（是否共同签名/追认/是否用于家庭日常生活）、个人债务剥离、虚构债务识别 |
| **中立审查** | 双向识别共同债务与个人债务的认定争议点 |

### 3. 敏感情形检查

- **虚构债务（🔴关键）**：识别到一方在离婚前虚构债务，试图侵占另一方财产——标注 🔴 关键，强制升级律师，提示作为第1092条隐匿/伪造债务处理
- **大额经营债务（🟠高）**：一方以个人名义举借大额经营性债务，涉及债权人权益——提示需要律师评估对外效力

### 步骤一：债务清单梳理

**1.1 债务类型识别与分类**

| 债务类型 | 典型示例 | 初步归类 | 证明材料 |
|---------|---------|---------|---------|
| 住房抵押贷款 | 婚后共同购房的房贷 | 通常为共同债务 | 借款合同/房贷余额证明 |
| 消费类信贷/信用卡 | 婚后的信用卡分期/消费贷 | 视用途而定（家庭日常消费一般为共同）| 信用卡账单/贷款合同 |

| 经营性债务 | 一方以个人名义为经营活动借款 | 须核实：是否超出家庭日常生活需要？债权人是否知情 | 借款合同/资金用途记录 |

### 步骤二：共同债务认定分析

**2.1 共同债务认定规则**（最高法婚姻家庭编司法解释(一)，**描述规则，条号 `[待验证]`**）

司法解释确立了以下共同债务认定路径：

**路径一：共债共签**
夫妻**双方共同签名**，或夫妻一方所负债务经另一方**事后追认**，为夫妻共同债务。
- 适用场景：购房借款（双方签名）、大额家庭消费（双方签名）
- 举证要求：债权人举证双方签名或追认的证明

**路径二：家庭日常生活需要**
夫妻一方在婚姻关系存续期间以**个人名义**为**家庭日常生活需要**所负的债务，为夫妻共同债务。
- 适用场景：日常生活费用、子女教育费用、家庭医疗费用、日常消费类信用卡
- 「家庭日常生活需要」的范围由法院根据双方收入水平、生活消费习惯等综合判断（无固定标准，`[地方 flagged]`）

**路径三：超出家庭日常生活需要须债权人举证**
夫妻一方在婚姻关系存续期间以个人名义**超出家庭日常生活需要**所负的债务，**债权人须举证**证明该债务用于夫妻共同生活、共同生产经营，或基于夫妻双方共同的意思表示，否则不认定为夫妻共同债务。
- 适用场景：大额经营性贷款、为他人担保债务、超出家庭消费能力的大额债务
- 举证责任在债权人而非债务人配偶

**2.2 个人债务情形**

| 个人债务情形 | 认定依据 |
|------------|---------|
| 婚前以个人名义所负的债务 | 婚前债务，配偶未共同签名 |
| 婚姻关系存续期间以个人名义负债，但与家庭无关 | 个人挥霍、违法犯罪、赌博等未用于家庭生活 |
| 未共同签名且超出家庭日常生活需要、债权人无法举证用于共同生活 | 依据路径三 |
| 担保债务（未经另一方签名/追认） | 个人单方行为 |

### 步骤三：对外清偿与内部分担

**3.1 核心原则（必须理解）**

> **离婚协议约定债务由一方承担，不能对抗善意债权人（对外效力局限）。**
>
> 内部约定（如「房贷由甲方承担」）仅对双方有约束力，**善意债权人依然可以向双方主张还款**，一方代替另一方还款后，可向另一方追偿。

这一原则必须在条款中明确告知当事人，防止误解「协议约定谁承担谁就不用管」。

**3.2 对外清偿与内部分担条款结构**

对于夫妻共同债务，协议通常包含两层约定：

**第一层：内部分担（对夫妻双方有效）**
```
第X条（共同债务内部分担）
以下债务系夫妻共同债务，离婚后由[甲/乙]方负责对外清偿：
（一）[债务名称，如：XX银行住房抵押贷款]，余额约 [金额] 元，由[甲/乙]方负责按期还款；
（二）[其他债务]……

双方同意，如上述债务由[另一方]代为清偿，[代偿方]有权向[应还方]追偿全额还款及合理费用。
```

**第二层：免除连带责任说明（仅供内部参考，不能对抗债权人）**
```
（以上内部约定仅在双方之间有效。上述债务的债权人依法有权向任何一方主张还款，
本约定不影响债权人对本合同任何一方的债权主张，但应还方应向代偿方偿还。）
```

**3.3 个人债务确认条款**

```
第X条（个人债务确认）
以下债务由债务人（[甲/乙]方）在婚姻关系存续期间以个人名义所负，
不属于夫妻共同债务，由债务人自行清偿，另一方不承担连带清偿责任：
（一）[债务名称]，余额约 [金额] 元；
（二）[其他债务]……

如债权人就上述个人债务主张另一方承担连带清偿责任，
另一方有权提出异议并要求债权人出示共同债务的证明。
```

**3.4 担保债务处理**

如一方在婚姻关系存续期间未经另一方知情或同意为他人提供担保：

```
第X条（担保债务）
[甲/乙]方在婚姻关系存续期间为[债务人名称]担保的债务，
系[甲/乙]方个人行为，另一方对此不知情/未签名/未追认，
不属于夫妻共同债务，由[甲/乙]方自行承担担保责任。
```

### 步骤四：虚构债务识别与处理

**识别信号**（任一出现须标注并提示）：

- 离婚前短期内突然出现大额新债务
- 债权人为亲属/密友，缺乏真实交易背景
- 债务金额与家庭收入/消费水平严重不符
- 无法提供资金流向证明（钱用于哪里）
- 对方拒绝提供借条/转账记录/用途说明

**处理方式**：

标注 🔴 关键（第1092条，建议复核）——虚构债务属于「伪造夫妻共同债务企图侵占另一方财产」，可主张少分或不分财产，并提示当事人保留追诉权：

```
第X条（虚构债务追责）
[甲/乙]方承诺本协议所列债务系真实债务，未存在虚构、伪造债务以侵占另一方财产的行为。
如日后发现存在虚构债务行为，另一方有权依据民法典第1092条请求再次分割财产，
并保留追究[甲/乙]方相应法律责任的权利。
```

| 情形 | 处理方式 | 升级/标注 |
|------|---------|---------|
| 大额举债的共同债务认定争议（路径三） | 须评估债权人能否举证资金用于共同生活；建议律师评估诉讼风险 | 建议律师介入 |

## 错误处理

| 错误类型 | 识别信号 | 处理方式 |
|---------|---------|---------|
| 虚构债务（🔴关键） | 大额债务突然出现/资金流向不明/债权人为亲属 | **强制升级**，提示第1092条伪造债务处理 |
| 混淆「协议约定」与「债权人无法追偿」| 当事人以为协议写明谁还款债权人就只能找那人 | 明确说明协议内部分担不对抗善意债权人 |

## 目的

分析离婚协议的生效程序、冷静期规则、协议反悔与可撤销情形、财产分割协议与离婚登记生效的关联效力，以及协议不成时的诉讼路径衔接。确保当事人理解协议从签署到生效的全过程，及时行使冷静期撤回权利，或在协议显失公平/存在意思表示瑕疵时获得救济。

### 1. 读取实践配置

读取 `family-legal/CLAUDE.md`，重点检查：

- **整体代理立场**：主张方（希望协议尽快生效）/ 被主张方（可能希望利用冷静期撤回/主张协议可撤销）/ 中立审查

如果配置缺失，以临时模式继续。

### 2. 代理立场区分

| 立场 | 审查侧重 |
|------|---------|
| **主张方（希望协议尽快生效）** | 关注冷静期期满后及时共同申请发证、协议条款可执行性、防止对方利用冷静期反悔后转诉讼 |
| **被主张方（可能利用冷静期撤回）** | 关注冷静期30日内的撤回权利、协议显失公平的可撤销情形、签署前是否存在欺诈/胁迫 |
| **中立审查** | 双向识别协议可撤销情形、冷静期操作要点、协议与离婚登记的关联效力 |

### 3. 敏感情形检查

- **家庭暴力情形下的冷静期**（🔴关键）：家暴情形下，协议离婚冷静期不能阻止受害方通过诉讼离婚（诉讼离婚无冷静期），且受害方可同时申请人身安全保护令。**须强制升级律师**，明确告知诉讼路径
- **协议签署存在欺诈/胁迫迹象**（🔴关键）：若一方在胁迫下签署协议，协议可能可撤销。**强制升级律师**

## 详细步骤

### 步骤一：协议离婚程序概览

**1.1 协议离婚法定要素**（民法典第1076条，建议复核）

协议离婚须同时满足以下三个要素，缺一不可：

| 要素 | 具体要求 | 备注 |
|------|---------|------|
| **双方自愿** | 双方均须真实自愿，不存在欺诈、胁迫 | 意思表示须真实，否则协议可撤销 |
| **书面离婚协议** | 须签订书面离婚协议，协议须载明：双方自愿离婚的意思表示 + 子女抚养安排 + 财产处理 + 债务处理 | 四项内容均须涵盖，无缺项 |
| **民政登记** | 双方须**亲自**到婚姻登记机关申请离婚登记 | 不可代理；须携带有效身份证件 |

**1.2 离婚协议必备条款核查清单**

在申请登记前，核查协议是否包含以下必备内容：

- [ ] 双方自愿离婚的意思表示
- [ ] 子女直接抚养权归属（双方均确认）
- [ ] 子女抚养费金额与支付方式（或明确无抚养费约定的说明）
- [ ] 财产处理安排（共同财产归属/个人财产确认）
- [ ] 债务处理安排（共同债务分担/个人债务确认）
- [ ] 双方签名（确认为本人亲笔签名）
- [ ] 签署日期

**重要**：婚姻登记机关审查协议是否涵盖上述要素，但通常不就实质公平性进行司法审查——这意味着条款显失公平的协议也可能通过登记，但可在登记后申请撤销。

### 步骤二：离婚冷静期规则（民法典第1077条，建议复核）

**2.1 冷静期时间轴**

```
申请登记之日 ─ [30日] ─ 冷静期结束 ─ [30日内] ─ 须共同申请发证 ─ 获发离婚证
                 ↑                           ↑
          任何一方可单方撤回          期满不申请=视为撤回
```

**2.2 冷静期关键规则**

| 规则 | 内容 |
|------|------|
| 撤回权 | 自婚姻登记机关收到离婚登记申请之日起**30日内**，任何一方均可向登记机关撤回离婚登记申请，无需说明理由 |
| 单方撤回 | 只需一方撤回即可终止该次申请，无需对方同意 |
| 期满申请 | 冷静期届满后30日内，双方须**共同亲自**向登记机关申请发给离婚证 |
| 视为撤回 | 期满后30日内未共同申请的，视为撤回（本次申请作废，如仍要离婚须重新提交） |
| 期间可补签协议 | 冷静期内若双方协商修改协议，可重新提交修改后的协议（须与登记机关确认操作流程 `[地方 flagged — 需核实当地民政局操作要求]`） |

**2.3 冷静期与诉讼离婚的关系**

> **重要区分**：协议离婚有冷静期，**诉讼离婚无冷静期**。
> 若双方已申请协议离婚且进入冷静期，一方在冷静期内撤回后，另一方可直接转向诉讼离婚（向法院提起离婚诉讼），无需等待冷静期结束。

**2.4 家暴情形的特别说明**

> 家庭暴力受害方**无需等待冷静期**，可直接向法院起诉离婚（家暴是诉讼离婚的法定准予条件，民法典第1079条）。协议离婚冷静期制度不阻断诉讼权利。同时，受害方可在冷静期内向法院申请人身安全保护令。
> 如识别到家暴情形，须**强制升级**，优先告知上述权利。

### 步骤三：协议反悔与可撤销情形

**3.1 协议离婚后反悔财产分割**

离婚协议生效后（离婚登记完成），一方对协议中**财产分割**部分反悔，须满足**可撤销情形**方可申请变更或撤销：

**可撤销的法定情形**（复用合同编意思表示瑕疵结构，**标「复用商事合同脊柱结论，建议复核」；不套合同编条号到婚姻家庭编实体规则**）：

| 可撤销情形 | 说明 | 举证要点 |
|-----------|------|---------|
| **欺诈** | 一方故意虚构事实/隐瞒真相，使对方在错误认识下签署协议（如虚报财产清单） | 须证明对方故意虚构，且受骗方在非欺诈情况下不会签署该条款 |
| **胁迫** | 一方以威胁手段迫使对方签署协议（家暴胁迫、扣押子女等） | 须证明胁迫行为与签署协议的因果关系 |
| **重大误解** | 对协议重大条款存在根本性误解（如误解财产范围） | 较难证明，须区分「自愿放弃」与「误解」 |
| **显失公平** | 协议签署时一方有优势地位，内容严重不公平 | 须证明签署时存在显失公平情形，仅事后悔改不构成 |

**3.2 申请撤销的期限**（描述规则，具体期限须核实现行法律规定 `[待验证]`）

申请撤销须在法定期限内（自知道或应当知道可撤销情形之日起计算），超过期限丧失撤销权。具体期限须核实《中华人民共和国民法典》合同编相关规定或婚姻家庭编司法解释。

**3.3 仅就财产分割条款反悔（不涉及离婚本身）**

> **重要**：协议离婚已完成（取得离婚证），一方仅对财产分割部分反悔，不影响离婚的效力——即不能以此为由「撤销」整个离婚。可撤销的仅为财产分割条款，离婚本身已成立。

### 步骤四：财产分割协议与离婚登记的关联效力

**4.1 关联效力原则**

> **财产分割协议以离婚登记完成为生效条件（附解除条件/停止条件）。**
>
> 若双方签署了包含财产分割约定的离婚协议，但最终**未办理离婚登记**（冷静期撤回/一方不愿），财产分割协议不独立生效——因为该协议是以「离婚」为前提缔结的，离婚未成立，财产分割协议也不产生分割效力。

**4.2 实践中的关联效力问题**

| 场景 | 效力结论 |
|------|---------|
| 已签协议，已完成离婚登记 | 协议（含财产分割）全面生效 |
| 已签协议，冷静期内撤回 | 协议不生效（无论是哪方撤回），双方重新谈判 |
| 已签协议，一方在冷静期后不去发证 | 视为撤回，协议不生效 |
| 已签协议，但未提交登记即发生纠纷 | 协议效力存在争议，须律师评估（已签订但未生效） |

**4.3 协议内容须完整处理方可申请登记**

- 登记机关通常不接受遗漏子女抚养安排、财产处理或债务处理的协议
- 如当前无子女/无共同财产/无共同债务，须在协议中明确写明「双方无共同子女/无共同财产/无共同债务」而非跳过该条款

### 步骤五：协议不成时转诉讼路径提示

如双方就离婚协议条款（特别是财产分割、子女抚养）无法达成一致，可转诉讼离婚路径：

**诉讼离婚路径**（民法典第1079条，建议复核）：

- 一方向有管辖权的基层人民法院（家事审判庭）提起离婚诉讼
- 法院须先行调解；调解不成且感情确已破裂的，应准予离婚
- 法庭判决抚养权与财产分割，无需双方同意（但须法院审理）
- **诉讼离婚无冷静期**，但通常审理周期较长（数月至一年以上）
- 初次起诉法院判决不准离婚，经过一年分居后再次起诉须准予（第1079条第5款，建议复核）

**建议提示当事人**：

```
协议离婚与诉讼离婚对比说明：

协议离婚：双方自愿+协议+登记（通常更快，成本低，但须双方全程配合）
诉讼离婚：一方起诉+法院调解/审理+判决（可单方推进，但周期较长，须律师代理）

如协议谈判陷入僵局，尤其是财产分割或子女抚养存在重大分歧，建议：
1. 考虑聘请家事调解机构协助调解（成本低于诉讼）
2. 若调解失败或一方有家暴等紧急情形，直接启动诉讼离婚程序
```
