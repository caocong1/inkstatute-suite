## 目的与整体证据管理流程

本技能协调四个子技能，系统完成从证据收集到证据交换的全流程：

1. **收集与保管链** → 收集所有相关证据，建立保管链记录
2. **三性审查** → 对每条证据审查真实性/合法性/关联性，评估证明力
3. **三大类目录编制** → 按强制分组规则编制证据目录（硬门禁）
4. **举证期限管理** → 确保在期限内提交，管理逾期风险

## 步骤一：三大类归类规则确认

### 第一类：基础交易关系类

**证明目的**：证明"基础违约事实"的前提——基础交易关系的存在和内容。

典型证据：
- 合同文本（含所有附件、补充协议、变更函）
- 招标文件、投标文件、中标通知书
- 采购订单、交货单、验收单（证明交易已形成）
- 合同标的物的技术规格说明
- 当事人身份证明（营业执照/法定代表人证明）

### 第二类：法律关系及索赔事实类

**证明目的**：证明法律关系有效成立，以及权利发生（索赔基础）。

典型证据：
- 保函原件/合同文本（证明保证关系成立）
- 索赔函/催告函原件
- 索赔函/催告函送达凭证（EMS快递回执/当面签收记录）
- 权利转让/债权转让文件（如有）
- 关于付款时间节点的确认函/补充协议

### 第三类：被告违约事实类

**证明目的**：证明被告（对方）未履行义务的具体违约事实。

典型证据：
- 催告记录（邮件/微信/通话录音）证明对方仍未付款/履行
- 对方拒付或拖延的会议纪要/函件
- 律师催告函及回执
- 财务凭证（证明款项未到账）
- 其他证明对方违约行为的证据

| 一条证据横跨多类 | 按主要证明目的归入一类，不重复列入（除非有特别说明）|
| 证据目录与答辩状中证据清单不一致 | 须确保两份文件一致，建议在 defense-assembly 完成后统一核对 |
| 对方证据（用于质证的）是否列入本目录 | 本目录为我方提交证据目录，对方证据的质证意见由 three-properties-review 处理 |

## 步骤二：证据类型清单与收集指引

### 2.1 书证类

| 证据类型 | 收集重点 | 原件/复印件要求 |
|---------|---------|--------------|
| 合同/协议文本 | 含所有附件、补充协议、变更函 | 须提供原件核对 |
| 往来函件/通知 | 送达凭证（快递单、签收记录）| 原件 + 送达凭证 |
| 财务凭证 | 发票、银行转账记录、付款截图 | 原件或银行加盖印章的流水单 |
| 会议纪要 | 双方签字确认版 | 原件 |
| 法律文件 | 起诉状、判决书、仲裁裁决（如有）| 原件 |

**原件核对标记**：若只有复印件，标记 `[原件待核对 — 复印件证明力较弱，建议提供原件]`。

### 2.2 电子数据类

> **电子数据取证合法性原则**：不得通过非法手段获取（如未经授权入侵系统、窃取他人数据）。非法取得的电子数据合法性存疑，不得提交，否则可能被认定为非法证据 `[待验证]`。

| 电子数据类型 | 保管链要求 | 公证/存证建议 |
|------------|---------|-------------|
| **微信/钉钉聊天记录** | 截图保存（含聊天对象名称+时间戳）+ 手机型号和操作系统版本 | 建议公证（公证效力优先认定）`[待验证]` |
| **电子邮件** | 完整邮件（含邮件头：发件人/收件人/时间/邮件服务器信息）| 建议导出EML格式存档 |
| **短信记录** | 截图 + 手机号信息 | — |
| **网页/平台信息** | 截图（含URL + 访问时间）+ 第三方存证（如可信时间戳）`[待验证]` | 建议可信时间戳或公证 |
| **OA/ERP系统记录** | 系统导出（含系统元数据：操作人/时间/IP）| 须经IT部门出具说明 |
| **录音录像** | 原始文件（不得剪辑）+ 取证时间 + 录制设备 | 如涉及对话录音，须评估合法性 |

**电子数据保管链记录表**（每条电子数据单独填写）：

| 字段 | 内容 |
|------|------|
| 数据名称/描述 | [如：微信聊天记录——关于货款确认] |
| 数据来源 | [如：我方法务手机 iPhoneXX，微信账号XXX] |
| 提取方式 | [截图/手机端直接提取/第三方公证提取] |
| 提取人 | [姓名] |
| 提取时间 | [YYYY-MM-DD HH:MM] |
| 完整性校验 | [如：已截图全部相关对话，无删减] |
| 存证方式 | [本地备份/云端备份/公证/区块链存证] |
| 原始性 | [是否为原始载体数据，还是二次截图] |
| 合法性声明 | [数据来源是否合法，有无侵犯他人合法权益] |

### 2.3 证人证言类

| 证人证言要素 | 说明 |
|------------|------|
| 证人资格 | 了解案件情况的自然人（须与本案无直接利益关系，利益关系须说明 `[待验证]`）|
| 书面证人证言 | 证人本人签字确认，注明日期 |
| 证人出庭 | 建议安排证人出庭接受质询（书面证言证明力弱于出庭 `[待验证]`）|
| 证人的感知来源 | 是亲历（亲眼所见/亲耳所闻）还是转述 |

### 2.4 鉴定意见类

| 鉴定要素 | 说明 |
|---------|------|
| 申请时机 | 须在举证期限内申请，逾期申请不予准许（除非有正当理由 `[待验证]`）|
| 鉴定机构资质 | 须由具有相应资质的鉴定机构出具 `[待验证]` |
| 鉴定事项范围 | 仅鉴定专业技术问题（如损失金额、技术缺陷、文件真实性等）|
| 鉴定人出庭 | 鉴定意见须在庭审中质证，鉴定人须出庭接受质询（除非双方同意不出庭）`[待验证]` |

## 目的

对案件中的每条证据（包括我方证据和对方证据）执行三性逐项审查：

1. **真实性**：证据是否客观真实，有无伪造/变造迹象
2. **合法性**：证据的来源和形式是否符合法律规定，取证方式是否合法
3. **关联性**：证据与争议事实之间是否存在关联，能否证明案件事实

并在此基础上：
- 评估我方证据的证明力
- 起草对方证据的质证要点
- 识别证明力弱项并建议补强

## 步骤一：举证责任分配（前置分析）

在逐证据审查前，先确认举证责任分配：

**已核实规则**：谁主张谁举证原则——当事人对自己提出的主张承担举证责任（《最高人民法院关于民事诉讼证据的若干规定》2020修正，条号待验证）。

| 争议焦点 | 举证责任方 | 依据 | 验证状态 |
|---------|---------|------|---------|
| [如：基础合同关系存在] | [原告] | 谁主张谁举证 | `[待验证]` |
| [如：我方已履行付款义务] | [我方（被告）] | 我方主张已履行 | `[待验证]` |
| [举证责任倒置情形] | [对方] | 产品缺陷致害/环境侵权/医疗纠纷等特殊举证责任倒置 `[待验证]` | `[待验证]` |

**自认规则提示**：当事人在诉讼过程中对对方事实的自认（明示或可推定），对方无需举证。注意我方答辩和陈述中勿对不利事实自认（条号待验证）。

## 边界条件

| 情形 | 处理方式 |
|------|---------|
| 录音合法性争议（偷录对方） | 标记 `[合法性争议 — 偷录的合法性在司法实践中存在分歧，须律师评估 `[待验证]`]`，不自行定性 |
| 对方证据真实性存在明显疑点 | 起草专门的真实性质疑意见，建议申请鉴定 |
| 证据三性均弱，对方证据几乎无可抗辩 | 如实反映，建议评估和解 |
| 电子数据没有保管链记录 | 标记 `[保管链缺失 — 建议补充取证说明]`，说明对真实性审查的影响 |
| 举证责任倒置情形（如医疗纠纷）| 明确说明举证责任在对方，我方无需就该事项举证，对方须证明 |

## 目的

系统管理举证期限，确保所有证据在期限内提交，并为证据交换/质证做好准备：

1. **举证期限管理**：识别举证截止日，评估现有证据提交进度，管理逾期风险
2. **逾期举证风险评估**：分析哪些证据可能逾期，逾期后果及正当理由评估
3. **证据交换准备**：整理证据材料，准备庭前证据交换或开庭质证
4. **申请事项时点**：鉴定/证据保全/调查取证申请均须在举证期限内提出

## 步骤一：举证期限确认

### 1.1 举证期限规则

**已核实规则**：举证期限不得少于**十五日**（普通程序，《民事诉讼法》2023修正，条号待验证）；简易程序不少于七日 `[待验证]`。

| 举证期限确定方式 | 说明 | 来源 |
|---------------|------|------|
| **当事人协商** | 双方协商一致确定举证期限 | 《证据规定》（2020修正）`[条号待验证]` |
| **法院指定** | 协商不成时，法院在首次庭前会议或开庭通知书中确定 | 《证据规定》（2020修正）`[条号待验证]` |
| **最低保障** | 普通程序：不少于15日；简易程序：不少于7日 `[待验证]` | 《民事诉讼法》（2023修正）`[条号待验证]` |

| 字段 | 内容 |
|------|------|

| **程序类型** | [普通程序/简易程序/仲裁] |

## 步骤三：逾期举证风险评估

### 3.1 逾期举证后果

> **重要**：逾期提交证据的后果为法院一般不予认可。

| 逾期场景 | 后果 | 来源 |
|---------|------|------|
| 逾期提交证据（无正当理由）| 法院一般不予认可；对方不同意质证时不得作为证据使用 `[待验证]` | 《证据规定》（2020修正）`[条号待验证]` |
| 逾期提交（有正当理由）| 法院可准许；须说明理由并可能承担一定费用 `[待验证]` | 《证据规定》（2020修正）`[条号待验证]` |
| 逾期申请鉴定 | 法院一般不予准许，除非有正当理由 `[待验证]` | 《证据规定》（2020修正）`[条号待验证]` |

## 边界条件

| 情形 | 处理方式 |
|------|---------|
| 举证期限尚未确定（法院未通知）| 记录「举证期限待确认」，标记「尽快通过开庭通知或联系法院确认举证截止日」|
| 证据已逾期，律师询问是否还能提交 | 明确告知逾期后果（法院一般不予认可），说明可提交但须准备正当理由，且可能被不采纳；不建议寄望于对方同意质证 |
| 仲裁举证期限规则 | 说明仲裁举证期限按各仲裁机构规则确定，不适用民诉法15日规则，须查询具体仲裁机构规则 `[待验证]` |
| 证据极多，无法在期限内处理 | 标记「证据量超预期」，建议优先处理核心证据（与主要争议焦点直接相关的），其余在期限内补充 |
| 新发现重要证据（举证期后）| 评估是否满足「新证据」认定标准；如为再审程序新发现，说明一、二审庭审后新发现的才算新证据 `[待验证]` |
