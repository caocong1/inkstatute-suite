# 子技能：dispute-focus

> 原独立子技能 `dispute-focus`：代理词起草子技能：从案件事实、证据和双方主张梳理争议焦点，对照法院归纳的争议焦点 逐条列出我方立场与对方立场，生成争议焦点对照表。 可由 representation-drafting 编排入口调用，也可单独触发。


# 争议焦点梳理

> **研究闸门**：除非用户明确豁免联网检索，必须先确认 `shared/research-gate/SKILL.md` 已运行，研究底稿已完成，再进入本子技能。
>
> **单独触发说明**：本子技能可通过 `「子技能：dispute-focus」章节（见本文档）` 单独触发，只运行争议焦点梳理，无需重跑整个代理词起草流程。

## 目的

系统梳理案件争议焦点，明确我方与对方的核心分歧，为后续事实论证（fact-argumentation）和法律论证（legal-argumentation）奠定逻辑基础。

争议焦点梳理的作用：
1. 防止代理词失焦——只对准法院需要裁决的事项展开论证
2. 识别我方强势焦点（有利）与弱势焦点（不利）
3. 为庭审辩论提供结构化应对框架

### 1.1 争议焦点信息来源优先级

| 来源 | 优先级 | 说明 |

## 步骤二：梳理争议焦点

### 2.1 争议焦点分类

将所有争议焦点归入以下分类：

| 类型 | 说明 | 示例 |
|------|------|------|
| **事实争议** | 双方对某项事实是否存在/如何认定存在分歧 | 合同是否已成立、货物是否已交付 |
| **法律适用争议** | 双方对适用何种法律规则或如何解释存在分歧 | 违约金是否过高、损害赔偿范围如何计算 |
| **程序性争议** | 管辖权、诉讼资格、举证责任分配等 | 仲裁协议是否有效、管辖法院是否正确 |
| **混合争议** | 同时涉及事实认定和法律适用 | 是否构成根本违约（需认定事实 + 法律判断）|

### 2.2 逐条梳理争议焦点

对每个争议焦点，完成以下分析：

**焦点 [N]：[焦点名称/描述]**

- **焦点类型**：[事实争议 / 法律适用争议 / 程序性争议 / 混合争议]
- **我方立场**：[用 1-2 句话概括我方核心主张]
- **关键事实支持**：[支持我方立场的关键事实 1-3 条，注明对应证据序号]
- **对方立场**：[用 1-2 句话概括对方核心主张]
- **对方关键主张**：[对方可能援引的事实或法律依据]
- **我方优势/劣势评估**：[我方在此焦点的胜算评估：强 / 中 / 弱 / 不确定]
- **需补充的证据或论证**：[如有缺口，标记需补充内容]

### 2.3 交叉质证要点

## 边界条件

| 情形 | 处理方式 |
|------|---------|
| 法院已归纳争议焦点 | 以法院归纳为权威来源，不作实质性替换；在我方立场栏填充我方应对立场 |
| 存在尚未质证的证据 | 在事实支持列标注「[未质证 — 仅参考，不作为确认事实]」 |
| 对方提出新证据/主张（尚未质证）| 标注「[对方新证据/主张 — 待质证，立场存不确定性]」 |
| 争议焦点超过 5 个 | 按对代理词最终结果影响排序，优先处理前 5 个核心焦点；其余列为「次要焦点」附录 |
| 仲裁案件 | 争议焦点梳理逻辑相同；注意仲裁庭可能不公开宣告争议焦点，需从双方文件中自行梳理 |
| 二审案件 | 二审争议焦点通常限于对一审判决有异议的事项，梳理时以上诉状/答辩状为起点 |

## 目的

起草代理词的事实部分：

1. **案件事实概述**：以有利于我方的叙事顺序梳理案件事实，突出关键事实
2. **证据支持**：每项陈述的事实对应具体证据，标注证据序号
3. **对方事实反驳**：对对方事实主张逐一反驳，指出其错误或不完整之处

**前提**：本子技能依赖 `dispute-focus` 产出的争议焦点对照表；如直接触发，需先向律师确认核心争议焦点和案件事实要素。

## 步骤一：组织事实叙述框架

### 1.1 确定叙事视角与顺序

根据我方角色选择叙事策略：

| 角色 | 叙事策略 | 说明 |
|------|---------|------|
| **原告** | 从权利受损开始叙事，突出对方过错 | 建立侵权/违约→损害的清晰因果链 |
| **被告** | 从合理行为开始叙事，质疑原告前提 | 弱化对方主张的事实基础，呈现替代解释 |

**叙事顺序选项**：

- **时间顺序**：适合事实脉络清晰的案件（合同签订→履行→违约）
- **逻辑顺序**：从最有利事实开始，递进加强；适合复杂案件
- **争议焦点顺序**：按争议焦点逐一呈现相关事实；适合多焦点案件

### 1.2 识别关键事实

从案件材料中提取关键事实，按重要性分级：

| 事实 | 我方主张 | 对应证据序号 | 重要性 | 是否已质证 |
|------|---------|------------|--------|---------|
| [事实 1] | [我方陈述] | 证据 [N] | [高/中/低] | [是/否/未知] |
| [事实 2] | [我方陈述] | 证据 [M] | [高/中/低] | [是/否/未知] |

> **纪律**：未经质证或法院未采纳的证据，**不得作为确认事实的依据**。对应事实须标注「[依赖未质证证据，暂不写入事实陈述，待质证后确认]」。

---

## 步骤二：起草事实概述段落

### 2.1 段落结构

事实概述段落遵循以下结构：

```
[引导句 — 概括我方核心事实立场，1-2 句]

[背景事实 — 双方关系、合同/交易背景，1-2 段]

[核心事实展开 — 按时间/逻辑顺序展开关键事实，每项标注证据，3-5 段]

[损害/后果说明 — 对方行为的直接结果，1 段]
```

### 2.2 事实陈述质量要求

每项事实陈述须符合以下要求：

- [ ] 有具体的时间、地点、当事人、行为
- [ ] 标注支持该事实的证据序号（如：「根据证据一[合同原件]」）
- [ ] 未经质证的证据标注「待质证」
- [ ] 不包含法律判断（法律分析保留至 `legal-argumentation`）
- [ ] 叙述语言客观，避免不当煽情或人身攻击

---

## 步骤三：起草对方事实反驳

### 3.1 识别对方的关键事实主张

从对方起诉状/答辩状/庭审陈述中提取对方的核心事实主张：

| 对方事实主张 | 反驳方式 | 支持反驳的证据 |
|------------|---------|-------------|
| [对方主张 1] | [直接否认/部分承认/替代解释] | 证据 [N]：[说明] |
| [对方主张 2] | [直接否认/部分承认/替代解释] | 证据 [M]：[说明] |

### 3.2 反驳策略

根据情况选择反驳策略：

| 策略 | 适用情形 | 注意事项 |
|------|---------|---------|
| **直接否认** | 对方事实与证据明显矛盾 | 需有我方证据明确支撑 |
| **部分承认 + 补充** | 对方只陈述了对其有利的部分事实 | 承认客观事实，补充被省略的关键细节 |
| **替代解释** | 对方解读同一事实得出不同结论 | 提出合理替代解释，说明我方理解更符合证据 |
| **证据质疑** | 对方证据的真实性/合法性/关联性存疑 | 指出具体疑点，不得泛泛质疑 |

### 3.3 反驳段落示意

反驳段落遵循：「对方主张 + 反驳内容 + 证据支持」三段式结构：

```
[对方在[诉讼请求/答辩状]中称……（引用对方原文或概括）。]

[然而，根据[证据序号]，……（呈现反驳事实）。]

[对方主张[不成立/不完整/存在误导]，原因在于……（说明反驳逻辑）。]
```

| 抗辩类型 | 法律依据 | 适用条件 |
|---------|---------|---------|
| 实体抗辩 | 请求权要件不满足（如过错不存在、损害与行为无因果关系）| 攻击对方请求权构成要件 |
| 程序性抗辩 | 管辖权异议、诉讼时效抗辩、起诉资格问题 | 须在答辩期间提出；时效抗辩须主动提出（法院不主动适用）|
| 仲裁协议抗辩 | 存在有效仲裁协议，排除法院管辖 | 《仲裁法》或裁或审原则，具体条号待验证 |
| 减损与贡献过错 | 原告未尽减损义务；原告存在过错 | 《民法典》相关条文 `[条号待验证]` |

## 步骤二：要件分析

### 2.1 确定法律构成要件

**原告**——以违约责任为例（其他类型参照执行）：

```
请求权基础：要求被告承担违约责任

要件：
(1) 合同成立且有效
(2) 被告存在违约行为（不履行/迟延履行/不适当履行）
(3) 原告已履行对待给付义务（如有）
(4) 损害及其范围（如主张赔偿损失）
(5) 违约行为与损害之间存在因果关系（如主张赔偿）
```

**被告**——以时效抗辩为例：

```
抗辩构成：原告诉讼时效已届满

要件：
(1) 时效期间已届满（一般3年=《民法典》第188条，已核实）
(2) 在时效期间内无中止/中断事由
(3) 被告主动提出时效抗辩（时效抗辩须当事人主动提出，法院不主动适用）
```

### 2.2 逐要件检验（涵摄）

对每个要件，完成「要件 → 相关事实 → 证据 → 是否满足」的检验：

| 要件编号 | 要件内容 | 相关事实（案件中对应情况）| 关键证据 | 满足状态 |
|---------|---------|---------------------|---------|---------|
| 要件(1) | [要件描述] | [案件中的具体事实] | 证据 [N] | 满足 / 不满足 / 存疑 |
| 要件(2) | [要件描述] | [案件中的具体事实] | 证据 [M] | 满足 / 不满足 / 存疑 |
| 要件(3) | [要件描述] | [案件中的具体事实] | [证据或无需证据]| 满足 / 不满足 / 存疑 |

**对「存疑」要件的处理**：说明存疑原因，提示证明方向，标注「[需律师确认事实/证据]」。

## 步骤三：法律论证段落起草

### 3.1 论证结构

法律论证遵循「要件 → 事实涵摄 → 结论」三段论结构：

```
[大前提（法律规则）]：根据《[法律名称]》第[X]条[第X款] `[待验证]`，……（法律规则表述）

[小前提（案件事实涵摄）]：本案中，……（将已证明的事实涵摄至法律要件）

[结论]：因此，[被告构成违约/原告请求权成立/抗辩成立等]。
```

### 3.2 各争议焦点的法律论证

对每个争议焦点，起草独立的法律论证段落。段落格式：

**（一）关于[争议焦点一]的法律分析**

[大前提：适用法条]

[小前提：事实涵摄]

[结论：我方法律主张]

**（二）关于[争议焦点二]的法律分析**

（同上）

### 3.3 指导性案例支持

如有与本案相关的最高人民法院指导性案例，附于对应焦点的法律分析之后：

> **[指导案例第X号] `[待验证]`**：[裁判要点摘要]。
>
> **裁判意义**：[对本案的借鉴意义]。
>
> **中国法律体系说明**：中国采成文法体系，本指导案例为参考，**不具有判例法约束力**，实际效力以法条为准。

# 代理词装配

> **研究闸门**：代理词装配须在所有前序子技能（dispute-focus / fact-argumentation / legal-argumentation）完成并经律师确认后执行。联网检索（研究闸门）须在此步骤之前完成。

> **单独触发说明**：本子技能可通过 `「子技能：representation-assembly」章节（见本文档）` 单独触发。直接触发时需提供：争议焦点对照表、事实论证段落、法律论证段落和代理请求清单。

## 目的

将前序子技能产出的各部分装配为完整、可交付的代理词文书，并生成配套的庭审工具：

1. **代理词全文**：开头（代理人身份/代理权限/简要意见）→ 事实部分 → 法律部分 → 代理请求/理由总结
2. **辩论提纲**：庭审辩论要点，按争议焦点排序，含应急应对提示
3. **法庭陈述**：开庭陈述（精简版）和结案陈词（总结式）
4. **交付前检查**：特权标题、研究闸门完成、引用验证状态、格式合规

## 步骤二：装配代理词全文

### 2.1 完整代理词结构

```
[文书标题]
[特权标题（如适用）]

审判长、审判员（或：仲裁庭）：

根据《中华人民共和国民事诉讼法》的相关规定，[代理人名称] 接受 [委托人名称] 的委托，担任本案的诉讼代理人。就本案发表如下代理意见：

一、代理人身份及代理权限
二、本案事实部分（整合 fact-argumentation 产出）
三、法律分析部分（整合 legal-argumentation 产出）
四、代理意见与请求

代理人：[签名]
日期：[日期]
```

### 2.2 各部分装配细则

**开头部分**：

- 代理人身份声明：律师姓名、执业证号（如有）、律所名称
- 代理权限声明：委托授权书编号（如有）、代理范围（一审/二审/全程）
- 简要代理意见：1-2 句概括我方核心法律立场（悬念式结构，引导法官关注重点）

**事实部分**：

- 直接整合 `fact-argumentation` 产出的完整事实概述段落
- 保留事实-证据对应标注（证据序号）
- 未质证证据的标注须保留

**法律部分**：

- 直接整合 `legal-argumentation` 产出的法律论证段落
- 保留法律依据（条文引用 + 来源标签 + 待验证标注）
- 指导性案例标注「参考，不具判例法约束力」须保留

**代理请求/理由总结**：

```
综上所述，[我方/被代理人] 认为，[核心法律立场总结，1-3 句]。

为维护 [委托人] 的合法权益，恳请法院（或仲裁庭）依法：

1. [请求一：具体请求内容]
2. [请求二：具体请求内容（如有）]
3. 本案诉讼费用由 [对方] 承担。

此致

[受理法院/仲裁机构名称]

代理人：[姓名]
日期：[日期]
```

## 步骤四：生成法庭陈述

### 4.1 开庭陈述（如适用）

开庭陈述为庭审第一环节，通常限时（3-5 分钟），须精简：

```
审判长、审判员，原被告各方：

本案代理人 [姓名] 代表 [委托人] 出庭。

本案核心争点在于：[1-2 个最关键争议焦点，一句话描述]。

我方的基本立场是：[核心法律立场，2-3 句]。

谢谢！
```

### 4.2 结案陈词

结案陈词（最终陈述）为庭审最后环节，总结强化我方立场：

```

经过今天的庭审，我方进一步确认：

[庭审强化点一：本次庭审证明了什么，1-2 句]
[庭审强化点二：对方论据为何不成立，1-2 句]

综上，我方请求法院依法支持/驳回[对方请求]：[重申核心请求]。

感谢法院的审理。
```

## 下一步决策树

代理词交付后，提示律师选择下一步：

1. **确认并提交** — 律师确认代理词内容，准备庭审提交
2. **修改调整** — 律师有修改意见，指定具体修改方向
3. **补充研究** — 需要进一步法律研究或证据核查
4. **庭审准备** — 进入庭审辩论准备（使用辩论提纲作为基础）
5. **时效监控** — 如案件涉及时效问题，运行 ``litigation-limitation-monitoring` 技能`

## 边界条件

| 情形 | 处理方式 |
|------|---------|
| 前序子技能产出不完整 | 标注「[依赖前序子技能产出未就绪：待 dispute-focus/fact-argumentation/legal-argumentation 完成后装配]」，不自行补全 |
| 仲裁案件 | 将「审判长、审判员」替换为「仲裁庭」；代理词结构相同，注意仲裁特有程序（如庭审不对外公开）|
| 二审代理词 | 开头须说明一审情况和上诉理由；事实和法律部分聚焦一审有争议的事项，不重复一审无争议事实 |
| 非律师角色 | 工作产物标题改为「研究笔记 — 非法律建议，供律师审查」；在每个法律结论处提示「此为研究草案，须经律师确认方可使用」|

## 错误处理

| 错误情形 | 处理方式 |
|---------|---------|
| 代理请求与事实/法律论证不一致 | 识别不一致之处，向律师反馈，等待确认后再装配，不自行调整 |
| 律师要求在代理词中加入过激措辞或人身攻击 | 解释代理词应保持客观，说明不当措辞可能影响法官观感，提供替代表达 |
| 文书格式与法院要求不符 | 如律师提供了法院的格式要求，优先遵从；否则采用本模板标准格式 |
