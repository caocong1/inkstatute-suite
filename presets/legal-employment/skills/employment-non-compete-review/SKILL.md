## 目的

审查竞业限制协议的合法性和可执行性，确保符合《劳动合同法》（2012年修正）第23-24条规定，
分析人员范围资格、期限与补偿合规性、范围合理性，以及双向违约救济路径。

## 目的

核查竞业限制约定的人员资格，判断劳动者是否属于法定三类可约定竞业限制的人员，
区分保密义务与竞业限制的法律性质，分析商业秘密的认定要件，
输出「谁能被约束」的资格结论与风险评级。

---

## 详细步骤

### 步骤 1：人员范围法定框架核查

**法定依据**（**第23条已核实锚点**）：

《劳动合同法》（2012年修正）第23条规定，用人单位可以对「负有保密义务的劳动者」
约定竞业限制；第24条进一步明确，竞业限制人员限于：

| 法定类别 | 说明 | 认定要点 |
|---------|------|---------|
| **高级管理人员** | 公司董事、监事、高级管理人员（《公司法》意义上，具体范围 `[待验证]`） | 依公司章程、公司法界定职位 |
| **高级技术人员** | 核心技术人员、研发人员等掌握关键技术/研发信息的人员 | 依实际掌握的技术信息类型判断，非仅依职称 |
| **其他负有保密义务的人员** | 接触用人单位商业秘密的其他岗位人员（如销售、市场、财务等接触核心经营信息者） | 依**实际接触**的商业秘密范围判断 |

**关键原则**：竞业限制的适用范围以**实际负有保密义务**为核心判断依据，
对于不实际接触商业秘密的普通员工，即便签署竞业限制协议，
在仲裁或诉讼中可能被认定不属于法定三类人员而影响效力（争议较大，标 `[待验证]`）。

### 步骤 2：具体人员资格核查

针对拟约定或已约定竞业限制的劳动者，逐项核查：

#### 2.1 职位核查（职位列表法）

| 职位类别 | 竞业限制适用资格 | 风险等级 |
|---------|--------------|---------|
| 公司董事/监事 | 适用（高级管理人员） | 🟢 |
| CEO/总经理/副总经理/财务总监/技术总监等高管 | 适用（高级管理人员，具体范围依公司章程 `[待验证]`） | 🟢 |
| 核心研发工程师/技术骨干（掌握核心技术） | 适用（高级技术人员） | 🟢 |
| 销售总监/大客户经理（掌握核心客户信息/定价策略） | 适用（其他负有保密义务人员，须核实接触商业秘密情况） | 🟡 |
| 一般行政/客服/前台等基础岗位 | 通常**不适用**（不属三类人员，竞业限制约定效力存争议🔴） | 🔴 |

#### 2.2 实际接触商业秘密核查

即使职位不在高管/高技列表，如果实际接触商业秘密，仍可能属于「其他负有保密义务的人员」：

| 信息类型 | 是否属于商业秘密（须满足三要件）| 劳动者是否实际接触 |
|---------|--------------------------|----------------|
| 核心技术配方/算法/源代码 | 须核查（秘密性/价值性/保密措施） | ☐ 是 / ☐ 否 |
| 核心客户名单（含联系方式/需求偏好）| 须核查（仅有公开信息的客户名单不构成） | ☐ 是 / ☐ 否 |
| 定价策略/成本结构 | 须核查 | ☐ 是 / ☐ 否 |
| 市场战略/产品路线图（未公开） | 须核查 | ☐ 是 / ☐ 否 |
| 内部管理流程/财务数据 | 视敏感程度判断 | ☐ 是 / ☐ 否 |

### 步骤 3：商业秘密三要件认定

竞业限制以保护商业秘密为前提。商业秘密须同时满足**三个要件**
（通常引用《反不正当竞争法》定义，具体条号 `[待验证]`）：

| 要件 | 说明 | 核查要点 |
|------|------|---------|
| **秘密性** | 不为公众所知晓（即「非公知性」）；公开出版/公开可获取的信息不构成商业秘密 | 竞争对手能否通过正当途径获取？是否有公开记录？ |
| **价值性** | 因其秘密性而具有商业价值，能为权利人带来竞争优势 | 该信息对业务的实际价值大小？泄露会造成什么损害？ |
| **保密措施** | 权利人采取了合理的保密措施（如加密/物理隔离/签署保密协议/限制知悉范围等） | 是否有书面保密制度？信息的实际保密状态如何？ |

**三要件任一欠缺，则该信息不构成商业秘密，不能作为竞业限制的正当理由**。

**常见认定争议**：

| 情形 | 风险说明 |
|------|---------|
| 客户名单：仅记录公开可查的公司名称 | 通常不构成商业秘密（无秘密性）`[待验证]` |
| 客户名单：含联系方式/特殊需求/合作历史 | 可能构成商业秘密（须核查保密措施） |
| 技术信息已申请专利（公开） | 专利公开后不再具有秘密性，不构成商业秘密 |
| 员工从公开渠道自主积累的技能/经验 | 个人技能和经验不属于商业秘密，不能被竞业限制约束 |

### 步骤 4：保密义务与竞业限制的区别

**这是法律实践中最常见的混淆点，须明确区分：**

| 维度 | 保密义务 | 竞业限制 |
|------|---------|---------|
| **适用人员范围** | **全体劳动者**均可约定 | **仅限三类人员**（高管/高技/其他负有保密义务者） |
| **是否须支付补偿** | **无须支付**额外补偿（属劳动者附随义务） | **必须按月支付**经济补偿（强制性） |
| **法律依据** | 诚实信用原则 + 约定（可约定于合同/保密协议） | 《劳动合同法》第23-24条（**已核实锚点**） |
| **约束内容** | 不泄露/不使用商业秘密 | 不到竞品单位工作/不自行开展竞争业务 |
| **约束期限** | 在职期间 + 离职后（商业秘密存续期间有效） | 离职后最长2年（第24条，**已核实锚点**） |
| **违约金** | 可约定，无法定限制 | 须区分：用人单位只能在竞业限制范围内约定违约金（约第25条 `[待验证]`） |

**常见错误做法**（须在审查中发现并纠正）：

- 将保密条款冠名为「竞业限制条款」：若实质上仅约定不泄露信息，而非禁止就业，须区分性质
- 对不属于三类人员的普通员工约定竞业限制：效力存争议，建议改为保密义务约定
- 保密义务约定无补偿（合法）与竞业限制无补偿（违法或效力存疑）混同：须分别审查

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 对普通员工（基础岗位）约定竞业限制 | 标🔴：效力存争议，即便支付补偿也可能因不属三类人员而存在纠纷；建议改为保密义务约定（无需补偿） `[待验证]` |

| 知悉商业秘密的范围极广（几乎全公司员工）| 须审查保密措施是否真实有效，过宽的保密范围可能导致商业秘密三要件（保密措施）认定存疑 |

## 目的

审查竞业限制协议中约定的期限和经济补偿是否符合法定要求，
分析经济补偿的强制性与月度支付义务，
提供地方性补偿比例参考，并说明用人单位未付补偿时的劳动者解除权。

---

## 详细步骤

### 步骤 1：竞业限制期限核查

**法定上限**（**第24条已核实锚点**）：

> 竞业限制的期限不得超过**两年**。

| 审查项 | 合规要求 | 状态 |
|-------|---------|------|
| 约定期限 | 不得超过2年 | ☐ [约定期限]：[合规/超限🔴] |
| 期限起算点 | 自劳动合同**解除或终止之日**起算 | ☐ 协议中是否明确起算点？ |
| 超过2年部分的效力 | 超出部分无效（以2年为上限截断） | — |
| 在职期间是否有效 | 竞业限制义务自劳动合同解除/终止后生效（在职期间靠保密义务约束） | ☐ 协议是否混淆在职/离职期限？ |

**常见问题**：

| 问题 | 说明 |
|------|------|
| 约定期限超过2年 | 超过部分无效，按2年执行；但建议修改协议，避免争议 |
| 期限起算点不明确 | 若协议未约定，一般从解除/终止之日起算；建议明确约定 |
| 将在职期间也纳入竞业限制计算 | 在职期间的「竞业限制」实质为职务忠实义务/保密义务，不应计入2年期限 |

### 步骤 2：经济补偿的强制性审查

**法定要求**（**第23条已核实锚点**）：

> 竞业限制须**在竞业限制期限内按月给予劳动者经济补偿**。

经济补偿是**竞业限制的对价**，属强制性约定要件：

| 情形 | 法律后果 |
|------|---------|
| 协议约定了合理补偿且按月支付 | 合规 🟢 |
| 协议约定了补偿但约定「一次性于终止时支付」 | 存在争议；建议约定月度支付 `[待验证]` |
| 协议约定了补偿但约定「在职期间已涵盖」 | 实践中多认为在职工资不能折抵离职后竞业限制补偿（争议，标 `[待验证]`）🟠 |
| 协议完全未约定补偿 | 劳动者实际履行竞业限制后，可主张按解除前12个月月均工资一定比例按月支付（司法解释规定，具体比例须核查，标 `[待验证]`）|
| 约定补偿但金额显著低于一定标准 | 存在效力争议，劳动者可能以补偿明显不合理为由拒绝履行 `[待验证]` |

**在职期间工资折抵竞业限制补偿的争议**：

用人单位有时在协议中注明「月工资已包含竞业限制补偿」或「以在职工资折抵」。
实践中，各地劳动仲裁委和法院对此认定不一（部分地区接受在职期间折抵，部分地区不接受），
须标注 `[待验证]` `[管辖 flagged — 需验证地方性规定]`，核查当地口径。

### 步骤 3：经济补偿标准评估（地方性指引）

未规定补偿比例下限。最高院司法解释对无约定补偿时的处理有规定（具体条号 `[待验证]`）。

**地方性补偿标准参考**（以下均须标 `[管辖 flagged — 需验证地方性规定]`，勿直接引用为硬标准）：

| 地区 | 地方性参考指引 | 补偿比例参考 | 注意 |
|------|------------|-----------|------|
| 北京 | 北京市地方性实践 | 约30%–50%（解除前12个月月均工资）`[管辖 flagged — 需验证地方性规定]` | 具体比例须核查北京最新仲裁口径 `[待验证]` |
| 上海 | 上海市高院指导意见 | 约33%（解除前12个月月均工资的1/3）`[管辖 flagged — 需验证地方性规定]` | 须核查上海最新意见 `[待验证]` |
| 广东省 | 广东省地方性实践 | 无统一规定，参照合同约定及损失 `[管辖 flagged — 需验证地方性规定]` | `[待验证]` |

### 步骤 4：月度支付合规核查

竞业限制补偿应**在竞业限制期限内按月支付**：

| 审查项 | 合规要求 | 状态 |
|-------|---------|------|
| 是否约定按月支付 | 须按月（在竞业限制期内每月发放） | ☐ 是/☐ 否→争议🟠 |
| 支付条件是否附加不合理前置要求 | 不得附加「需劳动者提供就业证明」等苛刻条件 | ☐ 无附加 / ☐ 有附加🟠 |
| 协议是否约定支付账户/方式 | 建议明确（防止争议） | ☐ 明确 / ☐ 未明确 |
| 实际支付是否与约定一致 | 核查历史支付记录（如已解除） | ☐ 一致 / ☐ 不一致🔴 |

### 步骤 5：用人单位未付补偿时的劳动者解除权（三个月规则）

**核心规则**（须核查司法解释 `[待验证]`）：

> 用人单位**连续三个月**未支付竞业限制经济补偿的，
> 劳动者有权**请求解除竞业限制约定**（即劳动者可解除竞业限制义务，
> 并恢复正常就业不受竞业限制约束）。

> **重要**：「三个月」规则为模型知识，须核查最高院相关司法解释具体条号和条件。
> 标注 `[待验证]`，引用前须通过 https://flk.npc.gov.cn 或法宝核查。

| 审查项 | 说明 | 状态 |
|-------|------|------|
| 用人单位是否连续未付补偿超过3个月 | 若是，劳动者可请求解除竞业限制约定 `[待验证]` | ☐ 未发生 / ☐ 已发生🔴 |
| 劳动者解除前是否已向用人单位催告 | 建议劳动者先催告再解除，留存催告记录 | ☐ 已催告 / ☐ 未催告 |
| 劳动者解除竞业限制约定后是否须返还已收补偿 | 一般不须返还（劳动者非违约方） `[待验证]` | — |
| 用人单位未付补偿但劳动者已违约（自行竞业）| 双向违约的责任分配较复杂，须升级分析 `[待验证]` | ☐ 适用 → 升级分析 |

**劳动者视角（立场为劳动者方时）**：

若用人单位3个月未支付补偿，劳动者可：
1. **主张解除竞业限制义务**（不再受竞业限制约束）
2. **同时主张追讨已欠付的补偿**（已履行期间的应付补偿）
3. **不承担违约金**（用人单位违约导致的解除，劳动者为守约方）

**用人单位视角（立场为用人单位方时）**：
- 须建立竞业限制补偿的及时支付机制（按月自动拨付或设提醒）
- 若已超过3个月，须立即补付并与劳动者书面确认继续有效 `[待验证]`

## 目的

从地域范围、行业竞品范围、岗位业务范围三个维度，
评估竞业限制约定范围的合理性与可执行性，
识别范围过宽导致被认定不可执行的风险，
以及与劳动者生存权/择业权的合理利益平衡，
输出「限制是否合理」的可执行性结论。

---

## 详细步骤

### 步骤 1：法定竞业范围框架核查

**法定范围基准**（**第24条已核实锚点**）：

《劳动合同法》（2012年修正）第24条规定，竞业限制范围为：

- **不得到**与本单位生产或经营**同类产品**、从事**同类业务**的有竞争关系的用人单位就职
- **不得自己开业**生产或经营同类产品、从事同类业务

**要点解析**：

| 要素 | 说明 |
|------|------|
| 「同类产品/同类业务」 | 以用人单位**实际**生产/经营的产品/服务为基准，而非可能涉及的所有业务 |
| 「有竞争关系」 | 须存在实际竞争关系，与本单位无竞争关系的单位不在限制范围内 |
| 「本单位」 | 指用人单位本身，关联公司通常需另行约定（若扩展至集团公司须明确列举 `[待验证]`） |

### 步骤 2：地域范围合理性分析

地域范围是竞业限制可执行性争议的高频领域：

#### 2.1 地域范围核查表

| 约定地域范围 | 合理性评估 | 风险等级 |
|-----------|----------|---------|
| 仅限用人单位实际开展业务的城市/省份 | 通常合理 | 🟢 |
| 全国范围，用人单位在全国均有实质业务 | 通常可支持（须有证据证明全国业务存在）| 🟡 |
| 全国范围，但用人单位实际仅在少数城市运营 | 范围明显过宽，不可执行风险🔴 | 🔴 |
| 全球/境外范围 | 范围过宽，中国法律框架下执行可能性极低🔴 | 🔴 |
| 特定省份/区域，与用人单位业务匹配 | 合理 | 🟢 |

#### 2.2 过宽地域范围的法律后果

- 地域范围明显超出用人单位实际业务范围的，仲裁委/法院可能：
  - 缩减至合理地域范围（司法适当缩减，各地实践不一 `[待验证]`）
  - 认定该条款整体无效（较少见 `[待验证]`）
- 劳动者可以「范围不合理」为由主张竞业限制条款不可执行

**建议**：

地域范围须与用人单位的实际商业利益（商业秘密的地理影响范围）相匹配，
用人单位须能举证说明该地域范围对保护其商业利益的必要性。

### 步骤 3：行业/竞品范围合理性分析

#### 3.1 竞品/竞争单位范围核查

| 约定方式 | 合理性评估 | 风险 |
|---------|----------|------|
| 明确列举竞争对手公司名称 | 清晰具体，通常合理 | 🟢（但名单可能不完整） |
| 定义为「从事同类产品/服务」的单位 | 符合法定标准，通常合理 | 🟡（「同类」的认定存在弹性） |
| 「包括但不限于以下竞争对手」+开放列举 | 开放列举存在扩大解释风险 | 🟠 |
| 所有「相关行业」或「类似行业」 | 定义模糊，明显过宽 | 🔴 |
| 劳动者未来任何工作单位 | 极端过宽，等同剥夺劳动权，通常不可执行🔴 | 🔴 |

#### 3.2 「包括但不限于」开放式列举的风险

协议常见表述：「不得就职于以下公司，包括但不限于：[竞品列表]...」

**风险分析**：

- 「包括但不限于」措辞使竞业范围无法明确，劳动者无法确知哪些单位属禁止范围
- 在仲裁/诉讼中，此类模糊约定可能被认定为范围不明确而影响执行力
- **建议**：改为明确列举或明确定义「同类产品」的判断标准

#### 3.3 自行创业的限制

**法定范围包含**自己开业生产或经营同类产品/从事同类业务（第24条，**已核实锚点**）。

但「自行创业」的限制须合理：
- 若劳动者仅以个人名义提供与竞争单位无关的服务，通常不构成违反竞业限制
- 若劳动者实际控制的公司从事同类业务，即便名义上非劳动者直接就业，也可能构成违反

### 步骤 4：岗位/业务范围合理性分析

竞业限制应与劳动者**原岗位接触的商业秘密**相关，而非泛化至所有工作：

| 审查项 | 说明 | 建议 |
|-------|------|------|
| 限制岗位是否与原岗位相关 | 须与原岗位接触的商业秘密/客户/技术相关 | 界定具体岗位类型 |
| 是否限制劳动者在竞争单位的**所有**岗位（含无关岗位）| 过宽：若劳动者去竞争单位做行政/财务，与原商业秘密无关，过宽限制影响择业权 | 建议限制与原岗位相关的具体职能 |
| 是否限制劳动者在非竞争单位的相关岗位 | 不合理：若用人单位不竞争该领域，此限制无正当利益 | 应删除 |

### 步骤 5：择业权与商业利益的平衡

**劳动者的基本权利保护**：

中国劳动法律体系保护劳动者的**劳动权利和生存权**，竞业限制作为对劳动者择业自由的限制，
在设计上须有合理性约束：

| 平衡维度 | 分析框架 |
|---------|---------|
| 是否有正当保护利益 | 用人单位须有真实的商业秘密/正当利益须保护，而非仅排挤竞争对手 |
| 限制范围是否超必要 | 限制范围不得超过保护正当利益的必要程度 |
| 劳动者是否获得充分对价 | 经济补偿须与限制程度相称（见`term-and-compensation`） |
| 是否严重妨碍劳动者维持生计 | 若劳动者技能专一且范围过宽导致无法就业，极端情形下可能被认为违反公共政策 `[待验证]` |

**不合理限制的认定后果**（各地实践 `[待验证]`）：

| 情形 | 可能后果 |
|------|---------|
| 地域/范围过宽 | 仲裁/法院缩减范围或认定部分无效 |
| 范围明显不合理损害劳动者基本生存权 | 条款可能被整体认定不可执行 `[待验证]` |
| 补偿明显过低 + 范围过宽 | 综合因素下条款效力存风险🔴 |

| 竞业限制范围约定极宽（全行业/全球/所有单位）| 标🔴：明显超出必要范围，可执行性极低；建议重新协商设定合理范围 |
| 用人单位经营范围不断扩张，原来约定的竞品已不能覆盖所有竞争对手 | 仅能执行协议约定时的范围，未来新竞争对手不能直接援引；须重新签署协议 `[待验证]` |
| 「关联公司」是否纳入禁止就职范围 | 须协议明确约定；未约定的情况下，关联公司是否被认为是「有竞争关系」存在争议 `[待验证]` |
| 劳动者的技能高度专一（如特殊领域工程师），范围合理但劳动者几乎无法就业 | 须评估补偿与限制的相称性；极端情形下可能影响效力 `[待验证]`；建议提高补偿以支持可执行性 |
| 约定禁止在特定行业内的「任何职位」（含非竞争岗位）| 标🟠：过宽；建议限制为与原岗位同类或相关的职能岗位 |

---

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 竞业范围约定使用中文模糊词汇（「类似业务」「相关行业」） | 分析：「定义不清晰，在执行时存在较大争议空间；建议明确列举或定义判断标准」 |
| 用人单位无法提供实际经营范围证明（无营业执照/年报）| 建议补充：竞业范围的合理性须与用人单位实际经营范围对应，若无法证明，范围约定的正当性存疑 |
| 劳动者主张「我的工作与竞争对手无关」| 按岗位职责和实际接触信息分析，而非仅依据劳动者主张；若确实无关，支持劳动者的主张 |

## 目的

分析竞业限制违约发生时的双向责任与救济路径：
劳动者违约时（违约金 + 继续履行竞业限制）；
用人单位违约时（劳动者解除权 + 追偿欠付补偿）；
违约金合理性调整机制；
以及与服务期违约金的制度分工边界，
输出「违约怎么办」的双向救济方案。

---

## 详细步骤

### 步骤 1：立场确认与违约性质判断

首先确认立场和违约情形：

| 违约类型 | 违约方 | 适用路径 |
|---------|-------|---------|
| **劳动者违约** | 劳动者违反竞业限制（去竞争单位就职/自行开展竞争业务）| 步骤2（劳动者违约责任与救济） |
| **用人单位违约** | 用人单位连续三个月未支付竞业限制补偿 | 步骤3（用人单位违约救济）+ 见`term-and-compensation` |
| **双向违约** | 劳动者违约且用人单位也存在补偿欠付 | 步骤2 + 步骤3 + 步骤4 |
| **尚未违约，事前评估** | 协议已签，评估潜在违约风险 | 步骤2、3 的风险分析框架 |

### 步骤 2：劳动者违约的救济路径（用人单位方视角）

**劳动者违约时，用人单位的救济手段**：

#### 2.1 违约金请求

**法律基础**（约第25条 `[待验证]`）：

《劳动合同法》（2012年修正）第25条规定，仅以下两种情形可约定由劳动者承担违约金：
1. 服务期约定（第22条，见`hiring-review/service-period-penalty`）
2. 竞业限制约定（**第23条**，本子技能分析范围）

**审查违约金约定**：

| 审查项 | 说明 | 状态 |
|-------|------|------|
| 是否约定了违约金 | 协议中是否有明确违约金条款 | ☐ 是 / ☐ 否（须主张实际损失） |
| 违约金金额/计算方式 | 固定金额 / 按月工资倍数 / 按竞业补偿总额计算 | [约定方式：  ] |
| 违约金是否明确适用竞业限制违约 | 须区分：若协议有多个违约金条款须分别评估 | ☐ 明确 / ☐ 不明确 |
| 违约金是否过高 | 须与实际损失相称（见2.2 违约金合理性分析） | [评估结论] |

#### 2.2 违约金合理性分析（可请求调整）

**调整机制**（`[待验证]` — 须核查劳动合同法相关司法解释）：

劳动者可向仲裁委/法院申请调整过高的竞业限制违约金。参考因素：

| 考量因素 | 说明 |
|---------|------|
| 用人单位的实际损失 | 劳动者违约造成的损失（商业秘密泄露的实际损害/客户流失等）|
| 劳动者的违约情节 | 违约程度（是否主动泄露机密/是否拉拢原客户）/ 违约持续时间 |
| 补偿与违约金的比例关系 | 违约金是否明显高于竞业限制补偿总额，是否有威慑过度之嫌 |
| 劳动者的支付能力 | `[待验证]`（是否纳入考量存在争议） |

**违约金调整原则**（`[待验证]`）：

> 「约定的违约金过分高于造成的损失，当事人可以请求适当减少」
>（类比民法典第585条第2款 `[待验证]`，劳动合同领域的具体适用须核查劳动法司法解释）

**重要提示**：劳动合同法语境下的违约金调整标准，与一般民事合同的调整标准
在适用依据上有差异，须核查最高院专项劳动争议司法解释 `[待验证]`。

#### 2.3 要求继续履行竞业限制义务

除违约金外，用人单位**还可以**要求劳动者继续履行竞业限制义务（即离开竞争单位/停止竞争业务），
**二者可并存**（违约金 + 继续履行，非二选一）：

| 救济措施 | 说明 | 是否可并存 |
|---------|------|---------|
| 违约金 | 对过去违约行为的损失赔偿 | ✓ |
| 继续履行竞业限制义务 | 对未来期间的约束延续（停止违约行为） | ✓（可与违约金并存） |
| 实际损失赔偿 | 违约金不足以覆盖实际损失时，主张差额（`[待验证]`） | ✓（须核查是否可补充主张） |

**继续履行竞业限制的可行性**：

- 若劳动者离职后已在竞争单位就职：要求继续履行意味着须退出该竞争单位
- 实际执行难度较高（无法强制劳动者辞职），通常通过申请禁令/调解实现 `[待验证]`
- 竞业限制期限已过的，继续履行不再有意义，仅剩违约金请求

#### 2.4 劳动者违约责任汇总

| 救济措施 | 适用条件 | 金额估算 |
|---------|---------|---------|
| 违约金（约定额或调整后额） | 协议有约定 | ¥[约定额] / 估算调整范围 |
| 继续履行竞业限制 | 期限未满 | 须离开竞争单位 |
| 损失赔偿（超出违约金部分，`[待验证]`） | 实际损失超出违约金 | ¥[估算损失 - 违约金] |

### 步骤 3：用人单位违约的劳动者救济（劳动者方视角）

**用人单位违约的两类情形**：

#### 3.1 连续三个月未支付补偿（解除权）

（与`term-and-compensation`子技能联动，此处简述救济路径）

| 劳动者救济手段 | 说明 |
|-------------|------|
| 解除竞业限制义务 | 可请求解除竞业限制约定，恢复自由就业 `[待验证]` |
| 追讨欠付补偿 | 已履行期间的应付补偿须追缴（属工资性质债权，仲裁时效1年） |
| 不承担违约金 | 用人单位违约导致解除，劳动者为守约方，不承担违约金 |

#### 3.2 用人单位单方终止竞业限制约定

若用人单位主动提出解除竞业限制约定（不再要求劳动者遵守），须：
- 书面通知劳动者解除竞业限制
- 支付劳动者已履行竞业限制期间的全部补偿（即便单方解除，已履行期间须付）
- 解除后劳动者恢复择业自由，不受原竞业限制约束

**若用人单位在解除通知发出前已停止支付补偿**：
按三个月未付规则，劳动者已可主张解除；
用人单位单方解除通知系确认该解除，通常不影响劳动者追讨欠付补偿的权利。

### 步骤 4：双向违约场景分析

当双方均存在违约（劳动者违反竞业限制 + 用人单位欠付补偿）时，责任分配较复杂：

| 场景 | 分析框架 |
|------|---------|
| **用人单位先欠付（超3个月），劳动者后违约** | 劳动者已有权解除竞业限制义务，其「违约」可能被认定为合法解除后的行为，违约金风险较低 `[待验证]` |
| **劳动者先违约（已就职竞争单位），用人单位后停付补偿** | 劳动者的先期违约通常不能免除用人单位的补偿义务（二者各自承担违约责任）`[待验证]` |
| **双方同步违约** | 须分析哪一方违约在先，以及各自违约对对方义务的影响 `[待验证]`；建议升级分析 |

**双向违约处理建议**：

1. 首先厘清违约时间线（谁先谁后）
2. 分别评估各自违约责任
3. 考虑双方是否可通过谈判和解，减少双方损失

### 步骤 5：与服务期违约金的制度分工

**本子技能与`hiring-review/service-period-penalty`的边界**：

| 维度 | 竞业限制违约金（本子技能）| 服务期违约金（service-period-penalty）|
|------|----------------------|--------------------------------------|
| **法律依据** | 《劳动合同法》第23条 + 第25条（约 `[待验证]`） | 《劳动合同法》第22条 + 第25条（约 `[待验证]`） |
| **触发情形** | 劳动者违反竞业限制义务（离职后就职竞争单位） | 劳动者接受专项培训后未满服务期离职 |
| **约定限制** | 无明确上限，但过高可申请调整 `[待验证]` | 不超过培训费用，且按剩余服务期分摊 |
| **补偿关系** | 竞业限制违约金与经济补偿相互独立 | 服务期违约金与经济补偿不冲突（服务期本身合法） |
| **深度审查位置** | **本子技能** | `hiring-review/service-period-penalty` |

**识别混同约定**：

若协议将竞业限制违约金和服务期违约金合并为同一条款，须分拆评估：
- 分别识别哪些金额对应竞业限制违约，哪些对应服务期违约
- 各自按对应的法律规则评估合理性

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 约定违约金畸高（如超过劳动者年薪10倍）| 标🔴：极大概率被调整；建议在争议前与对方谈判压低，或准备举证实际损失较低的证据 |
| 协议未约定违约金但劳动者确已违约 | 用人单位须自行举证实际损失，按实际损失主张赔偿（举证难度较高）；建议在签署时补充违约金条款 |
| 竞业限制期限已届满后劳动者违约（如末月才入职竞争单位）| 仍属违约（期限内有效），须按协议处理 |
| 用人单位欲主动解除竞业限制（无需劳动者遵守）| 可书面通知解除，并支付已履行期间补偿；无需劳动者同意 `[待验证]` |
| 劳动者违约后已离开竞争单位并回头履行竞业限制 | 已发生的违约期间的违约金仍可主张，但继续履行不再有实际意义 |

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 协议违约金条款语言模糊（「视情况赔偿损失」）| 分析：「此表述实质为约定按实际损失赔偿，无固定违约金，须举证损失金额」 |
| 违约金与服务期违约金合并约定为同一条款 | 须分拆评估：识别各自对应部分，分别按竞业限制和服务期规则审查 |
| 用人单位主张违约金且同时主张停止违约行为，劳动者认为二者不能并存 | 分析：「中国法律框架下，竞业限制违约金与继续履行请求可并存（均可主张），须向仲裁委/法院主张两项请求」 `[待验证]` |
| 实践配置文件无竞业限制违约金立场 | 使用一般原则：以合理补偿实际损失为基准，过高须申请调整，标`[临时模式]` |
