# 劳务派遣 / 劳务外包 / 委托代缴 定性对照表

> employment-legal 共享参考。供 `workforce-compliance-dd`（用工分类）、`hiring-review`（文件定性）、`labor-dispute-handling`（主体认定）引用。
> 来源：案例库 LWC-2026-0005（约 325 名「外包」人员中多数所属单位登记为用工方）与 LWC-2026-0006（「服务外包合同」+ 按人头计费补充协议；54 名「代发薪」人员劳动合同主体不明）两次同类发现。
> 引用规范遵循 `legal-basis-conventions.md`；条号凡未标「已核实」均为 `[待验证]`。

## 一、法律框架

| 规则 | 依据 | 验证状态 |
|---|---|---|
| 以承揽、外包等名义，按劳务派遣用工形式使用劳动者的，按劳务派遣处理 | 《劳务派遣暂行规定》（人社部令第 22 号，2014-03-01 施行）第 27 条 | 规则已核实；条号 `[待验证]` |
| 派遣只能用于临时性、辅助性、替代性岗位；派遣人数不得超过用工总量的 10% | 《劳动合同法》（2012 年修正）第 66 条；《劳务派遣暂行规定》第 3、4 条 | 规则已核实；条号 `[待验证]` |
| 经营劳务派遣须取得行政许可 | 《劳动合同法》第 57 条；《劳务派遣行政许可实施办法》 | `[待验证]` |
| 用工单位给被派遣劳动者造成损害的，与派遣单位承担连带赔偿责任 | 《劳动合同法》第 92 条 | `[待验证]` |
| 关联单位混同用工、变换签约主体连续订立固定期限合同的认定 | 法释〔2025〕12 号（2025-09-01 施行），见 `labor-law-citations.md` G 节 | 条号按 G 节 |
| 约定或承诺不缴社保无效；用人单位补缴后可请求返还已支付的社保补贴 | 法释〔2025〕12 号第 19 条 | 条号已核实（2026-10-14 联网核对）；条文摘要 `[模型知识 — 需验证]` |

## 二、定性要素对照表

逐项核对**商业合同文本 + 补充协议 + 实际履行证据**，不只看合同名称。每项记录证据来源（file_id / 页码）。

| 要素 | 真外包（承揽 / 服务）特征 | 实为派遣特征 | 本案证据 |
|---|---|---|---|
| 计价方式 | 按成果、工作量、服务等级计价 | 按人头、人月单价计费；费用 = 工资 + 社保 + 管理费 | |
| 人员选定 | 承包方自主安排人员 | 用工方面试、指定、要求更换具体人员 | |
| 指挥管理 | 承包方自行管理，用工方只验收成果 | 用工方直接排班、考勤、下达指令、绩效考核 | |
| 规章制度适用 | 适用承包方制度 | 适用用工方员工手册、考勤与奖惩制度 | |
| 工资与社保基数 | 承包方自定 | 用工方决定工资标准、社保基数、加班费 | |
| 考核与费用挂钩 | 按成果验收 | 个人考核结果直接影响服务费 | |
| 退回 / 换人机制 | 无针对个人的退回条款 | 约定用工方可退回不合格人员 | |
| 场所与工具 | 承包方场所或独立作业 | 在用工方场所使用用工方设备、工号、邮箱 | |
| 直接协议 | 用工方与人员无直接协议 | 用工方与「外包」人员直接签试用期 / 工资 / 保密补充协议 | |
| 三方主体一致性 | 合同相对方 = 实际派出单位 | 外包合同对方 ≠ 劳动合同用工单位 ≠ 解除协议主体（常见为跨省关联公司） | |
| 许可与协议 | 不需要派遣许可 | 应有派遣许可证、派遣协议、三性岗位说明；缺失即风险加重 | |
| 比例 | 不计入 10% | 定性为派遣后计入 10% 比例 | |

判定规则：

- 计价、选人、指挥管理三项中两项以上呈派遣特征 → 结论「名为外包实为派遣」，置信度高；
- 仅一项 → 条件句表述并列入待核实，要求补充派遣协议、许可证和实际履行证据；
- 用工方自有《外包服务管理制度》出现面试选人、人月单价、考勤与个人考核挂钩费用，即构成制度层面证据。

## 三、异地委托代缴 / 代发薪 / 挂靠的区分

| 形态 | 定义 | 法律定性 | 核查顺序 |
|---|---|---|---|
| 委托代缴 | 劳动合同主体为用人单位，社保以人力资源机构名义在异地参保 | 参保主体与用人单位不一致的合规瑕疵；社保转移、工伤认定、待遇申领风险；对照法释〔2025〕12 号第 19 条判断「变更缴纳主体」安排的效力 | ① 确认劳动合同主体 ② 参保地与工作地 ③ 是否有员工书面同意与补贴安排 |
| 代发薪 | 工资由机构代发，人员往往不在用人单位花名册 | **先问劳动合同主体**：与机构签约 → 按派遣审查（比例、许可、三性）；与用人单位签约 → 回到委托代缴 | ① 花名册 × 社保表 × 考勤表交叉 ② 劳动合同样本 ③ 机构服务协议附件 |
| 挂靠 | 无劳动关系的人员借用单位名义参保 | 骗取社保待遇风险（《社会保险法》第 88 条 `[待验证]`） | ① 是否存在劳动合同与考勤 ② 费用由谁承担 |

## 四、需要向客户索取的证据

1. 外包 / 派遣商业合同及全部补充协议、报价单、结算单（按人头计费的证据）；
2. 派遣单位营业执照与劳务派遣经营许可证；派遣协议；三性岗位说明；
3. 「外包」人员名册（含所属单位、岗位、工作地点）及用工方与其直接签订的任何协议；
4. 考勤、排班、绩效考核记录中由用工方制作的部分；
5. 用工方《外包服务管理制度》或类似内部规定；
6. 代缴 / 代发薪机构服务协议及附件、参保地、员工同意书；
7. 规章制度涉及派遣人员时的工会与民主程序证据。

