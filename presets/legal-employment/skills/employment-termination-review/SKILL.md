## 目的

核查拟议解除方案的法律事由是否属于《劳动合同法》（2012年修正）所规定的合法解除情形，
并核查是否触发禁止解除情形，输出「能不能解」的合法性结论及风险等级评估。

---

## 详细步骤

### 步骤 1：识别解除类型

首先确认拟议解除属于哪一类：

| 解除类型 | 特征 | 是否须支付经济补偿 |
|---------|------|-----------------|
| 协商解除（约第36条 `[待验证]`） | 双方协商一致 | 用人单位提出时须支付 |
| 过失性辞退（约第39条 `[待验证]`） | 劳动者有过错情形 | **不须支付** |
| 非过失性辞退（约第40条 `[待验证]`） | 劳动者无过错，但有特定情形 | **须支付 N** |
| 经济性裁员（约第41条 `[待验证]`） | 企业层面经济原因，批量裁减 | **须支付 N** |

> **引用纪律**：第36/39/40/41条已经相当确定地对应上述内容，但使用时仍标注 `[待验证]`，
> 引用前通过 https://flk.npc.gov.cn 核验。

### 步骤 2：核查各类解除的法定构成要件

#### 2.1 协商解除（《劳动合同法》约第36条 `[待验证]`）

**核心要件**：

- [ ] 用人单位与劳动者协商一致（须有双方意思表示）
- [ ] 签署书面协议（强烈建议，防止争议）
- [ ] 协议内容明确（解除日期 / 经济补偿金额 / 社保转移安排 / 工资结清）

**注意**：

- 若由**用人单位**提出协商解除，须支付经济补偿（约第46条 `[待验证]`）
- 若由**劳动者**提出协商解除，用人单位无须支付经济补偿
- 协商解除协议签署后，劳动者原则上不可反悔（须确认签署时意思表示自愿真实）

| 审查项 | 状态 |
|-------|------|
| 解除系哪方提出？ | ☐ 用人单位 / ☐ 劳动者 |
| 双方达成一致的证据 | ☐ 已有书面协议 / ☐ 仅口头 |
| 协议是否载明补偿金额 | ☐ 是 / ☐ 否 |
| 劳动者签字时是否有「被迫」迹象 | ☐ 是 🔴 / ☐ 否 |

#### 2.2 过失性辞退（《劳动合同法》约第39条 `[待验证]`）

过失性辞退无需提前通知，**无需支付经济补偿**。但须满足以下任一情形：

| 情形 | 法定描述 | 审查要点 |
|------|---------|---------|
| 试用期不符合录用条件 | 在试用期内被证明不符合录用条件 | 录用条件是否事先明确告知并有书面记录？ |
| 严重违反规章制度 | 严重违反用人单位的规章制度 | 规章制度是否经民主程序制定并公示（或书面告知）？「严重」的标准是否在制度中明确？ |
| 严重失职、营私舞弊 | 严重失职、营私舞弊，给用人单位造成重大损害 | 「重大损害」的认定依据？有无量化或明确标准？ |
| 双重劳动关系 | 同时与其他用人单位建立劳动关系，影响本职工作，经提出拒不改正 | 是否已提出（有书面记录）但劳动者拒不改正？ |
| 欺诈胁迫致合同无效 | 以欺诈、胁迫或乘人之危方式订立劳动合同，导致合同无效 | 欺诈/胁迫的证据？是否经仲裁或司法确认合同无效？ |
| 被追究刑事责任 | 被依法追究刑事责任 | 是否已有生效刑事判决或检察院起诉？拘留/羁押≠追究刑责 |

**重要边界条件（规章制度适用）**：

| 规章制度缺陷 | 法律后果 |
|------------|---------|
| 规章制度未经民主程序制定 | 不得作为解除依据，标🔴 |
| 规章制度经民主程序但未向劳动者公示/告知 | 不得作为解除依据，标🔴 |
| 「严重」标准缺失或模糊 | 在仲裁/诉讼中可能被认定不合规，标🟠 |
| 末位淘汰制度 | **末位淘汰≠「不能胜任工作」**，不适用非过失性辞退规定，绝不可直接依据此辞退劳动者，标🔴 |

#### 2.3 非过失性辞退（《劳动合同法》约第40条 `[待验证]`）

非过失性辞退须**提前30天书面通知**或支付**代通知金**（一个月工资），并**须支付经济补偿 N**。
须满足以下任一情形：

| 情形 | 法定描述 | 前置程序 | 审查要点 |
|------|---------|---------|---------|
| 医疗期满不能从事工作 | 劳动者患病或非因工负伤，医疗期满后不能从事原工作，也不能从事用人单位另行安排的工作 | 须先「另行安排工作」 | 医疗期是否已满？是否真的安排了其他工作？劳动者是否确实不能从事？ |
| 不能胜任工作 | 劳动者不能胜任工作，经过培训或者调整工作岗位，仍不能胜任工作 | 须先「培训或调岗」 | 是否进行了真实的培训或调岗？有无记录？调岗后仍不胜任的证据？ |
| 客观情况重大变化 | 劳动合同订立时所依据的客观情况发生重大变化，致使劳动合同无法履行，经与劳动者协商未能就变更劳动合同内容达成协议 | 须先「协商变更」 | 什么是「重大变化」？有无协商记录？协商是否诚实进行？ |

**重要说明**：

- 「不能胜任工作」须经**培训或调岗**验证，不能仅凭绩效考核末位即认定
- 「客观情况重大变化」须是外部重大变化（如政策法规变化、市场环境），不包括内部重组
  （注：内部重组是否构成本情形存在争议，标 `[待验证]`）
- 每种情形均须**先履行前置程序**（安排工作/培训调岗/协商变更），否则解除无效

#### 2.4 经济性裁员（《劳动合同法》约第41条 `[待验证]`）

经济性裁员有严格的数量门槛和法定情形：

**数量门槛**：

- 需要裁减人员**20人以上**；或
- 裁减人数不足20人但**占企业职工总数10%以上**

（同时满足其一即可）

**法定情形（须满足其一）**：

| 法定情形 | 说明 |
|---------|------|
| 企业破产重整 | 依照企业破产法规定进行重整 |
| 生产经营严重困难 | 实践中认定标准有争议 `[待验证]` |
| 企业转产、技术革新、经营方式调整 | 须有客观背景，非主观压缩人员 |
| 其他客观经济情况重大变化 | 兜底条款，须有实质支撑 |

**法定程序（必须依序履行）**：

1. [ ] **提前30天向工会或全体职工说明情况**（注意：须说明，非仅通知）
2. [ ] **听取工会或职工的意见**（须有记录）
3. [ ] **向劳动行政部门报告裁减人员方案**
4. [ ] **优先留用**以下人员：
   - 与本单位订立较长期限固定期限劳动合同的
   - 与本单位订立无固定期限劳动合同的
   - 家庭无其他就业人员、有需要赡养的老人或者未成年人（约第41条 `[待验证]`）
5. [ ] **6个月内重新招用人员的，须优先通知被裁减人员**（约第41条 `[待验证]`）

### 步骤 3：禁止解除情形前置核查（必须优先执行）

> **警告**：以下情形存在时，**非过失性辞退**和**经济性裁员**不得适用。

## 目的

精确计算劳动合同解除时劳动者应获得的经济补偿、代通知金或违法解除赔偿金，
清晰区分 N / N+1 / 2N 三种情形，提供计算工作表和金额汇总。

---

## 详细步骤

### 步骤 1：确定适用情形（N / N+1 / 2N 路径）

首先确认解除方式和合法性，进入对应计算路径：

| 情形 | 触发条件 | 计算公式 |
|------|---------|---------|
| **N（经济补偿）** | 合法解除且须支付经济补偿（协商由用人单位提出/非过失/裁员/合同到期维持条件不续等，约第46条 `[待验证]`） | N = 工龄年限 × 月工资基数（封顶规则见步骤3） |
| **N+1（经济补偿+代通知金）** | 非过失性辞退但**未提前30天书面通知**，以额外一个月工资代替提前通知 | N+1 = 经济补偿N + 1个月代通知金（两者性质不同，代通知金不计入N基数） |
| **2N（违法解除赔偿金）** | 用人单位违法解除或违法终止劳动合同（第87条**已核实锚点**） | 2N = N × 2（按第47条经济补偿标准二倍支付，与N互斥不并用） |
| **零（无需补偿）** | 过失性辞退（约第39条 `[待验证]`）且劳动者无过错申索 | 0 |
| **劳动者主动辞职** | 劳动者无故辞职（非因用人单位过错） | 0（但劳动者依约第38条因用人单位过错解除，须支付N `[待验证]`） |

> **核心区分**：
> - **N** 是合法解除的经济补偿，来源：第47条（**已核实锚点**）
> - **+1（代通知金）** 是替代提前30天通知的对价，性质为工资，不是经济补偿
> - **2N** 是违法解除的赔偿金，来源：第87条（**已核实锚点**），与N **互斥不并用**

### 步骤 2：确定月工资基数

月工资基数是计算经济补偿/赔偿金的关键变量：

**法定定义**（基于第47条，**已核实锚点**）：

| 定义项 | 标准 |
|-------|------|
| 计算区间 | 劳动合同解除或终止前**12个月**的平均工资 |
| 包含项目 | **应得**工资（含基本工资、绩效奖金、津贴、补贴等，解除前12个月实际发放的各项工资性收入） |
| 扣减后税前 | 以税前应得工资计算（非税后实得），含个人所得税部分 |
| 最低保障 | 劳动者月工资低于用人单位所在地最低工资标准的，按最低工资标准计算 |

**高收入封顶规则**（第47条**已核实锚点**）：

若劳动者月工资**高于用人单位所在地上年度职工月平均工资三倍**：
- **月工资基数封顶**：按「三倍」平均工资计算，超出部分不计
- **工龄年限封顶**：最高支付12年经济补偿（不论实际工龄多长）

> 示例：上年度当地职工月平均工资为 ¥8,000，三倍为 ¥24,000。
> 若劳动者月工资为 ¥30,000，基数封顶为 ¥24,000；若工龄15年，年限封顶12年。
> 经济补偿 = ¥24,000 × 12年 = ¥288,000

**争议性项目（须确认是否纳入基数）**：

| 项目 | 一般处理 | 风险提示 |
|------|---------|---------|
| 年终奖 | 月均摊入12个月 `[待验证]` | 各地仲裁口径不一，争议多 |
| 股权/期权收益 | 通常不纳入工资基数 `[待验证]` | 须核查合同约定 |
| 报销款项/差旅补贴 | 通常不纳入（非劳动报酬性质） | — |
| 住房补贴 | 纳入（属工资性质） `[待验证]` | — |

### 步骤 3：计算经济补偿 N（第47条，已核实锚点）

**工龄年限认定规则**（第47条**已核实锚点**）：

| 工龄段 | 计算方式 |
|--------|---------|
| 满1年 | 计1个月工资 |
| 满6个月不满1年 | 按1年计算，即1个月工资 |
| 不满6个月 | 支付半个月工资（0.5个月） |

> **工龄起算**：从劳动者入职本单位当日起算至劳动合同解除或终止日。
> 多次签订合同（固定期限续签）的，连续工龄累计计算。
> **历史问题（须提示）**：2008年1月1日（《劳动合同法》施行日）前后的工龄是否分段计算，
> 各地实践存在差异 `[待验证]`，建议核查当地最新仲裁口径。

### 步骤 4：代通知金计算（N+1 中的「+1」）

代通知金适用于：**非过失性辞退且未提前30天书面通知**。

| 项目 | 说明 |
|------|------|
| 金额 | 一个月工资（按劳动者月工资计算，非按三倍封顶基数） |
| 性质 | 替代提前30天通知义务的对价，属工资性质，**非经济补偿** |
| 与N的关系 | 二者并列，N+1 = 经济补偿N + 一个月代通知金 |
| 是否计入N基数 | **不计入**：代通知金不影响N的月工资基数计算 |

> **N+1 总计**：
> - N = 经济补偿（月工资基数 × 工龄年限）
> - +1 = 一个月工资（代通知金）
> - **合计 = N + 1个月工资**

### 步骤 5：违法解除赔偿金 2N（第87条，已核实锚点）

**触发条件**：用人单位违法解除或违法终止劳动合同（第87条**已核实锚点**）。

**计算规则**（第87条**已核实锚点**）：

> 按照第47条规定的经济补偿标准的**二倍**向劳动者支付赔偿金。

**选择权归属**（劳动者方主张时）：

| 选项 | 条件 | 结果 |
|------|------|------|
| 恢复劳动关系 | 劳动者要求继续履行且合同能够继续履行 | 继续履行 + 支付解除至恢复期间工资（不支付2N） |
| 支付2N赔偿金 | 劳动者不要求恢复，或合同已不能继续履行 | 支付2N，不另支付N |

> **2N 与 N 互斥**：违法解除支付2N，不另支付N；合法解除支付N，无需支付2N。

**2N 计算工作表**：

```

步骤 B：2N = N × 2
  2N = ¥[  ] × 2 = ¥[  ]

注意：2N计算基数与N相同（月工资基数 × 工龄年限），封顶规则同样适用。
```

| 场景 | 处理方式 |

## 目的

核查拟议解除或已发生解除的法定程序是否依法履行，
识别程序瑕疵（可能导致解除无效或赔偿责任），

## 详细步骤

### 步骤 1：确认解除类型与对应程序差异

不同解除类型对应不同法定程序要求，须首先确认类型：

| 解除类型 | 提前30天通知/代通知金 | 通知工会 | 向劳动行政部门报告 | 出具解除证明 | 档案社保转移 |
|---------|-------------------|---------|-----------------|-----------|-----------|
| 协商解除（约第36条 `[待验证]`） | ☐ 不要求（双方协商） | ☐ 建议通知 `[待验证]` | ☐ 不要求 | **☐ 必须** | **☐ 必须** |
| 过失性辞退（约第39条 `[待验证]`） | ☐ **无需提前通知** | **☐ 须事先通知工会** | ☐ 不要求 | **☐ 必须** | **☐ 必须** |
| 非过失性辞退（约第40条 `[待验证]`） | **☐ 提前30天书面通知或代通知金** | **☐ 须事先通知工会** | ☐ 不要求 | **☐ 必须** | **☐ 必须** |
| 经济性裁员（约第41条 `[待验证]`） | **☐ 提前30天向工会/职工说明** | **☐ 须提前说明并听取意见** | **☐ 须向劳动行政部门报告** | **☐ 必须** | **☐ 必须** |

### 步骤 2：提前通知/代通知金（非过失性辞退专项）

**适用范围**：仅非过失性辞退须履行此程序。
经济性裁员须提前30天向工会/职工**说明**，性质不同。

| 审查项 | 合规要求 | 状态 |
|-------|---------|------|
| 是否已提前30天书面通知 | 书面形式，须留存送达证明 | ☐ 是 / ☐ 否→支付代通知金 |
| 书面通知是否载明解除事由 | 须说明解除依据（约第40条情形） | ☐ 是 / ☐ 否🟠 |
| 30天期间劳动者是否正常工作 | 通知期内劳动者照常工作、领取工资 | ☐ 已履行 / ☐ 未履行🟠 |
| 如未提前通知：代通知金是否支付 | 额外支付一个月工资 | ☐ 已支付 / ☐ 未支付🔴 |

**送达合规**（书面通知的举证关键）：

| 送达方式 | 举证要求 | 建议 |
|---------|---------|------|
| 当面送达 | 劳动者签字确认、注明日期 | 首选，留存签收记录 |
| EMS 快递 | 快递回执 + 签收记录 | 务必保存回执，记录发件地址 |
| 电子邮件/企业微信/钉钉 | 发送记录 + 已读回执或回复 | 须有被送达方读取证明 |
| 留置送达 | 劳动者拒签时，见证人在场 + 照片/视频 | 最后手段，须有见证人 |
| 公告送达 | 用于无法送达的情形，须在劳动合同约定/企业公告栏公示 | 效力最弱，争议多 `[待验证]` |

### 步骤 3：工会通知（过失性辞退 / 非过失性辞退专项）

**适用范围**：过失性辞退和非过失性辞退均须**事先**通知工会，并说明解除理由。
若企业无工会，该程序豁免（但须确认无工会的事实）。

| 审查项 | 合规要求 | 状态 |
|-------|---------|------|
| 企业是否设有工会 | 确认工会存在情况 | ☐ 有工会 / ☐ 无工会（记录在案） |
| 是否**事先**通知工会（非事后） | 必须在解除**前**通知 | ☐ 已事先通知 / ☐ 未通知🔴 / ☐ 无工会 |
| 是否说明解除理由 | 通知应载明理由和依据 | ☐ 是 / ☐ 否🟠 |
| 工会是否提出异议 | 工会认为不合法可提出意见 | ☐ 无异议 / ☐ 有异议（处理方式：[  ]） |
| 工会异议是否处理 | 用人单位须考虑工会意见，再作决定 `[待验证]` | ☐ 已处理 / ☐ 未处理🟠 |

**重要边界**：

- 工会通知程序瑕疵（如解除后才通知工会）：
  - 一般认为程序违法，但部分地区认定可在诉讼前补正效力，标 `[待验证]`（各地实践不一）
  - 建议不依赖补正，严格在解除前完成通知

**经济性裁员中的工会程序**（区别于过失/非过失）：

| 程序要求 | 说明 |
|---------|------|
| 提前30天向工会或全体职工说明 | 主动说明，非仅「通知」（约第41条 `[待验证]`） |
| 听取工会或职工意见 | 须有书面记录，意见须被考虑（非仅形式性听取） |
| 裁员方案须经过意见程序 | 实践中意见程序结束后方可正式裁员 |

### 步骤 4：向劳动行政部门报告（经济性裁员专项）

**适用范围**：仅经济性裁员须履行此程序（约第41条 `[待验证]`）。

| 审查项 | 合规要求 | 状态 |
|-------|---------|------|
| 是否已向劳动行政部门报告 | 须提交裁员方案及说明 | ☐ 已报告 / ☐ 未报告🔴 |
| 报告时间 | 在正式裁员前完成 | ☐ 是 / ☐ 否🔴 |
| 报告材料 | 裁员原因说明 / 裁员名单 / 经济补偿方案 | ☐ 完备 / ☐ 不完备🟠 |

### 步骤 5：出具解除证明

**全部解除类型**均须出具书面解除证明（约劳动合同法相关条款 `[待验证]`）。

**解除证明的法定内容**（须核查是否齐全）：

| 内容项 | 是否必须 | 状态 |
|-------|---------|------|
| 劳动合同期限 | 必须 | ☐ 含 / ☐ 缺 |
| 解除或终止劳动合同的日期 | 必须 | ☐ 含 / ☐ 缺 |
| 工作岗位 | 必须 | ☐ 含 / ☐ 缺 |
| 在本单位的工作年限 | 必须 | ☐ 含 / ☐ 缺 |
| 解除或终止劳动合同的原因（如用人单位提出） | 劳动者要求时应提供 `[待验证]` | ☐ 按要求处理 |
| 是否注明「协商解除」/「非过失辞退」等具体方式 | 按约定和惯例 | ☐ 注明 / ☐ 未注明 |

**未出具解除证明的法律后果**：

- 用人单位未及时出具解除/终止劳动合同的书面证明，给劳动者造成损害的，须承担赔偿责任
  （约劳动合同法相关条款 `[待验证]`）
- 实践中，未出具解除证明可能导致劳动者无法在新单位入职，用人单位面临赔偿责任🟠

### 步骤 6：档案和社保转移

**时限要求**（约劳动合同法相关条款 `[待验证]`）：

| 事项 | 时限 | 操作主体 | 状态 |
|------|------|---------|------|
| 档案转移手续办理 | 解除/终止后**15日**内 | 用人单位协助办理 | ☐ 已完成 / ☐ 超期🟠 |
| 社保关系转移 | 解除后当月或次月社保中断 | 用人单位在系统中及时操作 | ☐ 已完成 / ☐ 超期🟠 |
| 住房公积金封存/转移 | 按公积金管理中心规定 `[待验证]` | 用人单位办理封存手续 | ☐ 已完成 / ☐ 待处理 |
| 解除/终止劳动合同证明归入档案 | 须归入劳动者档案 | 用人单位 | ☐ 已归档 / ☐ 未归档🟠 |

## 目的

在解除被认定为违法的情形下，分析劳动者的救济路径（恢复劳动关系 vs. 2N赔偿金），
核查举证责任分配，并为用人单位提供事前风险预防清单，
实现「解错了怎么救济、怎么预防」的完整闭环。

---

## 详细步骤

### 步骤 1：立场确认与违法解除认定来源

首先确认使用立场，决定救济分析方向：

| 立场 | 关注重点 |
|------|---------|
| 用人单位方 | 能否重新合规：撤销解除、补程序？不能则如何将损失最小化（接受2N谈判和解） |
| 劳动者方 | 主张恢复劳动关系还是2N赔偿金，哪个对劳动者更有利？ |

**违法解除常见来源**（须确认触发原因）：

| 来源 | 说明 |
|------|------|
| 解除事由不符合法定情形 | 由 `grounds-legality` 评估得出 |
| 程序瑕疵（未通知工会/未提前通知） | 由 `termination-procedure` 评估得出 |
| 解除对象在禁止解除情形中 | 医疗期/孕产哺乳期/工伤等 |
| 解除事由与实际情形不符 | 虚构解除理由 |

### 步骤 2：劳动者救济路径分析

违法解除时，劳动者有两条法定救济路径（**第87条已核实锚点**），**二者择一，不可兼得**：

#### 路径 A：恢复劳动关系（继续履行劳动合同）

**适用条件**：

- [ ] 劳动者要求继续履行劳动合同（须明确表达该意愿）
- [ ] 劳动合同**能够**继续履行（满足以下全部条件）：
  - 用人单位仍存续（未注销/未破产）
  - 岗位未撤销或可恢复（若岗位已不存在，可能不支持恢复）
  - 劳动关系不存在其他不能继续的客观障碍（如双方矛盾不可调和 `[待验证]`）

**法律后果**：

| 项目 | 内容 |
|------|------|
| 继续履行劳动合同 | 按原合同条款继续（职位/工资/待遇） |
| 中间期工资 | 支付解除之日至恢复劳动关系期间的工资（不低于原工资标准） |
| 是否支付2N | **不支付2N**（恢复劳动关系和2N赔偿金二者择一） |
| 社保补缴 | 通常须补缴中间期社保 `[待验证]` |

**不支持恢复的情形**（须在报告中明确提示）：

| 情形 | 处理 |
|------|------|
| 劳动合同已到期（解除时合同期限已终止） | 一般不支持恢复，转向2N `[待验证]` |
| 用人单位已注销 | 无法恢复，转向2N（向清算组或股东主张） |
| 岗位已不存在（如整个业务线撤销） | 争议，法院/仲裁委裁量 `[待验证]` |
| 合同期已届满（在仲裁/诉讼期间期满） | 转为支付2N（合同期届满后不能恢复） `[待验证]` |

#### 路径 B：违法解除赔偿金 2N（第87条，已核实锚点）

**适用条件**：

- 劳动者不要求恢复劳动关系，或
- 客观上劳动关系已不能继续履行（见上方不支持恢复情形）

**2N 计算**：按 `severance-calculation` 子技能中的2N计算规则执行：

| 步骤 | 说明 |
|------|------|
| 先算N | 按第47条（**已核实锚点**）：月工资基数 × 工龄年限（含封顶规则） |
| 2N = N × 2 | 违法解除赔偿金 = 经济补偿N × 2 |
| 与N互斥 | 支付2N，不另支付经济补偿N |

**重要说明**：

- 2N是**最低法定赔偿**，用人单位不得低于此标准；双方可协商高于2N的赔偿（和解谈判）
- 2N是**赔偿金**性质，与经济补偿N性质不同（一合法一违法），不可叠加

#### 两条路径对比

| 维度 | 路径A：恢复劳动关系 | 路径B：2N赔偿金 |
|------|-------------------|--------------|
| 适用前提 | 劳动者要求 + 合同能继续 | 劳动者不要求恢复 或客观不能恢复 |
| 经济补偿 | 不支付2N，但须支付中间期工资 | 支付2N，与N互斥 |
| 社保 | 须补缴中间期 | 按协议/判决处理 |
| 劳动者利益分析 | 关系存续价值 + 中间期工资；适合长工龄、临近退休、关系重要的情形 | 一次性了结；适合双方关系已破裂、工作已找到的情形 |
| 执行难度 | 用人单位不配合时执行难度较高 | 执行相对简单（金钱给付） |

### 步骤 3：举证责任分析

**核心原则**：**用人单位对解除合法性承担举证责任**（`[待验证]`——此规则在劳动争议实践中高度确定，具体条号须核查）。

| 举证负担 | 由谁承担 | 内容 |
|---------|---------|------|
| 解除事由的合法性 | 用人单位 | 须举证劳动者存在约定情形（如严重违纪的具体事实和证据） |
| 程序合规性 | 用人单位 | 须举证已完成通知工会/提前通知/出具证明等程序 |
| 劳动者签收解除通知 | 用人单位 | 须保留送达记录（签收/快递回执/电子记录） |
| 规章制度公示 | 用人单位 | 须举证规章制度经民主程序制定并告知劳动者 |
| 劳动者过错事实 | 用人单位 | 须有具体事实证据（非仅结论性评价） |

**举证不能的后果**：

| 情形 | 可能结论 |
|------|---------|
| 无法证明解除事由存在 | 解除被认定违法，须支付2N或恢复劳动关系 |
| 无法证明规章制度公示 | 不能以违反规章制度为由解除 |
| 无法证明工会通知 | 程序违法，可能导致解除无效（各地不一 `[待验证]`） |
| 无法证明通知送达 | 解除效力存疑，可能被认为解除通知未生效 |

### 步骤 4：用人单位风险预防清单（事前预防）

> 此清单供用人单位方在解除**前**使用，防患于未然。

#### 4.1 事由证据固化

- [ ] 过失行为的书面记录（违纪记录、处理意见、当事人签字确认）
- [ ] 绩效考核结论的书面证明（含考核标准、结果和劳动者知晓）
- [ ] 培训/调岗的书面记录（「不能胜任工作」前置程序的完整证明链）
- [ ] 客观情况变化的外部证据（政府政策文件/市场公告等）
- [ ] 劳动者欺诈/违规的具体证据（时间/地点/方式/损害金额）

#### 4.2 规章制度合规

- [ ] 规章制度是否经民主程序制定（职工大会或职工代表大会讨论/工会协商）
- [ ] 规章制度是否经公示（公告栏/系统发布/书面告知/入职培训签到）
- [ ] 「严重」标准是否在制度中明确量化（金额/次数/情节描述）
- [ ] 末位淘汰制度是否与「不能胜任工作」认定程序脱钩
- [ ] 违纪行为定义是否清晰，避免歧义

#### 4.3 通知与送达留痕

- [ ] 书面解除通知送达证明（首选当面签收，其次EMS留回执）
- [ ] 解除通知载明解除依据（具体情形，非泛称「违纪」）
- [ ] 非过失性辞退：提前30天通知或代通知金支付记录
- [ ] 协商解除：协议书原件留存（含双方签字、日期）

#### 4.4 工会程序

- [ ] 解除**前**向工会书面通知（留存通知记录）
- [ ] 工会意见是否收到（有书面回复的，留存；无回复的，记录通知已发）
- [ ] 工会异议是否有书面处理说明（若提出异议）

#### 4.5 全流程时间线记录

- [ ] 从事由发现到解除决定的时间线清晰（防止「时过境迁」证据失效）
- [ ] 各程序节点均有书面时间戳（通知日期/工会告知日期/解除生效日期）
- [ ] 与劳动者沟通记录留存（包括协商、培训、调岗等关键节点）

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 恢复劳动关系诉求实际难以执行（用人单位拒不配合） | 告知劳动者：仲裁委/法院可裁决支持恢复，用人单位不执行则视为违法拒绝履行，可强制执行或转为2N赔偿（各地实践 `[待验证]`）；建议优先考虑2N路径以便执行 |
| 仲裁/诉讼期间劳动合同期限届满 | 合同已届满则恢复劳动关系不再可行，转为支付2N赔偿金 `[待验证]` |
| 劳动者主张恢复劳动关系+2N双重请求 | 明确两者不可兼得，须在程序中作出明确选择；通知劳动者须确定一种主张 |
| 用人单位愿意协商和解但劳动者要求高于2N | 2N为法定最低标准，高于2N的和解为合法约定；根据案件风险评估建议合理协商区间 |
| 程序瑕疵但事由合法（如未通知工会但过失事由充分） | 纯程序违法时各地口径不一——有认为程序瑕疵即违法须2N，有认为事由合法可酌情处理 `[待验证]`；建议标🟠并在当地确认口径 |

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 双方对解除合法性争议大，无法判断是否违法 | 出具双路径分析：「若合法解除：N = ¥[  ]；若违法解除：2N = ¥[  ]，或恢复劳动关系」，提示最终结论需仲裁委/法院认定 |
| 用人单位已实际支付N但被认定违法解除 | 须补差额（2N - 已付N）= 额外支付N；已付N一般可抵扣 `[待验证]` |
| 禁止解除情形下强行解除 | 标🔴：强行解除医疗期/孕期等情形的，违法性清晰，支持恢复劳动关系或2N的概率极高；建议立即暂停执行解除方案，重新评估 |
| 劳动者未及时申请仲裁（时效问题） | 提示：劳动争议仲裁时效1年（《劳动争议调解仲裁法》第27条，**已核实锚点**），从知道或应当知道权利受侵害之日起算，迟延申请可能丧失仲裁权利 |
