# 劳动争议处理（编排入口）

> **新增技能说明**：本技能为 Phase 4 新增，覆盖劳动争议完整解决路径（定性时效 → 调解 → 仲裁 → 诉讼），填补原 employment-legal 插件在争议解决阶段的空白。
>
> **跨插件提示（Deferred）**：诉讼阶段的证据三性审查、时效监控定时提醒可后续接入 `litigation-legal` 插件的对应技能，标为 Deferred（不在本阶段实现）。

---

## 目的

提供劳动人事争议全链路处理能力：

1. **时效优先**：任何路径前必须先经 `dispute-classification-limitation` 核实时效（1年仲裁时效，第27条，已核实锚点）；
2. **路径选择**：评估调解/仲裁/诉讼的适用性；
3. **一裁终局识别**：核实争议是否属于终局裁决范围（第47条，已核实锚点），影响双方救济权利；
4. **全程立场加载**：用人单位方（防御/合规视角）vs 劳动者方（权益主张视角）。

```
          ↓

              ↓                    ↓

        (15日)           (30日，法定情形)[待验证]
```

## 入口级护栏

### 时效优先护栏（强制）

**进入任何路径前，必须先经 `dispute-classification-limitation` 确认：**

1. 争议是否属于劳动争议范围（仲裁前置适用）
2. 仲裁时效是否届满（1年，《劳动争议调解仲裁法》第27条，已核实）
3. 是否属于存续期间拖欠报酬（不受1年限制的特例）

**时效届满时**：评估对方是否会提出时效抗辩；无抗辩情形下仍可尝试；有抗辩情形下须评估其他补救。

### 一裁终局识别提示

在仲裁路径阶段（`arbitration-path`），必须核查争议是否属于第47条一裁终局范围：

- **一裁终局**：劳动者可15日内起诉；用人单位不可起诉，仅可30日内申请撤销（法定情形）`[待验证]`
- **非终局**：双方均可15日内起诉 `[待验证]`

### 用人单位方/劳动者方立场护栏

| 立场 | 争议处理视角 | 关注重点 |
|------|-----------|---------|
| **用人单位方** | 防御/合规视角 | 是否有合法解除依据？证据是否充分？调解能否降低2N风险？一裁终局利用策略（小额追索时倾向一裁终局终结争议）|
| **劳动者方** | 权益主张视角 | 时效是否在期限内？所有应得金额是否全部主张？一裁终局时劳动者起诉权充分保障 |

# 劳动争议定性与时效（dispute-classification-limitation）

> **所属编排**：`employment-legal/skills/labor-dispute-handling/SKILL.md`（劳动争议处理）
> **分工说明**：本子技能专责争议定性与仲裁时效核查。调解路径由 `mediation-path` 处理；仲裁路径由 `arbitration-path` 处理；诉讼路径由 `litigation-path` 处理。

## 目的

在进入任何争议解决路径之前：

1. **争议定性**：确认纠纷是否属于劳动争议范围（须适用仲裁前置程序），区分劳动争议与劳务/侵权/合同纠纷；
2. **时效核查**：核实仲裁申请时效是否届满（一般 1 年，《劳动争议调解仲裁法》第27条，已核实锚点）；
3. **时效起算**：确认起算点（知道或应当知道权利受侵害之日）及存续期间拖欠报酬特例；
4. **时效中止/中断**：识别时效中止/中断情形，防止时效被错误消灭。

### 属于劳动争议范围（仲裁前置适用）`[待验证 — 具体条号待核实]`

以下事项属于劳动争议，须先经劳动人事争议仲裁委员会仲裁，对裁决不服方可起诉：

| 争议类型 | 说明 | 典型情形 |
|---------|------|---------|
| 确认劳动关系 | 双方对是否存在劳动关系有争议 | 劳务协议被主张劳动关系、无书面合同 |
| 订立/履行/变更/解除/终止劳动合同 | 合同内容与履行争议 | 条款效力、变更未经协商、解除程序违法 |
| 除名、辞退、辞职、离职 | 各类终止雇佣关系的合法性争议 | 违法辞退、自动离职认定 |
| 工作时间、休息休假、社会保险、福利 | 劳动条件争议 | 加班费计算、年休假未休补偿、社保欠缴 |
| 劳动报酬 | 工资、奖金、提成、经济补偿等 | 欠薪、绩效克扣、经济补偿不足 |
| 工伤医疗费 | 工伤赔偿争议 | 医疗费报销、停工留薪期工资 |
| 培训费用/竞业限制补偿/赔偿金 | 违约金与补偿争议 | 竞业违约金、经济补偿、2N赔偿金 |

### 不属于劳动争议范围（须走普通民事途径）`[待验证]`

| 情形 | 分析 |
|------|------|
| 劳务关系争议（非劳动关系） | 独立承包人、个人劳务合同中不存在劳动关系的，不适用仲裁前置 |
| 社保行政争议（不服社保行政决定） | 属行政法律关系，应走行政复议/行政诉讼 |
| 用人单位内部规定不满（无具体权益侵害） | 不构成劳动争议，须先穷尽内部申诉 |

**审查要点：**

- [ ] 纠纷是否发生在劳动关系存续期间或终止后

- [ ] 争议标的是否在劳动争议范围内

## 第二步：仲裁时效核查（已核实锚点）

### 一般仲裁时效（《劳动争议调解仲裁法》第27条，已核实）

| 要素 | 内容 |
|------|------|
| **时效期间** | **1 年**（《劳动争议调解仲裁法》第27条，已核实锚点） |
| **起算点** | 当事人**知道或者应当知道**其权利被侵害之日起计算 |
| **法律后果** | 超过仲裁时效，仲裁委可能不予受理；即使受理，对方提出时效抗辩，胜诉可能性降低 |

### 时效起算点认定

| 争议类型 | 起算点认定方式 | 注意事项 |
|---------|-------------|---------|
| 欠薪争议（每月发薪日届期） | 每月发薪日后次日（分期欠薪按每次发薪日分别起算） | 🔴 若多月欠薪，须分月核算时效 |
| 违法解除争议 | 收到解除通知书或知道解除事实之日 | |
| 经济补偿不足 | 离职之日（协议约定金额未足额支付时，自约定支付日起算）`[待验证]` | |
| 工伤赔偿 | 工伤认定决定书下达后 `[待验证]` | |
| 竞业限制补偿 | 用人单位停止支付之日 `[待验证]` | |
| 未休年休假工资 | 存在争议：按年逐年计算 vs 离职时统一计算 `[学说争议，待验证]` | 🟡 建议尽早主张，不等到离职 |

**时效起算点实务技巧（劳动者方）：**

> 若劳动者「不知道」权利被侵害（如不知道社保应由用人单位全额缴纳），起算点可能延后——但举证「应当知道」难度大，不建议依赖该主张，应尽早申请仲裁。

## 第四步：拖欠劳动报酬特例（重要）

### 存续期间拖欠报酬不受1年限制（《劳动争议调解仲裁法》第27条，已核实）

> **特别规则**：劳动关系**存续期间**因**拖欠劳动报酬**发生争议的，劳动者申请仲裁**不受一年仲裁时效期间的限制**。
>
> **但是**：劳动关系**终止**后，应当在劳动关系终止之日起**一年内**提出申请。

| 情形 | 时效规则 |
|------|---------|
| 劳动关系存续期间欠薪（仍在职） | 不受1年限制，随时可申请仲裁 |
| 劳动关系已终止（已离职）后追欠薪 | 须在终止之日起1年内申请，超过则受时效限制 |

**审查要点：**

- [ ] 劳动关系是否仍存续（影响是否适用特例）
- [ ] 如已终止，终止日期是否已超过1年
- [ ] 追索的欠薪是否全部属于劳动报酬（非劳动报酬的其他金额不适用此特例）

## 第五步：时效届满的处理

### 超过仲裁时效但对方未抗辩

仲裁时效是可以被放弃的抗辩权——如果对方（通常是用人单位）在仲裁中未提出时效抗辩，仲裁委不应主动援引时效驳回。实务中，仲裁委的主动援引做法存在争议 `[待验证]`。

| 对方行为 | 处理方式 |
|---------|---------|
| 未提出时效抗辩 | 程序上可能仍可获支持，但须谨慎，不要依赖对方失误 |
| 提出时效抗辩 | 举证时效起算点（证明起算点晚于一年前）或时效中止/中断事实 |

| 错误场景 | 识别方式 | 处理方案 |

| 遗漏存续期间拖欠报酬特例 | 劳动者仍在职但说「时效已过」 | 🟠 存续期间拖欠报酬不受1年限制，重新核查 |

## 第一步：调解适用性评估

### 调解的适用场景

| 情形 | 调解适合性 | 原因 |
|------|-----------|------|
| 劳动关系仍存续，双方希望保持关系 | 高度适合 | 避免对抗，维护用工关系 |
| 欠薪金额较小，双方均愿和解 | 适合 | 快速解决，成本低 |
| 争议事实清晰，仅金额有争议 | 适合 | 可直接协商最终数字 |
| 解雇/违法解除，劳动者坚持复职 | 不太适合 | 复职诉求通常无法通过调解实现 |
| 用人单位拒绝参与任何调解 | 不适合 | 直接进入仲裁，调解不是强制程序 |
| 时效临近届满 | 谨慎使用 | 调解不自动中断时效（须书面主张权利或申请仲裁中断） |

**关键提醒**：**调解期间时效继续计算**——若时效即将届满，须同步书面主张权利以中断时效，或直接申请仲裁（仲裁申请会中断时效）。

## 第二步：调解组织选择

### 三类调解组织（均为自愿参与，非强制）`[待验证]`

| 调解组织 | 主要特点 | 适用场景 |
|---------|---------|---------|
| **企业劳动争议调解委员会** | 设于用人单位内部，由职工代表和用人单位代表组成；快速便捷，但中立性存疑（劳动者方慎用）| 双方关系尚可、用人单位愿意内部解决 |
| **基层人民调解组织** | 依托基层司法所/调解委员会，第三方中立调解；覆盖社区/村镇 | 欠薪等简单劳动报酬纠纷，第三方中立重要时 |
| **乡镇街道劳动争议调解组织** | 由基层政府设立，专职或兼职调解员；有一定官方背书 | 需要政府背景背书时；劳动者不信任企业内部调解时 |

### 调解申请要素 `[待验证]`

| 要素 | 内容 |
|------|------|
| 申请方式 | 书面申请（口头申请可被记录）`[待验证]` |
| 受理期限 | 调解组织收到申请后 5 个工作日内决定是否受理 `[待验证]` |
| 调解期限 | 自受理调解申请之日起 15 个工作日内结束，延长须双方同意 `[待验证]` |
| 调解失败处理 | 调解不成，当事人可申请仲裁 |

## 第三步：调解协议效力与支付令

### 调解协议的法律效力

调解协议书经双方签字（或盖章）后生效，但**不具有强制执行力**（不同于法院判决或仲裁裁决）。

若用人单位事后拒绝履行调解协议，劳动者须另行申请仲裁或起诉。

### 支付令（重要救济路径）`[待验证]`

**适用条件**：因以下事项达成调解协议，用人单位不履行的，劳动者可持**调解协议书**依法向**人民法院申请支付令** `[待验证]`：

| 适用事项 |
|---------|
| 拖欠劳动报酬 |
| 工伤医疗费 |
| 经济补偿 |
| 赔偿金 |

> **支付令的意义**：支付令是督促程序，无需经过完整诉讼程序；法院发出支付令后，用人单位须在法定期限内履行或提出异议。如无异议，支付令具有强制执行力，可申请强制执行。
>
> **关键纪律**：支付令申请的条件、程序与法院受理范围条号标 `[待验证]`，引用前通过官方渠道核验。

## 第四步：调解与仲裁/诉讼的衔接

### 调解不成后的路径衔接

```
调解申请
    ↓
调解成功 → 签署调解协议书
    ↓                   ↓
用人单位履行        用人单位不履行
（结案）          → 申请支付令（符合条件时）[待验证]
                  → 申请仲裁（补充或替代路径）

调解不成（或拒绝）
    ↓
→ 「子技能：arbitration-path」章节（见本文档）（仲裁路径）
→ 注意时效：调解期间时效未中断，须确认时效是否仍在1年内（第27条）
```

### 时效保全提示

| 场景 | 建议操作 |
|------|---------|
| 时效距届满 > 3 个月 | 可先尝试调解（3-6周），调解失败后及时申请仲裁 |
| 时效距届满 1-3 个月 | 建议调解与书面主张权利并行，或直接申请仲裁（仲裁申请中断时效） |
| 时效距届满 < 1 个月 | 立即申请仲裁；调解可在仲裁过程中由仲裁庭主持（仲裁庭在裁决前须先行调解 `[待验证]`） |

|------|---------|---------|

| 调解协议签署后用人单位反悔 | 劳动者须申请仲裁或起诉，主张调解协议的约束力；或申请支付令（符合条件时） | 🔴 调解协议无直接执行力，须另行救济 |
| 仲裁过程中申请调解 | 仲裁庭在裁决前须先行调解（调解成功出具调解书，具有法律效力）`[待验证]` | 🟢 仲裁调解书效力高于自行签署的调解协议 |
| 调解期间用人单位转移资产 | 提示申请仲裁/诉讼前做好财产保全准备 | 🔴 高风险，建议直接进入仲裁路径并考虑财产保全 |

## 错误处理

| 错误场景 | 识别方式 | 处理方案 |
|---------|---------|---------|
| 时效届满后才申请调解 | 时效已超过1年，且非存续期间拖欠报酬 | 🔴 告知当事人时效风险，评估对方是否会提出时效抗辩，同步评估和解可能性 |
| 将调解协议视为与裁决/判决同等执行力 | 误认为签署调解协议后可直接申请强制执行 | 🟠 纠正认知：须通过支付令（符合条件）或另行仲裁/诉讼实现强制执行 |
| 仲裁时效届满后希望以调解代替仲裁 | 时效已过，不想申请仲裁（认为调解更快） | 🔴 调解不能替代仲裁；时效届满须评估其他补救路径 |

## 第一步：仲裁前置原则确认

### 仲裁前置规则 `[具体条号待验证]`

**劳动争议须先经仲裁，对仲裁裁决不服方可向法院起诉**（仲裁前置原则，《劳动争议调解仲裁法》相关条款 `[待验证]`）。

**例外情形 `[待验证]`：**

部分情形可不经仲裁直接起诉（具体情形须核实 `[待验证]`）——实务中较为罕见，大多数劳动争议须经仲裁前置。

**流程：**

```

    ↓
（可先行调解，自愿）
    ↓
```

## 第二步：一裁终局识别（《劳动争议调解仲裁法》第47条，已核实）

### 一裁终局范围（已核实锚点）

以下两类劳动争议，仲裁裁决为**终局裁决**，自作出之日起发生法律效力：

| 类型 | 判断标准 | 示例 |
|------|---------|------|
| **（一）小额追索** | 追索**劳动报酬、工伤医疗费、经济补偿或者赔偿金**，争议金额**不超过当地月最低工资标准12个月金额**的 | 追索欠薪 ¥5,000（当地月最低工资×12=¥48,000），属一裁终局 |
| **（二）执行国家劳动标准** | 因执行国家劳动标准在**工作时间、休息休假、社会保险**等方面发生的争议 | 加班时间超标争议、年休假未休补偿争议（若金额不超小额标准也适用第一类） |

**判断步骤：**

1. 争议请求是否属于「劳动报酬/工伤医疗费/经济补偿/赔偿金」或「工时/休假/社保」范围？
2. 如属追索金额类，争议金额是否 ≤ 当地月最低工资 × 12？
3. 两个条件满足其一，即为一裁终局。

**核实当地月最低工资标准** `[管辖 flagged — 需验证地方性规定]`：

各地最低工资标准每1-2年调整，须核查仲裁申请时所在地（劳动合同履行地或用人单位所在地）的最新最低工资标准。

## 第三步：一裁终局对双方的不同救济

### 劳动者方的救济

**劳动者对终局裁决不服：可在收到裁决书之日起 15 日内向人民法院起诉** `[待验证]`

| 救济方式 | 条件 | 期限 |
|---------|------|------|
| 向法院起诉 | 劳动者不服终局裁决 | 收到裁决书之日起 15 日 `[待验证]` |

### 用人单位方的救济（有限）

**用人单位对终局裁决不服：不能向法院起诉，仅可在法定情形下申请中级法院撤销裁决** `[待验证]`

| 情形 | 说明 |
|------|------|
| 适用法律确有错误 | `[待验证]` |
| 仲裁庭无管辖权 | `[待验证]` |
| 违反法定程序 | `[待验证]` |
| 裁决依据的证据系伪造 | `[待验证]` |
| 对方当事人隐瞒了足以影响公正裁决的证据 | `[待验证]` |
| 仲裁员索贿受贿、徇私舞弊、枉法裁决 | `[待验证]` |

**申请撤销期限**：裁决书送达之日起 **30 日内**向用人单位住所地中级法院申请 `[待验证]`

> **关键纪律**：15日起诉期限与30日撤销期限、撤销情形条号均标 `[待验证]`，引用前通过官方渠道核验。

### 非终局裁决的救济

**双方均可**在收到裁决书之日起 15 日内向有管辖权的法院起诉 `[待验证]`。起诉不影响裁决的先行执行性（用人单位先行执行部分 `[待验证]`）。

# 诉讼路径与衔接（litigation-path）

> **所属编排**：`employment-legal/skills/labor-dispute-handling/SKILL.md`（劳动争议处理）
> **前置依赖**：本子技能须在仲裁裁决已作出后使用。如仲裁尚未开始，先运行 `arbitration-path`。
> **分工说明**：本子技能专责诉讼路径（含对仲裁裁决不服的起诉、一裁终局撤销申请）。调解路径由 `mediation-path` 处理；仲裁路径由 `arbitration-path` 处理。
> **可单独触发**：`「子技能：litigation-path」章节（见本文档）`

---

## 目的

在仲裁裁决作出后，指导当事人选择并实施正确的诉讼/救济路径：

1. **非终局裁决**：双方均可在收到裁决书之日起 15 日内起诉（起诉后仲裁裁决不生效 `[待验证]`）；
2. **一裁终局裁决**：劳动者可在 15 日内起诉；用人单位不可起诉，仅可在 30 日内申请中级法院撤销（仅限法定情形）；
3. 强制执行衔接（裁决/判决生效后的执行）；
4. 一审二审审级说明（劳动争议诉讼适用普通民事诉讼程序 `[待验证]`）。

---

## 前置

在执行本子技能前：

1. **读取 `employment-legal/CLAUDE.md`**：
   - `## 谁在使用` → 服务对象（用人单位方/劳动者方，决定诉讼策略）
   - `## 审查立场 → 解雇审查` → 经济补偿倾向（影响诉讼金额目标）
   - `## 升级矩阵` → 诉讼须升级到合伙人/法务总监
2. **确认 `arbitration-path` 已运行**（仲裁裁决结果已知）
3. **读取 `../_shared/labor-law-citations.md` 章节 C**（第47条一裁终局，已核实）
4. **读取 `../_shared/legal-basis-conventions.md`**（引用规范、法院层级）

## 第一步：仲裁裁决类型确认

在选择诉讼路径前，须确认仲裁裁决类型：

| 裁决类型 | 判断方法 | 诉讼路径 |
|---------|---------|---------|
| **非终局裁决** | 争议不属于《劳动争议调解仲裁法》第47条情形（第47条已核实） | 双方均可起诉，15日期限 `[待验证]` |
| **一裁终局裁决** | 争议属于第47条情形（小额追索或执行国家劳动标准） | 劳动者可起诉（15日）；用人单位仅可申请撤销（30日）`[待验证]` |

---

## 第二步：非终局裁决的起诉路径

### 起诉条件与期限 `[待验证]`

| 要素 | 内容 |
|------|------|
| **起诉期限** | 收到仲裁裁决书之日起 **15 日内** 向有管辖权的法院提起诉讼 `[待验证]` |
| **管辖法院** | 一般为基层人民法院（劳动合同履行地或用人单位所在地）`[待验证]` |
| **起诉效果** | 当事人一方起诉后，仲裁裁决不予执行；双方均不起诉的，裁决书生效可申请强制执行 `[待验证]` |
| **先行执行** | 特殊情形下可申请裁决书先行执行（追索劳动报酬、工伤医疗费等迫切需要的情形）`[待验证]` |

### 逾期未起诉的后果

若双方在 15 日内均未起诉，仲裁裁决自动生效，双方须履行；可申请法院强制执行。

---

## 第三步：一裁终局的有限救济

### 劳动者对终局裁决不服（可起诉）`[待验证]`

| 要素 | 内容 |
|------|------|
| **救济方式** | 向有管辖权的人民法院提起诉讼 |
| **期限** | 收到裁决书之日起 **15 日内** `[待验证]` |
| **特点** | 起诉权充分保障劳动者权益；用人单位须应诉 |

### 用人单位对终局裁决不服（仅可申请撤销，不可起诉）`[待验证]`

> **重要提示**：用人单位不得以对终局裁决不服为由向法院起诉，只能依法定情形申请撤销。

**申请撤销的法定情形** `[待验证]`（须有证据证明）：

| 法定情形 | 说明 |
|---------|------|
| 适用法律确有错误 | 裁决适用了错误的法律条文 `[待验证]` |
| 仲裁庭无管辖权 | 争议不属于该仲裁委管辖范围 `[待验证]` |
| 违反法定程序 | 严重违反仲裁程序规定（非一般程序瑕疵）`[待验证]` |
| 裁决依据的证据系伪造 | 有证据证明对方提交的关键证据系伪造 `[待验证]` |
| 对方当事人隐瞒了足以影响公正裁决的证据 | `[待验证]` |
| 仲裁员索贿受贿、徇私舞弊、枉法裁决 | 须有相应证明 `[待验证]` |

**申请撤销的程序** `[待验证]`：

| 要素 | 内容 |
|------|------|
| **申请对象** | 用人单位住所地**中级人民法院** `[待验证]` |
| **申请期限** | 收到仲裁裁决书之日起 **30 日内** `[待验证]` |
| **举证责任** | 用人单位须提供满足法定情形的证据 |

**撤销申请审查** `[待验证]`：中院审查仅限程序与法定情形，不对实体问题重新审查；撤销条件严格，实务中成功率较低。

---

## 第四步：诉讼程序与审级

### 劳动争议诉讼程序（适用普通民事诉讼程序）`[待验证]`

| 程序 | 说明 |
|------|------|
| **一审** | 一般由劳动合同履行地或用人单位所在地基层法院管辖 `[待验证]`；适用普通程序或简易程序 |
| **二审** | 对一审判决不服，在判决送达之日起 15 日内（裁定 10 日内）向中级法院上诉 `[待验证]` |
| **再审** | 二审终审判决生效后，通过审判监督程序申请再审（条件严格）`[待验证]` |

**劳动争议诉讼的特点：**

- 仲裁裁决已固定事实和请求范围，起诉时请求不应超出仲裁请求范围 `[待验证]`
- 举证责任分配同仲裁阶段（用人单位掌握的证据仍须其提供）
- 涉及劳动报酬的案件可申请先予执行 `[待验证]`

---

## 第五步：生效裁决/判决的强制执行

### 可申请强制执行的依据 `[待验证]`

| 执行依据 | 条件 |
|---------|------|
| 仲裁裁决书（非终局，双方均未起诉） | 15日期限届满，双方均未起诉 `[待验证]` |
| 仲裁裁决书（一裁终局） | 自作出之日起发生法律效力，可直接申请执行 `[待验证]` |
| 仲裁调解书 | 签署后具有执行力 `[待验证]` |
| 法院一审/二审判决 | 判决生效后（对方不上诉或二审判决）可申请执行 |
| 支付令 | 对方未提异议，支付令生效可申请执行 `[待验证]` |

### 强制执行申请 `[待验证]`

向有管辖权的法院（一般为被执行人财产所在地基层法院）申请强制执行，提供生效法律文书原件。

**执行期限** `[待验证]`：申请执行的期间一般为 2 年（民法典诉讼时效类比，具体规则待验证 `[待验证]`）。

## 边界条件

| 场景 | 处理方式 | 风险提示 |

## 错误处理

| 错误场景 | 识别方式 | 处理方案 |
|---------|---------|---------|
| 用人单位对终局裁决提起诉讼（不可） | 用人单位误以为与劳动者起诉权利对等 | 🔴 终局裁决用人单位不可起诉，只能申请撤销（30日，法定情形）；超期或无法定情形则裁决已生效 |
| 逾期未起诉（15日已过）| 起诉状提交时已超15日 | 🔴 法院不予受理；仲裁裁决生效，直接申请强制执行 |
| 15日与30日期限混淆 | 将撤销申请30日误用于起诉，或将起诉15日误用于撤销申请 | 🔴 纠正：起诉15日（劳动者/非终局双方）；撤销30日（用人单位对终局裁决）`[待验证]` |
| 强制执行被执行人无财产 | 法院查封无可供执行财产 | 🟠 申请终结执行，待对方有财产时申请恢复执行；建议事先调查财产状况 |
