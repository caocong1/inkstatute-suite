# inkstatute-platform-api

Default-off thin host surface for the InkStatute platform `RunRuntime`.

The package provides pure handler functions plus a `PlatformApiApp` container
that delegates to an injected `RunRuntime`. It does **not** start a production
HTTP server, database, queue, or local runtime, and it does **not** import
any concrete backend or channel adapter.

## Boundary

```
Inbound HTTP/ASGI/WSGI adapter
        |
        v
+-----------------------+
| PlatformApiApp        |  <-- default-off, ref/secret-ref first
+-----------------------+
        |
        v
+-----------------------+
| Injected RunRuntime   |  <-- platform-runtime (DefaultRunRuntime or other)
+-----------------------+
        |
        v
+-----------------------+
| Injected BackendAdapter|
+-----------------------+
```

The platform API host:

- Accepts plain Python dictionaries and returns plain Python dictionaries.
  ASGI/WSGI/starlette/fastapi adapters can wrap the handlers externally.
- Streams run events as Server-Sent Events frames without holding open a
  production HTTP server itself.
- Records sanitized contract log entries through the injected runtime
  contract log store; no extra persistence layer is added.
- Never imports `BackendAdapter`, `ChannelAdapter`, or any concrete backend
  package. A source-level boundary scan enforces the rule.

## Operations

| Operation         | Method | Path                                       | Description                  |
|-------------------|--------|--------------------------------------------|------------------------------|
| `create_run`      | POST   | `/v1/runs`                                 | Submit a run                 |
| `poll_run`        | GET    | `/v1/runs/{run_id}`                        | Poll a run                   |
| `cancel_run`      | DELETE | `/v1/runs/{run_id}`                        | Cancel a run                 |
| `submit_approval` | POST   | `/v1/runs/{run_id}/approvals`              | Submit an approval decision  |
| `stream_run`      | GET    | `/v1/runs/{run_id}/events` (`text/event-stream`) | Stream run events as SSE  |

## Configuration

| Env var                                  | Default | Effect                                  |
|------------------------------------------|---------|-----------------------------------------|
| `INKSTATUTE_PLATFORM_API_ENABLED`        | off     | Enable the platform API host (`1`/`true`/`yes`) |
| `INKSTATUTE_PLATFORM_API_BASE_PATH`      | `/v1`   | URL base path for the host              |
| `INKSTATUTE_PLATFORM_API_SECRET_REFS`    | (none)  | Comma-separated secret reference ids    |

The host remains **default-OFF** until the env flag is set. Calls before the
flag is set raise `PlatformApiDisabledError`.

## OpenAPI

`apps/platform_api/openapi/platform-api.json` is generated by
`platform_api.openapi.build_openapi_document()` and serialized with
`render_openapi_json(...)`. The document is sorted, ASCII-only, and used as
the source of truth for the TypeScript SDK.

## TypeScript SDK

The remote/thin TypeScript SDK is generated deterministically from the
OpenAPI document by `packages/platform-sdk-ts/scripts/generate_sdk.py`. The
generator sorts all multi-valued collections, so two consecutive runs on
the same input produce byte-identical output. The committed SDK is
re-generated by running the generator; tests assert determinism and check
that the SDK stays remote/thin (no `DefaultRunRuntime`, `BackendAdapter`, or
`RunRequest` references).

## Not live acceptance

The platform API host and the generated SDK are **not** production web
servers and **not** live acceptance evidence. They are fixture-grade,
default-off, and ref/secret-ref-first.
