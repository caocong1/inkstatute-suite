# Plan 01: Codex Adapter collect_artifacts + AgentResult.artifacts Population

## Objective

Productize `CodexBackendAdapter.collect_artifacts()` — replace the stub that returns an empty list with real artifact collection from `CodexExecResult.artifact_refs`. In `submit_run`, build `ArtifactRecord` entries from `result.artifact_refs` (mirroring the Hermes `_artifact_records` pattern) and store them in `self._artifacts[run_id]`. Populate `AgentResult.artifacts` with ref-based `Artifact` entries. Update `collect_artifacts()` to call `_require_run()` before returning. Set `artifact_return_support=True` in the manifest. This satisfies ARTIFACT-01 for the Codex adapter.
