# Plan 02: Provider_model Adapter collect_artifacts + AgentResult.artifacts Population

## Objective

Productize `ProviderModelBackendAdapter.collect_artifacts()` — replace the stub that returns an empty list with real artifact collection from `ProviderModelExecResult.artifact_refs`. In `submit_run`, build `ArtifactRecord` entries from `result.artifact_refs` (mirroring the Hermes `_artifact_records` pattern) and store them in `self._artifacts[run_id]`. Populate `AgentResult.artifacts` with ref-based `Artifact` entries. Update `collect_artifacts()` to call `_require_run()` before returning. Set `artifact_return_support=True` in the manifest. Update `parse_openai_response` to extract file output refs from provider responses into `artifact_refs`. This satisfies ARTIFACT-01 for the provider_model adapter.
