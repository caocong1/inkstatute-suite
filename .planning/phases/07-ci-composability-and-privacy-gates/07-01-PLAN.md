# Plan 07-01 - Local V2 Gate Runner And Coverage Reporter

## Objective

Create the repo-root local V2 gate command and a reusable coverage reporter that proves paired `AgentTurn`/`AgentResult` coverage and relationship breakage on provided sanitized streams without claiming synthetic fixtures are live acceptance evidence.

## Threat Model

<threat_model>
<risk id="T-07-01-runner" severity="medium">A CI-only implementation would make failures hard to reproduce locally. Mitigation: `scripts/run_v2_gates.py` is the authoritative command and CI only wraps it later.</risk>
<risk id="T-07-01-coverage" severity="high">Synthetic fixtures could be mislabeled as live lawyer-trial coverage. Mitigation: coverage reports carry evidence kind and report runtime input absence explicitly.</risk>
<risk id="T-07-01-breakage" severity="high">Relationship breakage could pass despite exceeding the PRD tolerance. Mitigation: reuse existing fixture and stream replay reports and enforce `max_breakage_rate=0.05`.</risk>
<risk id="T-07-01-leak" severity="high">Gate summaries could print raw contract records. Mitigation: coverage summary includes counts, rates, paths, and issue counts only, never raw event payloads.</risk>
</threat_model>
