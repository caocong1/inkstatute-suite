# Plan 07-03 - GitHub Actions Wrapper And Gate Documentation

## Objective

Add the first GitHub Actions workflow as a thin wrapper around `scripts/run_v2_gates.py` and document how to run Phase 7 gates locally, how optional sanitized runtime coverage inputs differ from committed fixtures, and why Phase 8 still owns live lawyer-trial acceptance.

## Threat Model

<threat_model>
<risk id="T-07-03-drift" severity="medium">CI YAML could drift from the local runner. Mitigation: workflow contains one primary test step that calls `python scripts/run_v2_gates.py`.</risk>
<risk id="T-07-03-artifacts" severity="high">CI could upload logs or raw runtime evidence. Mitigation: no artifact upload steps and docs prohibit uploading DB/log/media/callback/customer payload artifacts.</risk>
<risk id="T-07-03-live-claim" severity="high">Documentation could imply fixture checks satisfy live lawyer-trial acceptance. Mitigation: docs explicitly state Phase 7 gates are fixture/sanitized-input gates and Phase 8 owns real-trial metrics.</risk>
</threat_model>
