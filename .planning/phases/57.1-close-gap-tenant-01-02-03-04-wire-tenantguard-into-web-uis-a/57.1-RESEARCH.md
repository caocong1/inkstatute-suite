# Phase 57.1 Research: Wire TenantGuard into Web UIs and Admin Console API

**Researched:** 2026-07-06
**Status:** Complete

## Executive Summary

Tenant scoping primitives (`TenantGuard`, `TenantScopeResolver`, `ScopedQueryFilter`) are fully implemented in `platform-runtime` but NOT yet integrated into the web UI services. This research documents the current state and identifies the changes needed.

**Key Findings:**
- Admin-console-api views have NO tenant filtering — they return all data regardless of tenant
- Admin-web-ui extracts `tenant_id` from RBAC identity but does NOT pass it to admin-console-api for scoping
- Lawyer-web-chat extracts `tenant_id` from session tokens but does NOT enforce tenant scoping on data access
- The `ContractLogReadModel` has NO tenant filtering capabilities — a tenant-scoped wrapper needs to be created
- All three services need to integrate `TenantScopeResolver` and `TenantGuard` into their request flows

        # Returns TenantScope.NONE when multi_tenant_enabled=False

class TenantGuard:
    def __init__(self, *, feature_flags: RuntimeFeatureFlags) -> None: ...
    def enforce(self, scope: TenantScope) -> ScopedQueryFilter:

## 8. TenantGuard Test Patterns

From `test_tenant_scope.py`:
```python
def test_disabled_returns_disabled_filter(self):
    guard = TenantGuard(feature_flags=RuntimeFeatureFlags())
    f = guard.enforce(TenantScope.NONE)
    self.assertFalse(f.is_active)

def test_enabled_resolved_scope_returns_active_filter(self):
    guard = TenantGuard(feature_flags=RuntimeFeatureFlags(multi_tenant_enabled=True))
    f = guard.enforce(TenantScope(tenant_id="firm-a"))
    self.assertTrue(f.is_active)
    self.assertEqual(f.tenant_id, "firm-a")

def test_enabled_unresolved_scope_raises(self):
    guard = TenantGuard(feature_flags=RuntimeFeatureFlags(multi_tenant_enabled=True))
    with self.assertRaises(TenantScopeError):
        guard.enforce(TenantScope.NONE)
```

## 11. Risk Assessment

**High Risk:**
- Breaking existing behavior when `multi_tenant_enabled=False` — must ensure backward compatibility
- All new code must check the flag before enforcing scoping

**Medium Risk:**
- Feedback queue filtering — feedback_queue is a simple list, filtering by tenant_id in items
- Lawyer-web-chat session store — current session_id format includes tenant_id, no migration needed

**Low Risk:**
- Admin-web-ui — no changes needed, identity already flows through
- Gate script — already includes platform_runtime_src in PYTHONPATH
