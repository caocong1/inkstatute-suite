<objective>
Port `lawyer-desktop/src-tauri/src/citations/` module (mod.rs 55 lines + extract.rs 284 lines + verify.rs 250 lines = 589 lines total) into a Python `citations/` sub-package. This module extracts legal citations from generated text using 6 regex patterns, verifies each citation against local law library and retrieval evidence with three-state labeling (verified/retrieved/unverified), and produces a `CitationAudit` result. Also add `emit_citation_recorded()` to EventEmitter. All 14 Rust test cases (12 extract + 2 verify) are replicated as Python golden fixtures.

Purpose: Citation audit is the third legal guardrail — it post-hoc verifies whether legal citations in LLM output are backed by authoritative sources. Unverified citations get `[待律师复核]` labels. The `citation.recorded` event carries the audit result to the UI. The Rust regex patterns handle Chinese legal citation formats (法条, 司法解释, 案号) and must produce identical matches.

Output: `packages/agent-core/src/inkstatute_agent_core/citations/` (new sub-package, 3 files) + `packages/agent-core/src/inkstatute_agent_core/event_emitter.py` (modified — add `emit_citation_recorded()`) + 3 test files (~30 tests)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM output → citation audit | Citations extracted from LLM text; verification labels determine user trust level |
| Local law library → verification | Library lookup provides authoritative verification; absence degrades to retrieval/unverified |
| Retrieval evidence → verification | Retrieval results provide weaker verification; must contain ALL fragments to match |
