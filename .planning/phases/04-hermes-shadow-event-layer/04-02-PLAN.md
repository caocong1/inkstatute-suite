<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hermes hook context -> mapper | Untrusted mutable runtime context is normalized into contract events. |
| Mapper -> writer | Schema-valid payloads are wrapped in service-owned JSONL envelopes. |
| Writer -> filesystem | Contract logs are append-only local files and must not become raw payload storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-T | Tampering | Event relationships | mitigate | Tests assert matching turn, route, trace, and result IDs. |
| T-04-02-I | Information Disclosure | Mapper metadata/content | mitigate | Use capped previews and `raw_payload_ref`; scan tests for exact `raw_payload` keys and sensitive strings. |
| T-04-02-R | Repudiation | JSONL log ordering | mitigate | Writer envelope records `occurred_at`, `ingested_at`, and monotonic `seq`. |
| T-04-02-D | Denial of Service | Writer failures | mitigate | Hook catches writer exceptions and does not block Hermes. |
</threat_model>
