# Plan 117-03: Confidentiality gate + negative regression + phase summary

## Goal

Implement GRD-06 (confidentiality gate), create the guardrail integrator that wires all 6 guardrails into the ChatController, build the negative regression test suite (one bypass test per guardrail), and write the phase summary/transition.

## Tasks

### Task 1: Confidentiality gate (GRD-06)

Create `lib/guardrails/confidentiality_gate.dart`:
- `ConfidentialityGate` class:
  - `bool confirmed` — Whether the user has confirmed for this session
  - `Future<bool> requestConfirmation(BuildContext context)` — Shows one-time confirmation dialog with DeepSeek API transmission notice + desensitization reminder
  - `void confirm()` — Records confirmation
  - `bool requiresConfirmation(String promptText)` — Checks if prompt involves client materials (keywords: "合同", "案件", "客户", "当事人", "证据")
  - Confirmation record persisted to local database (sessions table or new confirmations table)

### Task 2: Guardrail integrator

Create `lib/guardrails/guardrail_integrator.dart`:
- `GuardrailIntegrator` class:
  - `static List<GuardrailResult> runAllChecks(AssistantMessage message, {HighRiskTaskType? taskType})` — Runs all 6 guardrail checks and returns results
  - `static bool shouldBlock(List<GuardrailResult> results)` — Returns true if any result has block severity
  - `static List<String> warnings(List<GuardrailResult> results)` — Returns warning messages
  - Integration point: ChatController calls this after receiving assistant message

### Task 3: Negative regression test suite

Create `test/guardrails/guardrail_bypass_regression_test.dart`:
- 6 bypass-attempt tests, one per guardrail:
  1. **GRD-01 bypass**: Assistant message with conclusions but no verified citations → research-gate checker returns warning
  2. **GRD-02 bypass**: Citations with invalid type → citation audit enforcer defaults to unverified
  3. **GRD-03 bypass**: Prompt sent while clarify lock is active → blocked by state machine
  4. **GRD-04 bypass**: Conclusion without `[POLISHED]` marker → polish checker returns warning
  5. **GRD-05 bypass**: High-risk task without `[HUMAN_REVIEW:]` → human review enforcer returns violated
  6. **GRD-06 bypass**: Client material prompt without confirmation → confidentiality gate blocks

### Task 4: Phase summary + transition

Create `117-SUMMARY.md` and `117-TRANSITION.md`:
- Summary: plans executed, requirements closed, test count, V4 gate status
- Transition: carry-forward notes for Phase 119 (packaging depends on 117)
- Update ROADMAP.md and STATE.md
