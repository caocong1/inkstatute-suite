# Plan 117-02: Clarify lock + polish checker + human review enforcer

## Goal

Implement the app-side enforcement for GRD-03 (ask-user lock), GRD-04 (de-AI polish), and GRD-05 (human review).

## Tasks

### Task 1: Clarify lock state machine (GRD-03)

Create `lib/guardrails/clarify_lock_state.dart`:
- `ClarifyLockState` — Enum: unlocked, locked
- `ClarifyLockStateMachine` class:
  - `ClarifyLockState state` — Current lock state
  - `void lock(String clarifyText)` — Enters locked state when `[CLARIFY:]` is detected
  - `void unlock()` — Exits locked state when user responds to clarification
  - `bool canSendPrompt()` — Returns false when locked; true when unlocked
  - `String? pendingClarifyText` — The clarification question that caused the lock
  - Integration point: ChatController checks `canSendPrompt()` before sending

### Task 2: Polish checker (GRD-04)

Create `lib/guardrails/polish_checker.dart`:
- `PolishChecker` class:
  - `static bool isPolished(String text)` — Returns true if text contains `[POLISHED]` marker
  - `static GuardrailResult check(AssistantMessage message)` — Returns warning if conclusion text lacks `[POLISHED]` marker
  - `static String removePolishMarker(String text)` — Removes `[POLISHED]` from display text
  - The app marks unpolished conclusions with "未经润色" tag

### Task 3: Human review enforcer (GRD-05)

Create `lib/guardrails/human_review_enforcer.dart`:
- `HumanReviewEnforcer` class:
  - `static bool hasHumanReviewMarker(AssistantMessage message)` — Returns true if `[HUMAN_REVIEW:]` markers present
  - `static GuardrailResult enforce(AssistantMessage message, HighRiskTaskType? taskType)` — Returns violated if high-risk task type has no human review marker
  - `static List<HumanReviewMarker> preserveMarkers(List<HumanReviewMarker> markers)` — Returns markers unchanged; this is a no-op that documents the immutability guarantee
  - No UI/API path can remove human review markers — enforced by the sealed message model

### Task 4: High-risk task config (GRD-05)

Create `lib/guardrails/high_risk_task_config.dart`:
- `HighRiskTaskConfig` class:
  - `static List<HighRiskTaskType> highRiskTypes` — Configured high-risk task types
  - `static bool isHighRisk(String taskDescription)` — Checks if a task description matches high-risk patterns
  - High-risk patterns: "法律结论", "诉讼策略", "合同实质条款", "定性建议"
