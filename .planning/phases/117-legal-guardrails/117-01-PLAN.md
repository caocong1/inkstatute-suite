# Plan 117-01: Guardrail core models + research-gate + citation audit enforcer

## Goal

Create the guardrail framework models and implement the app-side enforcement for GRD-01 (research-gate) and GRD-02 (citation audit).

## Tasks

### Task 1: Guardrail models

Create `lib/guardrails/guardrail_models.dart`:
- `GuardrailResult` — Result of a guardrail check (passed, violated, warning)
- `GuardrailType` — Enum: researchGate, citationAudit, askUser, polish, humanReview, confidentiality
- `GuardrailViolation` — Type, message, severity (block, warn)
- `PolishMarker` — Detects `[POLISHED]` marker in assistant text
- `HighRiskTaskType` — Enum: legalConclusion, litigationStrategy, contractSubstantiveClause

### Task 2: Research-gate checker (GRD-01)

Create `lib/guardrails/research_gate_checker.dart`:
- `ResearchGateChecker` class:
  - `static GuardrailResult check(AssistantMessage message)` — Returns violated if the message has conclusions but no verified citations
  - A "conclusion" is detected by keywords: "因此", "综上", "结论", "建议", "应当"
  - If no verified citations are present and conclusions are detected, returns warning with "待核实" tag
  - The preset persona layer (Phase 113) already instructs the model to research before concluding; this is the app-side second layer

### Task 3: Citation audit enforcer (GRD-02)

Create `lib/guardrails/citation_audit_enforcer.dart`:
- `CitationAuditEnforcer` class:
  - `static List<Citation> enforce(List<Citation> citations)` — Ensures all citations have a valid type; parse failures default to unverified
  - `static GuardrailResult audit(AssistantMessage message)` — Returns warning if any citation is unverified
  - `static bool hasUnverifiedCitations(AssistantMessage message)` — Returns true if any unverified citations exist
  - The visual warning for unverified is already rendered by CitationBadgeWidget (Phase 116)
