# Plan 95-02: WeCom Full Migration — Replace Direct Agent Calls with Gateway Consumer

## Goal

Switch the WeCom post-ACK composition path from direct agent calls (`runtime.create_run()` / `backend.get_run()`) to the Gateway event consumer created in Plan 95-01. The `run_post_ack_composition()` function in `webhook.py` is modified to call `WeComEventConsumer.consume_and_deliver()` instead of `WeComRuntimeIngress.handle_callback()`. The `wiring.py` is modified to inject a `GatewayClient` instead of a `DefaultRunRuntime` with a backend. The `__main__.py` is updated to read Gateway config from env vars.

After this plan:
- WeCom webhook → verify_and_ack → post-ACK → GatewayClient.create_run → SSE stream → aggregate_events → adapter.deliver
- No `runtime.create_run()` or `backend.get_run()` calls remain in the post-ACK composition path
- All 18 existing WeCom tests stay green (ACK, AES-CBC, template cards, media, idempotency preserved)
- The `ingress_runtime.py` and `session_runtime.py` files are kept but no longer called from post-ACK

## Reversibility Gate

**One-way-door:** Modifying `webhook.py`'s `run_post_ack_composition()` to call the event consumer instead of the ingress runtime. Once the post-ACK path uses the Gateway consumer, reverting would require restoring the direct agent call path. Strategy: the old `ingress_runtime.py` and `session_runtime.py` are NOT deleted — they remain as reference and for tests that directly exercise them. The `wiring.py` change is structured so that a `backend` parameter can still be passed (for backward compat with existing tests), but the post-ACK composition uses the `gateway_client` when available. Task 95-02-01 is a checkpoint to verify existing tests still pass before the full switchover.

**One-way-door:** Modifying `wiring.py` to inject `GatewayClient` config. The `WeComWiredRuntime` dataclass gains a `gateway_client` field. Existing tests that construct `WeComWiredRuntime` with a `backend` must still work — the `gateway_client` field is optional (defaults to None). When `gateway_client` is None, the post-ACK composition falls back to the old path (for backward compat during transition). When `gateway_client` is provided, the new Gateway consumer path is used.
