<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin-console-api → provider endpoint (probe) | Process-edge HTTP call to external provider; resolved secret crosses this boundary |
| admin-console-api → operator-config store | Probe reads store to find provider; never writes |
| Operator → admin-console-api probe route | Auth + RBAC + flag gate before probe executes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-76-05 | Information Disclosure | probe response body / resolved key | mitigate | probe_provider never calls resp.read(); returns generic {ok, code} only; _sanitize_probe_message strips URLs/tokens/paths |
| T-76-06 | Elevation of Privilege | probe bypassing flag gate | mitigate | Probe route dispatched through handle_admin_put which runs _authenticate_admin (flag → auth → RBAC → tenant) before handler |
| T-76-07 | Tampering | probe mutating config | mitigate | handle_config_probe never calls store.save; probe is read-only POST |
| T-76-08 | Information Disclosure | HTTP status code leaked to UI | mitigate | probe_provider maps HTTPError codes to generic strings (auth_error/network); never returns raw status code |
| T-76-09 | Spoofing | custom provider pointing to arbitrary URL | accept | Operator-chosen api_base_url; probe is non-destructive GET /models; no data exfiltration risk beyond reachability |
| T-76-SC | Tampering | pip installs | accept | No new packages — stdlib urllib only; empty-deps invariant preserved |
</threat_model>
