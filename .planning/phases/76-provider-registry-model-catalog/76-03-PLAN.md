<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator → admin-console-api | Untrusted provider/catalog bodies and target probe selectors cross auth, RBAC, feature-flag, and validation gates. |
| admin-console-api → DNS/provider endpoint | A resolved credential may be attached only after destination validation; redirects and unsafe addresses are hostile. |
| admin-console-api → operator-config store | Provider/catalog PUT may save validated refs; probe may load only and must never save. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-76-13 | Spoofing | client-supplied probe identity | mitigate | Accept only target=main|vision and resolve provider/model from validated stored catalog/vision docs; reject all identity/URL/ref/header overrides. |
| T-76-14 | Tampering | built-in provider/main/vision PUT | mitigate | Full document save invokes Plan 76-01 canonical URL, allowlist, and complete provider/model binding validation. |
| T-76-15 | Information Disclosure | target metadata and probe credential/response/error | mitigate | Expose only configured status and stored IDs; validate before Request construction; never expose refs/base URLs or read body/log exception; generic result codes only. |
| T-76-16 | Elevation of Privilege | probe gate bypass | mitigate | Exact route remains behind shared auth/RBAC and explicit operator_config_enabled check before side effects. |
| T-76-17 | Server-Side Request Forgery | main/vision custom URL/DNS/redirect | mitigate | Both configured targets share HTTPS + no userinfo, getaddrinfo/ipaddress public-only checks, exact built-in profiles, and disabled redirects; incomplete targets stop before DNS. |
| T-76-18 | Denial of Service | hanging probe | mitigate | One GET, finite 10-second timeout, no body consumption, no retries or catalog refresh. |
| T-76-19 | Repudiation | probe presented as live acceptance | mitigate | Result is ephemeral reachability only; tests and responses never mark provider/WeCom/QQ/lawyer gates complete. |
| T-76-SC | Tampering | package supply chain | accept | No installs; urllib, socket, ipaddress, and in-repo packages only. |
</threat_model>
