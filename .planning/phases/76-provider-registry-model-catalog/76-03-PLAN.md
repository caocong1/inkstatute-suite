<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator browser → admin-web-ui SSR | Form POST crosses this boundary; CSRF token + html.escape required |
| admin-web-ui → admin-console-api | SSR proxies PUT/POST to API; auth header forwarded |
| admin-web-ui → operator-config catalog | SSR imports BUILTIN_MODEL_CATALOG for rendering (read-only code data) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-76-10 | Cross-Site Scripting | SSR form rendering | mitigate | All dynamic strings through html.escape(str(value), quote=True); CSP strict; no innerHTML |
| T-76-11 | Cross-Site Request Forgery | POST /config/providers + /config/catalog + probe | mitigate | Hidden csrf_token field on every POST; Phase 78 completes full CSRF surface verification |
| T-76-12 | Information Disclosure | resolved secrets in SSR HTML | mitigate | Forms show ref strings only (env:FOO); never resolved values; api_key_ref is text input for references |
| T-76-13 | Tampering | empty POST wiping stored providers | mitigate | _providers_post_body_usable rejects bodies with no providers[N].* fields; blank provider_id entries dropped |
| T-76-14 | Information Disclosure | probe result leaking status/body | mitigate | Probe result copy is generic (UI-SPEC strings); never includes HTTP status codes, response snippets, or key material |
| T-76-SC | Tampering | npm/pip installs | accept | No new packages — stdlib SSR only; no SPA framework |
</threat_model>
