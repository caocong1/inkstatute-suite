# Phase 124 Plan 03: Event Mapper + GATE-12 Summary

**DSH session events → 15 unified RunEventEnvelope types → Tauri event channel → ui-core reducer integration gate**

## Performance

- **Started:** 2026-08-15
- **Completed:** 2026-08-15
- **Tasks:** 4
- **Files modified:** 8

## Accomplishments
- `mapper.rs` translates all DSH `SessionEventKind` values into the 15 unified `RunEventEnvelope` types consumed by `event-reducer.ts`. The mapper is stateful: it tracks the run ID, a monotonic output sequence, tool-call accumulation (first delta per index emits `tool_call.started`), and the pending session title (attached as metadata on the next envelope).
- `runtime.rs` connects the tailer → mapper → Tauri event channel (`inkstatute://run-event`). The observation loop is cancellable via `ObservationHandle::stop` or `Drop`.
- GATE-12 (`event-mapping.mjs`) validates the committed `expected-envelopes.json` fixture: 15-type vocabulary, monotonic seq, no raw engine internals leakage, reducer produces non-empty `RenderState` with terminal status, replay token budget metadata present, session title attached.
- `expected-envelopes.json` is a committed fixture regenerated by the `#[ignore]` test `dump_envelopes_from_fixture`.
- Phase 123 decision artifact updated: criterion 4 (prompt token budget) is now structurally covered via the observation plane's `metadata.usage.prompt_tokens`.

## Decisions Made
- 15 unified event types only — noise kinds (RequestHeader, AgentInboxSpliced, UserMessage, SessionCreated/Disposed/Flush, etc.) dropped.
- SessionTitle has no standalone event — stashed as metadata on next envelope.
- Usage chunk maps to `run.state_changed` with `usage` metadata (not a separate event type).
- TurnEnd(error) → `error` event with clean Chinese message; TurnEnd(normal) → `run.state_changed(completed)`.
- DOM globals stubbed in gate script — reducer is pure but dist touches `document` at load.
- `expected-envelopes.json` is a committed fixture, regenerated by `#[ignore]` test.
