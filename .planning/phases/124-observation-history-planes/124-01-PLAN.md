```rust
/// 日志第一行（无 seq）
#[derive(Debug, Clone, Deserialize)]
pub struct SessionHeader {
    pub id: String,
    pub version: u32,
    pub created_at: i64,          // "createdAt"
    #[serde(default)] pub cwd: Option<String>,
    #[serde(default)] pub delegation_depth: u32,
    #[serde(default)] pub agent_preset: Option<String>,
}

/// 后续每一行
#[derive(Debug, Clone)]
pub struct SessionEvent {
    pub seq: u64,
    pub time: i64,
    pub kind: SessionEventKind,
    pub raw: serde_json::Value,   // 保留原始 JSON，映射器按需取字段
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum SessionEventKind {
    TurnStart, TurnEnd,
    StepStart, StepEnd,
    UserMessage, AssistantMessage, AssistantChunk,
    ToolCall, ToolResult, ToolCodeDispatch, ToolCodeDispatchStart,
    SessionTitle, SessionCreated, SessionDisposed, SessionFlush, SessionEndSeed,
    RequestHeader, RequestContext,
    AgentInboxSpliced,
    Other(String),
}

/// assistant/chunk 的 data.chunk 联合
#[derive(Debug, Clone)]
pub enum AssistantChunk {
    BlockStart { index: u32, block_type: String },
    TextDelta { index: u32, text: String },
    ReasoningDelta { index: u32, text: String },
    ToolCallDelta { index: u32, id: String, name: Option<String>, arguments_delta: String },
    BlockEnd { index: u32, block: serde_json::Value },
    Usage { usage: serde_json::Value },
    Finish { reason: serde_json::Value },
    Unknown(serde_json::Value),
}
```

- `parse_line(line: &str) -> Result<ParsedLine, EventParseError>`，
  `ParsedLine` 是 `Header(SessionHeader)` / `Event(SessionEvent)` / `Ignored`。
  **未知 `type` 归入 `Other(String)` 而非报错**（DSH 是 pre-release，新增事件类型不得让尾随器崩）。
- `SessionEvent::assistant_chunk(&self) -> Option<AssistantChunk>`

- `SessionEvent::text_of_user_message(&self) -> Option<String>`：拼接 `data.content[].text`

### Task 3: src/engine/tailer.rs — 尾随器

- **type:** code
- **files:** apps/desktop/src-tauri/Cargo.toml, apps/desktop/src-tauri/src/engine/tailer.rs
- **action:** Cargo.toml 增 `notify = "7"`（可选，若用轮询则不需要——**优先用轮询，简单可靠**）。

```rust
pub struct TailerHandle {
    pub events: mpsc::UnboundedReceiver<TailedEvent>,
    /* 私有：停止信号 */
}

pub enum TailedEvent {
    Header(SessionHeader),
    Event(SessionEvent),
    /// 日志文件在超时内未出现
    LogNotFound { session_id: String },
    /// seq 不连续（可能是外部截断），附期望值与实际值
    SeqGap { expected: u64, got: u64 },
    Closed,
}

/// 在 sessions_root 下按 */<session_id>/session.jsonl 查找并尾随。
/// find_timeout 内文件未出现则发 LogNotFound 并结束。
pub fn tail_session(
    sessions_root: PathBuf,
    session_id: String,
    find_timeout: Duration,
) -> TailerHandle;

pub fn stop(handle: &TailerHandle);
```

**实现要点，逐条落实：**

1. **定位**：`sessions_root` 下一层目录逐个查 `<dir>/<session_id>/session.jsonl`。
   命中即用。未命中则每 200ms 重试，直到 `find_timeout`。
   **不要试图从 cwd 反推目录名**——规范化是有损的。

2. **增量读**：记录已读字节偏移。每 100ms 读一次新增部分。
   **只处理以 `\n` 结尾的完整行**；不完整的尾部留在内部缓冲，等下次拼接。
   这是防止读到半行的唯一机制。

3. **文件缩短检测**：若当前文件长度 < 已读偏移，说明文件被替换/截断
   → 重置偏移为 0、清空缓冲、重新从头读（引擎的崩溃恢复会重写文件）。

4. **seq 连续性**：期望 `events[i].seq == i`。不连续时发 `SeqGap` 但**继续尾随**，不中止。

5. **停止**：`stop()` 后读循环退出并发 `Closed`。
   `TailerHandle` 的 `Drop` 也要触发停止，防止任务泄漏。

6. **非 JSON 行忽略**，不报错、不中止。

- **verify:**
  - 单元测试：向 tempdir 里的文件分批 append（**故意在行中间切断**），断言收到的事件完整且顺序正确
  - 单元测试：文件先不存在，1 秒后创建 → 尾随器能追上
  - 单元测试：文件一直不存在 → `find_timeout` 后发 `LogNotFound`

  - 单元测试：混入非 JSON 行 → 被忽略且不中止
  - 单元测试：`stop()` 后通道收到 `Closed`
- **acceptance_criteria:**

  - 文件缺失不报错
