## Decisions Made

- Optional injection preserves existing hosts and tests when no memory orchestrator is configured.
- `MemoryUseEvidenceFailureMode.DEGRADED` is the default library behavior so unsupported in-memory stores remain usable while evidence-capable failures are visible; production legal hosts can configure `FAIL_CLOSED`.
- The WeCom legal runtime does not catch `MemoryUseEvidenceError`, so fail-closed evidence failures block backend submission.
