# Plan 41-03 — Read-Time Privacy Scrubbing on New Endpoints, Backward Compatibility Tests, and V2 Gate Verification

## Goal

Verify that all four new endpoints (`/conversations` list, `/tasks` list, `/traces/{trace_id}`, `/export`) apply read-time privacy scrubbing to response payloads by extending `test_privacy_scrub.py` with forbidden-key assertions for each new endpoint. Create a dedicated `test_backward_compat.py` that snapshots the exact top-level keys of existing endpoint responses (`/conversations/{id}`, `/tasks/{id}`, `/feedback`) and asserts they are unchanged after the Phase 41 extension. Run the full V2 gate suite to confirm all 13 gates stay green and the SAFETY-02/06 contract freeze tests pass (no contract drift).

This plan satisfies:
- READVIEW-03 (privacy scrubbing portion): All new endpoints apply read-time privacy scrubbing to response payloads.
- READVIEW-01/02/03 (backward compat): Existing endpoint response shapes are unchanged after the read-view extension.
- SAFETY-02/06: Contract freeze verified — no edits to `packages/platform-contract/` or `packages/platform-runtime/protocols.py`.

## Context

- Privacy scrubbing is read-time and raises on forbidden keys (`privacy.py:51-62`). `scrub_contract_payload` recursively walks mappings/lists and raises `ValueError` if any key in `ALL_FORBIDDEN_KEYS` is present. `ALL_FORBIDDEN_KEYS` is imported from `platform_runtime.privacy_keys` (the unified source of truth established by SAFETY-03).
- The existing `test_privacy_scrub.py:27-44` proves the current API paths (`/conversations/{id}`, `/tasks/{id}`) raise on forbidden keys using a `FakeReadModel`. Phase 41 extends this pattern to the 4 new endpoints.
- The `conversation-read-view` V2 gate already exists (`scripts/run_v2_gates.py:83-87`, gate #4) and discovers all tests under `services/conversation-read-view/tests/`. New tests are picked up automatically — no new gate is required.
- The `contract-test-suite` gate (line 124-128) has `read_view_src` on its PYTHONPATH, so cross-package contract tests can import the extended package.
- The `compileall` gate (line 133-155) already includes `services/conversation-read-view/src`.
- Gate count is 13 (Phase 40 added the `provider-model-backend` gate). Phase 41 does NOT add a new gate — it is a verification task confirming the existing gate stays green.
- SAFETY-02 contract-count freeze tests at `packages/contract-test-suite/tests/test_contract_count_freeze.py` assert `BACKEND_ADAPTER_METHOD_COUNT = 9`, `ADAPTER_CAPABILITY_SET_FIELD_COUNT = 14`, `CHANNEL_ADAPTER_METHOD_COUNT = 6` — these must remain green.
- Contract freeze (SAFETY-02, SAFETY-06): No changes to `packages/platform-contract/` or `packages/platform-runtime/protocols.py`.
