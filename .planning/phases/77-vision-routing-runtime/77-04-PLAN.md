<objective>
Ship the Phase 77 Vision Config SSR surface with real signed CSRF enforcement on the new POST route, consuming Plan 77-02 API metadata.

Purpose: VIS-01 requires an operator-facing UI for vision routing configuration. This plan creates a single-purpose stdlib SSR page at `/config/vision` with a routing-mode selector, vision provider/model selectors, a vision probe button, and a save button. It reuses the Phase 76 signed CSRF helpers (`csrf.py`), the existing probe route (`/config/providers/probe` with `target=vision`), and the `_page_template` page chrome. The vision save POST is bound to `/config/vision`; the vision probe POST is bound to `/config/providers/probe` (the probe route). This plan does not introduce React, shadcn, JavaScript, or a new SPA stack. It does not implement runtime routing logic (that lives in `vision_router.py` from Plan 77-03).

Output: `vision.py` SSR module, server/nav wiring, and green UI tests.
</objective>
