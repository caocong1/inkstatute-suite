# Plan 92-02: Wave 2 — Port chat interaction components: ClarificationCard, DraftingProgressSteps, MessageFeedback, DocDraftingLoader

## Goal

Port the four interaction components that consume specific event types from the unified event stream. These components are the user-facing interaction surfaces that make the chat UI complete: the ask_user clarification card (driven by `elicitation.requested`), the five-phase progress indicator (driven by `phase.changed`), the message feedback widget (submitting via Gateway `/v1/feedback`), and the document drafting loader (shown during streaming before content arrives).

Additionally, this plan ports the full `WorkflowProgressSteps` component (367 lines) which contains the `ClarificationCard` as a sub-component, plus `WorkflowNotice`, `ModeSwitchCard`, and `WorkflowSuggestions`. In Plan 92-01 the tracer included a simplified workflow notice; this plan replaces it with the full production component.

Each component is independently testable using fixture events — no live SSE connection needed. The components receive state via props from the `RenderState` produced by the event reducer (established in Plan 92-01), and they use adapter interfaces for any platform-specific operations.

## Reversibility Gate

**One-way-door: ClarificationCard submission via Gateway.** Once the card submits answers to `POST /v1/runs/{id}/elicitation` instead of the internal `onClarificationSubmit` callback, the component is coupled to the Gateway API. Strategy: the submission is done via a callback prop (`onSubmit`), which the consumer wires to `PlatformApiClient`. The component itself is Gateway-agnostic — it just calls `props.onSubmit(answers)`. This preserves testability and avoids hard-coupling to the SDK.

**One-way-door: DraftingProgressSteps phase mapping.** The `phaseToActiveIndex()` function is updated to accept `FivePhase` values (`research`/`intake`/`retrieval`/`draft`/`review`) instead of V2 phase strings (`thinking`/`tool`/`streaming`/`review`). Once changed, any consumer passing V2 strings will break. Strategy: the old V2 mapping is not needed in ui-core (ui-core only processes Phase 88 unified events). The new mapping is a pure function with fixture tests.
