# Plan 10-02 - Fake Adapters And Run Lifecycle Runtime

## Objective

Implement the first concrete embeddable runtime class and fake adapters so tests can prove create, poll, cancel, and approve behavior without any live backend, channel, server, database, or network dependency.

## Threat Model

<threat_model>
<risk id="T-10-02-backend-specific-runtime" severity="high">The runtime could encode concrete backend behavior. Mitigation: `runtime.py` accepts a `BackendAdapter` Protocol instance and never branches on backend names or private backend paths.</risk>
<risk id="T-10-02-channel-required" severity="high">Runtime construction could require a channel adapter, violating zero-channel embeddability. Mitigation: channels default to an empty tuple and tests construct the runtime with no channels.</risk>
<risk id="T-10-02-flag-bypass" severity="high">Lifecycle methods could run when the runtime lane is default-off. Mitigation: `create_run` checks `run_runtime_enabled` before submitting to the backend; tests prove the default disabled path.</risk>
<risk id="T-10-02-approval-unsafe" severity="medium">Approval calls could be accepted without the approval lane enabled. Mitigation: `approve` checks `approval_lane_enabled` and records sanitized approval state only when enabled.</risk>
</threat_model>

<action>Create `runtime.py` with `DefaultRunRuntime`, constructed from `backend`, optional `channels=()`, `feature_flags`, `contract_log_store`, `output_boundary`, `clock`, and `id_factory`. Implement `create_run`, `poll`, `stream`, `cancel`, and `approve` signatures compatible with the existing `RunRuntime` Protocol. `create_run` checks `run_runtime_enabled`, calls `backend.submit_run(req)`, records a `run` event and initial `run_event` in the contract log when `contract_log_enabled` is true, and returns the current run from `backend.get_run`. `poll` returns `backend.get_run`. `cancel` calls `backend.cancel_run` and appends a cancelled state event. `approve` checks `approval_lane_enabled`, calls `backend.submit_approval`, and appends an approval state event. Update `__init__.py` exports for `DefaultRunRuntime` and runtime errors.</action>
<acceptance_criteria>
- `DefaultRunRuntime` can be instantiated with `channels=()` and no server object.
- `isinstance(DefaultRunRuntime(...), RunRuntime)` is not required at runtime, but the class exposes async `create_run`, `poll`, `stream`, `cancel`, and `approve` methods.
- `create_run` raises `RuntimeFeatureDisabledError` when `run_runtime_enabled` is false.
- With explicit `run_runtime_enabled=True` and `contract_log_enabled=True`, `create_run` calls the fake backend and appends run lifecycle records to `InMemoryContractLogStore`.
- `approve` raises `RuntimeFeatureDisabledError` when `approval_lane_enabled` is false.
</acceptance_criteria>
</task>
