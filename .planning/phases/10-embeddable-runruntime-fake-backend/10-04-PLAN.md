# Plan 10-04 - Fake Runtime Contract Fixture And Replay Evidence

## Objective

Produce sanitized contract-test evidence for the Phase 10 fake runtime path, including relationship replay, append-only sequence checks, zero-channel embeddability evidence, output-boundary leak evidence, and default-off feature-flag evidence.

## Threat Model

<threat_model>
<risk id="T-10-04-fixture-sensitive-payload" severity="high">The fixture could store raw prompt or backend payload text. Mitigation: use synthetic non-sensitive data, `raw_payload_ref`, hashes, and sanitized policy summaries only.</risk>
<risk id="T-10-04-false-live-claim" severity="high">Fixture evidence could be mistaken for live channel acceptance. Mitigation: README and fixture metadata state `fake_backend`, `zero_channels`, `no_server`, and `not_live_acceptance`.</risk>
<risk id="T-10-04-relationship-gap" severity="medium">New runtime records could miss required relationship links. Mitigation: tests verify `ChannelMessage -> AgentTurn -> Run -> RunEvent/RunStep -> AgentResult/ArtifactRecord -> ChannelDelivery` IDs where the fixture includes those objects.</risk>
<risk id="T-10-04-test-runner-path" severity="medium">Contract-test runner may not import platform-runtime tests/helpers. Mitigation: update the runner source paths to include `packages/platform-runtime/src` only when needed for Phase 10 tests.</risk>
</threat_model>
