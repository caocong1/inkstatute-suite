# Plan 88-03: Elicititation Contract — Ask-User Protocol and RunInterrupt Interconversion

## Goal

<action>
Create `packages/platform-contract/src/platform_contract/schemas/elicitation_question.schema.json` as a standalone, reusable JSON Schema for the ask-user question format. Schema structure:
- `$schema`: `"https://json-schema.org/draft/2020-12/schema"`
- `$id`: `"https://inkstatute.dev/schemas/platform-contract/elicitation_question.schema.json"`
- `title`: `"ElicitationQuestion"`
- `type`: `"object"`, `additionalProperties`: false
- `required`: `["id", "question"]`
- `properties`:
  - `id`: `{"type": "string"}` — question identifier
  - `question`: `{"type": "string"}` — question text
  - `allow_multiple`: `{"type": "boolean", "default": false}` — false = single-select, true = multi-select
  - `options`: `{"type": "array", "items": {"type": "object", "additionalProperties": false, "required": ["label", "value"], "properties": {"label": {"type": "string"}, "value": {"type": "string"}}}}` — absence of options array implies free-text question

This schema matches ASK-USER-PROTOCOL.md exactly: `intro` is on the parent `elicitation_requested.schema.json`, not here. The `options` array items have `label` (Chinese display text) and `value` (machine value). Free-text questions have no `options` key.
</action>

<action>
Create `packages/platform-contract/src/platform_contract/elicitation.py` with:

1. `elicitation_to_run_interrupt(payload: ElicitationRequestedPayload, run_id: str, session_id: str, created_at: str) -> RunInterrupt` — converts an ElicitationRequestedPayload to a RunInterrupt. Field mapping:
   - `interrupt_id` ← `payload.interrupt_id`
   - `run_id` ← `run_id` parameter
   - `session_id` ← `session_id` parameter
   - `status` ← `InterruptStatus.WAITING_FOR_USER`
   - `reason` ← `"clarification"`
   - `created_at` ← `created_at` parameter
   - `prompt_ref` ← a reference string constructed as `f"elicitation://{payload.interrupt_id}"` (reference-first, not full text)
   - `resume_state_ref` ← `payload.resume_state_ref` (or `""` if None)
   - `expected_response_schema_ref` ← `f"https://inkstatute.dev/schemas/platform-contract/elicitation_question.schema.json"` (the schema that validates the question structure)
   - `expires_at` ← `payload.expires_at`
   - `metadata` ← `{"intro": payload.intro, "questions": [dataclasses.asdict(q) for q in payload.questions], **payload.metadata}` (store full question structure in metadata for round-trip fidelity)

2. `run_interrupt_to_elicitation(interrupt: RunInterrupt) -> ElicitationRequestedPayload` — converts a RunInterrupt back to ElicitationRequestedPayload. Field mapping:
   - `interrupt_id` ← `interrupt.interrupt_id`
   - `intro` ← `interrupt.metadata.get("intro", "")`
   - `questions` ← reconstruct `list[ElicitationQuestion]` from `interrupt.metadata.get("questions", [])`, each item dict converted to `ElicitationQuestion` with `ElicitationOption` list
   - `resume_state_ref` ← `interrupt.resume_state_ref`
   - `expires_at` ← `interrupt.expires_at`
   - `metadata` ← remaining metadata keys (excluding `intro` and `questions`)

3. `validate_question_count(questions: list[ElicitationQuestion]) -> None` — raises `ValueError` if `len(questions) < 2` or `len(questions) > 4`. Enforces the 2-4 question constraint from ASK-USER-PROTOCOL.md.

4. `format_answer_display(questions: list[ElicitationQuestion], answers: dict[str, str]) -> str` — formats the answer display text per ASK-USER-PROTOCOL.md: numbered list with question text and answer. For multi-select answers (values joined by `|`), display Chinese labels joined by `、`. For single-select, display the label for the selected value. For free-text (no options), display the raw answer string.

Import `from .events import RunInterrupt` and `from .unified_events import ElicitationRequestedPayload, ElicitationQuestion, ElicitationOption` and `from .enums import InterruptStatus`. Use `import dataclasses` for `asdict`.

Update `__init__.py`: add `from .elicitation import elicitation_to_run_interrupt, run_interrupt_to_elicitation, validate_question_count, format_answer_display`. Add all four to `__all__`.
</action>
