# Plan 06-01 - Contract Log Read Model

## Objective

Create the dependency-light `services/conversation-read-view/` package and its read-only in-memory model over V2 contract event logs. This plan does not expose HTTP routes yet; it creates the derived source of truth that Plan 06-03 will route through.

## Threat Model

<threat_model>
<risk id="T-06-01-authority" severity="high">A derived read model could silently become an authoritative session database. Mitigation: no database files, no persistent queue, README states derived/rebuildable, and tests assert package dependencies remain empty.</risk>
<risk id="T-06-01-privacy" severity="high">Contract logs or API views could expose callback bodies, customer documents, secrets, or exact raw payload fields. Mitigation: add recursive privacy scrub/reject helpers and tests for exact raw payload key rejection while preserving raw_payload_ref.</risk>
<risk id="T-06-01-ordering" severity="medium">Out-of-order records could produce unstable task/conversation views. Mitigation: sort by occurred_at, ingested_at, and seq before indexing.</risk>
<risk id="T-06-01-fabrication" severity="medium">Missing result/trace/feedback associations could be fabricated. Mitigation: expose missing_associations and source_status metadata instead of synthetic facts.</risk>
</threat_model>
