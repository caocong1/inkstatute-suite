<objective>
Wire `ExportDialog` into `ChatView` so users can export the current session's change list to a Word docx with track-changes. Add an export button to the chat AppBar and/or a message context menu on assistant messages. Connect to `DocxExporter` with real portable Python. This closes INT-04 — the major gap where export components are implemented but not accessible from the chat UI.
</objective>

<tasks>

### Task 1: Add export capability to ChatController

- **type:** code
- **files:** apps/flutter_app/lib/chat/chat_controller.dart
- **action:**
  1. Add imports: `import 'package:flutter_app/export/change_list_parser.dart'`, `import 'package:flutter_app/export/change_list_schema.dart'`, `import 'package:flutter_app/export/docx_exporter.dart'`, `import 'package:flutter_app/export/hg4_status.dart'`.
  2. Add optional fields to `ChatController`:
     - `final DocxExporter? _docxExporter` — injected from main.dart with real portable Python paths.
     - `final Hg4Tracker? _hg4Tracker` — injected from main.dart.
  3. Add these as optional constructor parameters: `DocxExporter? docxExporter`, `Hg4Tracker? hg4Tracker`.
  4. Add a method `ChangeList? extractChangeListFromLastAssistant()` that:
     - Finds the last `AssistantMessage` in `_messages`.
     - Calls `ChangeListParser.extractFromMessage(lastAssistant)`.
     - Returns the `ChangeList` or null if no change list is found.
  5. Add a method `bool canExport()` that returns true if:
     - `_docxExporter` is not null.
     - `_hg4Tracker` is not null.
     - `extractChangeListFromLastAssistant()` returns a non-null `ChangeList` with items.
  6. Add a method `Future<ExportResult?> exportToDocx({required String inputDocxPath, required String outputDocxPath})` that:
     - Checks `canExport()` — returns null if not exportable.
     - Gets the change list from the last assistant message.
     - Calls `_docxExporter!.export()` with the change list, input, and output paths.
     - Returns the `ExportResult`.
- **verify:**
  - `flutter analyze` passes
  - New test: verify `canExport()` returns false when no assistant message has a change list, true when one does.
  - Existing tests still pass.
- **acceptance_criteria:**
  - `ChatController` can extract change lists from assistant messages
  - `ChatController.canExport()` correctly reports export availability
  - `ChatController.exportToDocx()` delegates to `DocxExporter` with real paths
