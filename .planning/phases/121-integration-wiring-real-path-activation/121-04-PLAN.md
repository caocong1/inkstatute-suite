<tasks>

### Task 1: Automate portable Python download in build_windows_installer.sh

- **type:** shell
- **files:** scripts/build_windows_installer.sh
- **action:**
  1. Replace lines 83-85 (the `echo "NOTE: Portable Python must be downloaded..."` block) with an automated download section.
  2. Define the portable Python download URL and version:
     ```bash
     PYTHON_VERSION="3.12.7"
     PYTHON_ARCH="amd64"
     PYTHON_URL="https://www.python.org/ftp/python/${PYTHON_VERSION}/python-${PYTHON_VERSION}-embed-${PYTHON_ARCH}.zip"
     PYTHON_ZIP="$STAGING_DIR/python-portable.zip"
     PYTHON_DIR="$STAGING_DIR/python"
     ```
  3. Download the portable Python embeddable zip:
     ```bash
     echo "Downloading portable Python ${PYTHON_VERSION}..."
     if command -v curl >/dev/null 2>&1; then
       curl -L -o "$PYTHON_ZIP" "$PYTHON_URL"
     elif command -v wget >/dev/null 2>&1; then
       wget -O "$PYTHON_ZIP" "$PYTHON_URL"
     else
       echo "ERROR: neither curl nor wget found — cannot download portable Python" >&2
       exit 1
     fi
     ```
  4. Extract to `staging/python/`:
     ```bash
     echo "Extracting portable Python..."
     if command -v unzip >/dev/null 2>&1; then
       unzip -q -o "$PYTHON_ZIP" -d "$PYTHON_DIR"
     elif command -v 7z >/dev/null 2>&1; then
       7z x -y -o"$PYTHON_DIR" "$PYTHON_ZIP"
     else
       echo "ERROR: neither unzip nor 7z found — cannot extract portable Python" >&2
       exit 1
     fi
     rm -f "$PYTHON_ZIP"
     ```
  5. Install `python-docx` and `lxml` into the portable Python (the track-changes script depends on `python-docx`):
     - The embeddable distribution doesn't include pip by default. Add pip:
       ```bash
       # Enable pip in embeddable Python
       echo "Installing pip into portable Python..."
       curl -L -o "$PYTHON_DIR/get-pip.py" "https://bootstrap.pypa.io/get-pip.py"
       "$PYTHON_DIR/python.exe" "$PYTHON_DIR/get-pip.py" --no-warn-script-location
       rm -f "$PYTHON_DIR/get-pip.py"
       ```
     - Uncomment `import site` in `python312._pth` (or the version-appropriate file) to enable site-packages:
       ```bash
       PTH_FILE=$(find "$PYTHON_DIR" -name "python*._pth" | head -1)
       if [ -n "$PTH_FILE" ]; then
         sed -i 's/#import site/import site/' "$PTH_FILE"
       fi
       ```
     - Install required packages:
       ```bash
       echo "Installing python-docx and lxml..."
       "$PYTHON_DIR/python.exe" -m pip install --no-warn-script-location python-docx lxml
       ```
  6. Verify the portable Python works:
     ```bash
     echo "Verifying portable Python..."
     "$PYTHON_DIR/python.exe" -c "import docx; import lxml; print('Python + python-docx + lxml OK')"
     if [ $? -ne 0 ]; then
       echo "ERROR: portable Python verification failed" >&2
       exit 1
     fi
     ```
  7. Remove the old `echo "NOTE: Portable Python must be downloaded..."` lines.
  8. Keep the track-changes script copy step (line 79-82) as-is — it already copies the script to `staging/scripts/`.
- **verify:**
  - `bash -n scripts/build_windows_installer.sh` (syntax check) passes
  - On a system with curl + unzip: running the Python download section produces a working `python.exe` in `staging/python/` with `python-docx` and `lxml` installed.
  - The verification command `python.exe -c "import docx; import lxml; print('OK')"` succeeds.
- **acceptance_criteria:**
  - No manual `echo "NOTE: Portable Python must be downloaded..."` remains
  - Portable Python is downloaded via curl/wget automatically
  - pip is bootstrapped into the embeddable distribution
  - `python-docx` and `lxml` are installed
  - Verification step confirms the Python environment works
  - Script fails loud if download or extraction fails (no silent skip)

### Task 3: Update build_windows_installer.sh to handle offline/cached Python

- **type:** shell
- **files:** scripts/build_windows_installer.sh
- **action:**
  1. Add an environment variable `PYTHON_ZIP_CACHE` that, if set, points to a pre-downloaded portable Python zip. This allows CI or offline builds to skip the download:
     ```bash
     if [ -n "${PYTHON_ZIP_CACHE:-}" ] && [ -f "$PYTHON_ZIP_CACHE" ]; then
       echo "Using cached portable Python: $PYTHON_ZIP_CACHE"
       cp "$PYTHON_ZIP_CACHE" "$PYTHON_ZIP"
     else
       # Download from URL (as in Task 1)
     fi
     ```
  2. Add a `--skip-python` flag for builds where Python is already in staging (development convenience):
     ```bash
     case "$1" in
       --skip-python) SKIP_PYTHON=true; shift ;;
     esac
     ```
  3. If `SKIP_PYTHON` is true and `staging/python/python.exe` exists, skip the download step.
- **verify:**
  - `bash -n scripts/build_windows_installer.sh` passes
  - `PYTHON_ZIP_CACHE=/path/to/cached.zip bash scripts/build_windows_installer.sh` uses the cached zip
  - `--skip-python` flag skips the download when Python is already present
- **acceptance_criteria:**
  - Cached Python path is supported via `PYTHON_ZIP_CACHE` env var
  - `--skip-python` flag for development convenience
  - Default behavior (no cache, no skip) downloads from the internet
