### Task 3: Complete ContentUpdater.checkAndUpdate() + atomic switch + rollback

**Files:** `lib/content/content_updater.dart`, `test/content/content_updater_integration_test.dart`

**Action:**

1. Complete `ContentUpdater.checkAndUpdate()` in `lib/content/content_updater.dart`:
   ```
   Future<UpdateResult> checkAndUpdate() async {
     1. Fetch remote manifest
     2. Load local manifest (may be null)
     3. Check engine compatibility (throw if mismatch)
     4. Check for downgrade attack (throw if remote < local)
     5. If no update (remote == local), return UpdateResultUpToDate
     6. Download zip to temp file
     7. Verify zip sha256 (from sidecar or manifest)
     8. Extract to staging dir (<version>-staging)
     9. Verify per-skill sha256 hashes
     10. Atomic rename staging → release dir
     11. Update last-good pointer to current version
     12. Update current pointer to new version (atomic: write temp, rename)
     13. Cleanup old releases (keep current + last-good)
     14. Return UpdateResultSuccess(newVersion, previousVersion)
     
     On any failure:
     - Delete staging dir if exists
     - If current pointer was not yet updated, return UpdateResultFailure with rolledBackTo=null
     - If current pointer was updated but verification failed after, rollback to last-good
     - Return UpdateResultFailure with rolledBackTo=lastGoodVersion
   }
   ```

2. Add private helper methods:
   - `Future<void> _downloadZip(String zipUrl, String outputPath)` — Uses `http.Client.get()`, writes bodyBytes to file. Throws `UpdateException(networkError)` on non-200 or network failure.
   - `Future<void> _atomicRename(String from, String to)` — Renames directory. Deletes target if exists (for re-runs). Throws `UpdateException` on failure.
   - `Future<void> _updatePointer(String pointerPath, String version)` — Atomic pointer update: write to `.tmp` file, rename to pointer path.
   - `Future<void> _cleanupOldReleases(String currentVersion, String lastGoodVersion)` — Deletes release directories that are neither current nor last-good.
   - `Future<void> _rollbackToLastGood()` — Reads last-good pointer, updates current pointer to last-good version.

3. Create `test/content/content_updater_integration_test.dart`:
   - **Full success path:** Mock HTTP server returns manifest + zip. Verify staging → release → pointer update → cleanup. Assert `UpdateResultSuccess`.
   - **No update needed:** Remote version == local version. Assert `UpdateResultUpToDate`.
   - **First install:** No local manifest. Download, extract, verify, switch. Assert `UpdateResultSuccess` with `previousVersion=null`.
   - **Hash mismatch on zip:** Mock returns corrupted zip. Assert `UpdateException(hashMismatch)`, staging cleaned up, current pointer unchanged.
   - **Hash mismatch on skill:** Zip extracts but skill sha256 doesn't match manifest. Assert `UpdateException(hashMismatch)`, staging cleaned up.
   - **Network error:** Mock returns 404. Assert `UpdateException(networkError)`.
   - **Downgrade attack:** Remote version < local version. Assert `UpdateException(versionDowngrade)`.
   - **Engine mismatch:** Remote manifest has different `min_engine_version`. Assert `UpdateException(engineMismatch)`.
   - **Rollback:** Simulate failure after pointer update. Verify rollback to last-good.
   - **Offline behavior:** No network. `checkAndUpdate()` catches network error, returns `UpdateResultFailure` with `rolledBackTo=currentVersion`.
