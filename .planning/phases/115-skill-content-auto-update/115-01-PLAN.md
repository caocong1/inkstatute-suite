# Plan 115-01: ContentPaths + UpdateException + ContentUpdater core

## Goal

Add the `http`, `archive`, `pub_semver`, and `crypto` dependencies. Create `ContentPaths` for content directory resolution (Windows `%LOCALAPPDATA%` + Linux/WSL fallback), `UpdateException` for error handling, and `ContentUpdater` core with manifest fetching, version comparison (semver), and engine compatibility checking.

## Files to create/modify

- `apps/flutter_app/pubspec.yaml` — Add `http: ^1.6.0`, `archive: ^3.6.1`, `pub_semver: ^2.1.4`, `crypto: ^3.0.3`
- `apps/flutter_app/lib/content/content_paths.dart` — Path resolution for content directory
- `apps/flutter_app/lib/content/update_exception.dart` — Exception types for update failures
- `apps/flutter_app/lib/content/content_updater.dart` — Core updater class
- `apps/flutter_app/test/content/content_paths_test.dart` — Path resolution tests
- `apps/flutter_app/test/content/content_updater_test.dart` — Core updater tests

### Task 1: Add dependencies + ContentPaths

**Files:** `pubspec.yaml`, `lib/content/content_paths.dart`, `test/content/content_paths_test.dart`

**Action:**

1. Add to `pubspec.yaml` dependencies:

   ```yaml
   pub_semver: ^2.1.4
   crypto: ^3.0.3
   ```

2. Create `lib/content/content_paths.dart`:
   - `ContentPaths` static class with:
     - `resolveContentDir()` — Returns `<LOCALAPPDATA>\InkStatute\content` on Windows, `~/.local/share/InkStatute/content` on Linux. Follows the pattern from `DshPaths.resolveDshHome()`.
     - `resolveSkillsDir()` — Returns `<contentDir>/skills`
     - `resolveReleaseDir(String version)` — Returns `<skillsDir>/<version>`
     - `resolveStagingDir(String version)` — Returns `<skillsDir>/<version>-staging`
     - `resolveCurrentPointer()` — Returns `<skillsDir>/current`
     - `resolveLastGoodPointer()` — Returns `<skillsDir>/last-good`
     - `getCurrentReleaseVersion()` — Reads `current` pointer file, returns version string or null if not found
     - `getCurrentReleasePath()` — Returns path to current release directory based on pointer
     - `getLastGoodReleaseVersion()` — Reads `last-good` pointer file
   - All path operations use `path` package for cross-platform separators (already available via Flutter).

3. Create `test/content/content_paths_test.dart`:
   - Test `resolveContentDir()` returns a non-empty path
   - Test `resolveSkillsDir()` appends `/skills`
   - Test `resolveReleaseDir('1.0.0')` contains `1.0.0`
   - Test `resolveStagingDir('1.0.0')` contains `1.0.0-staging`
   - Test pointer paths end with `current` and `last-good`
   - Test `getCurrentReleaseVersion()` returns null when pointer doesn't exist
   - Test `getCurrentReleaseVersion()` reads pointer file correctly (create temp file, read it)

### Task 2: UpdateException + UpdateResult

**Files:** `lib/content/update_exception.dart`

**Action:**

Create `lib/content/update_exception.dart`:
- `UpdateException` class extending `Exception` with:
  - `message` (String)
  - `kind` (UpdateExceptionKind enum: `networkError`, `hashMismatch`, `versionDowngrade`, `engineMismatch`, `extractionFailed`, `pointerUpdateFailed`, `noCurrentRelease`, `noLastGood`, `invalidManifest`, `pathTraversal`)
  - `toString()` returns `UpdateException(<kind>): <message>`
- `UpdateResult` sealed class:
  - `UpdateResultUpToDate` — No update available, current version is latest
  - `UpdateResultSuccess` — Update applied successfully, contains `newVersion` and `previousVersion`
  - `UpdateResultFailure` — Update failed, contains `exception` and `rolledBackTo` (nullable)

### Task 3: ContentUpdater core (manifest fetch + version comparison + engine check)

**Files:** `lib/content/content_updater.dart`, `test/content/content_updater_test.dart`

**Action:**

1. Create `lib/content/content_updater.dart`:
   - `ContentUpdater` class with:
     - Constructor: `ContentUpdater({String? contentReleaseUrl, String? engineVersion, http.Client? httpClient})`
     - `contentReleaseUrl` — defaults to `Platform.environment['CONTENT_RELEASE_URL']` or a placeholder default
     - `engineVersion` — defaults to `47f943859b` (read from DSH pin in production)
     - `httpClient` — injectable for testing
     - `Future<ContentManifest?> fetchRemoteManifest()` — Downloads `content-manifest.json` from release URL, parses with `ContentManifest.fromJson()`. Throws `UpdateException` on network error or invalid JSON.
     - `Future<ContentManifest?> loadLocalManifest()` — Reads manifest from current release directory. Returns null if no current release.
     - `bool hasUpdate(ContentManifest remote, ContentManifest? local)` — Uses `pub_semver` `Version.parse()` to compare `releaseVersion`. Returns true if remote > local.
     - `void checkDowngradeAttack(ContentManifest remote, ContentManifest local)` — Throws `UpdateException(versionDowngrade)` if remote < local.
     - `void checkEngineCompatibility(ContentManifest manifest)` — Uses `manifest.isCompatibleWith(engineVersion)`. Throws `UpdateException(engineMismatch)` if incompatible.
     - `Future<UpdateResult> checkAndUpdate()` — Orchestrates: fetch remote → load local → compare versions → if update available, delegate to download/extract/switch (stub for now, returns `UpdateResultUpToDate` if no update). This method will be fully implemented in Plan 115-02.

2. Create `test/content/content_updater_test.dart`:
   - Test `hasUpdate()` returns true when remote version > local version
   - Test `hasUpdate()` returns false when versions are equal
   - Test `hasUpdate()` returns true when local is null (first install)
   - Test `checkDowngradeAttack()` throws when remote < local
   - Test `checkDowngradeAttack()` does not throw when remote >= local
   - Test `checkEngineCompatibility()` throws when engine version doesn't match
   - Test `checkEngineCompatibility()` passes when engine version matches
   - Test `fetchRemoteManifest()` with mock HTTP client returning valid JSON
   - Test `fetchRemoteManifest()` throws on network error (mock returns 404)
   - Test `fetchRemoteManifest()` throws on invalid JSON
   - Test `loadLocalManifest()` returns null when no current release
   - Test `loadLocalManifest()` returns manifest when current release exists (temp dir)

