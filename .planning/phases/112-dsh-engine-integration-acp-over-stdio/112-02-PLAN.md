<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ACP stdio (Dart client ↔ ACP server) | All protocol messages cross this boundary; server responses and notifications are untrusted input |
| Permission policy callback | App-level policy function receives untrusted tool call data from the engine; must not execute based on untrusted input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-112-03 | Elevation of Privilege | session/prompt single in-flight | mitigate | Client-side guard rejects second prompt before sending (DP-4); server also enforces but client guard is primary |
| T-112-04 | Tampering | session/new cwd validation | mitigate | Client validates cwd is absolute before sending; server also validates with -32602 error |
| T-112-05 | Information Disclosure | session/update output boundary | mitigate | Only agent_message_chunk text is delivered to onUpdate stream; unknown sessionUpdate types are silently dropped |
| T-112-06 | Elevation of Privilege | session/request_permission default deny | mitigate | Default policy returns reject-once when no hook is set; policy hook is explicit, not implicit |
</threat_model>
