  <action>
    Create `acp_transport.dart`: Implement `AcpTransport` class with an `IOSink` for writing and a `Stream<List<int>>` for reading. The `send` method writes `jsonEncode(message) + "\n"` to the IOSink. The `messages` getter transforms the input stream with `utf8.decoder` → `LineSplitter()` → filter empty lines → `jsonDecode` each line as `Map<String, dynamic>`. This is NDJSON framing — NOT Content-Length headers (ACP uses NDJSON, verified from `@agentclientprotocol/sdk/dist/stream.js`).

    Create `acp_protocol.dart`: Define JSON-RPC 2.0 types: `JsonRpcRequest` (id, method, params), `JsonRpcResponse` (id, result), `JsonRpcNotification` (method, params), `JsonRpcError` (code, message). Use Dart classes with `fromJson` / `toJson` factory constructors. Protocol version constant: `PROTOCOL_VERSION = 1`.

    Create `acp_types.dart`: Define ACP v1 method parameter and result types: `InitializeParams` ({protocolVersion: 1, clientCapabilities: {}}), `InitializeResult` ({protocolVersion, agentInfo: {name, version}, agentCapabilities: {promptCapabilities: {image, audio, embeddedContext}}, authMethods: []}), `SessionNewParams` ({cwd, mcpServers: []}), `SessionNewResult` ({sessionId}). Use typed classes with `fromJson`/`toJson`.

    Create `acp_client.dart`: Implement `AcpClient` class that wraps an `AcpTransport`. Maintains `_nextId` counter (starting at 1) and `_pending` map of `int` → `Completer<Map<String, dynamic>>`. The `_call(method, params)` method assigns an ID, creates a completer, sends the request via transport, and returns the completer's future. The message handler distinguishes: (a) response (has `id`, no `method`) → complete pending future; (b) notification (has `method`, no `id`) → dispatch to notification handler; (c) server request (has `id` + `method`) → dispatch to server request handler. Implement `initialize()` that calls `_call('initialize', {'protocolVersion': 1, 'clientCapabilities': {}})` and returns a typed `InitializeResult`.

    Create `mock_acp_server.dart`: A Dart script that acts as a scripted mock ACP server. It reads NDJSON from stdin, matches incoming requests by method, and writes scripted NDJSON responses to stdout. For `initialize`, respond with `{"jsonrpc":"2.0","id":<id>,"result":{"protocolVersion":1,"agentInfo":{"name":"mock-acp","version":"0.0.1"},"agentCapabilities":{"promptCapabilities":{"image":false,"audio":false,"embeddedContext":false}},"authMethods":[]}}`. For `session/new`, respond with `{"jsonrpc":"2.0","id":<id>,"result":{"sessionId":"mock-session-001"}}`. On stdin close, exit with code 0. The mock server is a `main()` function that can be run as `dart run test/fixtures/mock_acp_server.dart`.

Close the client (close stdin), await `process.exitCode`, assert exit code == 0. This is the tracer — it must pass.
