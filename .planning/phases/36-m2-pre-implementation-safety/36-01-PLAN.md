# Plan 01: Selection Gate Bypass Fix + M2 Feature Flags Default-OFF

## Goal

Implement the two smallest, independent safety measures: (1) remove the selection gate bypass that allows non-Hermes prototype adapters to serve live WeCom turns, and (2) add 6 M2 feature flags that all default to `False` so no M2 service is implicitly ON.

## Tasks

### Task 01: Remove selection gate bypass and add bypass-blocking test (SAFETY-01)

<read_first>
- services/wecom-service/src/wecom_service/agent_backend.py (current bypass at lines 50-51)
- services/wecom-service/tests/test_agent_backend.py (existing test patterns, manifest() helper at lines 43-67)
- packages/platform-contract/src/platform_contract/agent_adapter.py (AgentBackendMode enum at lines 12-15: HERMES, CODEX, PROVIDER_MODEL)
</read_first>

<action>
Delete lines 50-51 in `services/wecom-service/src/wecom_service/agent_backend.py`:
- Remove the `if requested_mode != AgentBackendMode.HERMES.value and metadata.get("production_ready") is True:` conditional and its body `live_acceptance_allowed = True`.
- Line 49 (`live_acceptance_allowed = production_ready and requested_mode == AgentBackendMode.HERMES.value`) remains as the sole logic: `live_acceptance_allowed` is `True` only when both `production_ready` is truthy AND mode is HERMES.

Add a new test method `test_non_hermes_manifest_production_ready_bypass_is_blocked` to the `AgentBackendSelectorTests` class in `services/wecom-service/tests/test_agent_backend.py`:
- Iterate over `(AgentBackendMode.CODEX, AgentBackendMode.PROVIDER_MODEL)` using `self.subTest(mode=mode)`.
- For each mode, call `self.manifest(mode, no_channel_io=True, production_ready=True)` to build a manifest with `production_ready=True` in metadata.
- Call `select_agent_backend({"agent_backend": {"mode": mode.value}}, [manifest])`.
- Assert `selection.mode == mode.value`.
- Assert `selection.contract_compatible` is `True`.
- Assert `selection.live_acceptance_allowed` is `False`.
- The test method name contains "bypass" so `pytest -k bypass` selects it.
</action>
