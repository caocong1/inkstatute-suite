# Plan 02: Contract-Count Freeze + Contract Freeze Baseline Hash

## Goal

Establish two contract drift detectors in the contract-test-suite gate: (1) a runtime introspection test that freezes `BackendAdapter` method count, `AdapterCapabilitySet` field count, and `ChannelAdapter` method count at the v1.5 baseline, and (2) a SHA-256 baseline hash test that detects any modification to the 31 contract surface files (26 schema JSON + 4 Python binding + 1 Protocol) during the V2 human gate period.

<action>
Step 1 — Generate baseline fixture: Create `packages/contract-test-suite/fixtures/contract_freeze_baseline.json`. This is a JSON object with keys `"algorithm": "sha256"` and `"files": {}` mapping 31 relative file paths to their SHA-256 hashes. The 31 files are:
- All 26 `*.schema.json` files in `packages/platform-contract/src/platform_contract/schemas/` (sorted alphabetically)
- `packages/platform-contract/src/platform_contract/agent_adapter.py`

- `packages/platform-contract/src/platform_contract/__init__.py`
- `packages/platform-runtime/src/platform_runtime/protocols.py`

Generate the hashes by reading each file's bytes and computing `hashlib.sha256(...).hexdigest()`. The relative paths are relative to the repo root. Run the generation from the repo root so paths match what the test will compute.

Step 2 — Create `packages/contract-test-suite/tests/test_contract_freeze.py` with a `ContractFreezeTests(unittest.TestCase)` class:

Constants:
- `REPO_ROOT = Path(__file__).resolve().parents[3]`
- `BASELINE_PATH = Path(__file__).resolve().parents[1] / "fixtures" / "contract_freeze_baseline.json"`

Test methods:
1. `test_schema_files_match_baseline_hash` — load baseline JSON, iterate `baseline["files"].items()`, for each `(rel_path, expected_hash)`: assert `(REPO_ROOT / rel_path).exists()`, compute `actual_hash = hashlib.sha256((REPO_ROOT / rel_path).read_bytes()).hexdigest()`, assert `actual_hash == expected_hash` with message `"contract file modified from v1.5 baseline: {rel_path}"`. Use `self.subTest(file=rel_path)`.
2. `test_no_new_schema_files_added_without_baseline` — load baseline JSON, compute `current_files = {str(p.relative_to(REPO_ROOT)) for p in (REPO_ROOT / "packages/platform-contract/src/platform_contract/schemas").glob("*.schema.json")}`, compute `baseline_files = set(baseline["files"].keys())`, assert `current_files - baseline_files` is empty with message listing new files.

Imports needed: `hashlib`, `json`, `unittest`, `from pathlib import Path`.
</action>
