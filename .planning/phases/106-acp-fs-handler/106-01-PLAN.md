# Plan 01: FSSandbox + ReferenceSanitizer — Core Security Primitives

## Objective

Create the two foundational security primitives that all fs/read_text_file handling depends on: (1) `FSSandbox` with five-layer path validation that rejects path traversal, symlink escapes, absolute-path越界, non-allowlist extensions, and oversized files; (2) `ReferenceSanitizer` that wraps reference file content in unforgeable delimiters, detects prompt-injection patterns, and logs detections. These primitives have no dependency on ACPClient or transport changes and can be built and tested in isolation.

**Scope note:** Extension allowlist is text-only for v1 (`.txt`, `.md`, `.json`, `.yaml`, `.yml`, `.csv`, `.html`, `.xml`, `.log`, `.py`, `.js`, `.ts`); binary formats (`.docx`, `.pdf`) are deferred to a future phase. Only `fs/read_text_file` is in scope; `fs/write`, `fs/list` are not implemented.

<action>
Create `packages/acp-client/src/inkstatute_acp_client/fs_sandbox.py` with the following symbols:

1. `FSSandboxError(Exception)` — base exception for all sandbox violations. Constructor takes a `message: str` and an optional `reason: str = ""`. Store both as attributes.

2. `DEFAULT_ALLOWED_EXTENSIONS: frozenset[str]` — constant containing `frozenset({".txt", ".md", ".json", ".yaml", ".yml", ".csv", ".html", ".xml", ".log", ".py", ".js", ".ts"})`.

3. `DEFAULT_MAX_FILE_SIZE: int` — constant `1_048_576` (1 MB).

4. `FSSandboxConfig` — `@dataclass(frozen=True, slots=True)` with fields: `allowed_root: Path`, `allowed_extensions: frozenset[str] = DEFAULT_ALLOWED_EXTENSIONS`, `max_file_size: int = DEFAULT_MAX_FILE_SIZE`.

5. `FSSandbox` class with:
   - `__init__(self, config: FSSandboxConfig)` — store config; resolve `config.allowed_root` via `Path.resolve()` and store as `self._root`.
   - `validate_path(self, path: str | Path) -> Path` — execute five checks in order, returning the resolved `Path` on success:
     a. **Reject `..` components**: `p = Path(path)`; if `".." in p.parts`, raise `FSSandboxError(f"path traversal not allowed: {path}", reason="traversal")`.
     b. **Symlink rejection**: compute `abs_path = p.absolute()`; walk from the filesystem root to `abs_path` by iterating `abs_path.parts[1:]` (skip the anchor). For each component, build `current = current / part` starting from `Path(abs_path.anchor)`. If `os.path.islink(current)` is `True`, raise `FSSandboxError(f"symlink rejected: {current}", reason="symlink")`. Use `os.path.islink` (NOT `os.path.realpath` which follows symlinks).
     c. **Resolve normalization**: `resolved = p.resolve()`.
     d. **Prefix-check root constraint**: if `self._root not in resolved.parents and resolved != self._root`, raise `FSSandboxError(f"path outside allowed root: {resolved}", reason="outside_root")`.
     e. **Extension allowlist**: `suffix = resolved.suffix.lower()`; if `suffix not in self.config.allowed_extensions`, raise `FSSandboxError(f"extension not allowed: {suffix}", reason="bad_extension")`.
     Return `resolved`.
   - `read_text_file(self, path: str | Path) -> str` — call `validate_path(path)` to get `resolved`; check `resolved.stat().st_size > self.config.max_file_size` and raise `FSSandboxError(f"file too large: {resolved.stat().st_size} > {self.config.max_file_size}", reason="oversized")` if exceeded; read and return `resolved.read_text(encoding="utf-8")`.

6. `__all__ = ["FSSandbox", "FSSandboxConfig", "FSSandboxError", "DEFAULT_ALLOWED_EXTENSIONS", "DEFAULT_MAX_FILE_SIZE"]`.

Create `packages/acp-client/tests/test_fs_sandbox.py` with class `FSSandboxEscapeTests(unittest.TestCase)` using `tempfile.TemporaryDirectory()` in `setUp` to create an isolated root. Write the 11 tests listed in `<behavior>`. For the symlink test (Test 2), use `os.symlink(target, link_path)` where `target` is a file created outside the temp dir. For the intermediate symlink test (Test 10), create a symlink `root/subdir_link` pointing to `/etc` (or another dir outside root) and call `validate_path("subdir_link/passwd")`. For the oversized test (Test 5), write `b"\x00" * (max_file_size + 1)` to a `.txt` file. For the boundary test (Test 11), write exactly `DEFAULT_MAX_FILE_SIZE` bytes for the positive case and `DEFAULT_MAX_FILE_SIZE + 1` for the negative case. Import via `from inkstatute_acp_client.fs_sandbox import FSSandbox, FSSandboxConfig, FSSandboxError, DEFAULT_MAX_FILE_SIZE`.
