# Plan 08-01 - Trial Metrics Model And Acceptance Checker

## Objective

Add a dependency-free trial acceptance helper and tests that calculate Phase 8 lawyer-trial status from minimized evidence rows while failing closed when live/sanitized runtime input is absent.

## Threat Model

<threat_model>
<risk id="T-08-01-fixture-live" severity="high">Synthetic fixture rows could be counted as live trial evidence. Mitigation: the checker requires accepted live evidence kinds for any pass.</risk>
<risk id="T-08-01-privacy" severity="high">Trial rows could store raw legal payloads or callback bodies. Mitigation: evidence validation rejects exact `raw_payload` and exposes refs only.</risk>
<risk id="T-08-01-threshold" severity="high">Acceptance could pass with too few tasks, categories, feedback, or response actions. Mitigation: explicit threshold checks and failing statuses.</risk>
<risk id="T-08-01-repair" severity="medium">Positive feedback below 60% could be hidden. Mitigation: only `passed_with_repair_plan` is allowed when a categorized repair plan exists.</risk>
</threat_model>
