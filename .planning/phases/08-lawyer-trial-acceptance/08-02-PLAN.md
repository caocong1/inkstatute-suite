# Plan 08-02 - Trial Runbook And Evidence Templates

## Objective

Create the operator-facing trial runbook and minimized evidence template needed to collect Phase 8 live lawyer-trial evidence without placing sensitive runtime material in the repository.

## Threat Model

<threat_model>
<risk id="T-08-02-early-clock" severity="high">The trial clock could start before InkStatute WeCom service and output boundary are live. Mitigation: runbook prerequisites block counting until live prerequisites are checked.</risk>
<risk id="T-08-02-data-leak" severity="high">Operators could paste raw callback bodies, legal text, files, or secrets into repo artifacts. Mitigation: template uses refs only and runbook lists forbidden fields.</risk>
<risk id="T-08-02-metric-gap" severity="medium">Operators could collect narrative evidence that cannot be checked. Mitigation: JSON template mirrors checker-required fields.</risk>
</threat_model>
