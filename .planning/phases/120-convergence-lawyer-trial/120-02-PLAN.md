# Plan 120-02: Offline behavior + last-good fallback

## Goal

Implement offline behavior: app can start offline, view history, and clearly prompts when new tasks require network.

## Tasks

### Task 1: Network status detector

Create `lib/offline/network_status.dart`:
- `NetworkStatus` — Enum: online, offline
- `NetworkStatusDetector` class:
  - `Future<NetworkStatus> check()` — Checks network connectivity
  - `Stream<NetworkStatus> statusStream` — Stream of status changes

### Task 2: Last-good fallback

Create `lib/offline/last_good_fallback.dart`:
- `LastGoodFallback` class:
  - `bool canStartOffline` — Whether the app can start with last-good engine+content
  - `Future<bool> verifyLastGood()` — Verifies last-good engine and content are available
  - `Future<void> switchToLastGood()` — Switches to last-good engine+content
  - `String get lastGoodEnginePath` — Path to last-good engine
  - `String get lastGoodContentPath` — Path to last-good content pack

### Task 3: Offline UI prompts

Create `lib/offline/offline_prompt.dart`:
- `OfflinePrompt` widget:
  - Shows when user tries to start a new task while offline
  - Message: "当前处于离线状态，新任务需要联网。您可以查看历史会话。"
  - Provides option to view history or retry
