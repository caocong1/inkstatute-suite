# Plan 120-03: v3.x freeze annotation + human gate signing

## Goal

Annotate v3.x platform components as frozen, prepare retirement process, and set up human gate signing workflow.

## Tasks

### Task 1: v3.x freeze annotations

Update README files for all v3.x components to mark them as frozen:
- `services/gateway/README.md` — Add FROZEN notice
- `services/wecom-service/README.md` — Add FROZEN notice
- `services/qqbot-service/README.md` — Add FROZEN notice
- `services/arena-service/README.md` — Add FROZEN notice
- `packages/agent-core/README.md` — Add FROZEN notice
- `packages/acp-client/README.md` — Add FROZEN notice (TS version)
- `packages/ui-core/README.md` — Add FROZEN notice (SolidJS)
- `apps/web/README.md` — Add FROZEN notice
- `apps/desktop/README.md` — Add FROZEN notice

Create `lib/legacy/freeze_annotation.dart`:
- `FrozenComponent` — Lists all frozen v3.x components
- `FreezeStatus` — Enum: frozen, retired
- `FreezeAnnotation` class — Tracks freeze status

### Task 2: Human gate signing process

Create `lib/gates/human_gate_signing.dart`:
- `HumanGate` — Enum: hg1LegalQuality, hg3LawyerTrial, hg4TrackChanges
- `GateSignStatus` — Enum: pending, signed, rejected
- `HumanGateSigning` class:
  - `Map<HumanGate, GateSignStatus> statuses` — Current signing status
  - `void recordPending(HumanGate gate)` — Records gate as pending signature
  - `void sign(HumanGate gate, String signerName)` — Records signature (human action)
  - `void reject(HumanGate gate, String reason)` — Records rejection
  - **Never auto-signs** — all gates start as pending and only change via explicit human action

### Task 3: LEG-02 retirement preparation

Create `lib/legacy/retirement_plan.dart`:
- `RetirementPlan` class:
  - `List<String> componentsToRetire` — v3.x components to be retired
  - `bool lawyerTrialAccepted` — Whether lawyer trial was accepted (human gate)
  - `bool canRetire` — True only if lawyer trial accepted AND all human gates signed
  - `Future<void> executeRetirement()` — Removes retired directories (only after acceptance)
