# Plan 120-01: Opt-in telemetry + engine health probe

## Goal

Implement opt-in, desensitized telemetry with engine health probe and owner remote log path.

## Tasks

### Task 1: Telemetry models

Create `lib/telemetry/telemetry_models.dart`:
- `TelemetryEvent` — Sealed class: healthCheck, crash, usage, error
- `TelemetryConfig` — opt-in flag, endpoint URL, desensitization rules
- No API keys, no customer full text, no raw payloads in events

### Task 2: Telemetry collector

Create `lib/telemetry/telemetry_collector.dart`:
- `TelemetryCollector` class:
  - `bool optIn` — Whether telemetry is enabled (default: false)
  - `void recordEvent(TelemetryEvent event)` — Records a desensitized event
  - `List<TelemetryEvent> pendingEvents` — Events waiting to be sent
  - `Future<void> flush()` — Sends pending events to endpoint
  - `String desensitize(String input)` — Removes sensitive data from text

### Task 3: Engine health probe

Create `lib/telemetry/engine_health_probe.dart`:
- `EngineHealthProbe` class:
  - `Future<HealthStatus> check()` — Pings engine via ACP initialize handshake
  - `HealthStatus` — Enum: healthy, degraded, offline
  - Records health check events to telemetry collector
