# Plan 01: Multi-Agent Runtime Adapter

## Objective

Create a new `packages/multi-agent-adapter/` package implementing `MultiAgentRuntimeAdapter` — a composite `BackendAdapter` that wraps multiple sub-adapters and orchestrates them in sequential, parallel, or supervisor patterns. The adapter delegates by `solution.backend_id`, enforces `max_handoffs=5` with cycle detection, and maintains copy-on-write shared state scoped to `parent_run_id`. When `multi_agent_enabled` is `False` (default), the adapter is transparent pass-through. This satisfies MULTIAGENT-01, MULTIAGENT-02, and MULTIAGENT-03.
