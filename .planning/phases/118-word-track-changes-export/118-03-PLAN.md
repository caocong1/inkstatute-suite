# Plan 118-03: Export UX + GATE-03 E2E + HG-4 status + phase summary

## Goal

Implement the export UX (one-click export from chat), create the GATE-03 E2E test, record HG-4 as HUMAN_NEEDED, write the research conclusion, and produce phase summary/transition.

## Tasks

### Task 1: Export dialog UX

Create `lib/export/export_dialog.dart`:
- `ExportDialog` widget:
  - Shows when user clicks "导出 Word 修订稿" button
  - Lets user choose output path (file picker)
  - Shows export progress
  - Shows success (with path) or failure (with error message)
  - Failure does not pollute the chat session (output boundary maintained)
- Integration: ChatView gets an "导出" button that opens the dialog when a ChangeList is available

### Task 2: HG-4 status tracking

Create `lib/export/hg4_status.dart`:
- `Hg4Status` — Enum: pendingConfirmation, confirmed, rejected
- `Hg4Tracker` class:
  - `Hg4Status status` — Current HG-4 status for an export
  - `void markPending(String outputPath)` — Records that a docx is pending lawyer confirmation
  - `void confirm()` — Records lawyer confirmation (human action, not automated)
  - `void reject()` — Records lawyer rejection
  - **Never auto-completes** — status starts as pendingConfirmation and only changes via explicit human action
  - Persistence: status saved to local database

### Task 3: GATE-03 E2E test

Create `test/export/gate03_e2e_test.dart`:
- Mock ACP full flow: prompt → stream → approval card → response → committed text
- Verify change list extraction from committed text
- Verify docx export produces valid output
- Verify output boundary is maintained (no engine noise in export)
- Real engine path: marked with `@Tags(['real-api'])` — skipped without API key
