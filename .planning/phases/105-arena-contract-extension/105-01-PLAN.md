# Plan 01: Arena Event Vocabulary — Enum, Dataclasses, JSON Schemas, TypeScript Interfaces

## Objective

Add 8 Arena lifecycle event types to the existing unified event vocabulary using the exact four-layer pattern (Python enum + Python dataclass + JSON Schema + TypeScript interface) already established for the 13 V3 event categories. This is CONTRACT-01: the event vocabulary extension that all downstream Arena components will reference.
