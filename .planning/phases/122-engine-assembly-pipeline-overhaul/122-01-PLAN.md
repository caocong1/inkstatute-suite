### Task 3: 写 scripts/gen-engine-lock.mjs

- **type:** code
- **files:** scripts/gen-engine-lock.mjs
- **action:** 新建 Node ESM 脚本，职责：读 pin → 在临时目录 `npm install` 精确版本 → 读 lockfile → 裁剪 → 产出 `engines/engine-lock.json`。

  脚本必须实现：
  1. 解析 `engines/dsh-pin.txt`：`key=value` 行 + `packages=` 之后的缩进列表。
  2. 建临时目录，写最小 `package.json`，执行
     `npm install <每个包>@<dsh_version> --no-audit --no-fund --registry <registry>`。
     **每个包名后必须显式拼接 `@${dsh_version}`**，禁止裸包名。
  3. 读临时目录的 `package-lock.json`，断言：
     - `lockfileVersion === 3`
     - 无嵌套条目（任何 key 的 `node_modules` 出现次数 > 1 即抛错）
     - 每个非空 key 的条目都有 `resolved` 与 `integrity`
     若断言失败，**抛错退出（exit 1）**，不产出文件。
  4. 产出 `engines/engine-lock.json`，结构：
     ```json
     {
       "schema_version": "1.0.0",
       "engine_version": "<dsh_version>",
       "node_version": "<node_version>",
       "target_platform": "<target_platform>",
       "compatible_app_range": ">=0.1.0 <1.0.0",
       "cordis_config_sha256": "<engines/acp.cordis.yml 的 sha256>",
       "generated_at": "<ISO8601 UTC>",
       "prune": {
         "node-pty/prebuilds": ["darwin-arm64", "darwin-x64", "win32-arm64"]
       },
       "packages": {
         "node_modules/@deepseek-ai/dsh-acp-demo": {
           "name": "@deepseek-ai/dsh-acp-demo",
           "version": "0.1.0-rc.6",
           "integrity": "sha512-...",
           "tarball_path": "/@deepseek-ai/dsh-acp-demo/-/dsh-acp-demo-0.1.0-rc.6.tgz"
         }
       }
     }
     ```
     **`tarball_path` 只存 registry 之后的路径部分**，不存完整 URL——装配器用配置的 registry 基址拼接，这样切换镜像不用重新生成 lock。
     从 lockfile 的 `resolved` 字段中剥离 registry 前缀得到 path；`name` 从 key 尾部或条目的 `name` 字段取。
  5. `prune.node-pty/prebuilds` 列出**要删除**的平台目录（保留 `target_platform`）。
  6. 打印摘要：条目数、总下载体积估算（若 lockfile 有 `size` 则汇总，否则打印 "unknown"）。

  脚本顶部注释必须写明：**本脚本是构建期工具，运行时不使用；装配由 Rust 侧完成。**

- **verify:**
  - `node scripts/gen-engine-lock.mjs` 成功退出（exit 0）
  - `engines/engine-lock.json` 存在且是合法 JSON
  - `python3 -c "import json;d=json.load(open('engines/engine-lock.json'));print(len(d['packages']))"` 输出 ≥ 100
  - `python3 -c "import json;d=json.load(open('engines/engine-lock.json'));assert all('integrity' in v and 'tarball_path' in v for v in d['packages'].values());print('ok')"` 输出 ok
  - `grep -c 'registry.npmmirror.com' engines/engine-lock.json` 返回 0（tarball_path 不含域名）
- **acceptance_criteria:**
  - 脚本可重复执行，产出稳定
  - 断言失败时 exit 1 且不写文件
  - `engine-lock.json` 提交进仓库
