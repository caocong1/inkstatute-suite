# Plan 37-02 — Discovery Endpoint, API Handler, and Feature Flag Integration

## Objective

Create the Cloudflare agent-skills-discovery index builder (`discovery.py`) and the pure-Python API route handler (`api.py`) that exposes `GET /skills`, `GET /skills/{skill_id}`, `GET /skills/search`, and `GET /.well-known/agent-skills/index.json`. Integrate the `skill_registry_enabled` feature flag so the handler rejects requests when the flag is disabled (default-off). This plan delivers SKILL-02 (discovery endpoint) and the read-only/feature-flag enforcement aspect of SKILL-01.

## Context

- Depends on Plan 37-01: `SkillRegistry` class and `manifest_skill_to_descriptor`/`load_skills_from_manifests` functions already exist in `packages/skill-registry/src/inkstatute_skill_registry/`.
- Cloudflare RFC v0.2.0: index at `/.well-known/agent-skills/index.json` with `$schema` field (`https://schemas.agentskills.io/discovery/0.2.0/schema.json`) and `skills[]` array. Each entry: `name` (lowercase alphanumeric + hyphens), `type` (`"skill-md"`), `description` (max 1024 chars), `url`, `digest` (`sha256:<hex>`).
- API pattern follows `services/conversation-read-view/src/conversation_read_view/api.py` — pure `handle_get(path, query, registry)` returning `(status_code, body)` tuples. No FastAPI/aiohttp.
- Feature flag `skill_registry_enabled` exists at `packages/platform-runtime/src/platform_runtime/feature_flags.py:21` (default `False`). The `require_enabled()` method (line 27-32) raises `RuntimeFeatureDisabledError` when disabled.

   - `handle_get(path: str, query: str | Mapping[str, str] | None, registry: SkillRegistry, flags: RuntimeFeatureFlags | None = None) -> tuple[int, dict[str, Any]]`: Pure route handler. If `flags` is not `None`, call `flags.require_enabled("skill_registry_enabled")` before processing (raises `RuntimeFeatureDisabledError` when disabled). Route logic:
     - `/.well-known/agent-skills/index.json` -> call `build_discovery_index(registry.list_skills())`, return `(200, index)`.
     - `/skills` -> return `(200, {"items": [_descriptor_to_dict(s) for s in registry.list_skills()], "count": len(skills), "metadata": {"read_only": True, "source": "solution_pack_manifests"}})`.

     - `/skills/{skill_id}` -> call `registry.get_skill(skill_id)`, return `(200, _descriptor_to_dict(skill))` or `(404, _not_found("skill", skill_id))`.

   - `_split_path_query(path, query) -> tuple[str, dict[str, str]]`: Split path on `?`, merge inline and separate query params (follow conversation-read-view pattern).
