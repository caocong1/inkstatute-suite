# Plan 12-04 - Embeddable Web Chat And Contract Evidence

## Objective

Add a minimal embeddable web chat renderer for `RunEvent` streaming and contract-suite evidence tying Phase 12 channel/API/client artifacts together.

## Threat Model

<threat_model>
<risk id="T-12-04-ui-scope" severity="medium">Web chat could become a full product UI. Mitigation: implement a small embeddable renderer and fixtures only.</risk>
<risk id="T-12-04-xss" severity="high">Renderer could inject unescaped event text. Mitigation: renderer escapes text and tests include unsafe fixture input.</risk>
<risk id="T-12-04-live-claim" severity="high">Client fixtures could be mistaken for live acceptance. Mitigation: fixture metadata says not live acceptance.</risk>
</threat_model>

## Artifacts This Phase Produces

- `apps/web_chat/src/render.ts`
- Web chat fixtures and tests
- Phase 12 contract-suite evidence test
- Web chat README
