# Plan 12-03 - Platform API OpenAPI And TypeScript SDK

## Objective

Create a thin platform API host surface, deterministic OpenAPI document, and generated TypeScript SDK without adding a production server dependency.

## Threat Model

<threat_model>
<risk id="T-12-03-server-scope" severity="medium">API host could accidentally become a production server. Mitigation: implement pure handlers and docs; no ASGI/WSGI dependency.</risk>
<risk id="T-12-03-sdk-drift" severity="medium">Generated SDK could drift from OpenAPI. Mitigation: deterministic generator and tests compare output.</risk>
<risk id="T-12-03-secret-leak" severity="high">API request examples could include secrets or raw payloads. Mitigation: examples use refs and hashes only.</risk>
</threat_model>

## Artifacts This Phase Produces

- `PlatformApiConfig`
- `PlatformApiApp`
- OpenAPI JSON
- TypeScript SDK and generator
