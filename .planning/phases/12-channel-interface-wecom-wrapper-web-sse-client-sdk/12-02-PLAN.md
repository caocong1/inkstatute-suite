# Plan 12-02 - Web API SSE Fixture Channel

## Objective

Add a fixture-grade Web API/SSE channel implementation to prove channel neutrality without productionizing a web channel.

## Threat Model

<threat_model>
<risk id="T-12-02-live-claim" severity="high">Fixture Web/SSE evidence could be mistaken for production readiness. Mitigation: fixture and README metadata state not-live acceptance.</risk>
<risk id="T-12-02-raw-payload" severity="high">Web payloads could store raw text or secrets. Mitigation: fixtures use refs/hashes; tests reject raw payload-like keys.</risk>
<risk id="T-12-02-backend-coupling" severity="high">Web channel could call backend directly. Mitigation: source scan rejects backend imports.</risk>
</threat_model>

## Artifacts This Phase Produces

- `WebSseChannelConfig`
- `WebSseChannelAdapter`
- `encode_sse_event`
- Sanitized multichannel fixture
