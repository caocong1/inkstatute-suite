# Plan 40-02 — AsyncOpenAI Lazy SDK Import, submit_run → AgentResult Flow, and Error Normalization

<objective>
Implement the `OpenAIClientRunner` that invokes `AsyncOpenAI.chat.completions.create` via a **lazy SDK import** (`importlib.import_module("openai")` inside the `invoke` method), wire it into `ProviderModelBackendAdapter.submit_run` so the full `submit_run → AgentResult` flow works end-to-end with fixture-driven tests, and implement error normalization on first failure (first API error is terminal — no success flip). Verify the package imports cleanly without the `openai` SDK installed.

This plan satisfies ADAPTER-02 Success Criteria 2:
- SC2: Fixture-driven `submit_run → AgentResult` flow through the provider_model adapter via `AsyncOpenAI` lazy SDK import, and the package imports cleanly without the SDK installed.
</objective>

## Context

- The `AsyncOpenAI` import must be lazy (`importlib.import_module("openai")` inside `invoke`) so the package imports cleanly without the SDK installed.
- Tests must use mock/fake transports, not real API calls — no network access in CI.
- `AgentResult` schema at `packages/platform-contract/src/platform_contract/events.py:140-155`.
- `ErrorInfo` at `events.py:84-92`: `category`, `code`, `message`, `stage`, `retryable`, `details`, `metadata`.
- `ErrorCategory` at `enums.py:17-22`: `CONTRACT_ERROR`, `RUNTIME_ERROR`, `CHANNEL_ERROR`.
- The `ProviderModelRunner` Protocol and `ProviderModelExecResult` dataclass were defined in Plan 40-01's `adapter.py`.
- OpenAI chat completion response shape: `choices[0].message.content` → `AgentResult.content`, `choices[0].finish_reason == "stop"` → `SUCCEEDED`, `usage` → sanitized metadata.
- OpenAI API errors: `RateLimitError`, `AuthenticationError`, `APIConnectionError`, `APIStatusError` — mapped to normalized `ErrorInfo` with sanitized messages (no model names, URLs, tokens).
- Error normalization on first failure: the first API error produces a single `AgentResult` with `status=FAILED` and normalized `ErrorInfo`. No subsequent event can flip it back to `SUCCESS`.
