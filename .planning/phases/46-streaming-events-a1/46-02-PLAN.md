# Plan 02: Provider Model Adapter Streaming Events

## Objective

Productize `ProviderModelBackendAdapter.stream_events()` — replace the `if False: yield` stub (adapter.py:129-132) with a real async generator that yields `RunEvent` records from OpenAI SSE chat completion deltas via an injected `StreamingProviderModelRunner` protocol. Every stream must end with a terminal `STATE_CHANGED` event with `status=SUCCEEDED` or `status=FAILED` (never "completed"). The manifest's `stream_event_support` capability becomes configurable based on whether a streaming runner is injected. This satisfies STREAM-01 for the provider_model adapter.

    - When no streaming runner is injected (self._streaming_runner is None), stream_events yields a single terminal STATE_CHANGED event with the stored run's status

    - provider_model_prototype_capabilities() accepts an optional stream_event_support: bool = False parameter
