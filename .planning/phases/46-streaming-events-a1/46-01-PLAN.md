# Plan 01: Codex Adapter Streaming Events

## Objective

Productize `CodexBackendAdapter.stream_events()` — replace the `if False: yield` stub (adapter.py:130-133) with a real async generator that yields `RunEvent` records from Codex exec JSONL streaming via an injected `StreamingCodexExecRunner` protocol. Every stream must end with a terminal `STATE_CHANGED` event with `status=SUCCEEDED` or `status=FAILED` (never "completed"). The manifest's `stream_event_support` capability becomes configurable based on whether a streaming runner is injected. This satisfies STREAM-01 for the Codex adapter.
