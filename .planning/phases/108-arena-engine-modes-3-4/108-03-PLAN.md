# Plan 03: Mode 4 — Adversarial (Arena Review + Adversarial + Multi-round + Early Stop)

## Objective

Implement `mode4.py` with `run_mode4_adversarial()` — Mode 4 builds on Mode 3's arena review, then adds: (1) adversarial weakness-finding by a dedicated `adversarial_adapter` that challenges the synthesis output, (2) multi-round synthesis that re-synthesizes incorporating adversarial findings, and (3) early stopping with a hard round cap + convergence condition (≥8/10 score AND zero high-severity findings). The early stop logic uses `_should_stop_early()` which checks all three conditions and emits `arena.early_stop_triggered` with the appropriate reason.

Implement `_should_stop_early(round: int, max_rounds: int, synthesis_score: int, high_severity_count: int) -> tuple[bool, str]` in mode4.py:

```python
def _should_stop_early(round, max_rounds, synthesis_score, high_severity_count):
    # Hard round cap — checked FIRST (takes precedence)
    if round >= max_rounds - 1:
        return (True, "hard_round_cap")
    # Convergence — all 3 conditions must be met
    if synthesis_score >= 8 and high_severity_count == 0:
        return (True, "converged")
    return (False, "")
```

The hard round cap is checked first because reaching the cap is not "early" — it's the maximum. The convergence condition requires ALL three: `synthesis_score >= 8` AND `high_severity_count == 0`. Missing ANY one condition means no stop.

Wire `_should_stop_early()` into the adversarial loop in `run_mode4_adversarial()`: after each adversarial challenge + score extraction, call `_should_stop_early()`. If `(True, reason)`: emit `arena.early_stop_triggered` with `reason` and `round=r`, set `stopped_early=(reason == "converged")`, `stop_reason=reason`, break the loop. If `(False, "")`: proceed to re-synthesis for the next round.

Note: `stopped_early=True` only when `reason="converged"` (genuine early stop). When `reason="hard_round_cap"`, `stopped_early=False` (all rounds exhausted). When `reason="user_stopped"`, `stopped_early=True`.

Add tests to `test_mode4.py` with `EarlyStoppingTests(unittest.TestCase)` for the unit tests (1-5, pure function) and add integration tests to `Mode4AdversarialTests` for tests 6-8.
