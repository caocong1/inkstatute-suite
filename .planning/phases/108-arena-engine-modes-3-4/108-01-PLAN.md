# Plan 01: Structured Review Output + Cross-Family Pairing Primitives

## Objective

Create the two foundational primitives that Modes 3 and 4 depend on: (1) `review.py` with `ReviewFinding`, `ConfidenceLevel`, and `SeverityLevel` — the structured review output format with categorical confidence (Certain/Likely/Possible, NOT numeric percentages) and confirmed/disproved marking; (2) `families.py` with `get_backend_family()`, `DEFAULT_FAMILY_MAP`, and `_pair_cross_family()` — the cross-family review enforcement (SAFE-06) that ensures `backend_family(A) != backend_family(B)` for review pairs, with explicit degradation (warning + flag, never silent) when only same-family agents are available.

Define `CrossFamilyPairingResult` as `@dataclass(frozen=True, slots=True)` with fields: `pairs: dict[str, str]`, `degraded: bool`, `reason: str`, `metadata: dict[str, Any] = field(default_factory=dict)`.

Implement `_pair_cross_family(slots: list[str], families: dict[str, str]) -> CrossFamilyPairingResult`:
- If `len(slots) <= 1`: return `CrossFamilyPairingResult(pairs={}, degraded=True, reason="single_agent")`.
- Build cyclic pairing: for each `slots[i]`, try to pair with `slots[(i+1) % n]`, then `slots[(i+2) % n]`, etc., skipping self and same-family. Use a greedy assignment that ensures each slot reviews exactly one other slot and each slot is reviewed by exactly one other slot (when possible).
- If ALL slots are the same family (no cross-family pair possible for any slot): return `CrossFamilyPairingResult(pairs={}, degraded=True, reason="same_family_only")`.
- If some slots can be cross-paired but others cannot (partial degradation): pair what can be cross-paired, mark the unpaired slots in `metadata["unpaired_slots"]`, set `degraded=True`, `reason="partial_same_family"`.
- On success (all slots cross-paired): return `CrossFamilyPairingResult(pairs={...}, degraded=False, reason="")`.
