# Plan 04: Engine Dispatch + BackendAdapter Protocol + Mock ACP + Re-exports

## Objective

Wire Modes 3 and 4 into the `ArenaEngine` dispatch, add `backend_family()` to the `BackendAdapter` Protocol and `MockACPBackendAdapter`, update `__init__.py` re-exports, and add engine-level integration tests that verify the full dispatch path from `ArenaEngine.run()` through Mode 3 and Mode 4 execution. This plan completes the integration layer that makes Modes 3+4 accessible via the same `ArenaEngine` entry point as Modes 1+2.
