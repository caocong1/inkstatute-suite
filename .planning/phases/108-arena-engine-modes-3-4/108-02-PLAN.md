# Plan 02: Mode 3 — Arena Review (Self-score + Cross-review + Independent Synthesis)

## Objective

Implement `mode3.py` with `run_mode3_arena_review()` — the Mode 3 arena review that builds on Mode 2's self-score iteration, then adds multi-agent cross-review (each agent's best output reviewed by a different-family agent, enforced by `_pair_cross_family()` from Plan 01), and finally an independent agent session (fresh context) that takes the highest-scoring result plus all review findings to produce the final synthesized version. The orchestrator never produces content — synthesis is done by a separate `synthesis_adapter` BackendAdapter instance.
