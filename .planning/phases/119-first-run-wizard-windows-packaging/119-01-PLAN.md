# Plan 119-01: First-run wizard

## Goal

Implement the three-step first-run wizard: practice area selection → API key input → model confirmation. After completion, the app starts directly to the chat UI with zero terminal/config.

## Tasks

### Task 1: Wizard state and models

Create `lib/wizard/wizard_models.dart`:
- `WizardStep` — Enum: practiceArea, apiKey, modelConfirmation, complete
- `WizardState` — Current step, selected practice area, API key (transient), model config
- `PracticeAreaOption` — Card data (name, description, icon, preset name)
- Five practice areas: 商事法, 劳动法, 家事法, 诉讼法, 通用法律

### Task 2: Wizard widgets

Create `lib/wizard/first_run_wizard.dart`:
- `FirstRunWizard` widget — Multi-step wizard with navigation
- Step 1: Practice area cards (selectable, single-select)
- Step 2: API key input (password field, stored transiently, saved to OS credential store on completion)
- Step 3: Model confirmation (shows default DeepSeek model, allows confirmation)
- Navigation: Next/Back buttons, step indicator
- On completion: saves settings and navigates to chat UI

### Task 3: Wizard settings persistence

Create `lib/wizard/wizard_settings.dart`:
- `WizardSettings` class:
  - `bool hasCompletedWizard` — Whether the wizard has been completed
  - `String selectedPracticeArea` — Default practice area
  - `String modelConfig` — Model configuration (default: deepseek-v4)
  - `Future<void> save()` — Persists settings to local storage
  - `Future<WizardSettings?> load()` — Loads saved settings
  - Uses shared_preferences or local file for persistence
