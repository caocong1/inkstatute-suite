# Plan 119-02: Credential security + owner mode

## Goal

Implement credential security: API key stored in OS credential store, injected via environment at engine startup, zero plaintext keys in logs/telemetry. Add owner mode for key rotation.

## Tasks

### Task 1: Credential store

Create `lib/security/credential_store.dart`:
- `CredentialStore` class:
  - `Future<void> saveApiKey(String key)` — Stores API key in OS credential store
  - `Future<String?> loadApiKey()` — Retrieves API key from OS credential store
  - `Future<void> deleteApiKey()` — Removes API key
  - Uses platform channel for Windows Credential Manager access
  - Key is never written to files, logs, or telemetry

### Task 2: Engine environment injection

Create `lib/security/engine_env.dart`:
- `EngineEnv` class:
  - `Map<String, String> buildEnv({required String apiKey})` — Builds environment variables for engine process
  - API key injected as `DEEPSEEK_API_KEY` environment variable
  - No other sensitive data in environment
  - `void zeroPlaintextAssert(String output)` — Asserts no plaintext API key in output (for logs/telemetry)

### Task 3: Owner mode

Create `lib/security/owner_mode.dart`:
- `OwnerMode` class:
  - `bool isActive` — Whether owner mode is currently active
  - `void activate()` — Activates owner mode (Ctrl+Shift+D on settings page)
  - `void deactivate()` — Deactivates owner mode
  - When active: shows key rotation UI, model/provider config, advanced settings
  - When inactive: hidden from normal users

### Task 4: Zero-plaintext grep assertion test

Create `test/security/zero_plaintext_assert_test.dart`:
- Scans all source files, test files, and config files for potential API key patterns
- Asserts no hardcoded keys, no keys in comments, no keys in test fixtures
- Pattern: `sk-[a-zA-Z0-9]{20,}` (DeepSeek API key format)
