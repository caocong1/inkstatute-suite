# Plan 119-04: Three-layer update orchestrator + phase summary

## Goal

Implement the three-layer update orchestrator (app/engine/content), with engine updates disabled by default, and produce the phase summary/transition.

## Tasks

### Task 1: Update orchestrator

Create `lib/update/update_orchestrator.dart`:
- `UpdateLayer` — Enum: app, engine, content
- `UpdateOrchestrator` class:
  - `Future<UpdateStatus> checkUpdates()` — Checks all layers for updates
  - `Future<UpdateResult> updateApp()` — App layer self-update (installer)
  - `Future<UpdateResult> updateEngine()` — Engine layer update (DISABLED by default, only with app version)
  - `Future<UpdateResult> updateContent()` — Content pack auto-update (Phase 115, only auto layer)
  - `bool isEngineAutoUpdateEnabled` — Always false (engine never auto-updates)
  - Manifest check, signature verification, rollback path

### Task 2: Update status models

Create `lib/update/update_models.dart`:
- `UpdateStatus` — Per-layer update availability
- `UpdateResult` — Success/failure of an update operation
- `ManifestInfo` — Parsed manifest (version, sha256, download URL)

### Task 3: Phase summary + transition

Create `119-SUMMARY.md` and `119-TRANSITION.md`:
- Summary: plans executed, requirements closed, test count, V4 gate status
- Transition: carry-forward for Phase 120 (convergence & lawyer trial)
- Update ROADMAP.md and STATE.md
