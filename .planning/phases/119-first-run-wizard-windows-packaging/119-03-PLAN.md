# Plan 119-03: Windows packaging

## Goal

Create the single-exe Windows installer that bundles Flutter build + engine zip + portable Python + initial content pack + presets, installs to %LOCALAPPDATA%\InkStatute, and creates start menu/desktop shortcuts.

## Tasks

### Task 1: Build configuration

Create `scripts/build_windows_installer.sh`:
- Runs `flutter build windows --release`
- Bundles engine zip (from engines/)
- Bundles portable Python + lxml
- Bundles track-changes script (from assets/scripts/)
- Bundles initial content pack (from presets/)
- Bundles engine manifest
- Creates installer package

### Task 2: Inno Setup installer script

Create `scripts/inkstatute_installer.iss`:
- Inno Setup script for Windows installer
- Install directory: %LOCALAPPDATA%\InkStatute
- Start menu shortcut: "墨律 InkStatute"
- Desktop shortcut (optional)
- Uninstaller: clean removal with runtime data retention prompt
- File associations: .docx (optional)
- Registry entries for uninstall information

### Task 3: App startup configuration

Create `lib/app/app_startup.dart`:
- `AppStartup` class:
  - `Future<bool> shouldShowWizard()` — Checks if first-run wizard is needed
  - `Future<void> initializeEngine()` — Starts DSH engine with credential injection
  - `Future<void> loadContentPack()` — Loads initial content pack
  - `Future<void> checkUpdates()` — Checks for app/engine/content updates on startup
  - Coordinates wizard → engine start → chat UI flow

## Verification

- Build script runs without errors
- Inno Setup script is valid
- All tests pass
- V4 gates pass
