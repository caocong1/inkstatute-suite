# Plan 90-02: ACP Output Filter — Backend Noise Blocking, ACP-Specific Boundary Rules, Default-Deny Notification Allowlist

## Goal

Create `output_filter.py` — the ACP-specific output boundary pre-filter that blocks backend noise (meta / gateway / system / update / command / help / `available_commands_update` / terminal content) before it reaches the unified event stream. This module operates as the first enforcement point in the bridge's output boundary pipeline; the existing `DefaultAssistantOutputBoundary` remains the second enforcement point. Create comprehensive backend noise fixtures and tests proving that every noise category is blocked or rewritten. This plan touches only files in the `acp-event-bridge` package and does not modify `bridge.py` (integration into the bridge happens in Plan 90-04).

## Reversibility Gate

**One-way-door:** The set of blocked ACP notification types and content patterns defines what users can never see. Once blocked, adding new allowed types requires explicit allowlist changes — this is intentional (default-deny). Strategy: implement a default-deny allowlist for ACP notification types — only explicitly allowed types pass through; everything else is blocked. The blocked content patterns are additive to the existing `DefaultAssistantOutputBoundary` rules (they do not modify the existing rules). Task 90-02-01 is a checkpoint to verify the existing boundary rules are not modified and the new rules are purely additive.

<action>
Create `packages/acp-event-bridge/src/inkstatute_acp_event_bridge/output_filter.py`. This module provides ACP-specific output boundary pre-filtering that runs before the existing `DefaultAssistantOutputBoundary`.

**Allowed ACP notification types (allowlist):** Define a frozenset `ALLOWED_ACP_NOTIFICATION_TYPES` containing the ACP update types and notification methods that are legitimate user-facing content: `"agent_message_chunk"`, `"agent_message"`, `"agent_thought_chunk"`, `"tool_call_update"`, `"plan"`, `"plan_update"`, `"elicitation"`, `"elicitation/create"`, `"session/request_permission"`, `"status"`, `"artifact"`, `"citation"`. Any ACP notification type NOT in this allowlist is blocked by default (default-deny).

**ACP-specific blocked content patterns:** Define a tuple `ACP_BLOCK_PATTERNS` of `(rule_id, compiled_regex)` pairs for ACP backend noise content that must never reach users:
- `("acp_meta", re.compile(r"\bmeta[:\s]"))` — ACP meta diagnostic content
- `("acp_gateway", re.compile(r"\bgateway[:\s]"))` — ACP gateway status noise
- `("acp_system", re.compile(r"\bsystem[:\s]"))` — ACP system diagnostic content
- `("acp_update_notice", re.compile(r"\bupdate[:\s]"))` — ACP update notices (not `tool_call_update` which is a type, not content)
- `("acp_command", re.compile(r"\bcommand[:\s]"))` — ACP command echoes
- `("acp_help", re.compile(r"\bhelp[:\s]"))` — ACP help system content
- `("acp_available_commands", re.compile(r"\bavailable_commands_update\b"))` — ACP available commands update
- `("acp_terminal", re.compile(r"\bterminal[:\s]"))` — ACP terminal content

**ACP-specific rewrite patterns:** Define a tuple `ACP_REWRITE_PATTERNS` for content that should be rewritten to InkStatute business notices rather than blocked:
- `("acp_debug", re.compile(r"\bacp[:\s]"))` — ACP debug content → rewrite to InkStatute notice
- `("acp_agent_protocol", re.compile(r"\bagent[- ]?client[- ]?protocol[:\s]"))` — ACP protocol debug → rewrite

**Filter function:** Define `filter_acp_notification(acp_notification: dict) -> FilterDecision` that:
1. Extracts the notification type (method for top-level notifications, `params.update.type` for `session/update`).
2. If the type is NOT in `ALLOWED_ACP_NOTIFICATION_TYPES`, returns `FilterDecision(action="block", reason="unknown_acp_type", visible_text=None, audit_metadata={"rule_id": "unknown_acp_type", "acp_type": type})`.
3. Extracts text content from the notification (from `params.update.content`, `params.intro`, `params.description`, etc.).
4. Checks text against `ACP_BLOCK_PATTERNS` — if matched, returns `FilterDecision(action="block", ...)`.
5. Checks text against `ACP_REWRITE_PATTERNS` — if matched, returns `FilterDecision(action="rewrite", visible_text=_ACP_REWRITE_NOTICE, ...)`.
6. If no patterns match, returns `FilterDecision(action="allow", visible_text=text, ...)`.

**Combined filter function:** Define `apply_acp_output_boundary(acp_notification: dict, event: RunEvent | None = None) -> RunEvent | None` that:
1. Calls `filter_acp_notification(acp_notification)` for ACP-type-level filtering.
2. If blocked at type level, returns `None`.
3. If the event is available, calls `DefaultAssistantOutputBoundary().apply(visibility_target="user", text=extracted_text, event_type=event.event_type)` for content-level filtering (the second enforcement layer).
4. If the boundary decision is `BLOCK`, returns `None`.
5. If the boundary decision is `REWRITE`, returns a new `RunEvent` with the rewritten text in the payload (using `dataclasses.replace`).
6. If `ALLOW`, returns the event unchanged.
7. If no event is provided (pre-mapping filtering), returns `None` for block, a dict with rewritten text for rewrite, or the notification for allow.

**Dataclass:** Define `@dataclass(frozen=True, slots=True) class FilterDecision` with fields: `action: str` (one of `"allow"`, `"rewrite"`, `"block"`), `reason: str`, `visible_text: str | None`, `audit_metadata: dict`.

**Constants:** Define `_ACP_REWRITE_NOTICE = "InkStatute is processing your request. Please wait for the next update."` (same as existing `_OWNED_SERVICE_NOTICE`).

Import `re`, `hashlib`, `dataclasses` from stdlib. Import `RunEvent` from `platform_runtime.protocols`, `DefaultAssistantOutputBoundary` from `platform_runtime.output_boundary`. Define `__all__ = ["filter_acp_notification", "apply_acp_output_boundary", "FilterDecision", "ALLOWED_ACP_NOTIFICATION_TYPES"]`.
</action>
