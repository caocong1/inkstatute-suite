# Plan 90-01: ACP Event Bridge Tracer — Package Scaffold, Reverse Mapping Core, Bridge with Forward Mapping Integration, Gate Registration

## Goal

Create the `packages/acp-event-bridge` package with the reverse mapping core (unified → ACP user responses) and an `EventBridge` class that integrates the existing forward mapping from `acp-client` with the new reverse mapping. This is the tracer slice — a complete end-to-end path from ACP notification → unified event → user response → ACP JSON-RPC response — verified before any expansion work. Register the `acp-event-bridge` gate so the package is covered by CI from the start.

## Reversibility Gate

**One-way-door:** Creating a new package `packages/acp-event-bridge/` and registering its gate in `scripts/run_v2_gates.py`. Once the gate is registered, the `gate-coverage` meta-test will fail if the gate is removed or the package's `src/` directory is not covered. Strategy: add the gate additively — do not modify any existing gate entry. The reverse mapping functions construct JSON-RPC responses using original request IDs (per RESEARCH §1 — ACP v1 does NOT use separate methods for user responses; responses are JSON-RPC responses to the original request IDs). This design is locked to ACP v1 semantics. Task 90-01-01 is a checkpoint to verify the package scaffolds, compiles, and the gate registration is additive before building on top of it.

<action>
Create `packages/acp-event-bridge/src/inkstatute_acp_event_bridge/reverse_mapping.py`. This module maps unified events back to ACP JSON-RPC responses. Per RESEARCH §1, ACP v1 does NOT use separate methods for user responses — responses are JSON-RPC responses to the original request IDs.

Define three functions:

1. `map_elicitation_response_to_acp(original_request_id: str, action: str, content: dict | None = None) -> dict` — constructs a JSON-RPC response to an `elicitation/create` request. Returns `{"jsonrpc": "2.0", "id": original_request_id, "result": {"action": action, "content": content or {}}}`. The `action` must be one of `"accept"`, `"decline"`, `"cancel"`. If `action` is not one of these, raise `ValueError(f"invalid elicitation action: {action}")`.

2. `map_permission_decision_to_acp(original_request_id: str, outcome: str, option_id: str = "") -> dict` — constructs a JSON-RPC response to a `session/request_permission` request. Returns `{"jsonrpc": "2.0", "id": original_request_id, "result": {"outcome": {"outcome": outcome, "optionId": option_id}}}`. The `outcome` must be one of `"selected"`, `"cancelled"`. If `outcome` is not one of these, raise `ValueError(f"invalid permission outcome: {outcome}")`. CRITICAL: this function must NEVER produce a response that auto-approves a dangerous permission — it only records the user's explicit decision. The `option_id` is the ID of the option the user selected (e.g., `"allow"`, `"deny"`), but the bridge and adapter enforce that `terminal`/`execute_code` kinds cannot be approved (enforced in Plan 90-04).

3. `map_cancel_to_acp(session_id: str, request_id: int | str) -> dict` — constructs a `session/cancel` JSON-RPC request. Returns `{"jsonrpc": "2.0", "id": request_id, "method": "session/cancel", "params": {"sessionId": session_id}}`.

Also define a dispatcher function `map_unified_to_acp(event_type: str, original_request_id: str, **kwargs) -> dict` that routes to the correct function based on `event_type`:
- `RunEventType.ELICITATION_REQUESTED.value` → `map_elicitation_response_to_acp`
- `RunEventType.PERMISSION_REQUESTED.value` → `map_permission_decision_to_acp`
- `RunEventType.RUN_STATE_CHANGED.value` → `map_cancel_to_acp` (if `session_id` and `request_id` in kwargs)
- Unknown event_type → raise `ValueError(f"no reverse mapping for event_type: {event_type}")`

Import `RunEventType` from `platform_contract.enums`. All functions are pure (no side effects, no I/O). Define `__all__` listing all four functions.
</action>

<action>
Create `packages/acp-event-bridge/src/inkstatute_acp_event_bridge/bridge.py`. Define a class `EventBridge` that sits between the ACP client and the platform runtime, transforming events in both directions.

**Request ID tracking:** The bridge must maintain a mapping from ACP request IDs (for `elicitation/create` and `session/request_permission`) to unified event metadata, so that when a user response arrives, the bridge can construct the correct JSON-RPC response with the original request ID. Define an internal dict `_request_id_map: dict[str, dict]` that maps request IDs to `{"event_type": str, "interrupt_id": str, "permission_id": str}`.

**Forward path (ACP → unified):** Define `async def forward(self, acp_notification: dict, run_id: str, seq: int, occurred_at: str) -> RunEvent | None` that:
1. Calls `map_acp_update_to_run_event(acp_notification, run_id, seq, occurred_at)` from `inkstatute_acp_client.event_mapping`.
2. If the notification is `elicitation/create` or `session/request_permission`, extracts the request ID from the notification `id` field and stores it in `_request_id_map` with the event type and relevant metadata (interrupt_id or permission_id).
3. Returns the mapped `RunEvent` or `None` if unrecognized.

**Reverse path (unified → ACP):** Define `def reverse(self, event_type: str, original_request_id: str, **kwargs) -> dict` that:
1. Looks up `original_request_id` in `_request_id_map` to verify it corresponds to a known forward event.
2. Calls `map_unified_to_acp(event_type, original_request_id, **kwargs)` from `.reverse_mapping`.
3. Returns the JSON-RPC response dict.
4. If `original_request_id` is not in `_request_id_map`, raises `KeyError(f"unknown request id: {original_request_id}")`.

**Output boundary integration (tracer-level):** Define `def apply_output_boundary(self, event: RunEvent) -> RunEvent | None` that:
1. Extracts text content from the event payload (e.g., `payload.get("delta")`, `payload.get("content")`).
2. Calls `DefaultAssistantOutputBoundary().apply(visibility_target="user", text=text, event_type=event.event_type)`.
3. If the decision is `BLOCK`, returns `None` (event is dropped).
4. If the decision is `REWRITE`, returns a new `RunEvent` with the rewritten text in the payload.
5. If the decision is `ALLOW`, returns the event unchanged.
This is the tracer-level boundary — Plan 90-02 adds ACP-specific pre-filtering rules.

**Constructor:** `def __init__(self) -> None` — initializes `_request_id_map = {}` and `_boundary = DefaultAssistantOutputBoundary()`.

Import `RunEvent` from `platform_runtime.protocols`, `RunEventType` from `platform_contract.enums`, `map_acp_update_to_run_event` from `inkstatute_acp_client.event_mapping`, `map_unified_to_acp` from `.reverse_mapping`, `DefaultAssistantOutputBoundary` from `platform_runtime.output_boundary`.

Define `__all__ = ["EventBridge"]`.
</action>
