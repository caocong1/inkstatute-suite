Modify `packages/acp-client/src/inkstatute_acp_client/adapter.py`:
- Add `get_active_pids(self) -> set[int]` method to `ACPBackendAdapter`:
  ```python
  def get_active_pids(self) -> set[int]:
      """Return PIDs of all active subprocess sessions."""
      pids: set[int] = set()
      for client in self._sessions.values():
          transport = getattr(client, "_transport", None)
          if transport is not None:
              pid = getattr(transport, "pid", None)
              if pid is not None:
                  pids.add(pid)
      return pids
  ```
  This accesses the `ACPClient._transport` attribute (which holds the `StdioACPTransport` instance) and reads its `pid` property.
