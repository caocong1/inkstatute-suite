# Plan 116-03: Local session store (drift/SQLite)

## Goal

Implement the local session database using drift (SQLite ORM) for persisting sessions, messages, citations, and approval records. Provide a repository layer for CRUD operations, grouping by practice area, deletion, and export.

## Tasks

### Task 1: Add drift dependency + database definition

Add to `pubspec.yaml`:
```yaml
drift: ^2.20.0
sqlite3_flutter_libs: ^0.5.0
path_provider: ^2.1.0
path: ^1.9.0
```

Create `lib/chat/session_database.dart`:
- Drift database definition with tables:
  - `Sessions` — id (text PK), practiceArea (text), title (text), createdAt (dateTime)
  - `Messages` — id (text PK), sessionId (text FK), role (text: user/assistant/system), text (text), createdAt (dateTime), sortOrder (int)
  - `Citations` — id (text PK), messageId (text FK), source (text), citationType (text: verified/retrieved/unverified), text (text)
  - `Approvals` — id (text PK), sessionId (text FK), toolCallId (text), toolName (text), status (text: pending/approved/rejected), createdAt (dateTime)
- `SessionDatabase` class extends `GeneratedDatabase`
- Uses `NativeDatabase` from `sqlite3_flutter_libs` for native SQLite
- Database file at `<contentDir>/inkstatute.db` (reuses ContentPaths pattern)

### Task 2: Session repository

Create `lib/chat/session_repository.dart`:
- `SessionRepository` class:
  - `Future<void> createSession(ChatSession session)` — Insert session + messages
  - `Future<ChatSession?> getSession(String id)` — Load session with all messages, citations, approvals
  - `Future<List<ChatSession>> listSessions({String? practiceArea})` — List sessions, optionally filtered by practice area
  - `Future<void> addMessage(String sessionId, ChatMessage message)` — Append message to session
  - `Future<void> updateApproval(String approvalId, ApprovalStatus status)` — Update approval status
  - `Future<void> deleteSession(String id)` — Delete session and all related records (cascade)
  - `Future<String> exportSession(String id)` — Export session as JSON string (for privacy/data export)
  - `Future<List<String>> listPracticeAreas()` — Distinct practice areas with sessions
