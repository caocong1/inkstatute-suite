# Plan 116-02: Chat UI widgets

## Goal

Build the Flutter widgets for the chat UI: message rendering, approval cards, clarification cards, citation badges, status bar, and the main chat view that ties them together.

## Tasks

### Task 1: ChatMessageWidget

Create `lib/chat/chat_message_widget.dart`:
- Renders `ChatMessage` subtypes:
  - `UserMessage` — right-aligned bubble with user text
  - `AssistantMessage` — left-aligned bubble with parsed text, citation badges, human review markers
  - `SystemErrorMessage` — centered error card with user-readable message and error icon
- Uses `TextParser.parse()` to extract and render citations/review markers inline
- Citation badges rendered as colored chips after the relevant text section

### Task 2: ApprovalCardWidget

Create `lib/chat/approval_card_widget.dart`:
- Renders `ApprovalMessage` as a card with:
  - Tool name display
  - "允许" (allow) and "拒绝" (reject) buttons
  - Status display (pending/approved/rejected)
  - No batch approval control (single card per request)
- Callbacks: `onAllow(toolCallId)`, `onReject(toolCallId)`
- Visual states: pending (yellow border), approved (green check), rejected (red X)

### Task 3: ClarificationCardWidget

Create `lib/chat/clarification_card_widget.dart`:
- Renders `ClarifyMessage` as a card with:
  - Clarify question text from `[CLARIFY: …]`
  - Text input field for user's supplementary information
  - "提交补充" (submit) button
- Callback: `onSubmit(clarifyText, userResponse)`
- After submission, the card shows the user's response and collapses

### Task 4: CitationBadgeWidget

Create `lib/chat/citation_badge_widget.dart`:
- Renders `Citation` as a colored badge/chip:
  - `verified` — green badge with check icon, tooltip "已验证"
  - `retrieved` — blue badge with search icon, tooltip "已检索"
  - `unverified` — orange badge with warning icon, tooltip "未验证"
- Human review marker rendered as a red badge with review icon, tooltip "需人审"

### Task 5: StatusBarWidget

Create `lib/chat/status_bar_widget.dart`:
- Displays current `MessageStatus`:
  - `idle` — no status text
  - `processing` — "处理中..." with spinner
  - `completed` — no persistent status
  - `cancelled` — "已取消" briefly
  - `error` — error indicator
- Practice area display (e.g. "商事法" / "诉讼法")
- Cancel button visible during `processing` state

### Task 6: ChatView

Create `lib/chat/chat_view.dart`:
- Main chat view widget (StatefulWidget):
  - Message list (ListView) rendering all ChatMessage subtypes via ChatMessageWidget
  - Approval cards interleaved in message list
  - Clarification cards interleaved in message list
  - Input field at bottom with send button
  - Input disabled when status is `processing` (single in-flight)
  - "处理中" indicator when processing
  - Cancel button during processing
  - Status bar at top
- Integrates with AcpClient.onUpdate stream for real-time message rendering
