# Plan 116-01: Chat models + output boundary + text parser

## Goal

Create the data models for chat messages, the output boundary filter that blocks non-assistant noise, and the text parser that extracts `[CLARIFY:]`, `[HUMAN_REVIEW:]`, and citation badges from assistant text.

## Tasks

### Task 1: Chat models

Create `lib/chat/chat_models.dart`:
- `ChatMessage` — sealed class hierarchy:
  - `UserMessage` — text, timestamp
  - `AssistantMessage` — text, timestamp, citations (List<Citation>), humanReviewMarkers (List<HumanReviewMarker>), clarifyRequests (List<ClarifyRequest>)
  - `ApprovalMessage` — toolCallId, toolName, status (pending/approved/rejected), timestamp
  - `ClarifyMessage` — clarifyText, userResponse (nullable), timestamp
  - `SystemErrorMessage` — errorType (enum: engineNotStarted, rateLimited, authFailed, timeout, unknown), userMessage, timestamp
- `Citation` — source, citationType (enum: verified, retrieved, unverified), text
- `HumanReviewMarker` — text (content of `[HUMAN_REVIEW: …]`)
- `ClarifyRequest` — text (content of `[CLARIFY: …]`)
- `ChatSession` — id, practiceArea, title, createdAt, messages (List<ChatMessage>)
- `MessageStatus` — enum: idle, processing, completed, cancelled, error

### Task 2: Output boundary

Create `lib/chat/output_boundary.dart`:
- `OutputBoundary` class:
  - `static bool shouldRender(SessionUpdate update)` — Returns true ONLY for `agent_message_chunk` with `content.type == 'text'`. All other update types (meta, system, tool activity) are filtered out.
  - `static SystemErrorMessage mapError(Exception error)` — Maps exceptions to user-readable error types:
    - `ProcessException` / connection refused → `engineNotStarted` → "引擎未启动，请检查安装"
    - HTTP 429 / rate limit → `rateLimited` → "请求过于频繁，请稍后重试"
    - HTTP 401 / auth error → `authFailed` → "鉴权失败，请检查 API 密钥"
    - `TimeoutException` → `timeout` → "请求超时，请重试"
    - Other → `unknown` → "发生未知错误"
  - Raw stack traces are never included in the user message — only logged locally.

### Task 3: Text parser

Create `lib/chat/text_parser.dart`:
- `TextParser` class:
  - `static ParsedAssistantText parse(String rawText)` — Extracts structured elements from assistant text:
    - `[CLARIFY: question text]` → ClarifyRequest
    - `[HUMAN_REVIEW: review note]` → HumanReviewMarker
    - Citation badges: `[CITE:verified:source]`, `[CITE:retrieved:source]`, `[CITE:unverified:source]`
  - `ParsedAssistantText` — cleanText (with markers removed), clarifyRequests, humanReviewMarkers, citations
  - Regex patterns for each marker type
  - Clean text preserves original formatting minus the marker tokens
