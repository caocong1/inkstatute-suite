# Plan 116-04: App shell + error mapping + integration + phase summary

## Goal

Wire the chat UI to the ACP client via a controller, implement error mapping for all four error scenarios, replace the tracer main.dart with a full app shell, and write the phase summary/transition.

## Tasks

### Task 1: ChatController

Create `lib/chat/chat_controller.dart`:
- `ChatController` class (ChangeNotifier):
  - Manages current session state: messages list, status, current session
  - Connects to AcpClient.onUpdate stream → filters via OutputBoundary → parses via TextParser → appends AssistantMessage
  - `Future<void> sendPrompt(String text)` — Creates UserMessage, sends via AcpClient.prompt(), sets status to processing, disables input
  - `Future<void> cancelInFlight()` — Calls AcpClient.cancel(), sets status to cancelled
  - `void handleApproval(String toolCallId, bool allow)` — Sends PermissionOutcome via AcpClient
  - `void handleClarifyResponse(String clarifyText, String userResponse)` — Sends userResponse as new prompt
  - Error handling: catches exceptions, maps via ErrorMapper, appends SystemErrorMessage
  - Persists all messages to SessionRepository
  - Single in-flight enforcement: rejects sendPrompt when status is processing

### Task 2: Error mapper

Create `lib/chat/error_mapper.dart`:
- `ErrorMapper` class:
  - `static SystemErrorMessage map(Exception error)` — Maps exceptions to SystemErrorMessage:
    - `ProcessException` → engineNotStarted → "引擎未启动，请检查安装"
    - Connection refused / socket error → engineNotStarted
    - HTTP 429 → rateLimited → "请求过于频繁，请稍后重试"
    - HTTP 401 → authFailed → "鉴权失败，请检查 API 密钥"
    - `TimeoutException` → timeout → "请求超时，请重试"
    - Other → unknown → "发生未知错误"
  - `static void logStackTrace(Exception error, StackTrace stack)` — Logs to local file only, never to UI

### Task 3: App shell (main.dart)

Replace `lib/main.dart` with full app shell:
- `InkStatuteApp` — MaterialApp with theme
- `HomeScreen` — Scaffold with:
  - Navigation drawer: session list grouped by practice area, settings link
  - Chat view (from Plan 116-02)
  - Settings access (content settings from Phase 115)
- Theme: 墨律三主题 (light/dark/sepia) — basic Material theme with legal-professional color palette
- Session list from SessionRepository

Create `116-SUMMARY.md` and `116-TRANSITION.md`:

- Transition: carry-forward notes for Phase 117 (guardrails) and Phase 118 (Word export)
