## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-111-05-01 | Tampering | Path traversal via reference_dir | mitigate | FSSandbox.validate_path rejects `..` components (fs_sandbox.py:160) — 5-layer validation (resolve + prefix-check + symlink rejection + extension allowlist + size cap). |
| T-111-05-02 | Tampering | Symlink escape via reference_dir | mitigate | FSSandbox.validate_path rejects symlinks at any path component (fs_sandbox.py:176). |
| T-111-05-03 | Tampering | Prompt injection via reference file content | mitigate | ReferenceSanitizer delimiter-wraps content + detects injection patterns (sanitizer.py) — sanitized content is clearly delimited as reference material, not agent instructions. |
| T-111-05-04 | Denial of Service | Large reference files | mitigate | FSSandboxConfig.max_file_size (default 1MB) caps individual file size; read_text_file raises FSSandboxError if exceeded. |
| T-111-05-SC | Tampering | npm/pip/cargo installs | accept | No package installs — FSSandbox and ReferenceSanitizer are existing tested modules from Phase 106. |
</threat_model>
