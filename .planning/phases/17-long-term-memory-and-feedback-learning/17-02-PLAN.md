<objective>
Convert normalized feedback into safe current-session context refs and human-reviewed memory/routing candidates.

Purpose: feedback should improve future context without silently changing legal skills, routing behavior, or reusable legal conclusions.
Output: a runtime `FeedbackLearningPolicy`, tests proving feedback-to-context behavior, repeated-negative candidate generation, and preserved feedback-service dedupe queues.
</objective>

- Do not make `services/feedback-service` import `platform_runtime`; dependency direction stays feedback events -> runtime policy input.
- Do not call skill optimizers, mutate routing rules, write legal skills, or approve candidates automatically.
- Feedback message text may be transient input but must not be persisted in memory/candidate/use/context records except as hashes, lengths, labels, action/category, and refs.
- Keep all policy behavior deterministic and stdlib-only.
</constraints>
