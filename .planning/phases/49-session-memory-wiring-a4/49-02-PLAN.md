# Plan 02: Adapter session_memory_support Declarations

## Objective

Update the three backend adapter manifests (codex, provider_model, hermes) to declare `session_memory_support=True` in their `AdapterCapabilitySet`. This signals that each adapter can consume `ContextBundle.memory_refs` from `RunRequest.metadata["context_bundle"]`. No adapter imports or calls `HindsightMemory` or any memory provider directly — they read the context bundle that the runtime injects. This satisfies SESSMEM-02.
