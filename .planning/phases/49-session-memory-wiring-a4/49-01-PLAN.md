# Plan 01: Runtime Memory Wiring

## Objective

Add `memory_orchestrator` as an optional keyword-only injected dependency on `DefaultRunRuntime`. When `session_memory_enabled=True`, the runtime delegates context assembly to `MemoryOrchestrator.recall_and_assemble()`, which queries a `MemoryStoreAdapter` scoped by `(tenant_id, workspace_id, user_id)` and injects recalled `memory_refs` into the `ContextBundle` before `backend.submit_run()`. When `session_memory_enabled=False` (default), the runtime behaves identically to v1.6 — no memory orchestration occurs. This satisfies SESSMEM-01.
