    - `RouterService.__init__` gains two optional params: `legal_risk_classifier: LegalRiskClassifierPort | None = None`, `model_classifier: ModelClassifierPort | None = None`. Stored as `self._legal_risk_classifier` and `self._model_classifier`.
    - `decide()` dispatches to `_decide_hybrid()` when `self._strategy == RouterStrategy.HYBRID`.
    - `_decide_hybrid(context)` implements:
      1. **Legal-risk pre-check**: If `self._legal_risk_classifier` is not None, call `classify(message)`. If `is_high_risk` is True → return `_build_decision(mode=matched, primary_skill="hermes", confidence=<computed>, metadata_extra={"router_strategy": "hybrid", "forced_to_hermes": True, "legal_risk_assessment": {...}, "cascade_stage": "legal_risk_override"})`. The confidence is the best computed from rule/skill layers, but routing is forced to Hermes.
      2. **Rule layer**: Call `classify_intent(message)`. If intent found and registry has matching skill → confidence=0.9, primary_skill=skill_id, matched_rule=f"rule:{intent}". If intent found but no registry match → confidence=0.6 (clarify zone). If no intent → proceed to Skill layer.
      3. **Skill layer**: Check `skill_id` in context → `get_skill(skill_id)` → confidence=1.0. Then search by message → single match confidence=0.85, multiple matches confidence=0.6 with supporting_skills.
      4. **Model layer**: If `self._model_classifier` is not None → call `classify(context)` → use `result.confidence` and `result.predicted_skill`. If None → confidence=0.0.
      5. **Threshold application** (only if not high-risk):
         - confidence ≥ 0.8 → mode=matched, primary_skill=matched skill (or model predicted skill)
         - 0.5 ≤ confidence < 0.8 → mode=simple_qa, primary_skill=None, metadata["clarification_needed"]=True
         - confidence < 0.5 → mode=zero_match, primary_skill=None, metadata["fallback_to_hermes"]=True
      6. All decisions include `metadata["router_strategy"]="hybrid"`, `metadata["router_service_version"]=ROUTER_SERVICE_VERSION`, `metadata["cascade_stage"]` indicating which layer produced the decision, and `metadata["legal_risk_assessment"]` if classifier was run.
