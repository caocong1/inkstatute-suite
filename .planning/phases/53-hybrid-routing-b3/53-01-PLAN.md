# Plan 01: Legal-Risk Classifier, ModelClassifierPort, and HYBRID Enum

## Objective

Add the foundational components for hybrid routing: the `RouterStrategy.HYBRID` enum value, a `LegalRiskClassifierPort` Protocol with a keyword-based default implementation, and a `ModelClassifierPort` Protocol for optional model-based confidence scoring. These components are the building blocks that Plan 02 will wire into the HYBRID strategy cascade.
