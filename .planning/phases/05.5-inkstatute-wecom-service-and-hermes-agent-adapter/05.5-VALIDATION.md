---

## Sampling Rate

- **After every task commit:** Run the relevant service/package unittest module for touched files.
- **After every plan wave:** Run the full suite command above plus any Hermes bootstrap tests added by the wave.
- **Before `$gsd-verify-work`:** Full suite must be green, with live WeCom evidence either `passed` or explicitly `blocked`.
- **Max feedback latency:** 90 seconds for automated feedback.
