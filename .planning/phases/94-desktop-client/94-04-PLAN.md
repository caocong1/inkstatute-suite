# Plan 94-04: Wave 3 — Native menus, E2E tests, gate registration, phase completion

## Goal

Implement the Tauri native menu bar (File/Edit/View/Window/Help), create E2E integration tests that verify the complete desktop workflow, verify all 6 Phase 94 success criteria, and mark UI-05 as complete. This is the final plan in Phase 94 — it brings the phase to completion by verifying that the desktop app and web app behave identically on the same task (success criterion #6), that all 6 success criteria are met, and that the gate system is green.

The native menu bar provides standard application menus with keyboard shortcuts, matching the UI-SPEC §Native Menus contract. E2E tests cover the full workflow: app launch → home → new conversation → send task → SSE streaming → clarification → artifact download → feedback, plus offline mode and FTS5 search. The phase completion task verifies all 6 success criteria from the ROADMAP and updates STATE.md, REQUIREMENTS.md, and ROADMAP.md.

## Reversibility Gate

**One-way-door: Native menu configuration.** The Tauri native menu bar is configured in Rust via `Menu::with_items()`. Once menus are registered, they are part of the app's permanent structure. Strategy: menus are additive — they provide keyboard shortcuts and navigation that complement the UI. Menu events are handled in the frontend via Tauri event listeners. Removing menus would not break the app (all actions are also available via UI buttons), but the keyboard shortcuts would be lost.

**One-way-door: Phase 94 completion and UI-05 marking.** Once UI-05 is marked complete in REQUIREMENTS.md, the requirement is considered delivered. This is a project-level commitment. Strategy: all 6 success criteria must be verified with concrete evidence (tests, grep assertions, build verification) before marking complete. The verification task (94-04-04) is the gate.

3. Create `apps/desktop/src/menuHandlers.ts`:
   - Register Tauri event listeners for all menu events:
     ```typescript
     import { listen } from "@tauri-apps/api/event";

     export function setupMenuHandlers(callbacks: MenuCallbacks): () => void {
       const unlisteners: Array<() => void> = [];

       async function setup() {
         unlisteners.push(await listen("menu-event", (event) => {
           const id = event.payload as string;
           switch (id) {
             case "about": callbacks.onAbout?.(); break;
             case "settings": callbacks.onSettings?.(); break;
             case "quit": callbacks.onQuit?.(); break;
             case "new-conversation": callbacks.onNewConversation?.(); break;
             case "open-file": callbacks.onOpenFile?.(); break;
             case "export-word": callbacks.onExportWord?.(); break;
             case "theme-a": callbacks.onTheme?.("a"); break;
             case "theme-b": callbacks.onTheme?.("b"); break;
             case "theme-c": callbacks.onTheme?.("c"); break;
             case "zoom-in": callbacks.onZoomIn?.(); break;
             case "zoom-out": callbacks.onZoomOut?.(); break;
             case "actual-size": callbacks.onZoomReset?.(); break;
             case "toggle-fullscreen": callbacks.onToggleFullscreen?.(); break;
             case "minimize": callbacks.onMinimize?.(); break;
             case "maximize": callbacks.onMaximize?.(); break;
             case "close-window": callbacks.onCloseWindow?.(); break;
             case "search-workspace": callbacks.onSearchWorkspace?.(); break;
             case "check-update": callbacks.onCheckUpdate?.(); break;
           }
         }));
       }
       setup();

       return () => unlisteners.forEach((u) => u());
     }
     ```
