# Plan 03: Mode 1 Standard Parallel

## Objective

Implement `run_mode1_parallel` — N agents process the same task in parallel via `asyncio.TaskGroup`, each agent's streamed events are tagged with `metadata.agent_slot`, results are persisted via `ArtifactStore`, and the user can select one result from N. This is the first user-facing arena mode and the simplest concurrency pattern.
