<action>
Create `SlotResult` frozen slotted dataclass in `slot_runner.py`: fields `slot_id: str`, `status: str` (values: "success", "timeout", "failed"), `content: str | None`, `events: list[RunEvent]` (default_factory=list), `metadata: dict[str, Any]` (default_factory=dict), `run_id: str | None = None`.

Create `run_agent_slot` async function with signature `async def run_agent_slot(slot_id: str, adapter: BackendAdapter, run_request: RunRequest, timeout: float = 30.0, max_retries: int = 2) -> SlotResult`. Implementation: wrap `adapter.submit_run()` + `adapter.stream_events()` collection in `asyncio.wait_for()` with `timeout`. On `asyncio.TimeoutError`: return `SlotResult(status="timeout", metadata={"error": "timeout", "partial": True})`. On `Exception`: return `SlotResult(status="failed", metadata={"error": str(exc), "partial": True})`. On success: collect all events from `stream_events()`, extract content from `MESSAGE_COMPLETED` event payload, return `SlotResult(status="success", content=content, events=events, run_id=run_id)`.

Create `_run_with_retry` internal async function: retry loop up to `max_retries + 1` total attempts. On failure (timeout or crash), if retries remain, `await asyncio.sleep(0.01 * (attempt + 1))` for backoff, then retry. On final attempt failure, return the last `SlotResult`. Only retry on "failed" and "timeout" statuses, not on "success".

Exception isolation pattern: `run_agent_slot` must NEVER raise — all exceptions are caught and converted to `SlotResult(status="failed")`. This ensures `asyncio.TaskGroup` does not cancel sibling tasks when one slot fails.

Create `test_slot_runner.py` with `SlotRunnerFailureTests(unittest.IsolatedAsyncioTestCase)` covering all 6 behaviors. For Test 5 (concurrent isolation), use `asyncio.TaskGroup` with two tasks calling `run_agent_slot` — assert both return `SlotResult` without `TaskGroup` raising `ExceptionGroup`.
