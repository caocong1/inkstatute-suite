# Plan 05: ArenaEngine Class — ArenaWorkflow Protocol + User Stop/Cancel

## Objective

Implement the `ArenaEngine` class that implements the `ArenaWorkflow` Protocol from `platform_runtime.protocols`. It wires Mode 1 and Mode 2 together with guardrail boundary enforcement, artifact persistence, provenance logging, and user stop/pause/cancel. Cancel triggers graceful shutdown of all background tasks and adapter sessions — zero orphaned processes. This is the top-level orchestration entry point.

Create `ArenaEngine` class in `engine.py` implementing the `ArenaWorkflow` Protocol.

Constructor: `__init__(self, *, artifact_store: ArtifactStore | None = None, provenance_logger: ProvenanceLogger | None = None, storage_dir: str | Path | None = None)`. If `artifact_store` is None and `storage_dir` is provided, create `ArtifactStore(storage_dir)`. If `provenance_logger` is None and `storage_dir` is provided, create `ProvenanceLogger(storage_dir)`.

Internal state:
- `_arenas: dict[str, ArenaStatus]` — tracks arena status
- `_configs: dict[str, ArenaWorkflowConfig]` — stores configs
- `_adapters: dict[str, dict[str, BackendAdapter]]` — per-arena adapter map
- `_stop_signals: dict[str, asyncio.Event]` — per-arena stop signal
- `_pause_flags: dict[str, asyncio.Event]` — per-arena pause/resume signal
- `_bg_tasks: dict[str, asyncio.Task]` — per-arena background task
- `_selections: dict[str, str]` — per-arena user slot selection
- `_results: dict[str, Mode1Result | Mode2Result]` — per-arena results

Method `async def start(self, config: ArenaWorkflowConfig) -> ArenaHandle`:
1. Store config in `_configs[config.arena_id]`.
2. Create `ArenaStatus(arena_id=config.arena_id, mode=config.mode, status="running", agent_slots=list(config.agent_slots))` in `_arenas`.
3. Create `asyncio.Event()` for stop signal and pause flag in `_stop_signals` and `_pause_flags`.
4. Return `ArenaHandle(arena_id=config.arena_id, status="running", created_at=datetime.now(UTC).isoformat())`.
5. Do NOT start background execution here — `start` is synchronous setup. Background execution starts when adapters are registered via a separate method `_register_adapters(arena_id, adapters)` or when the engine is explicitly run. For testing, the engine should support both sync `start` + explicit `run` and a combined flow. Use a method `async def _run_arena(self, arena_id: str, agent_adapters: dict[str, BackendAdapter], event_emitter: EventEmitter | None = None) -> None` that dispatches to `run_mode1_parallel` or `run_mode2_iteration` based on `config.mode`.

Method `async def cancel(self, arena_id: str) -> ArenaHandle`:
1. Set stop signal: `_stop_signals[arena_id].set()`.
2. Cancel background task if exists: `_bg_tasks[arena_id].cancel()` (wrap in try/except).
3. Call `adapter.cancel_run(run_id)` for each active run in each adapter (best-effort, catch exceptions).
4. Update `_arenas[arena_id]` status to `"cancelled"`.
5. Return `ArenaHandle(arena_id=arena_id, status="cancelled", created_at=...)`.

**Scope note on PID assertion (ENGINE-09):** Phase 107 uses mock adapters (no real subprocesses), so "zero orphaned processes" is validated by asserting all mock sessions are closed (`adapter._sessions` is empty). Real subprocess PID assertion is Phase 109 (Arena Service) where real ACP subprocesses are spawned. This is a deliberate scope split — the mock-based test validates the cleanup logic; the PID assertion validates the real subprocess cleanup.

Method `async def submit_user_action(self, arena_id: str, action: ArenaUserAction) -> ArenaHandle`:
- `action="select"`: store `action.selected_slot` in `_selections[arena_id]`.
- `action="stop"`: set `_stop_signals[arena_id]`; update status to `"stopped"`.
- `action="pause"`: set `_pause_flags[arena_id]` (pause = event set); update status to `"paused"`.
- `action="resume"`: clear `_pause_flags[arena_id]`; update status to `"running"`.
- Return `ArenaHandle(arena_id=arena_id, status=current_status, created_at=...)`.

Method `async def query_status(self, arena_id: str) -> ArenaStatus`:
- Return `_arenas[arena_id]` (raise `KeyError` if not found).
