# Plan 02: ArtifactStore + GuardrailBoundary + ProvenanceLogger

## Objective

Implement three boundary-layer modules that enforce safety and persistence invariants at the arena-engine edge: `ArtifactStore` for reference-first structured output persistence (ENGINE-07), `GuardrailBoundary` for post-hoc citation audit + de-AI polish + high-risk review enforcement on external ACP agents (SAFE-01..04), and `ProvenanceLogger` for per-claim agent → reviewer → source chain logging (SAFE-07). These modules are pure functions/classes with no LLM provider dependencies.
