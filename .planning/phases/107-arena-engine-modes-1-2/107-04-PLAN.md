# Plan 04: Mode 2 Self-score Iteration

## Objective

Implement `run_mode2_iteration` — each agent self-scores its output using a free-form 10-point framework, self-optimizes across rounds, and the user can manually stop iteration at any time. On stop, the best result per slot is preserved. The 10-point framework is free-form (agent self-scores, no fixed dimensions). No auto-stop on convergence — the user must explicitly stop.

Create `_extract_self_score(content: str) -> int` — uses regex `r'(?:自评分数|score|评分)\s*[:：]\s*(\d{1,2})\s*(?:/\s*10)?'` to extract score; returns `int(match.group(1))` if found, else `0`. Clamp to 0-10 range.

Create `run_mode2_iteration` async function with signature `async def run_mode2_iteration(config: ArenaWorkflowConfig, agent_adapters: dict[str, BackendAdapter], event_emitter: EventEmitter | None = None, artifact_store: ArtifactStore | None = None, stop_signal: asyncio.Event | None = None) -> Mode2Result`.

Implementation:
1. Initialize `best_results: dict[str, IterationState] = {}` and `rounds_completed = 0`.
2. For each round `r` from 0 to `config.max_rounds - 1`:
   a. Check `stop_signal.is_set()` at the TOP of each round — if set, break and emit `arena.early_stop_triggered`.
   b. Build fresh `RunRequest` per slot with `turn_id=f"{config.arena_id}-{slot_id}-round{r}"` and `content` including the previous round's content + self-score feedback for self-optimization (if round > 0, append `f"\n\n上一轮自评分数：{prev_score}/10，请优化你的回答。"` to the instruction).
   c. Use `asyncio.TaskGroup` to run all slots in parallel for this round.
   d. For each successful `SlotResult`: extract score via `_extract_self_score`, emit `arena.score_recorded` with `ArenaScoreRecordedPayload` fields (`arena_id`, `agent_slot`, `round=r`, `score=score`), persist via `artifact_store.store_round_output(arena_id=..., agent_slot=..., round=r, content=...)`.
   e. Update `best_results[slot_id]` if this round's score > previous best score (or if no previous best exists).
   f. Increment `rounds_completed`.
3. After loop (either completed or stopped): if stopped early, emit `arena.early_stop_triggered` with `reason="user_stopped"`, `round=rounds_completed`.
4. Emit `arena.workflow_completed` with `status="completed"` or `status="stopped_early"`.
5. Return `Mode2Result(arena_id=config.arena_id, best_results=best_results, rounds_completed=rounds_completed, stopped_early=stop_signal.is_set() if stop_signal else False, metadata={"mode": "mode2_iteration"})`.
