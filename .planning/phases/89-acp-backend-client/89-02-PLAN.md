# Plan 89-02: BackendAdapter 9-Method Implementation, Process Mode Enum, and Hermes Integration

## Goal

Implement the `ACPBackendAdapter` class that satisfies the `BackendAdapter` 9-method Protocol from `packages/platform-runtime/src/platform_runtime/protocols.py`, using the ACP client core from Plan 89-01. Add the `backend_process_mode` enum (`per_session`/`pooled`/`remote`) to the platform contract, implementing only `per_session`. Include Hermes version compatibility matrix and `bootstrap_check` logic. Prove the adapter works end-to-end with the echo agent fixture.

## Reversibility Gate

**One-way-door:** Adding `BackendProcessMode` enum to `platform_contract/agent_adapter.py`. Once the enum is in the contract, downstream code may reference its values. Strategy: additive-only — add the new enum class without modifying existing `AgentBackendMode` or `AdapterCapabilitySet`. The `pooled` and `remote` values exist but raise `NotImplementedError` when used. Task 02-01 is a checkpoint to confirm the contract change is additive and existing gates stay green.

<action>
Create `packages/acp-client/src/inkstatute_acp_client/adapter.py`. Define a dataclass `ACPBackendConfig` with fields: `backend_id: str`, `command: tuple[str, ...]`, `env: dict[str, str] | None = None`, `process_mode: BackendProcessMode = BackendProcessMode.PER_SESSION`, `timeout_seconds: float = 300.0`, `required_capabilities: RequiredCapabilities = field(default_factory=lambda: RequiredCapabilities(streaming=True))`, `hermes_home: str | None = None`, `compatibility_matrix: dict[str, str] = field(default_factory=dict)`. Define a class `ACPBackendAdapter` that implements all 9 `BackendAdapter` Protocol methods:

- `__init__(self, config: ACPBackendConfig, transport_factory: Callable[[ACPBackendConfig], ACPTransport] | None = None)` — stores config, creates `_runs: dict[str, Run]`, `_events: dict[str, list[RunEvent]]`, `_artifacts: dict[str, list[ArtifactRecord]]`, `_sessions: dict[str, ACPClient]` (run_id → client), `_next_run: int = 1`, `_next_event: int = 1`, `_clock` (default system clock). Calls `validate_process_mode(config.process_mode)` in __init__ to reject unimplemented modes early. The `transport_factory` defaults to creating `StdioACPTransport`.

- `backend_id(self) -> str` — returns `self.config.backend_id`.

- `capabilities(self) -> AdapterCapabilitySet` — returns the `AdapterCapabilitySet` from the last successful `initialize` negotiation, or a default set with `stream_event_support=True` if not yet negotiated.

- `async bootstrap_check(self) -> BootstrapStatus` — spawns a transport using `transport_factory`, calls `client.initialize()`, checks: (1) protocol version is 1, (2) agent name/version against `config.compatibility_matrix` (if the agent version is not in the matrix or is below the minimum, add an issue to `BootstrapStatus.issues`), (3) required capabilities are met. Returns `BootstrapStatus(ok=True/False, backend_id=self.config.backend_id, checked_at=clock.now(), issues=[...], metadata={"agent_name": ..., "agent_version": ..., "protocol_version": 1, "process_mode": self.config.process_mode.value})`. Closes the transport after check. If `CapabilityMismatchError` is raised, returns `BootstrapStatus(ok=False, issues=[str(error)])`.

- `async submit_run(self, req: RunRequest) -> RunHandle` — (1) creates a new `StdioACPTransport` and `ACPClient`, (2) calls `client.initialize()`, (3) calls `client.new_session()`, (4) calls `client.prompt(session_id, req.turn.content)`, (5) stores the client and session in `_sessions[run_id]`, (6) creates a `Run` with status `RUNNING` and stores in `_runs[run_id]`, (7) starts an async background task to collect events from `client.stream_updates()` into `_events[run_id]`, (8) returns `RunHandle(run_id=run_id, backend_run_id=session_id, status=AsyncTaskState.RUNNING)`. Sets `HERMES_HOME` env var if `config.hermes_home` is set.

- `async get_run(self, run_id: str) -> Run` — returns `self._runs[run_id]` or raises `KeyError`.

- `async stream_events(self, run_id: str) -> AsyncIterator[RunEvent]` — yields events from `self._events[run_id]` in seq order. If the background collection task is still running, polls for new events. When the run reaches a terminal state (SUCCEEDED/FAILED/CANCELLED), stops yielding. Raises `KeyError` for unknown run_id.

- `async cancel_run(self, run_id: str) -> Run` — calls `client.cancel(session_id)`, updates run status to `CANCELLED`, returns updated Run.

- `async submit_approval(self, run_id: str, approval: Approval) -> Run` — for ACP, approvals map to elicitation responses or permission responses. Sends the appropriate JSON-RPC response via the client. Updates run metadata with approval record. Returns updated Run. Must NOT auto-approve `terminal` or `execute_code` permissions — if `approval.decision` is `"approved"` and the approval metadata indicates a terminal/execute_code permission, reject it by setting the run to `WAITING_FOR_USER` with an issue.

- `async collect_artifacts(self, run_id: str) -> list[ArtifactRecord]` — returns `self._artifacts.get(run_id, [])`.

Define a helper `_new_run_id(self) -> str` that returns `f"acp-run-{self._next_run:03d}"` and increments. Define a helper `_make_run_event(self, run_id: str, event_type: str, payload: dict) -> RunEvent` that creates a RunEvent with auto-incrementing seq and clock timestamp. Define a Hermes compatibility matrix constant `HERMES_COMPATIBILITY_MATRIX: dict[str, str]` mapping minimum compatible Hermes versions to feature sets (e.g., `{"0.19.0": "streaming,session_update,elicitation_unstable"}`). Import all needed types from `platform_runtime`, `platform_contract`, and the local modules.
</action>

- `BackendProcessMode` enum in platform contract with `per_session` (implemented), `pooled`/`remote` (raise `NotImplementedError`)
- Hermes version compatibility matrix covers v0.17.0–0.19.0+
- `bootstrap_check` performs ACP initialize handshake and checks agent version against compatibility matrix
- `create_hermes_adapter` is the production entry point for `hermes acp` with `HERMES_HOME` env injection
- `submit_approval` rejects auto-approval of `terminal`/`execute_code` permissions
- All adapter integration tests pass with echo agent fixture (no network)
