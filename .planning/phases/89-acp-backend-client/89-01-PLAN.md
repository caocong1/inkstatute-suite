# Plan 89-01: ACP Client Core — Stdio Transport, Initialize Negotiation, Event Mapping, Echo Agent Fixture

## Goal

Create the `packages/acp-client` package with a Python ACP client that speaks ACP v1 over stdio, locks protocol v1 at `initialize`, negotiates capabilities, and maps ACP `session/update` variants to Phase 88's unified event vocabulary. Include an in-repo echo agent fixture so all tests run without network or external agents. This is the tracer slice — every subsequent plan in Phase 89 depends on this client core.

## Reversibility Gate

**One-way-door:** Adding `agent-client-protocol` as a dependency and locking protocol v1. Once the client is built around v1 semantics, upgrading to v2 requires re-negotiation logic changes. Strategy: pin `agent-client-protocol>=0.12,<0.13` in `pyproject.toml`, pass `protocolVersion: 1` at `initialize`, and isolate all SDK imports in `client.py` so the rest of the package never imports the SDK directly. Task 01-01 is a checkpoint to confirm the SDK is installable and the v1 initialize handshake works with the echo agent before building on top of it.

4. 5. If `params.update.type == "plan"` or `"plan_update"`: return RunEvent with `event_type=RunEventType.PLAN_UPDATED.value`, `payload={"plan": params.update.plan}`.
6. If `params.update.type == "elicitation"` or method is `elicitation/create`: return RunEvent with `event_type=RunEventType.ELICITATION_REQUESTED.value`, `payload={"interrupt_id": params.id, "intro": params.intro, "questions": params.questions, "resume_state_ref": params.resume_state_ref}`.
7. 8. If `params.update` contains artifact content blocks: return RunEvent with `event_type=RunEventType.ARTIFACT_CREATED_V3.value`, `payload={"artifact": params.update.artifact}`.
9. If `params.update` contains `_meta.citation`: return RunEvent with `event_type=RunEventType.CITATION_RECORDED.value`, `payload={"citations": params.update._meta.citation}`.
10. If `params.update.type == "status"` or method is `session/cancel`: return RunEvent with `event_type=RunEventType.RUN_STATE_CHANGED.value`, `payload={"status": params.update.status}`.
11. If the notification is a JSON-RPC error: return RunEvent with `event_type=RunEventType.ERROR.value`, `payload={"error": {"category": "runtime_error", "code": "acp_error", "message": error.message}}`.

Define a constant `ACP_UPDATE_TYPE_TO_EVENT_TYPE: dict[str, str]` mapping ACP type strings to RunEventType V3 values for the simple cases.
