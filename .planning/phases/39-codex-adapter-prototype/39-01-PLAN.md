# Plan 39-01 — Codex Adapter Package Structure, Manifest, and Capability Probe

## Goal

Create the `packages/backends/codex/` package mirroring the Hermes adapter structure, implement `CodexBackendAdapter` with all 9 `BackendAdapter` Protocol methods, build `AgentBackendManifest` with `production_ready: false` and `no_channel_io: true`, and implement the `CodexCapabilityProbe` returning a 14-field `AdapterCapabilitySet`.

This plan satisfies ADAPTER-01 Success Criteria 1 and 2:
- SC1: `agent_backend.mode=codex` routes to a Codex adapter returning a valid `AgentBackendManifest` with `production_ready: false` and `no_channel_io: true`.
- SC2: Capability probe passes, returning `AdapterCapabilitySet` consistent with the v1.5 baseline 14-field count.

## Context

- The `BackendAdapter` Protocol (9 methods) is frozen at `packages/platform-runtime/src/platform_runtime/protocols.py:222-239`.
- `AdapterCapabilitySet` (14 fields) is frozen at `packages/platform-contract/src/platform_contract/agent_adapter.py:18-33`.
- `AgentBackendMode.CODEX` already exists at `agent_adapter.py:14` — no enum change needed.
- The runtime selector at `services/wecom-service/src/wecom_service/agent_backend.py:23-56` already routes by mode and validates manifests — no selector changes needed.
- The Hermes adapter at `packages/backends/hermes/` is the structural template.
- `codex_backend_enabled` feature flag exists at `packages/platform-runtime/src/platform_runtime/feature_flags.py:24` (default False).
- The adapter must NOT import `platform_runtime` to preserve the thin-layer boundary.

1. Create `packages/backends/codex/src/inkstatute_backends_codex/probe.py`:
   ```python
   class CodexProbeTransport(Protocol):
       def run_version(self) -> str: ...

   @dataclass(frozen=True, slots=True)
   class CodexProbeIssue:
       code: str
       message: str

   @dataclass(frozen=True, slots=True)
   class CodexProbeReport:
       ok: bool
       capabilities: AdapterCapabilitySet
       codex_version: str | None = None
       issues: list[CodexProbeIssue] = field(default_factory=list)

   class CodexCapabilityProbe:
       def __init__(self, transport: CodexProbeTransport, config: CodexBackendConfig | None = None) -> None:
           self.transport = transport
           self.config = config or CodexBackendConfig()

       def probe(self) -> CodexProbeReport:
           try:
               version = self.transport.run_version()
           except Exception:
               return CodexProbeReport(
                   ok=False,
                   capabilities=codex_prototype_capabilities(),
                   issues=[CodexProbeIssue(code="codex_binary_unavailable", message="codex --version failed")],
               )
           return CodexProbeReport(
               ok=True,
               capabilities=codex_prototype_capabilities(),
               codex_version=version,
               issues=[],
           )
   ```
   Import `codex_prototype_capabilities` from `.manifest`.
