# Plan 39-02 — CodexExecRunner JSONL Parsing, submit_run → AgentResult Flow, and Error Normalization

## Goal

Implement the `SubprocessCodexExecRunner` that invokes `codex exec --json` via subprocess and parses JSONL output into `CodexExecResult`, wire it into `CodexBackendAdapter.submit_run` so the full `submit_run → AgentResult` flow works end-to-end with fixture-driven tests, and implement error normalization on first failure (first `turn.failed`/`error` event is terminal — no success flip).

This plan satisfies ADAPTER-01 Success Criterion 3:
- SC3: Fixture-driven `submit_run → AgentResult` flow through the Codex adapter via `codex exec --json` subprocess, mapping to the platform contract `AgentResult` schema with error normalization on first failure.

## Context

- `codex exec --json` emits JSONL events to stdout: `thread.started`, `turn.started`, `item.*`, `turn.completed`, `turn.failed`, `error`.
- The adapter must handle field-name drift: `item.type` vs `item.item_type`, `assistant_message` vs `agent_message`.
- Error normalization on first failure: the first `turn.failed` or `error` event produces a single `AgentResult` with `status=FAILED` and normalized `ErrorInfo`. No subsequent event can flip it back to `SUCCESS`.
- `AgentResult` schema at `packages/platform-contract/src/platform_contract/events.py:140-155`.
- `ErrorInfo` at `events.py:84-92`: `category`, `code`, `message`, `stage`, `retryable`, `details`, `metadata`.
- `ErrorCategory` at `enums.py:17-22`: `CONTRACT_ERROR`, `RUNTIME_ERROR`, `CHANNEL_ERROR`.
- All tests use fixtures (JSONL files + `FakeCodexExecRunner`) — no real `codex` binary required in CI.
- The `CodexExecRunner` Protocol and `CodexExecResult` dataclass were defined in Plan 39-01's `adapter.py`.

   - Import: `json`, `subprocess`, `dataclasses.field`, `typing.Any/Protocol`, `platform_contract.enums` (`AgentResultStatus`, `AsyncTaskState`, `ErrorCategory`, `ReplyType`), `platform_contract.events` (`AgentResult`, `ErrorInfo`, `JsonObject`), `platform_runtime` (`RunRequest`).
   - Import `CodexExecResult`, `CodexExecRunner` from `.adapter`.
   - Define `SubprocessTransport` Protocol: `def run(self, command: tuple[str, ...], input_text: str | None, timeout: float | None) -> tuple[int, str, str]` (returns `(returncode, stdout, stderr)`).
   - Define `_SystemSubprocessTransport` class implementing `SubprocessTransport` using `subprocess.run(command, input=input_text, capture_output=True, text=True, timeout=timeout)`.
   - Define `parse_codex_jsonl(lines: list[str], run_id: str, turn_id: str) -> CodexExecResult`:
     - Initialize: `content = None`, `status = None`, `error = None`, `thread_id = None`, `usage = {}`, `unparsed = []`, `failed = False`.
     - For each line: `line.strip()`; skip empty lines; `try: event = json.loads(line) except: unparsed.append(line); continue`.
     - `event_type = event.get("type")`.
     - If `event_type == "thread.started"`: `thread_id = event.get("thread_id")`.
     - If `event_type == "item.completed"` (or `"item.updated"`): extract `item = event.get("item", {})`; `item_type = item.get("type") or item.get("item_type")`; if `item_type in ("assistant_message", "agent_message")`: `content = item.get("text") or item.get("content")`.
     - If `event_type == "turn.completed"` and not `failed`: `status = AsyncTaskState.SUCCEEDED`.
     - If `event_type == "turn.failed"` and not `failed`: `failed = True`; `status = AsyncTaskState.FAILED`; `error = _normalize_error(event, stage="turn")`.
     - If `event_type == "error"` and not `failed`: `failed = True`; `status = AsyncTaskState.FAILED`; `error = _normalize_error(event, stage="stream")`.
     - After loop: if `status is None`: if `unparsed` and no `turn.completed`/`turn.failed` seen: `status = AsyncTaskState.FAILED`; `error = ErrorInfo(category=ErrorCategory.CONTRACT_ERROR, code="codex_empty_stream", stage="parse", message="no terminal event in codex jsonl stream")`. Else: `status = AsyncTaskState.SUCCEEDED` (default if content was found but no terminal event).
     - Build `AgentResult`: `result_id=f"codex-result-{run_id}"`, `turn_id=turn_id`, `status=AgentResultStatus.SUCCESS if status == AsyncTaskState.SUCCEEDED else AgentResultStatus.FAILED`, `reply_type=ReplyType.TEXT`, `content=content`, `error=error`, `metadata={"codex_thread_id": thread_id, "codex_usage": usage, "source": "codex_exec"}`.
     - Return `CodexExecResult(status=status, result=result, thread_id=thread_id, raw_payload_ref=None, metadata={"codex_thread_id": thread_id, "codex_usage": usage, "codex_unparsed_lines": unparsed[:5]})`.
   - Define `_normalize_error(event: dict, stage: str) -> ErrorInfo`:
     - Extract `message = event.get("message") or event.get("error", {}).get("message", "") if isinstance(event.get("error"), dict) else event.get("message", "")`.
     - Extract `error_obj = event.get("error", {})` if dict else `{}`.
     - `error_kind = error_obj.get("kind", "")` if dict.
     - Determine `code` and `retryable`:
       - If `"rate_limit" in error_kind or "rate limit" in str(message).lower()`: `code="codex_rate_limit"`, `retryable=True`.
       - If `"auth" in error_kind or "auth" in str(message).lower()`: `code="codex_auth_error"`, `retryable=False`.
       - If `stage == "turn"`: `code="codex_turn_failed"`, `retryable=None`.
       - If `stage == "stream"`: `code="codex_stream_error"`, `retryable=None`.
     - Sanitize `details`: apply `_sanitize_error_details(error_obj)` to strip `raw_payload`, `content`, `transcript`, `prompt`, `response_body`, `secret`, `token`, `profile_path` keys.
     - Return `ErrorInfo(category=ErrorCategory.RUNTIME_ERROR, code=code, message=_sanitize_message(message), stage=stage, retryable=retryable, details=sanitized_details)`.
   - Define `_sanitize_message(msg: str) -> str`: strip URLs (`http://`, `https://`), file paths (replace `/home/...` or `/.codex/...` patterns with `[redacted]`), tokens (replace `token=...` with `token=[redacted]`). Keep it simple: replace anything matching `https?://\S+` with `[url_redacted]`, and `token=\S+` with `token=[redacted]`.
   - Define `_sanitize_error_details(details: dict) -> JsonObject`: reuse the `_sanitize_metadata` pattern from adapter.py — skip keys in `{"raw_payload", "content", "transcript", "prompt", "response_body"}`, skip keys containing `"secret"`, `"token"`, `"profile_path"`.
   - Define `SubprocessCodexExecRunner` class:
     - `__init__(self, config: CodexBackendConfig | None = None, transport: SubprocessTransport | None = None, timeout: float = 120.0)`.
     - `async def invoke(self, req: RunRequest) -> CodexExecResult`:
       - `command = list(self.config.exec_command) + [req.turn.content or ""]`.
       - `returncode, stdout, stderr = self.transport.run(tuple(command), input_text=None, timeout=self.timeout)`.
       - `lines = stdout.splitlines()`.
       - `result = parse_codex_jsonl(lines, run_id="exec", turn_id=req.turn.turn_id)`.
       - If `returncode != 0` and `result.status != AsyncTaskState.FAILED`: override to `FAILED` with `ErrorInfo(category=ErrorCategory.RUNTIME_ERROR, code="codex_exec_nonzero_exit", stage="exec", message=f"codex exec exited with code {returncode}")`.
       - If `subprocess.TimeoutExpired` caught: return `FAILED` with `ErrorInfo(code="codex_exec_timeout", retryable=True, stage="exec")`.
       - Return result.
   - `__all__ = ["SubprocessCodexExecRunner", "SubprocessTransport", "parse_codex_jsonl"]`
