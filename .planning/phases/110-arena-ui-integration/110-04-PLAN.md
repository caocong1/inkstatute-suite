# Plan 04: End-to-End Integration Tests — All 4 Modes

## Objective

Create end-to-end integration tests that exercise the full arena flow (create → stream → score → review → synthesis → export) across all 4 modes (Mode 1-4) using fixture agents (`MockACPBackendAdapter`). These tests verify the complete pipeline from arena-service HTTP endpoints through the arena engine to SSE event emission, validating that the entire arena workflow produces the expected event sequence and structured outputs.
