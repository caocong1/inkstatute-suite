# Plan 01: ArenaEventReducer + Arena Stream Store

## Objective

Create the `ArenaEventReducer` that demultiplexes N interleaved agent streams by composing the existing single-stream `reduce()` per slot — no rewrite of reducer logic. Create the `arenaStream.ts` store that consumes the arena SSE endpoint, persists slot states to localStorage, and reconnects with Last-Event-ID without re-rendering already-received content.

## Context

- @packages/ui-core/src/event-reducer.ts — Existing `reduce(state: RenderState, event: RunEventEnvelope): RenderState` (line 224). Pure, idempotent, handles 13 unified event types. ArenaEventReducer MUST compose this, not rewrite it.
- @packages/ui-core/src/stores/eventStream.ts — Existing SSE consumer with Last-Event-ID reconnection (lines 75-83), exponential backoff (1s/2s/4s/8s/max 30s). Arena stream store mirrors this pattern but targets `/v1/arena/{arena_id}/stream` and maintains `Map<string, RenderState>` per slot.
- @packages/platform-sdk-ts/src/events.ts — `RunEventEnvelope` (line 290) with `metadata?: Record<string, unknown>` — `metadata.agent_slot` is the demultiplexing key. Arena lifecycle payload interfaces at lines 158-288.
- @services/arena-service/src/arena_service/sse.py — `encode_arena_sse_event` (line 30) preserves `metadata.agent_slot` in JSON. `parse_last_event_id` (line 73) extracts Last-Event-ID header.
- @services/arena-service/src/arena_service/event_buffer.py — `ArenaEventBuffer.replay(arena_id, last_seq)` (line 127) returns events with `seq > last_seq` — guarantees no duplication on reconnect.
- @packages/ui-core/tests/event-reducer.test.ts — Fixture-driven test pattern with `feedAll()` helper (line 15).
- @.planning/phases/110-arena-ui-integration/110-RESEARCH.md — §6 ArenaEventReducer design, §7 State persistence design
- @.planning/phases/110-arena-ui-integration/110-VALIDATION.md — Wave 1 core reducer + state

- Define `function extractAgentSlot(event: RunEventEnvelope): string | null`:
  - Check `event.metadata?.agent_slot` — if string, return it.
  - For arena lifecycle events, check `(event.payload as any)?.agent_slot` — if string, return it.
  - Return `null`.
- Define `function arenaEventReducer(slotStates: ArenaSlotStates, event: RunEventEnvelope): ArenaSlotStates`:
  1. Extract `agentSlot = extractAgentSlot(event)`.
  2. If `agentSlot` is not null: get existing slot state from map (or `initialState()`), apply `reduce(slotState, event)`, return new Map with updated slot.
  3. If `agentSlot` is null AND event type is in `ARENA_LIFECYCLE_EVENT_TYPES`: broadcast — apply `reduce(slotState, event)` to ALL existing slot states, return new Map with all updated.
  4. If `agentSlot` is null and not a lifecycle event: return map unchanged (drop untagged non-lifecycle events).
  5. Always return a NEW Map (immutable update for SolidJS reactivity).
- Define `function getSlotState(map: ArenaSlotStates, slot: string): RenderState` — returns `map.get(slot) ?? initialState()`.
- Define `function getAllSlotStates(map: ArenaSlotStates): Array<{ slot: string; state: RenderState }>` — sorted by slot name.
- Define `function arenaMetaReducer(meta: ArenaMetaState, event: RunEventEnvelope): ArenaMetaState` — processes arena lifecycle events to update `ArenaMetaState` (scores, reviews, synthesis, status, round). This is separate from slot demultiplexing and feeds ScoreCard/ReviewSummary/SynthesisViewer.
