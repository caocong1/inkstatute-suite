# Plan 02: ArenaWorkflowCreator + ParallelStreamPanel

## Objective

Create the `ArenaWorkflowCreator` component where lawyers select mode (1-4), choose N ACP backend agents, input task instructions, and select a reference file directory. Create the `ParallelStreamPanel` that renders N demultiplexed real-time agent streams in a grid, each slot independently rendering streaming replies, thoughts, and tool calls.
