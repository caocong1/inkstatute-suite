# Plan 02: Hindsight Bank Isolation Enforcement + Migration Test

## Objective

Add explicit tenant guard enforcement to `HindsightMemory` bank operations (retain/recall/reflect), verifying that the input's `tenant_id` matches the resolved tenant scope and preventing bank-id spoofing. Add a migration test that asserts no null `tenant_id` in any persisted record (contract logs, memory records, cache keys) when `multi_tenant_enabled=True`, and verifies that null `tenant_id` is allowed when disabled (v1.6 behavior).
