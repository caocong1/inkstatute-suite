# Plan 01: TenantScopeResolver, TenantGuard, and Tenant-Scoped Stores

## Objective

Create the core multi-tenant isolation primitives in `packages/platform-runtime/`: `TenantScopeResolver` (resolves `tenant_id` from request context via priority chain), `TenantGuard` (enforces `tenant_id` filter on every query when enabled), `TenantScopedContractLogStore` (partitions contract logs by tenant path), and `TenantNamespacedCache` (namespaces cache keys by tenant). All components are opt-in via `multi_tenant_enabled` and default to v1.6 behavior when disabled.

    - TenantScope is a frozen dataclass with fields: tenant_id: str | None = None, workspace_id: str | None = None
    - TenantScope.NONE is a class-level sentinel with both fields None
    - TenantScope.is_resolved property returns True when tenant_id is not None
    - TenantScope.partition_path property returns "tenants/{tenant_id}/workspaces/{workspace_id}/" when resolved, or "tenants/{tenant_id}/" when workspace_id is None, or "" when not resolved
    - ScopedQueryFilter is a frozen dataclass with fields: tenant_id: str | None = None, workspace_id: str | None = None, active: bool = False
    - ScopedQueryFilter.disabled() classmethod returns a filter with active=False
    - ScopedQueryFilter.is_active property returns the active field
    - TenantScopeError is a RuntimeError subclass raised when multi_tenant_enabled=True but tenant_id is unresolved
    - TenantScopeRequestContext is a frozen dataclass that carries optional resolution inputs: identity (Any with tenant_id attr), request (Any with tenant_id attr), scope (SessionScope), headers (Mapping[str, str])
    - TenantScopeResolver.__init__ accepts feature_flags: RuntimeFeatureFlags
    - TenantScopeResolver.resolve(context: TenantScopeRequestContext) -> TenantScope uses priority chain when multi_tenant_enabled=True:
      1. If context.identity is not None and has tenant_id attr that is truthy → use it
      2. Else if context.scope is not None and scope.tenant_id is truthy → use it
      3. Else if context.request is not None and request.tenant_id is truthy → use it
      4. Else if context.headers is not None and "X-Tenant-Id" in headers → use headers["X-Tenant-Id"]
      5. Else return TenantScope.NONE
      workspace_id is resolved from the same source that provided tenant_id (scope.workspace_id, request.workspace_id, or None)
    - When multi_tenant_enabled=False, resolve() always returns TenantScope.NONE regardless of context
    - TenantGuard.__init__ accepts feature_flags: RuntimeFeatureFlags
    - TenantGuard.enforce(scope: TenantScope) -> ScopedQueryFilter:
      - When multi_tenant_enabled=False → return ScopedQueryFilter.disabled()
      - When True and scope.is_resolved → return ScopedQueryFilter(tenant_id=scope.tenant_id, workspace_id=scope.workspace_id, active=True)
      - When True and not scope.is_resolved → raise TenantScopeError
    - All classes are exported from platform_runtime.__init__
  </behavior>

  <behavior>
    - TenantScopedContractLogStore wraps a delegate ContractLogStore (InMemoryContractLogStore or compatible)
    - __init__ accepts delegate: Any (the wrapped store), feature_flags: RuntimeFeatureFlags
    - append(event_key, event, *, scope=None, occurred_at=None, ingested_at=None):
      - When multi_tenant_enabled=False: delegate directly to wrapped store.append() with no tenant tagging (v1.6 behavior)
      - When True and scope is not None and scope.is_resolved: inject tenant_id and workspace_id into event metadata, derive partition_path, call delegate.append() with the enriched event
      - When True and scope is None or not resolved: raise TenantScopeError
      - Returns the ContractLogEntry from the delegate
    - entries(*, scope=None):
      - When disabled: return delegate.entries() (all entries, v1.6 behavior)
      - When enabled and scope is resolved: return only entries whose event contains tenant_id matching scope.tenant_id
      - When enabled and scope is None: raise TenantScopeError
    - entries_for_run(run_id, *, scope=None):
      - When disabled: return delegate.entries_for_run(run_id)
      - When enabled and scope is resolved: return delegate.entries_for_run(run_id) filtered by tenant_id
      - When enabled and scope is None: raise TenantScopeError
    - partition_path(scope) static method returns the tenant partition path string
    - The store is exported from platform_runtime.__init__
  </behavior>

  <behavior>
    - TenantNamespacedCache is a simple in-memory dict-based cache with tenant key namespacing
    - __init__ accepts feature_flags: RuntimeFeatureFlags
    - get(scope: TenantScope, key: str) -> Any | None:
      - When disabled: return self._cache.get(key) (no namespacing, v1.6 behavior)
      - When enabled and scope.is_resolved: return self._cache.get(self._namespaced_key(scope, key))
      - When enabled and not scope.is_resolved: raise TenantScopeError
    - set(scope: TenantScope, key: str, value: Any) -> None:
      - When disabled: self._cache[key] = value
      - When enabled and scope.is_resolved: self._cache[self._namespaced_key(scope, key)] = value
      - When enabled and not scope.is_resolved: raise TenantScopeError
    - delete(scope: TenantScope, key: str) -> bool:
      - When disabled: return self._cache.pop(key, None) is not None
      - When enabled and scope.is_resolved: return self._cache.pop(self._namespaced_key(scope, key), None) is not None
      - When enabled and not scope.is_resolved: raise TenantScopeError
    - _namespaced_key(scope, key) -> str: returns f"tenant:{scope.tenant_id}:{key}"
    - keys() -> tuple[str, ...]: returns all cache keys (for inspection/testing)
    - clear() -> None: clears all cache entries
    - Exported from platform_runtime.__init__
  </behavior>
