    - Import `preset_reader.dart` and `dart:io`.
    - `BudgetResult` class: holds `passed` (bool), `totalChars` (int), `budget` (int), `skillCount` (int), `details` (String — per-skill breakdown).
    - `BudgetGate` class with static method `check(String presetDir, {int budget = 8000})`:
      1. Parse `presetDir/agent.cordis.yml` via `PresetReader.parseComposition()`.
      2. For each dir in `customSkillDirs`, expand `~` to the home directory.
      3. Scan each expanded dir for `*/SKILL.md` files (one level of subdirectory).
      4. For each SKILL.md, parse frontmatter via `PresetReader.parseSkillFrontmatter()`.
      5. Compute rendered length per skill: `name.length + " — ".length + description.length + 1` (newline).
      6. Sum all rendered lengths into `totalChars`.
      7. Return `BudgetResult(passed: totalChars <= budget, totalChars: ..., budget: budget, skillCount: ..., details: ...)`.
    - Also provide `checkFromSkillDirs(List<String> skillDirs, {int budget = 8000})` for testing with arbitrary directories without a full preset.
