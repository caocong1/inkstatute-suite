## Shared Patterns

### Reference-First Safety
Every function that touches `turn.attachments` must read only `kind`, `mime_type`, and `uri` (a reference). No raw bytes, no base64, no fetching. Image detection uses `VisionRouter.has_image_attachments()`.

### Optional Dependency Injection
`DefaultRunRuntime` continues to work without `vision_resolver` or `vision_runner`. Service wiring injects them only when config is available. This keeps `platform-runtime` backend-neutral and `operator-config` out of the runtime package.

### Store-Wins-if-Exists
`build_vision_resolver` and `load_wecom_channel_config` follow the same pattern: if `store.path.exists()` use `store.load()`, else fallback (env or default). This is consistent with Phase 75 implementations.

### Dataclass Replacement
`dataclasses.replace` is the standard for immutable `RunRequest`/`AgentTurn` updates in `platform-runtime` and `platform-contract`. Use it for `vision_then_main` request mutation.

### Type-Only Cross-Package References
`platform-runtime` `vision_router.py` already uses `TYPE_CHECKING` for `VisionPolicyDoc`. Keep `platform-runtime` free of runtime `operator-config` imports. `operator-config` `vision_resolver.py` may import `platform-runtime` types because no reverse dependency exists.
