# Phase 78.1 Plan 03: service wiring for QQBot and WeCom

**Wire the vision resolver/runner into the real QQBot and WeCom service runtime compositions so image-bearing turns call `VisionRouter.decide()`.**

## Performance

- **Duration:** ~20 min
- **Tasks:** 3
- **Files modified:** 4
- **Files created:** 4

## Accomplishments

- Updated `services/qqbot-service/src/qqbot_service/wiring.py` to accept `vision_runner`, build `vision_resolver` via `build_vision_resolver`, and pass both to `DefaultRunRuntime`.
- Added `vision_resolver` and `vision_runner` fields to `QQBotWiredRuntime`.
- Updated `services/qqbot-service/src/qqbot_service/http_server.py` to fall back to `build_qqbot_wired_runtime` when `self.server.wired` is `None` and `self.server.backend` plus `self.server.config_store` are available.
- Created `services/qqbot-service/tests/test_wiring_vision.py` verifying `vision_resolver` is callable, `vision_runner` is passed through, and `DefaultRunRuntime` receives both.
- Created `services/wecom-service/src/wecom_service/wiring.py` with `WeComWiredRuntime` and `build_wecom_wired_runtime` that loads WeCom channel config, builds `WeComChannelAdapter`, and composes `DefaultRunRuntime` with `vision_resolver` and `vision_runner`.
- Exported `WeComWiredRuntime` and `build_wecom_wired_runtime` from `services/wecom-service/src/wecom_service/__init__.py`.
- Updated `services/wecom-service/pyproject.toml` to declare dependencies on `inkstatute-channels-wecom`, `inkstatute-operator-config`, and `inkstatute-platform-runtime`.
- Created `services/wecom-service/tests/test_wecom_wiring.py` verifying the wired runtime, `vision_runner` passthrough, `load_wecom_channel_config` usage, and package exports.
- Added `services/wecom-service/tests/__init__.py` so `unittest` discover works.
