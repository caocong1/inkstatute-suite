# Plan 03: Cost Tracking with Budget Ceilings + Integration Tests + V2 Gate Integration

## Objective

Add per-tenant/matter cost tracking with budget ceilings to the `ModelProviderGateway`. Token usage from provider responses is accumulated per tenant per matter, and when a budget ceiling is exceeded, further requests are rejected with a clear `model_gateway_budget_exceeded` error. Add comprehensive integration tests covering the full gateway flow and integrate the new package into the V2 gate script.
