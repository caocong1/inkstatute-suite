# Plan 02: Rate Limiting + Circuit Breakers + Fallback Chains + Tried-Provider Tracking

## Objective

Add per-tenant/provider rate limiting (RPM, TPM, concurrency), circuit breakers (CLOSED/OPEN/HALF_OPEN), and fallback chains with `tried_providers` tracking to the `ModelProviderGateway`. When a provider fails or its circuit breaker is open, the gateway falls back to the next provider in the configured fallback chain, tracking all tried providers in run metadata. Rate limiting uses pure-Python sliding-window deque + `asyncio.monotonic()` + `asyncio.Semaphore` — no external dependencies.

    - ModelProviderGateway.__init__ creates RateLimiter and CircuitBreakerRegistry from config
    - When config.enabled is True, submit_run:
      1. Build provider order: primary = solution.backend_id, then fallback_chain providers with closed/half-open circuit breakers
      2. For each provider in order:
         a. Check circuit breaker can_execute → if not, skip to next provider
         b. Check rate limiter RPM → if over, skip to next provider (record tried)
         c. Acquire concurrency semaphore
         d. Delegate submit_run to sub-adapter
         e. Check result status: if SUCCEEDED → record_success, release concurrency, return handle with tried_providers in metadata
         f. If FAILED → record_failure, release concurrency, add to tried_providers, continue to next provider
      3. If all providers exhausted → return a failed RunHandle with error "model_gateway_all_providers_failed" and tried_providers list
    - tried_providers is a list of backend_id strings stored in RunHandle.metadata["tried_providers"]
    - When config.enabled is False: pass-through (no rate limiting, circuit breaking, or fallback) — just delegate to matching sub-adapter
    - Over-limit RPM/TPM requests are rejected/skipped (provider is skipped in fallback chain, not hard error unless all providers exhausted)
    - Gateway exports RateLimiter, RateLimitConfig, CircuitBreaker, CircuitBreakerConfig, CircuitBreakerRegistry, CircuitState from __init__.py
  </behavior>
