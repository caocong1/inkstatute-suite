### Task 100-03-01: Implement AgentContextAssembler (history trim + skill body injection)

**Action**: Create `context.py` with `AgentContextAssembler` that combines conversation history trimming with skill body injection under a total token budget.

**`AgentContextPolicy`** (frozen dataclass):
- `budget_tokens: int = 32768` (generous default for skill bodies 2K-20K)
- `chars_per_token: int = 4`
- `system_prompt_protected: bool = True` (system prompt never trimmed)
- `skill_body_budget_fraction: float = 0.6` (max fraction of budget for skill bodies)
- `history_budget_fraction: float = 0.3` (max fraction for conversation history)
- `max_history_turns: int = 20`
- `trim_strategy: str = "protected_then_skill_then_history"`

**`AgentContextResult`** (frozen dataclass):
- `messages: list[dict]` — assembled message list (system + skill bodies + history + current turn)
- `estimated_tokens: int`
- `dropped_sections: dict` — what was trimmed (history turns, skill sections)
- `trimmed_skill_sections: list[dict]` — detailed skill body trim report
- `protected_sections: tuple[str, ...]` — sections that were never trimmed

**`AgentContextAssembler` class**:
- `__init__(self, policy: AgentContextPolicy | None = None)`
- `assemble(self, *, system_prompt: str, skill_bodies: list[dict], history: list[dict], current_turn: dict, policy: AgentContextPolicy | None = None) -> AgentContextResult`

**Assembly algorithm** (deterministic — same input + same budget → same output):
1. **System prompt**: Always included first, protected (never trimmed). Estimate tokens.
2. **Skill body injection**: For each skill body, use the section-priority trim pattern from `body_injector.py`:
   - Parse body into sections by `## ` headers
   - Assign priorities: Protected (frontmatter + description + first section), High (research-gate, ask-user), Medium (other), Low (example, appendix, reference)
   - Trim from lowest priority with most tokens until skill body fits within `budget * skill_body_budget_fraction`
   - Record trimmed sections in `trimmed_skill_sections`
3. **Conversation history**: Apply the trim order from `context_assembler.py`:
   - Truncate to `max_history_turns` most recent turns
   - If still over `budget * history_budget_fraction`, drop oldest turns first
   - Record dropped turns in `dropped_sections`
4. **Current turn**: Always included, protected.
5. **Total budget check**: If total estimated tokens > `budget_tokens`, trim history further, then skill bodies (low priority first).
6. **Return**: Assembled messages list (system + skill bodies + history + current turn), with trim reports.

**CJK-aware token estimation**: Reuse the `_is_cjk()` + `_estimate_tokens()` pattern from `body_injector.py` (CJK chars = 1 token, non-CJK = chars // 4).

### Task 100-03-02: Implement async turn loop (always-streaming, tool-call events, heartbeat)

**Action**: Create `turn_loop.py` with the `run_turn()` async generator and `TurnLoopConfig` / helper functions. This is the heart of Phase 100 — the fix for the "整轮静默" (whole-round silence) defect.

**`run_turn()` signature**:
```python
async def run_turn(
    *,
    messages: list[dict],
    tools: list[dict] | None,
    provider: LlmProvider,
    emitter: EventEmitter,
    config: AgentCoreConfig,
    tool_executor: Callable[[str, str, dict], Awaitable[ToolResult]] | None = None,
    run_id: str,
) -> AsyncIterator[RunEvent]:
```

**Turn loop flow** (per round, `range(config.max_turns)`):
1. `yield emitter.emit_phase_changed("research")` (or configurable phase)
2. `yield emitter.emit_thought_delta("正在分析...")` — pre-LLM thought
3. `emitter.maybe_heartbeat()` — check silence threshold before LLM call
4. Build `ChatRequest` with `messages`, `tools`, `stream=True`, `max_tokens`, `temperature`
5. `async for delta in provider.chat_stream(request):`
   - If `ContentDelta`: `yield emitter.emit_message_delta(delta.content)`
   - If `ReasoningDelta`: `yield emitter.emit_thought_delta(delta.reasoning)`
   - If `ToolCallDelta`: accumulate tool calls (may arrive in fragments)
   - If `UsageDelta`: accumulate usage via `UsageAccumulator`
   - If `FinishDelta`: note finish reason
6. After stream ends, check accumulated tool calls:
   - **If tool calls present**: For each tool call:
     a. `yield emitter.emit_tool_call_started(tool_call_id, tool_name)`
     b. `emitter.maybe_heartbeat()` — check silence during tool execution
     c. If `tool_executor` is provided: `result = await tool_executor(tool_call_id, tool_name, arguments)`
        - If success: `yield emitter.emit_tool_call_delta(tool_call_id, "执行完成")`, `yield emitter.emit_tool_call_completed(tool_call_id, status="succeeded", content=result.content)`
        - If error: `yield emitter.emit_tool_call_completed(tool_call_id, status="error", error=ErrorInfo(...))`
     d. If `tool_executor` is `None` (Phase 100 skeleton — no real tools yet): `yield emitter.emit_tool_call_completed(tool_call_id, status="succeeded", content="[fixture tool result]")`
     e. Append tool result to messages as `{"role": "tool", "tool_call_id": ..., "content": ...}`
   - `yield emitter.emit_thought_delta("工具执行完成，正在整合结果...")` — transition thought
   - `continue` — next round
7. **If no tool calls** (final content round):
   - `yield emitter.emit_message_completed(full_content, metadata={"provider_usage": usage_accumulator.to_dict()})`
   - `yield emitter.emit_run_state_changed("succeeded", metadata={"provider_usage": usage_accumulator.to_dict()})`
   - `return` — stop generator
8. **Turn limit reached** (loop exhausted):
   - `yield emitter.emit_error(ErrorInfo(code="turn_limit_exceeded", message="达到最大轮次上限"))`
   - `yield emitter.emit_run_state_changed("failed")`
   - `return`

**Error recovery**: Tool execution exceptions are caught. The error is emitted as `tool_call.completed` with `status="error"` and `ErrorInfo`. The error message is appended as a tool result (`{"role": "tool", "content": "Error: ..."}`) to the message history. The loop continues to the next round — the LLM can see the error and decide to retry or produce a final answer.

**Provider errors**: If `provider.chat_stream()` raises an exception, emit `error` event with normalized `ErrorInfo`, then `run.state_changed` to `"failed"`, and return.

**`ToolResult` dataclass** (frozen):
- `content: str` — tool result content
- `error: ErrorInfo | None = None` — error info if tool failed
- `metadata: dict = field(default_factory=dict)`
