### Task 100-01-03: Implement EventEmitter with monotonic seq + silence threshold + heartbeat

**Action**: Create `event_emitter.py` with the `EventEmitter` class. This is the core event infrastructure that all other plans depend on.

**EventEmitter responsibilities**:
1. **Monotonic seq**: Assign strictly increasing `seq` integers starting from 0 to each emitted event. Used for SSE replay (Phase 91 Last-Event-ID support).
2. **Silence threshold**: Track `last_event_time` (using injectable clock for testing). If no event has been emitted for more than `silence_threshold_seconds`, emit a heartbeat `thought.delta` event with `metadata={"heartbeat": true}` and a contextual progress message.
3. **RunEvent construction**: Build `RunEvent` objects with `event_id` (UUID), `run_id`, `event_type` (from `RunEventType` V3 values), `occurred_at` (ISO-8601), `seq`, `payload` (serialized via `serialize_payload()` from `unified_events.py`), and `metadata`.
4. **Convenience methods**: `emit_message_delta(delta, message_id)`, `emit_message_completed(content, message_id, metadata)`, `emit_thought_delta(delta, metadata)`, `emit_tool_call_started(tool_call_id, tool_name, kind, title)`, `emit_tool_call_delta(tool_call_id, content, status)`, `emit_tool_call_completed(tool_call_id, status, content, error)`, `emit_phase_changed(phase, previous_phase)`, `emit_run_state_changed(status, previous_status, error, metadata)`, `emit_error(error_info)`.
5. **Heartbeat**: `maybe_heartbeat()` method that checks elapsed time since last event and emits a heartbeat `thought.delta` if threshold exceeded. The turn loop calls this before/after long operations.

**Key design**:
- Injectable `clock: Callable[[], str]` for `occurred_at` timestamps (default: `datetime.now(timezone.utc).isoformat()`)
- Injectable `monotonic_clock: Callable[[], float]` for silence threshold tracking (default: `time.monotonic()`)
- `run_id` is set at construction time
- `silence_threshold_seconds` comes from `AgentCoreConfig`
- Each convenience method calls `_emit(event_type, payload, metadata)` which assigns seq, builds RunEvent, updates `last_event_time`, and returns the RunEvent
