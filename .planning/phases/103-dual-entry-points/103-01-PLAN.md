# Plan 103-01: In-Process BackendAdapter

## Objective

Implement `InProcessAgentCoreAdapter` — a `BackendAdapter` Protocol implementation that wraps the agent-core's `run_turn()` for direct in-process use by the Gateway. No IPC, no subprocess, full observability.

## Files to Create

### `packages/agent-core/src/inkstatute_agent_core/backend_adapter.py`
In-process BackendAdapter implementing all 9 Protocol methods:

1. **`backend_id()`** → returns `"inkstatute"`
2. **`capabilities()`** → returns `AdapterCapabilitySet` with:
   - `stream_event_support=True`
   - `cancel_support=True`
   - `approval_support=True`
   - `session_memory_support=True`
   - No `fs/*` or `terminal/*` capabilities
3. **`bootstrap_check()`** → verifies model provider is configured; returns `BootstrapStatus(ok=True, backend_id="inkstatute", ...)`
4. **`submit_run(req: RunRequest) -> RunHandle`** →
   - Extract prompt/messages from `RunRequest.turn`
   - Create EventEmitter + model provider from config
   - Start `run_turn()` as a background asyncio.Task
   - Buffer events in an asyncio.Queue
   - Return `RunHandle(run_id=..., status=AsyncTaskState.RUNNING)`
5. **`get_run(run_id) -> Run`** → return current Run state from internal dict
6. **`stream_events(run_id) -> AsyncIterator[RunEvent]`** → yield events from the queue until terminal state
7. **`cancel_run(run_id) -> Run`** → cancel the background task, emit `run.state_changed` to "cancelled"
8. **`submit_approval(run_id, approval) -> Run`** →
   - **SAFETY**: Reject auto-approval of `terminal` / `execute_code` (same as ACPBackendAdapter)
   - Store approval for the turn loop to consume
9. **`collect_artifacts(run_id) -> list[ArtifactRecord]`** → collect artifact events from the event stream

## Implementation Details

### Event Buffering
Use `asyncio.Queue` per run. The background `run_turn()` task pushes events; `stream_events()` pulls from the queue. When `run_turn()` completes, push a sentinel to signal completion.

### RunRequest → Messages Mapping
`RunRequest.turn` contains the agent turn. Extract the user prompt and build the messages list for `run_turn()`:
- System prompt from `build_system_prompt()` (Phase 102)
- User message from `RunRequest.turn`

### Model Provider Factory
The config provides a `provider_factory` callable. In production, this creates an OpenAI/Anthropic/Ollama provider. In tests, this creates a `FixtureProvider`.

### Cancellation
`cancel_run()` calls `task.cancel()` on the background asyncio.Task. The turn loop's async generator will receive `asyncio.CancelledError` and stop. Emit a `run.state_changed` event with status "cancelled".

### Approval Safety
Reuse the `_DANGEROUS_PERMISSION_KINDS` pattern from `ACPBackendAdapter`. Any approval with `decision="approved"` for `terminal` or `execute_code` kinds must raise `ValueError`.
