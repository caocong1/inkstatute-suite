<objective>
实现 ACP 控制面客户端：NDJSON JSON-RPC 帧收发、五个协议方法、多会话管理、权限请求应答。**`session/cancel` 必须作为通知发送**——这是实测确认的陷阱，写成请求会静默失败。

## 实测的协议形状（照抄，不要臆测）

握手：
```
→ {"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":1,"clientCapabilities":{"fs":{"readTextFile":false,"writeTextFile":false},"terminal":false}}}
← {"jsonrpc":"2.0","id":1,"result":{"protocolVersion":1,"agentInfo":{"name":"deepseek-harness-acp","version":"0.0.1"},"agentCapabilities":{"promptCapabilities":{"image":false,"audio":false,"embeddedContext":false}},"authMethods":[]}}
```

建会话（`cwd` 必须绝对路径）：
```
→ {"jsonrpc":"2.0","id":2,"method":"session/new","params":{"cwd":"/abs/path","mcpServers":[]}}
← {"jsonrpc":"2.0","id":2,"result":{"sessionId":"cede64c0-4cd3-4d37-8814-baa0ef8bedb8"}}
```

发提示：
```
→ {"jsonrpc":"2.0","id":3,"method":"session/prompt","params":{"sessionId":"...","prompt":[{"type":"text","text":"..."}]}}
← {"jsonrpc":"2.0","id":3,"result":{"stopReason":"end_turn"}}
错误时 ← {"jsonrpc":"2.0","id":3,"error":{"code":-32603,"message":"Internal error: turn failed: ..."}}
```

取消（**通知，无 id**）：
```
→ {"jsonrpc":"2.0","method":"session/cancel","params":{"sessionId":"..."}}
← （无响应）随后原 prompt 请求收到 {"jsonrpc":"2.0","id":3,"result":{"stopReason":"cancelled"}}
```

**反例（实测）**：带 `id` 发送会得到
`{"jsonrpc":"2.0","id":N,"error":{"code":-32601,"message":"\"Method not found\": session/cancel"}}`

会话更新（服务端→客户端**通知**）：
```
← {"jsonrpc":"2.0","method":"session/update","params":{"sessionId":"...","update":{"sessionUpdate":"agent_message_chunk","content":{"type":"text","text":"..."}}}}
```

权限请求（服务端→客户端**请求**，必须应答）：
```
← {"jsonrpc":"2.0","id":7,"method":"session/request_permission","params":{...,"toolCall":{"toolCallId":"..."},"options":[{"optionId":"allow-once",...},{"optionId":"reject-once",...}]}}
→ {"jsonrpc":"2.0","id":7,"result":{"outcome":{"outcome":"selected","optionId":"reject-once"}}}
```

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct InitializeResult {
    pub protocol_version: u32,          // serde rename "protocolVersion"
    pub agent_info: AgentInfo,          // "agentInfo"
    #[serde(default)] pub auth_methods: Vec<serde_json::Value>,
}

pub struct AgentInfo { pub name: String, pub version: String }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct NewSessionResult { pub session_id: String }   // "sessionId"

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PromptResult { pub stop_reason: String }      // "stopReason"

/// 服务端推来的会话更新（只有 agent_message_chunk 一种，实测确认）
#[derive(Debug, Clone)]
pub enum SessionUpdate {
    AgentMessageChunk { session_id: String, text: String },
    Unknown { session_id: String, raw: serde_json::Value },
}

/// 权限请求
#[derive(Debug, Clone)]
pub struct PermissionRequest {
    pub request_id: i64,
    pub session_id: String,
    pub tool_call_id: Option<String>,
    pub tool_name: Option<String>,
    pub options: Vec<PermissionOption>,
    pub raw: serde_json::Value,
}
pub struct PermissionOption { pub option_id: String, pub name: String, pub kind: Option<String> }

#[derive(Debug, Clone, Copy)]
pub enum PermissionDecision { AllowOnce, RejectOnce }
```

**所有 `#[serde(rename_all = "camelCase")]`**，因为线上是 camelCase。

### Task 2: NDJSON 传输与请求路由

- **type:** code
- **files:** apps/desktop/src-tauri/src/engine/acp.rs
- **action:** 实现：

```rust
pub struct AcpClient { /* 私有 */ }

impl AcpClient {
    /// 接管子进程的 stdin/stdout，启动读循环。
    pub fn new(stdin: ChildStdin, stdout: ChildStdout) -> Self;

    pub async fn initialize(&self, timeout: Duration) -> Result<InitializeResult, EngineError>;
    pub async fn new_session(&self, cwd: &Path) -> Result<String, EngineError>;
    pub async fn prompt(&self, session_id: &str, text: &str) -> Result<PromptResult, EngineError>;

    /// !!! 通知，无 id !!! 写成请求会返回 Method not found 而静默失败。
    pub async fn cancel(&self, session_id: &str) -> Result<(), EngineError>;

    /// 订阅服务端推来的 session/update 通知
    pub fn subscribe_updates(&self) -> broadcast::Receiver<SessionUpdate>;

    /// 订阅权限请求；调用方必须对每条调用 respond_permission，否则引擎侧挂起
    pub fn subscribe_permissions(&self) -> mpsc::UnboundedReceiver<PermissionRequest>;

    pub async fn respond_permission(&self, request_id: i64, d: PermissionDecision) -> Result<(), EngineError>;

    /// 关闭：停止读循环，让所有挂起请求以 EngineError::Disconnected 结算
    pub async fn close(&self);
}
```

**实现要点，逐条落实：**

1. **帧格式**：一行一个紧凑 JSON，`\n` 结尾。读侧按行切；**非 JSON 行必须忽略而非报错**（引擎偶发在 stdout 打非协议内容时不能崩）。

2. **id 分配**：`AtomicI64` 自增，从 1 起。挂起请求表 `Mutex<HashMap<i64, oneshot::Sender<Result<Value, JsonRpcError>>>>`。

3. **帧分类**（收到一行 JSON 后）：
   - 有 `id` 且有 `method` → 服务端→客户端**请求**（目前只有 `session/request_permission`）→ 投递到 permissions 通道
   - 有 `id` 无 `method` → **响应** → 取出挂起 sender 结算（`error` 字段存在则结算为 Err）
   - 无 `id` 有 `method` → **通知**（`session/update`）→ 广播到 updates 通道
   - 其它 → 忽略

4. **`cancel` 必须这样写**，并在上方加注释：
   ```rust
   /// session/cancel 是 JSON-RPC **通知**，不是请求。
   /// 实测：带 id 发送 → {"error":{"code":-32601,"message":"Method not found: session/cancel"}}
   ///       无 id 发送 → in-flight prompt 立即结算为 {"stopReason":"cancelled"}
   /// 因此这里绝不能走 self.request()。
   pub async fn cancel(&self, session_id: &str) -> Result<(), EngineError> {
       self.notify("session/cancel", json!({ "sessionId": session_id })).await
   }
   ```

5. **单 in-flight 保护**：`prompt` 内部对同一 `session_id` 加锁；已有 in-flight 时返回 `EngineError::PromptInFlight`，不要排队（ACP 侧也会拒）。

6. **绝对路径断言**：`new_session` 里 `cwd.is_absolute()` 为 false 时直接返回 `EngineError::CwdNotAbsolute`，不发帧。

7. **断连结算**：读循环结束（EOF / 进程退出）时，所有挂起请求以 `EngineError::Disconnected` 结算，两个通道关闭。**不得让调用方永久挂起。**

- **verify:**
  - 单元测试：`cancel` 发出的帧**不含 `id` 字段**（断言序列化后的 JSON 对象无 `"id"` 键）——这是防回归的关键测试
  - 单元测试：非 JSON 行被忽略不 panic
  - 单元测试：相对路径 `new_session` 被拒且未发帧
  - 单元测试：同会话第二次 `prompt` 返回 `PromptInFlight`
  - 单元测试：EOF 后挂起请求以 `Disconnected` 结算
- **acceptance_criteria:**
  - cancel 通知形式有测试固化
  - 断连不挂起

### Task 3: mock ACP server fixture

- **type:** test
- **files:** apps/desktop/src-tauri/tests/fixtures/mock_acp_server.mjs
- **action:** 写一个 Node 脚本作为可脚本化的 mock ACP server，供集成测试用（不需要真实引擎、不需要网络）。行为：
  - 读 stdin 的 NDJSON 帧
  - `initialize` → 回标准握手结果
  - `session/new` → 回递增的假 `sessionId`；若 `cwd` 非绝对路径则回 error
  - `session/prompt` → **延迟 5 秒**后回 `{"stopReason":"end_turn"}`（给取消留窗口）；期间每 500ms 推一条 `session/update` 的 `agent_message_chunk`
  - `session/cancel`（通知）→ 立即把该会话的挂起 prompt 结算为 `{"stopReason":"cancelled"}`
  - 环境变量 `MOCK_REQUEST_PERMISSION=1` 时，收到 prompt 后先发一条 `session/request_permission` 请求，等客户端应答再继续
  - 收到非法帧一律忽略
- **verify:** `node tests/fixtures/mock_acp_server.mjs` 能被手工用 echo 驱动
- **acceptance_criteria:** mock 覆盖成功、取消、权限三条路径
