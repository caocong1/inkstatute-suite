<constraints>
- Keep this dependency-free: Python stdlib only, no package installs, no database, no queue, no server, no service process.
- Keep the resolver backend-neutral; do not import WeCom service, Hermes backend, router, skill registry, MCP registry, or model gateway code from `platform-runtime`.
- Do not store raw legal/customer text, callback bodies, media, runtime logs, backend notices, or secrets. Store `raw_payload_ref`, hashes, lengths, IDs, timestamps, statuses, and reason codes only.
- Short-term context assembly is Phase 16. Long-term memory and feedback learning are Phase 17. External memory adapter evaluation is Phase 18.
</constraints>

<must_haves>
Truths:
- CTX-01: A recent viable session continues without `/new`, `/resume`, or any agent/session command.
- CTX-02: Resolution uses a scoped identity of tenant/workspace/channel/user/bot plus conversation/session/thread signals.
- CTX-02: Pending unresolved interrupt has precedence over active task, active task has precedence over recent-session continuation, and recent-session continuation has precedence over fallback session creation.
- CTX-03: A stale session, terminal session/run status, or clearly new task signal starts a new session when no higher-precedence pending interrupt or active task exists.
- CTX-04: Serialized decisions contain no user text; they include only refs, hashes, lengths, statuses, timestamps, and reason/action metadata.

Required artifacts:
- `packages/platform-runtime/src/platform_runtime/session_resolver.py`
- `packages/platform-runtime/tests/test_session_resolution.py`
- Public exports from `packages/platform-runtime/src/platform_runtime/__init__.py`

Key links:
- `resolve_session_turn(...)` returns `SessionResolutionDecision` before host code creates/resumes a run.
- `SessionResolutionDecision.as_event()` can be appended to `ContractLogStore` under `session_resolution`.
- `InMemorySessionResolutionStore` is copy-safe and scope-safe, matching the privacy posture of `InMemoryContractLogStore`.
</must_haves>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| channel/platform host -> session resolver | Untrusted user text and channel metadata are inspected for routing but must not be persisted raw. |
| resolver -> contract log store | Decision evidence crosses into append-only audit storage. |
| resolver store lookup | Scoped session/interrupt/task snapshots must not cross tenant/workspace/channel/user/bot boundaries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-15-01-01 | Elevation of Privilege | `resolve_session_turn` | mitigate | Match sessions, active tasks, and pending interrupts by `SessionScope` fields, not only `conversation_id`; add scope-mismatch tests. |
| T-15-01-02 | Information Disclosure | `SessionResolutionDecision.as_event` | mitigate | Serialize only IDs, refs, hashes, lengths, timestamps, statuses, and reason codes; add negative assertions for raw text. |
| T-15-01-03 | Tampering | new-task/stale policy | mitigate | Make action and reason deterministic and covered by tests for terminal/stale/new-task branches. |
| T-15-01-SC | Tampering | package installs | mitigate | No package-manager install tasks; stdlib-only implementation. |
</threat_model>
