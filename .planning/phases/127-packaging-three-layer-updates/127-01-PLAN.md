消灭两个"联网才能用"的隐患：随包带 Node 运行时（缺陷 D3），字体本地化（缺陷 D2）。目标是**断网的中国大陆 Windows 电脑上，界面与功能都不降级**。

<tasks>

### Task 1: scripts/fetch-node-runtime.mjs

- **type:** code
- **files:** scripts/fetch-node-runtime.mjs
- **action:** 构建期脚本，下载并解出目标平台的 Node 运行时：
  1. 从 `engines/dsh-pin.txt` 读 `node_version`（`24.19.0`）与 `target_platform`（`win32-x64`）。
  2. 下载 `https://nodejs.org/dist/v<ver>/node-v<ver>-win-x64.zip`
     （镜像可配，默认 `https://npmmirror.com/mirrors/node/`）。
  3. **校验 SHA256**：同时下载同目录的 `SHASUMS256.txt`，比对。不符则 exit 1。
  4. 解压，**只取 `node.exe`**（不要 npm、不要 npx、不要 docs），
     输出到 `apps/desktop/src-tauri/resources/node/node.exe`。
  5. 打印最终体积。
  6. 若目标文件已存在且版本匹配（用旁边的 `node.version` 标记文件记录），跳过下载。
  7. **非 Windows 开发机**上运行时，同时解出本机平台的 node 到 `resources/node/node`
     （便于 `tauri dev` 时联调），并在 `.gitignore` 中排除 `resources/node/`。

- **verify:**
  - `node scripts/fetch-node-runtime.mjs` 成功
  - `ls -la apps/desktop/src-tauri/resources/node/` 有 node.exe（或本机平台 node）
  - 故意改坏 SHA 比对逻辑的输入 → exit 1
- **acceptance_criteria:** node 运行时可复现获取且经校验；不含 npm

### Task 2: paths.rs 接入便携 Node

- **type:** code
- **files:** apps/desktop/src-tauri/src/engine/paths.rs, apps/desktop/src-tauri/tauri.conf.json
- **action:**
  1. `tauri.conf.json` 的 `bundle.resources` 增加 `"resources/node/**/*"`。
  2. `paths::node_binary()` 改为：
     - 生产：从 Tauri 的 resource dir 解析 `node/node.exe`（Windows）/ `node/node`（其它）
     - 开发：若 resource 不存在，回退环境变量 `INKSTATUTE_NODE_BIN`，再回退 `which node`
     - **三者都不存在时返回 `EngineError::NodeRuntimeMissing`**，
       其用户文案为「运行环境缺失，请重新安装」
  3. 因为 `paths` 模块现在需要 `AppHandle` 来解析 resource dir，
     改为在启动时用 `paths::init(app_handle)` 注入一次，存 `OnceLock`。
     其余函数签名不变。

- **verify:**
  - `cargo check && cargo test`
  - 单元测试：三级回退各一例
  - 单元测试：全不存在 → `NodeRuntimeMissing`
- **acceptance_criteria:** 引擎 spawn 用绝对路径的便携 node，不依赖 PATH

### Task 3: 字体本地化

- **type:** code
- **files:** packages/ui-core/src/themes/molv-tokens.css, packages/ui-core/src/themes/fonts/
- **action:**
  1. **删除** `molv-tokens.css` 第 7 行的
     `@import url('https://fonts.googleapis.com/css2?...')`。
     **这是本 Task 的核心——CDN 依赖必须清零。**
  2. 下载拉丁字体的 WOFF2 并放入 `packages/ui-core/src/themes/fonts/`：
     - `Newsreader` 400/500（serif 拉丁）
     - `SplineSansMono` 400/500（mono）
     （从 Google Fonts 下载 WOFF2 静态文件，**不是 CSS 链接**。许可为 OFL，需在"关于"页列出。）
  3. 在 `molv-tokens.css` 顶部改为本地 `@font-face`：
     ```css
     @font-face {
       font-family: "Newsreader";
       src: url("./fonts/Newsreader-Regular.woff2") format("woff2");
       font-weight: 400; font-display: swap;
     }
     /* 其余字重与 SplineSansMono 同理 */
     ```
  4. **改字体族回退栈**，CJK 靠系统字体：
     ```css
     --serif: "Newsreader", "Source Han Serif SC", "Noto Serif CJK SC", "SimSun", Georgia, serif;
     --serif-latin: "Newsreader", Georgia, serif;
     --sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB",
             -apple-system, "Segoe UI", system-ui, sans-serif;
     --mono: "Spline Sans Mono", "Cascadia Mono", "SF Mono", Consolas, ui-monospace, monospace;
     ```
     **只改这四行与 `@import`/`@font-face`，其余 180 余行 token 一字不动。**
  5. `packages/ui-core` 的 vite 配置确保字体文件被打包进产物（`assetsInclude` 或默认处理）。
  6. 在设置面板"关于"页加 OFL 许可声明。

- **verify:**
  - `grep -c 'fonts.googleapis.com' packages/ui-core/src/themes/molv-tokens.css` 返回 **0**
  - `grep -rc 'https://' packages/ui-core/src/themes/*.css` 全部返回 0
  - `bunx vitest run` 通过
  - `git diff packages/ui-core/src/themes/molv-tokens.css | grep '^-' | grep -c '^\-  --'`
    ≤ 5（确认只改了字体族那几行，没动配色 token）
- **acceptance_criteria:** CSS 中零外部 URL；配色 token 未被误改

### Task 4: GATE — 离线资产门禁

- **type:** code
- **files:** scripts/gates/v5/offline-assets.mjs, scripts/gates/v5/run-gates.mjs
- **action:** 门禁断言「断网可用」：
  1. **零外部 URL**：扫描 `packages/ui-core/src/**/*.css`、`apps/desktop/src/**/*.{css,ts,tsx}`、
     `apps/desktop/index.html`，断言无 `http://` / `https://` 开头的资源引用
     （允许出现在注释与字符串常量中的文档链接——用 `url(` / `@import` / `<link` / `<script src` 上下文判定）。
  2. **字体文件存在**：`packages/ui-core/src/themes/fonts/` 下至少 4 个 `.woff2`。
  3. **Node 运行时存在**：`apps/desktop/src-tauri/resources/node/` 下有 `node.exe` 或 `node`
     （CI 上若未跑 fetch 脚本则跳过并警告，不红灯）。
  4. **CSP 不放行外部源**：`tauri.conf.json` 的 `app.security.csp` 中
     `font-src` 与 `style-src` **不得含 `fonts.googleapis.com` / `fonts.gstatic.com`**。
     顺带把 lawyer-desktop 遗留的这两项从 CSP 里删掉。
  5. 注册进 `run-gates.mjs`，名为 `offline-assets`。

- **verify:**
  - `node scripts/gates/v5/offline-assets.mjs` 绿灯
  - 人为在某 CSS 里加一行 `@import url('https://x')` → 门禁红灯并指出文件与行号
  - `node scripts/gates/v5/run-gates.mjs` 输出 `5 passed, 0 failed`
- **acceptance_criteria:** 门禁能定位到具体文件行号
