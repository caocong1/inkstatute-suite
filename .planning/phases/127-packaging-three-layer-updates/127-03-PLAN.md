### Task 1: 首启向导

- **type:** code
- **files:** apps/desktop/src/components/FirstRunWizard.tsx, apps/desktop/src/components/FirstRunWizard.css, apps/desktop/src-tauri/src/commands/setup.rs
- **action:** 三步向导。**不问执业方向**（v5 由 LLM 自动判断法律领域）：

  **第 1 步 — 选择模型服务商**
  - 卡片式列出 `list_providers()` 的 9 个（DeepSeek 置顶并标"推荐"）
  - 每张卡显示中文名与一句话说明（如"DeepSeek — 国内直连，性价比高"）

  **第 2 步 — 填入密钥**
  - `type="password"` 输入框 + 「从剪贴板粘贴」按钮
  - 下方一行小字："密钥保存在 Windows 凭据管理器，不会写入任何文件。"
  - 「测试连接」按钮 → `test_provider()` → 成功显示绿勾与实际模型名；失败显示中文原因
  - **必须测试通过才能下一步**

  **第 3 步 — 就绪检查**
  - 依次显示并自动执行：引擎安装 ✓ / 法律技能包 ✓ / 引擎自检 ✓
  - 引擎自检即调一次冒烟；失败当场给中文原因 + 「重试」
  - 全通过 → 「开始使用」按钮 → 进主界面

  Rust 侧：
  ```rust
  #[tauri::command] pub fn is_first_run() -> bool;                    // settings.json 不存在或无 active_provider
  #[tauri::command] pub async fn complete_setup(provider: String) -> Result<(), String>;
  #[tauri::command] pub async fn preflight() -> Result<PreflightReport, String>;  // 引擎/技能/冒烟三项
  ```

  `App.tsx`：`is_first_run()` 为真 → 渲染向导；否则直接 `engineStart()`。

- **verify:**
  - 测试：首启渲染向导，非首启不渲染
  - 测试：测试连接未通过时"下一步"禁用
  - 测试：密钥输入框 `type === "password"` 且提交后被清空
  - 测试：preflight 任一项失败时显示重试
- **acceptance_criteria:** 三步可走通；密钥不落文件；无"选执业方向"步骤

### Task 3: Windows 安装包构建脚本

- **type:** code
- **files:** scripts/build-windows-installer.mjs
- **action:** 一条命令产出安装包。步骤：
  1. 前置检查：`engines/engine-lock.json` 存在、`resources/node/node.exe` 存在、
     v5 门禁全绿（调 `run-gates.mjs`，红灯即 exit 1）。
  2. 装配引擎基线到 `apps/desktop/src-tauri/resources/engine/<version>/`
     （复用 Rust 装配器：`cargo run --bin assemble-engine -- --out <path>`；
     若无该 bin 则本 Task 顺带写一个最小的）。
  3. 物化预设与内容包基线到 `resources/presets/`、`resources/skills/`。
  4. `tauri.conf.json` 的 `bundle.resources` 覆盖：
     `resources/node/**/*`、`resources/engine/**/*`、`resources/presets/**/*`、`resources/skills/**/*`
  5. `bunx tauri build --target x86_64-pc-windows-msvc`
  6. 打印产物路径与体积；断言体积 < 300MB。
  7. 首次运行时 Rust 侧把 `resources/` 下的引擎/预设/技能**复制**到 `%LOCALAPPDATA%\InkStatute\`
     并写 `current` 指针（在 `commands/setup.rs` 的 `preflight` 里做）。

- **verify:**
  - `node scripts/build-windows-installer.mjs` 在 Windows 上成功产出 `.msi` 或 `.exe`
  - 门禁红灯时脚本 exit 1 且不构建
- **acceptance_criteria:** 一条命令出包；门禁未过不出包

- **action:** 写发布手册，内容必须包含：

  5. **回滚流程**：把 `engine-lock.json` 换回旧版本；用户侧也可在设置里手动回退
  6. **首次运行 Defender 提示**的处理说明（无代码签名证书时）
