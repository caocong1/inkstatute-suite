<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| host/runtime -> ContextAssembler | Current user turn text, refs, scope, active task state, pending clarification state, and output constraints enter a library function. |
| ContextAssembler -> ContextBundle | Backend-bound context is serialized into a contract object and metadata. |
| rolling summary store lookup | Summary refs must remain isolated by tenant/workspace/channel/user/bot/conversation/thread scope. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-16-01-01 | Information Disclosure | `ContextAssemblyResult.as_event` / bundle metadata | mitigate | Serialize refs, hashes, lengths, IDs, and policy metadata only; add tests that raw current turn and summary text are absent. |
| T-16-01-02 | Elevation of Privilege | `InMemoryRollingSummaryStore` | mitigate | Key summaries by full `SessionScope`, not only conversation/session id; add cross-user scope isolation tests. |
| T-16-01-03 | Denial of Service | `ContextAssembler.assemble` | mitigate | Cap recent turn/artifact/feedback refs and enforce deterministic budget accounting so long histories cannot grow backend payloads unbounded. |
| T-16-01-04 | Tampering | protected trimming set | mitigate | Treat current turn, pending clarification, and output-policy/output-constraints as protected sections with tests for every trim branch; fail closed on impossible budgets. |
| T-16-01-05 | Information Disclosure | rolling summaries | mitigate | Store summary refs and ref lists by default; reject full-text keys such as `full_text`, `payload_text`, `document_text`, and `case_facts`. |
| T-16-01-SC | Tampering | package installs | mitigate | No package-manager install tasks; stdlib-only implementation. |
</threat_model>
