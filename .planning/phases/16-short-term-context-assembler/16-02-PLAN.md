<objective>
Wire Phase 16 context assembly into the embeddable runtime as an explicit opt-in lane.

Purpose: runtime calls should be able to send bounded context to backends while preserving the established default-off, dependency-injected, backend-neutral runtime architecture.
Output: a default-off feature flag, optional `ContextAssembler` injection in `DefaultRunRuntime`, backend-bound `RunRequest` metadata with sanitized `ContextBundle`, and runtime lifecycle tests.
</objective>

<constraints>
- Keep runtime context assembly default-off and injected. Enabling the lane without a `ContextAssembler` must fail before `BackendAdapter.submit_run`.
- Do not mutate caller-owned `RunRequest`, `metadata`, `AgentTurn`, `OutputConstraints`, or runtime collaborator objects; use `dataclasses.replace` and cloned metadata.
- Do not import channel services, Hermes code, external memory systems, tokenizers, databases, queues, or network clients.
- Do not duplicate raw current turn content into `context_bundle` metadata. The backend already receives `RunRequest.turn`; the bundle should carry refs, IDs, hashes, lengths, and policy metadata.
</constraints>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| DefaultRunRuntime -> BackendAdapter | ContextBundle metadata crosses into backend-bound `RunRequest` objects. |
| DefaultRunRuntime -> ContractLogStore | ContextBundle evidence may be appended to audit storage when contract logging is enabled. |
| interrupt resume -> context assembler | User answer text and pending clarification refs are converted into sanitized backend context. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-16-02-01 | Information Disclosure | `DefaultRunRuntime._attach_context_bundle` | mitigate | Attach serialized `ContextBundle` refs/hashes/lengths only and assert raw current/answer text is absent from backend metadata and contract log entries. |
| T-16-02-02 | Denial of Service | enabled context assembly lane | mitigate | Keep lane default-off, require injected assembler, and rely on deterministic budget enforcement before backend submission. |
| T-16-02-03 | Tampering | `RunRequest` metadata merge | mitigate | Use `dataclasses.replace` with cloned metadata and preserve existing resume metadata keys rather than mutating caller objects. |
| T-16-02-04 | Elevation of Privilege | interrupt resume scope | mitigate | Keep Phase 15 `SessionScope` validation before context assembly and include only the matching pending interrupt record. |
| T-16-02-05 | Information Disclosure | output policy constraints | mitigate | Preserve output-policy/output-constraints refs or bounded structured constraints through protected metadata; do not drop them during trimming. |
| T-16-02-SC | Tampering | package installs | mitigate | No package-manager install tasks; stdlib-only runtime wiring. |
</threat_model>
