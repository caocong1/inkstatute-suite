# Plan 03: Multi-Provider Error Normalization + Adapter Wiring + Contract Tests

## Objective

Extract the shared error normalization pattern from `openai_runner.py` into a common `error_normalization.py` module that all three runners (OpenAI, Anthropic, Ollama) use. The shared `_normalize_provider_error` function handles both SDK-based errors (string-based class-name detection for OpenAI and Anthropic) and HTTP-based errors (status code detection for Ollama), mapping all to the existing `ErrorCategory` enum with provider-specific detail in `ErrorInfo.details`. Add contract tests verifying all three runner types produce valid `ProviderModelExecResult` with `ErrorInfo` on failure. This satisfies MULTIPROV-03.
