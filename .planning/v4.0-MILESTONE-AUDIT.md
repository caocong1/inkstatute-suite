## Critical Integration Gaps

### INT-01: Guardrails not wired into ChatController (CRITICAL)

**From:** Phase 117 → Phase 116
**Affected:** GRD-01..06 (all 6 guardrails)

`GuardrailIntegrator` and all 6 guardrail checkers are implemented in `lib/guardrails/` but `ChatController` does not import or invoke them. Guardrails are not enforced in the chat flow.

**Fix:** Wire `GuardrailIntegrator.runAllChecks()` into `ChatController._handleUpdate()` so every assistant message passes through guardrail enforcement before rendering.

### INT-02: App startup flow missing (CRITICAL)

**From:** Phase 119 → main.dart
**Affected:** APP-06, DSH-05, PKG-01

`main.dart` is a minimal shell that starts directly to `ChatView`. `AppStartup`, `FirstRunWizard`, and `CredentialStore` are never instantiated.

**Fix:** Rewrite `main.dart` to use `AppStartup`: check `shouldShowWizard()` → show `FirstRunWizard` or load credentials → spawn engine → render `ChatView`.

### INT-03: DSH Process Manager not wired (CRITICAL)

**From:** Phase 112 → AppStartup
**Affected:** DSH-01, DSH-02, DSH-05

`DshProcessManager` is implemented but never instantiated. `AcpClient` is created without a spawned engine process.

**Fix:** Wire `DshProcessManager.spawn()` into `AppStartup.buildEngineEnv()` and connect stdio to `AcpClient`.

### INT-04: Export dialog not wired into ChatView (MAJOR)

**From:** Phase 118 → Phase 116
**Affected:** APP-04

`ExportDialog` and `DocxExporter` are implemented but not accessible from the chat UI.

**Fix:** Add an export action to `ChatView` that opens `ExportDialog` with the current session's change list.

### INT-05: Portable Python not automated in packaging (MINOR)

**From:** Phase 119 → Phase 118
**Affected:** PKG-01

`build_windows_installer.sh` has a manual echo note instead of automated Python download.

**Fix:** Automate portable Python download in the build script.
