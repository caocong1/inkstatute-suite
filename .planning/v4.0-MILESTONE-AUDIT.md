## Integration Gaps — ALL CLOSED (Phase 121)

### INT-01: Guardrails wired into ChatController ✅ CLOSED

**Fix applied:** `GuardrailIntegrator.runAllChecks()` is now called in `ChatController.sendPrompt()` after each assistant message is finalized. Block results produce a `SystemErrorMessage` in the message list. 6 guardrail integration tests pass.

### INT-02: App startup flow wired ✅ CLOSED

**Fix applied:** `main.dart` rewritten with `StartupGate` that instantiates `AppStartup`, checks `shouldShowWizard()`, shows `FirstRunWizard` when needed, and transitions to `HomeScreen` on completion. 10 startup integration tests pass.

### INT-03: DSH Process Manager wired ✅ CLOSED

**Fix applied:** `HomeScreen._startEngine()` calls `DshProcessManager.spawn()`, runs `healthProbe()`, calls `client.initialize()` + `client.newSession()`, and wires `ApprovalPolicy` through `client.setPermissionPolicy()`. Engine boot verified with extracted archive.

### INT-04: Export dialog wired into ChatView ✅ CLOSED

**Fix applied:** Export button added to `HomeScreen` app bar. `_showExportDialog()` scans for the latest `AssistantMessage` that parses as a `ChangeList` and opens `ExportDialog` with real `DocxExporter` and `Hg4Tracker`.

### INT-05: Portable Python automated ✅ CLOSED

**Fix applied:** `build_windows_installer.sh` now downloads Python 3.12.7 embeddable zip, extracts it, installs pip + python-docx + lxml, and verifies imports. Supports `SKIP_PYTHON` and `PYTHON_ZIP_CACHE` env vars. Standalone test script created.
