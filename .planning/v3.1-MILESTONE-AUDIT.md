## Tech Debt

### CRITICAL — Desktop Arena UI Integration (Phase 110)

The milestone goal states "律师可在桌面 app 内完成完整的竞技体验" but the desktop app (`apps/desktop/src/`) has zero arena imports. All arena UI components (ArenaWorkflowCreator, ParallelStreamPanel, ScoreCard, ReviewSummary, SynthesisViewer) are built, tested (95 vitest tests), and exported from `packages/ui-core/src/index.ts`, but none are imported or rendered in the desktop app. WorkspacePage only uses ChatPanel, DocPreview, CitationPanel.

**Fix:** Add an arena page/route to the desktop app, wire ArenaWorkflowCreator → arena-service POST /v1/arena, wire arenaStream.ts → SSE endpoint, render ParallelStreamPanel/ScoreCard/ReviewSummary/SynthesisViewer.

### CRITICAL — Word Export Endpoint (Phase 110)

SynthesisViewer has an `onExport` callback but arena-service has no export/docx endpoint (only 6 operations: create/stream/cancel/action/status/openapi). Word track-changes implementation exists in agent-core (`packages/agent-core/tests/test_trackchanges_verification.py`) but is not exposed via arena-service.

**Fix:** Add `POST /v1/arena/{arena_id}/export` endpoint to arena-service that calls agent-core's track-changes generation.

### MEDIUM — FS Handler Not Wired to Engine (Phase 107)

ArenaWorkflowConfig.reference_dir field exists but arena-engine has zero imports of fs_handler/fs_sandbox. The FS handler is built and tested (fs-sandbox-escape gate: 12 tests green) but never used by the engine.

**Fix:** Wire FS handler into arena-engine's agent context preparation — when reference_dir is set, use FSSandbox.read_text_file() to read allowed files and inject sanitized content into agent context.

### REGRESSION — BackendAdapter Method Count Test (qqbot-channel)

`test_backend_adapter_has_exactly_9_methods` fails because `backend_family()` was added to `BackendAdapter` Protocol (now 10 methods) for SAFE-06 cross-family review enforcement, but the v1.8 safety baseline test wasn't updated.

**Fix:** Update `packages/channels/qqbot/tests/test_v1_8_safety_baseline.py` line 58 to assert 10 methods instead of 9.

### PRE-EXISTING — QQ Bot Wakeup Recall Test (qqbot-channel)

`test_recall01_c2c_over_window_wakeup_omits_msg_id_on_wire` fails on baseline (not caused by v3.1). Present before any v3.1 changes.
