# Plan 88-01: Core 13 Unified Event Types

## Goal

Define the 13-category unified event vocabulary (15 enum values including 3 tool_call sub-types) with JSON Schema, Python bindings, and TypeScript interfaces. This is the tracer slice — the protocol foundation that every subsequent plan and phase depends on. The event vocabulary is isomorphic to ACP v1 `session/update` per V3-PRD §3.2.

## Reversibility Gate

**One-way-door:** Expanding `RunEventType` enum in `enums.py` and `run_event_type` in `common.schema.json`. Once new values are added, downstream code may depend on them. The strategy is **additive only** — keep all 9 existing V2 enum values intact, add 15 new V3 values alongside. No V2 value is removed, renamed, or changed. Task 01-01 is a checkpoint to confirm this strategy before implementation.
