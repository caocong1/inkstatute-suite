# Plan 88-05: Bot Degradation Aggregator — Declarative Rules and Deterministic Output

## Goal

Implement a pure-function bot degradation aggregator that takes a sequence of `RunEvent` dicts and produces a deterministic `BotDelivery` result. Each of the 13 event categories has a declared degradation behavior (silent, buffer, deliver, discard, fold, first-then-silent, attach, on-failure). Given the same input event sequence, the aggregator always produces the same output — testable with golden fixtures.

1. `DegradationCategory` StrEnum with 8 members:

   - `DELIVER = "deliver"` — send as final message/card/file
   - `DISCARD = "discard"` — drop (no business value for bots)
   - `FOLD = "fold"` — collapse to business prompt
   - `FIRST_THEN_SILENT = "first_then_silent"` — first occurrence delivered, subsequent silent
   - `ATTACH = "attach"` — append to final delivered message
   - `ON_FAILURE = "on_failure"` — only deliver on failure, as business prompt

2. `DEGRADATION_RULES: dict[str, DegradationCategory]` — mapping from event type string to degradation category per V3-PRD §3.2:
   - `"session.started"` → `SILENT`
   - `"message.delta"` → `BUFFER`
   - `"message.completed"` → `DELIVER`
   - `"thought.delta"` → `DISCARD`
   - `"tool_call.started"` → `FOLD`
   - `"tool_call.delta"` → `FOLD`
   - `"tool_call.completed"` → `FOLD`
   - `"plan.updated"` → `FIRST_THEN_SILENT`
   - `"phase.changed"` → `FIRST_THEN_SILENT`
   - `"elicitation.requested"` → `DELIVER`
   - `"permission.requested"` → `DELIVER`
   - `"artifact.created"` → `DELIVER`
   - `"citation.recorded"` → `ATTACH`
   - `"run.state_changed"` → `ON_FAILURE`
   - `"error"` → `ON_FAILURE`

3. `@dataclass(frozen=True, slots=True)` `BotDelivery` — the output of the aggregator:
   - `final_message: str | None = None` — the final delivered text message (from buffered message.deltas + message.completed)
   - `intermediate_prompts: list[str] = field(default_factory=list)` — business prompts for "still processing" (from first plan.updated/phase.changed, folded tool_calls)
   - `cards: list[JsonObject] = field(default_factory=list)` — delivered cards (elicitation, permission)
   - `files: list[JsonObject] = field(default_factory=list)` — delivered files (artifact.created)
   - `citations: list[JsonObject] = field(default_factory=list)` — attached citations
   - `error_prompt: str | None = None` — business prompt on failure (from on-failure events)
   - `delivered: bool = False` — whether any content was delivered to the user

4. `aggregate_events(events: list[dict]) -> BotDelivery` — the pure-function aggregator. Takes a list of RunEvent dicts (each with at minimum `event_type`, `seq`, and optional `payload`/`message_delta`/`error` fields). Processing logic:
   - Sort events by `seq` ascending (handle out-of-order)
   - For each event, look up `DEGRADATION_RULES[event_type]`:
     - `SILENT`: skip
     - `DISCARD`: skip
     - `BUFFER`: append `message_delta` (or `payload.delta`) to a buffer string
     - `DELIVER`: if `message.completed`, set `final_message` to `payload.content` (or buffered deltas if no explicit content). If `elicitation.requested` or `permission.requested`, append payload to `cards`. If `artifact.created`, append payload to `files`. Set `delivered=True`.
     - `FOLD`: if this is the first tool_call event in the sequence, append a business prompt like `"正在检索法规…"` to `intermediate_prompts`. Subsequent tool_call events are silent.
     - `FIRST_THEN_SILENT`: if this is the first plan.updated or phase.changed event, append `"仍在处理"` to `intermediate_prompts`. Subsequent are silent.
     - `ATTACH`: append `payload.citations` to `citations` list.
     - `ON_FAILURE`: if `run.state_changed` with status `failed`, or `error` event, set `error_prompt` to a business prompt like `"处理失败，请稍后重试或联系管理员"`. Set `delivered=True`.
   - If `final_message` is set and `citations` is non-empty, append citations to `final_message` as a formatted reference section.
   - Return `BotDelivery`.

5. `get_degradation_category(event_type: str) -> DegradationCategory | None` — looks up `DEGRADATION_RULES`, returns `None` for unknown event types (V2 event types like `state_changed` that don't have V3 degradation rules).

The function must be deterministic: same input always produces same output. No random, no time-dependent behavior, no side effects.

Update `__init__.py`: add `from .bot_degradation import DegradationCategory, BotDelivery, DEGRADATION_RULES, aggregate_events, get_degradation_category`. Add all to `__all__`.
</action>
