# Plan 92-04: Wave 3 — Remaining components, Workspace orchestrator, SDK expansion, web_chat deprecation, gate verification, phase complete

## Goal

Complete the shared UI core by porting the remaining 9 components (Icons, MentionComposer, MentionMenu, TitleBar, HomePage, ConversationDrawer, Workspace, AgentTracePanel, jsonHighlight), expanding `platform-sdk-ts` with Gateway endpoints from Phase 91's OpenAPI, marking `apps/web_chat` deprecated (UI-06), and running the final gate verification to confirm all 6 success criteria are met.

This plan brings the total ported component count to 17 components + 2 utils + 1 test = 20 items (the 3 deferred components — SettingsPanel, SkillRefinementPanel, AppUpdateBanner — are Phase 94 scope). The `Workspace` component is the layout orchestrator that ties together ChatPanel + DocPreview + CitationPanel with a resizable splitter. The `AgentTracePanel` is ported behind a dev flag.

After this plan, the phase is complete: `packages/ui-core` has build artifacts and type declarations, all 13 event types are consumed, `apps/web_chat` is deprecated, and all gates are green.

## Reversibility Gate

**One-way-door: Marking `apps/web_chat` deprecated.** Once the prototype renderer is marked deprecated, it signals that ui-core is the single chat UI implementation. Strategy: add a deprecation header comment to `apps/web_chat/src/render.ts` and `apps/web_chat/src/index.ts` pointing to `@inkstatute/ui-core`. Do NOT delete the files — removal happens in Phase 104 (Legacy Convergence). The deprecation is a documentation change, not a code deletion.

**One-way-door: Expanding `platform-sdk-ts` with Gateway endpoints.** Regenerating `index.ts` from the expanded OpenAPI spec adds new client methods (`submitElicitation`, `getArtifact`, `uploadAttachment`, `submitFeedback`, `listSkills`). Once added, ui-core components depend on these methods. Strategy: the regeneration is done via `generate_sdk.py` (the existing codegen script), preserving the auto-generated nature of the file. The `streamRun()` method must be patched to accept an optional `lastEventId` parameter (for reconnection support).
