### Task 100-02-01: Implement LlmProvider Protocol + StreamDelta union types

**Action**: Create `model/provider.py` with the unified provider abstraction.

**`StreamDelta` union types** (frozen dataclasses):
- `ContentDelta(content: str)` — text content streaming
- `ReasoningDelta(reasoning: str)` — thinking/reasoning content streaming (maps to `thought.delta`)
- `ToolCallDelta(tool_call_id: str, tool_name: str, arguments: str)` — tool call from LLM (arguments is JSON string)
- `UsageDelta(usage: dict)` — token usage (prompt_tokens, completion_tokens, total_tokens)
- `FinishDelta(finish_reason: str)` — stream end signal

**`ChatRequest` dataclass** (frozen):
- `messages: list[dict]` — chat messages (role + content)
- `tools: list[dict] | None = None` — tool definitions (OpenAI function-calling format)
- `model: str | None = None` — model name override
- `max_tokens: int | None = None` — response token limit
- `temperature: float | None = None` — sampling temperature
- `stream: bool = True` — always True (unified streaming)

**`LlmProvider` Protocol**:
```python
class LlmProvider(Protocol):
    async def chat_stream(self, request: ChatRequest) -> AsyncIterator[StreamDelta]: ...
    def model_name(self) -> str: ...
    def supports_tools(self) -> bool: ...
```

**`UsageAccumulator` helper class**: Accumulates `UsageDelta` across a single stream (sums prompt_tokens, completion_tokens, total_tokens). Provides `to_dict()` for attaching to event metadata.

### Task 100-02-02: Implement FixtureProvider with TurnScript for testing

**Action**: Create `fixtures.py` with `FixtureProvider` and `TurnScript` for testing the turn loop without external LLM calls.

**`TurnScript` dataclass** (frozen):
- `deltas: list[StreamDelta]` — pre-configured stream deltas for this turn
- `delay_seconds: float = 0.0` — configurable delay before yielding each delta (for silence threshold testing)
- `error: Exception | None = None` — if set, the provider raises this error instead of yielding deltas

**`FixtureProvider` class**:
- `__init__(self, script: list[TurnScript], *, model_name: str = "fixture", supports_tools: bool = True)`
- Implements `LlmProvider` Protocol
- `chat_stream(request)`: Pops the next `TurnScript` from the script (round-robin). If `TurnScript.error` is set, raises it. Otherwise, yields each delta from `TurnScript.deltas` with optional `asyncio.sleep(delay_seconds)` between yields.
- Tracks `call_count` (how many times `chat_stream` was called) for turn limit testing
- If script is exhausted, raises `RuntimeError("fixture script exhausted")`
- `model_name()` returns `"fixture"`
- `supports_tools()` returns the configured value

**What to add**:
- `OpenAIStreamProvider` class implementing `LlmProvider` Protocol

  - `choices[0].delta.content` → `ContentDelta`
  - `choices[0].delta.reasoning_content` (if present) → `ReasoningDelta`

- Tool call accumulation: OpenAI streams tool calls in fragments (function name in first chunk, arguments in subsequent chunks). - Transport abstraction: `OpenAITransport` Protocol with both `create_chat_completion()` (non-streaming) and `create_chat_completion_stream()` (streaming) methods. Tests inject `FakeOpenAITransport` with pre-configured streaming responses.

### Task 100-02-04: Merge Anthropic runner with streaming + tool call support

**What to add**:
- `AnthropicStreamProvider` class implementing `LlmProvider` Protocol
- `chat_stream(request: ChatRequest) -> AsyncIterator[StreamDelta]`: Calls the transport's streaming method. Anthropic streaming uses SSE events with different types:
  - `content_block_start` with `type: "text"` → start of text content
  - `content_block_delta` with `type: "text_delta"` → `ContentDelta`
  - `content_block_delta` with `type: "thinking_delta"` → `ReasoningDelta` (if extended thinking enabled)
  - `content_block_start` with `type: "tool_use"` → `ToolCallDelta` (tool call start)
  - `content_block_delta` with `type: "input_json_delta"` → accumulate tool call arguments
  - `content_block_stop` → tool call complete, yield accumulated `ToolCallDelta`
  - `message_delta` with `usage` → `UsageDelta`
  - `message_stop` → `FinishDelta`
- System prompt handling: Anthropic uses top-level `system` parameter (not in messages array). The runner extracts system messages from `ChatRequest.messages` and moves them to the `system` parameter.
- Tool definitions: Convert from OpenAI function-calling format to Anthropic tool format if needed.

### Task 100-02-07: Implement gateway components wrapper (circuit breaker + rate limiter + cost tracker)

**Action**: Create `model/gateway_components.py` that wraps the model-gateway components for use by the agent-core model layer.

**`GatewayComponents` class**:
- `__init__(self, *, circuit_registry: CircuitBreakerRegistry | None = None, rate_limiter: RateLimiter | None = None, cost_tracker: CostTracker | None = None, tenant_id: str = "default", matter_id: str | None = None)`
- If components are `None`, creates default instances (pass-through mode — no limits, no budgets)
- `async def before_call(self, provider_id: str) -> bool`: Check circuit breaker (`can_execute`), check rate limit (`check_rpm`). Returns `True` if call should proceed, `False` if blocked.
- `async def after_call(self, provider_id: str, success: bool, usage: dict | None = None)`: Record success/failure in circuit breaker, record request in rate limiter, record usage in cost tracker.
- `get_usage_summary() -> dict`: Return accumulated usage for the current turn.

**`ProtectedProvider` wrapper class**:
- Wraps any `LlmProvider` with gateway component checks
- `chat_stream(request)`: Calls `before_call()`, if blocked raises an error event. Otherwise, delegates to the wrapped provider's `chat_stream()`. After streaming completes, calls `after_call()` with success/failure and accumulated usage.
- `model_name()` and `supports_tools()` delegate to the wrapped provider.
