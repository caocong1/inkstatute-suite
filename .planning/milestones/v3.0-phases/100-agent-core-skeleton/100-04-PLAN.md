### Task 100-04-02: Write silence threshold verification test (no gaps > 5s)

**Action**: Create `tests/test_silence_threshold.py` that verifies the key Phase 100 success criterion: no event silence period exceeds the threshold during tool rounds.

**Test approach**:
1. Use `FixtureProvider` with configurable delays between deltas (e.g., `delay_seconds=8` — longer than the 5s threshold)
2. Use injectable monotonic clock in `EventEmitter` to control time progression
3. Run the turn loop and collect all emitted `RunEvent` objects
4. Calculate gaps between consecutive events: `gap[i] = occurred_at[i+1] - occurred_at[i]`
5. Assert: `max(gaps) <= silence_threshold_seconds + heartbeat_tolerance` (e.g., `max_gap <= 5.5`)
6. Assert: heartbeat `thought.delta` events with `metadata={"heartbeat": true}` are present during long operations
7. Assert: at least one `thought.delta` or `tool_call.*` event is emitted during each tool round

**Test scenarios**:
- **Long LLM call**: `FixtureProvider` with `delay_seconds=8` before first delta → heartbeat should fire
- **Long tool execution**: Tool executor with `asyncio.sleep(8)` → heartbeat should fire during tool execution
- **Multi-round with delays**: 3 rounds, each with 6s delay → heartbeats in each round
- **No delay (fast)**: All deltas immediate → no heartbeats needed, no gaps > threshold
