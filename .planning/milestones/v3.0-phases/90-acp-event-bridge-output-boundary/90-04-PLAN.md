# Plan 04: Full Bidirectional Roundtrip Tests + Permission Safety Double-Layer + Full Gate Suite Green

## Goal

Prove that Phase 90's success criteria are fully met: (1) every ACP `session/update` variant roundtrips through the bridge with semantic equivalence (ACP → unified → ACP response), (2) permission safety is enforced at both the adapter layer (existing) and the bridge layer (new) — no `auto_approve` / `allow_once` path exists, and (3) all gates (existing + `acp-event-bridge`) are green. This plan integrates the bridge, output filter, and privacy scanner into end-to-end tests that verify the complete Phase 90 contract.

## Reversibility Gate

**One-way-door:** The roundtrip test fixtures establish the golden fixture set for bidirectional mapping. Once these fixtures are locked, any change to the forward or reverse mapping that breaks roundtrip equivalence will fail the tests. Strategy: the fixtures are derived from the ACP v1 spec (RESEARCH.md §1, §6) and the existing forward mapping in `event_mapping.py` — they are stable by definition. The roundtrip tests use field-by-field equivalence checks, not fuzzy matching, so any semantic loss is caught.

**One-way-door:** The permission safety double-layer test asserts that no `allow_once` or `auto_approve` path exists. Once this test is in place, any future code that introduces an auto-approval path will fail the test. Strategy: this enforces the AGENTS.md binding constraint ("Permission requests must never be auto-approved server-side") — it is a safety assertion, not a design choice.
