# Plan 90-03: Privacy Scanning & Secrets Detection — ACP-Specific Secret Patterns, Reference-First Logging Enforcement

## Goal

Implement `privacy_scan.py` with ACP-specific secret pattern detection and reference-first logging enforcement for all bridge output events. This module scans unified events produced by the bridge for secret patterns (API keys, tokens, ACP subprocess credentials, internal paths, provider leaks) and asserts that no bridge event stores sensitive full text — all events must use `raw_payload_ref` (hash + length) instead.

This plan depends on Plan 90-02 because both plans modify `__init__.py` — Plan 90-02 adds output filter exports first, then this plan adds privacy scan exports.

## Reversibility Gate

**One-way-door:** The set of secret patterns detected by the privacy scanner defines what content is considered sensitive. Once a pattern is added, removing it would allow previously-caught secrets to pass through undetected. Strategy: the patterns are derived from two sources: (1) the existing patterns in `output_boundary.py` (already production-validated) and (2) ACP-specific patterns from RESEARCH.md §4 (HERMES_HOME paths, ACP env vars). Both sources are stable — the existing patterns have been in production since V2, and the ACP patterns are dictated by the ACP protocol's credential model.

**One-way-door:** The reference-first logging enforcement (`raw_payload_ref` instead of full text) is a binding constraint from AGENTS.md. Once the scanner asserts that no event stores full text, any future code that stores full text will fail the privacy scan test. Strategy: this is a safe constraint — it enforces an existing binding decision, not a new one.

<action>
Create `packages/acp-event-bridge/src/inkstatute_acp_event_bridge/privacy_scan.py`. This module scans bridge output events for secret patterns and enforces reference-first logging.

Define:

1. A frozen slotted dataclass `ScanResult` with fields: `clean: bool`, `findings: list[dict]`, `event_id: str`, `event_type: str`. Each finding in `findings` is a dict with `rule_id: str`, `matched_pattern: str` (the pattern name, not the actual secret text), `field_path: str` (which field in the event contained the match), `audit: dict` (hash prefix + length of the matched value, no original text).

2. A constant `_SECRET_PATTERNS: tuple[tuple[str, re.Pattern[str]], ...]` — compiled regex patterns for secret detection. Reuse the pattern categories from `output_boundary.py` and add ACP-specific patterns:
   - `"secret_like"`: `r"\b(?:access|refresh|api|client|encoding)[_-]?(?:token|key|secret)\b"` (from output_boundary.py)
   - `"secret_assignment"`: `r"\b(?:token|secret|key)\s*[:=]"` (from output_boundary.py)
   - `"internal_path"`: `r"(?:^|\s)(?:/[^ \n\t]+){2,}"` (from output_boundary.py)
   - `"windows_path"`: `r"[a-z]:\\[^ \n\t]+"` (from output_boundary.py)
   - `"hermes_home_path"`: `r"/home/[^/]+/\.hermes"` (ACP-specific — RESEARCH.md §4)
   - `"hermes_dot_path"`: `r"\.hermes[^/]"` (ACP-specific — RESEARCH.md §4)
   - `"acp_env_secret"`: `r"\b(?:HERMES_HOME|ACP_[A-Z_]+|AGENT_[A-Z_]+)\s*[:=]\s*\S+"` (ACP-specific — RESEARCH.md §4)
   - `"provider_leak"`: `r"\b(?:model[:\s]|provider[:\s]|api[_-]?key|quota|token[_\s-]?usage)(?!\w)"` (from output_boundary.py)
   - `"api_error"`: `r"\b(?:api key invalid|quota exceeded|rate limit retry|insufficient quota)\b"` (from output_boundary.py)
   - `"acp_debug"`: `r"\b(?:acp:|agent-client-protocol:)"`
   - `"profile_path"`: `r"\bprofile path\b"` (from channel-core output_policy.py)
   - `"env_secret_combo"`: `r"\benv\b.*\b(?:secret|token|key)\b"` (from channel-core output_policy.py)

3. A constant `_SENSITIVE_FIELD_NAMES: frozenset[str]` — field names in event payloads that are considered sensitive and must use `raw_payload_ref` instead of full text: `"content"`, `"delta"`, `"raw_input"`, `"raw_output"`, `"text"`, `"data"`, `"body"`. These fields should be checked for both secret patterns AND reference-first compliance.

4. A function `_audit_value(value: str, *, rule_id: str, field_path: str) -> dict` — returns `{"rule_id": rule_id, "field_path": field_path, "input_hash_prefix": hashlib.sha256(value.encode("utf-8")).hexdigest()[:16], "input_length": len(value), "privacy": "no_original_text_stored"}`. No original text in the audit.

5. A function `_scan_string(value: str, field_path: str) -> list[dict]` — scans a single string value against all `_SECRET_PATTERNS`. Returns a list of finding dicts (each with `rule_id`, `matched_pattern` name, `field_path`, and `audit`). Does NOT include the matched text itself — only the pattern name and audit metadata.

6. A function `_scan_dict(obj: dict, field_path: str = "") -> list[dict]` — recursively scans all string values in a dict. For each key, constructs the field path as `f"{field_path}.{key}"` (or just `key` if `field_path` is empty). For nested dicts, recurses. For lists, scans each element with path `f"{field_path}.{key}[{i}]"`. Returns aggregated findings.

7. A function `scan_event(event: RunEvent) -> ScanResult` — scans a `RunEvent` for secret patterns. Scans `event.payload` (all string values recursively) and `event.metadata` (all string values recursively). Returns a `ScanResult` with `clean=True` if no findings, `clean=False` if any secrets detected. The `event_id` and `event_type` are copied from the event.

8. A function `scan_events(events: list[RunEvent]) -> list[ScanResult]` — scans a list of events, returns a list of `ScanResult` objects (one per event). Events with no findings have `clean=True`.

9. A function `assert_reference_first(event: RunEvent) -> bool` — checks that an event uses reference-first logging. Returns `True` if the event's metadata contains a `raw_payload_ref` key (or if the event type does not require reference-first logging — e.g., elicitation and permission events which need their content for user interaction). Returns `False` if a sensitive field (`content`, `delta`, `text`, `data`, `body`) exists in the payload but no `raw_payload_ref` is present in metadata. This enforces the AGENTS.md constraint: "Contract logs prefer references such as raw_payload_ref and must not store sensitive full text by default."

10. A function `assert_all_reference_first(events: list[RunEvent]) -> list[str]` — checks all events for reference-first compliance. Returns a list of event_ids that violate the reference-first rule (empty list if all compliant).

11. A constant `EVENT_TYPES_REQUIRING_RAW_PAYLOAD_REF: frozenset[str]` — event types whose payloads contain sensitive content fields and must have `raw_payload_ref` in metadata: `"message.completed"`, `"tool_call.completed"`, `"artifact.created"`, `"citation.recorded"`. Event types like `"message.delta"`, `"thought.delta"`, `"elicitation.requested"`, `"permission.requested"` are exempt because their content is needed for real-time user interaction or is inherently non-sensitive (short deltas).

Import `re`, `hashlib` from stdlib. Import `RunEvent` from `platform_runtime.protocols`. Import `RunEventType` from `platform_contract.enums`.

The scanner must NEVER include the actual matched secret text in any finding — only the pattern name, field path, and audit metadata (hash prefix + length).
