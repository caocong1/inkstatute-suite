# Plan 89-03: Subprocess Lifecycle Management — Per-Session Cleanup, Timeout Recovery, Crash Restart, Orphan Detection

## Goal

Implement controlled subprocess lifecycle for ACP per-session mode: session-end cleanup, timeout recovery, crash detection and restart, and orphan process prevention. Tests must assert no orphan processes remain after session close, timeout, or crash. This module is the safety net that makes `per_session` mode production-usable at single-firm scale (≤50 lawyers).

## Reversibility Gate

**One-way-door:** The lifecycle cleanup strategy (atexit handler + context manager + orphan detection) becomes a runtime invariant once deployed. Strategy: implement cleanup as an additive module (`lifecycle.py`) that wraps the existing `ACPClient`/`StdioACPTransport` from Plan 01 — no changes to those modules. The `atexit` handler is registered at module import time and is idempotent (safe to call multiple times). Task 03-01 is a checkpoint to verify the echo agent can be spawned, killed, and detected as dead before building the full lifecycle manager.

</read_first>
<action>
Create `packages/acp-client/src/inkstatute_acp_client/lifecycle.py`. Define a dataclass `SubprocessInfo` with fields: `pid: int`, `session_id: str | None`, `started_at: float`, `last_activity: float`, `process: asyncio.subprocess.Process | None = None`. Define a class `SubprocessLifecycleManager`:

- `__init__(self, timeout_seconds: float = 300.0, restart_on_crash: bool = True, max_restarts: int = 1)` — stores config, creates `_subprocesses: dict[str, SubprocessInfo]` (keyed by a lifecycle_id), `_atexit_registered: bool = False`. Registers an `atexit` handler `self._atexit_cleanup` if not already registered.

- `register(self, lifecycle_id: str, pid: int, process: asyncio.subprocess.Process | None = None, session_id: str | None = None) -> None` — creates a `SubprocessInfo` with `started_at` and `last_activity` set to `time.monotonic()`, stores in `_subprocesses`.

- `touch(self, lifecycle_id: str) -> None` — updates `last_activity` for the given lifecycle_id to `time.monotonic()`. Raises `KeyError` if not registered.

- `async cleanup(self, lifecycle_id: str) -> None` — performs session-end recovery: (1) looks up `SubprocessInfo`, (2) if process is available, sends `SIGTERM` via `process.terminate()`, (3) waits up to 5 seconds for process to exit via `asyncio.wait_for(process.wait(), timeout=5.0)`, (4) if still alive, sends `SIGKILL` via `process.kill()`, (5) waits up to 2 more seconds, (6) removes from `_subprocesses`. Catches `ProcessLookupError` (already dead — fine). Logs the cleanup action.

- `async cleanup_all(self) -> None` — calls `cleanup` for every registered lifecycle_id. Used by atexit handler and context manager `__aexit__`.

- `async check_timeouts(self) -> list[str]` — iterates `_subprocesses`, finds any where `time.monotonic() - last_activity > timeout_seconds`, calls `cleanup` for each, returns list of cleaned-up lifecycle_ids.

- `async detect_crash(self, lifecycle_id: str) -> bool` — checks if the process has exited unexpectedly: if `process` is available and `process.returncode is not None` and the process was not explicitly cleaned up (still in `_subprocesses`), returns `True`. Otherwise `False`.

- `async restart_if_needed(self, lifecycle_id: str, restart_command: tuple[str, ...], env: dict[str, str] | None = None) -> int | None` — if `detect_crash` returns `True` and `restart_on_crash` is `True` and restart count < `max_restarts`: (1) cleanup the old process, (2) spawn a new subprocess via `asyncio.create_subprocess_exec(*restart_command, stdin=PIPE, stdout=PIPE, stderr=PIPE, env=env)`, (3) register the new PID, (4) return the new PID. If max restarts exceeded, return `None`.

- `get_active_pids(self) -> list[int]` — returns PIDs of all registered subprocesses.

- `_atexit_cleanup(self) -> None` — synchronous atexit handler that iterates `_subprocesses` and sends `SIGKILL` to any still-alive process (best-effort, no async). Uses `os.kill(pid, signal.SIGKILL)` wrapped in try/except.

- `async __aenter__(self) -> SubprocessLifecycleManager` — returns self.
- `async __aexit__(self, exc_type, exc_val, exc_tb) -> None` — calls `await self.cleanup_all()`.

Define a standalone async function `assert_no_orphans(manager: SubprocessLifecycleManager, grace_seconds: float = 2.0) -> None` that: (1) calls `await manager.cleanup_all()`, (2) waits `grace_seconds`, (3) for each PID that was in `manager.get_active_pids()` before cleanup, checks `os.kill(pid, 0)` — if any PID is still alive, raises `RuntimeError(f"orphan process detected: pid {pid} still alive after cleanup")`. This function is used by tests to assert no orphan processes.

Import `asyncio`, `atexit`, `os`, `signal`, `time`, `logging`, `dataclasses` from stdlib.
</action>

  - `restart_if_needed` returns `None` when max_restarts is exceeded
  - `assert_no_orphans` raises `RuntimeError` if any PID is still alive after cleanup + grace period
