# Plan 42-03 — admin_api_enabled Feature Flag, V2 Gate Integration, and Contract Freeze Verification

## Goal

Verify that `admin_api_enabled` defaults to `False` and that the Admin Console API refuses all requests when the flag is off (even with a valid token). Register the `admin-console-api` gate in `scripts/run_v2_gates.py` and add `services/admin-console-api/src` to the `compileall` gate. Run the full V2 gate suite to confirm all 14 gates stay green and the SAFETY-02/06 contract freeze tests pass (no contract drift).

This plan satisfies:
- SC3 (feature flag portion): Operator can verify that `admin_api_enabled` defaults to `False` and that the Admin Console API refuses all requests when the flag is off.
- GATE-01 (partial): New `admin-console-api` gate registered in `run_v2_gates.py`.
- SAFETY-02/06: Contract freeze verified — no edits to `packages/platform-contract/` or `packages/platform-runtime/protocols.py` or `packages/platform-runtime/src/platform_runtime/feature_flags.py`.

## Context

- The `admin_api_enabled` feature flag already exists in `RuntimeFeatureFlags` (`packages/platform-runtime/src/platform_runtime/feature_flags.py:22`) with default `False`. Phase 42 does NOT modify this file — it wires the flag into the API handler (done in Wave 1) and verifies the default-off behavior.
- The `handle_admin_get` function (from Wave 1, `api.py`) calls `feature_flags.require_enabled("admin_api_enabled")` before processing any request. When the flag is `False`, `RuntimeFeatureDisabledError` is raised and the handler returns 403 `admin_api_disabled`.
- The V2 gate suite currently has 13 gates (`scripts/run_v2_gates.py:67-156`). Phase 42 adds a 14th gate for `admin-console-api`.
- The `compileall` gate (`run_v2_gates.py:133-155`) compiles all source directories. `services/admin-console-api/src` must be added.
- SAFETY-02 contract-count freeze tests at `packages/contract-test-suite/tests/test_contract_count_freeze.py` assert `BACKEND_ADAPTER_METHOD_COUNT = 9`, `ADAPTER_CAPABILITY_SET_FIELD_COUNT = 14`, `CHANNEL_ADAPTER_METHOD_COUNT = 6` — these must remain green.
- Contract freeze (SAFETY-02, SAFETY-06): No changes to `packages/platform-contract/` or `packages/platform-runtime/protocols.py`.
