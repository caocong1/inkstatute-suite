# Plan 41-02 — Trace Reconstruction by trace_id and CSV/JSON Export

## Goal

Add a `/traces/{trace_id}` endpoint that reconstructs all related events (AgentTurn, RouteDecision, ExecutionTrace, AgentResult, FeedbackEvent) in occurrence order, and a `/export` endpoint that exports conversation-read-view query results as CSV or JSON. Both endpoints route responses through `scrub_contract_payload`.

This plan satisfies:
- READVIEW-02: Operator can query `conversation-read-view` by `trace_id` and receive all related events reconstructed in occurrence order.
- READVIEW-03 (export portion): Operator can export conversation-read-view query results as CSV or JSON.

## Context

- The read model already indexes `trace_to_task_id: dict[str, str]` (`read_model.py:117-121`) by extracting `trace_id` from `ExecutionTrace.trace_id` and `AgentResult.metadata.trace_id`. This is the seed for trace reconstruction.
- `from_records` (`read_model.py:44-127`) sorts records by `(occurred_at, ingested_at, seq)` and groups by `turn_id`. It currently discards per-event records after building turn views (keeps only the first of each event type per turn). Phase 41 extends the read model to retain a `trace_events` index for full reconstruction.
- The API entry point `handle_get` (`api.py:11-58`) routes by path prefix. New routes are added as new `if` branches — existing routes are untouched.
- `scrub_contract_payload` (`privacy.py:51-62`) raises `ValueError` on forbidden keys. All new endpoints must route through it.
- The package has `dependencies = []` — CSV export uses stdlib `csv` module only.
- Contract event types (read-only, frozen — `packages/platform-contract/src/platform_contract/events.py`):
  - AgentTurn: `turn_id`, `conversation_id`, `channel`, `user_id`, `received_at` — join key `turn_id`.
  - RouteDecision: `route_decision_id`, `turn_id`, `primary_skill`, `mode`, `created_at` — join key `turn_id`.
  - ExecutionTrace: `trace_id`, `turn_id`, `occurred_at`, `seq` — join keys `turn_id` + `trace_id`.
  - AgentResult: `result_id`, `turn_id`, `status`, `metadata.trace_id` — join key `turn_id` (+ `metadata.trace_id`).
  - FeedbackEvent: `feedback_id`, `turn_id`, `conversation_id`, `created_at` — join key `turn_id`.
- Contract freeze (SAFETY-02, SAFETY-06): No changes to `packages/platform-contract/` or `packages/platform-runtime/protocols.py`.
