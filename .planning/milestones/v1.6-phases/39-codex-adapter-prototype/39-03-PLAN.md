# Plan 39-03 — V2 Gate Integration and Contract Freeze Verification

## Goal

Wire the new `packages/backends/codex/` package into the V2 gate suite by adding a dedicated `codex-backend` gate to `scripts/run_v2_gates.py`, adding `codex_backend_src` to the `contract-test-suite` gate PYTHONPATH and `compileall` paths, and adding a contract-test-suite test that verifies the real `build_codex_manifest()` passes through `select_agent_backend` with `live_acceptance_allowed=False`. Verify that the existing SAFETY-02 contract-count freeze tests (9 methods, 14 fields) remain green and the gate count rises from 11 to 12.

This plan completes ADAPTER-01 integration:
- The new `codex-backend` gate runs all Codex adapter tests in the full V2 gate suite.
- The `contract-test-suite` gate can import `inkstatute_backends_codex` for cross-package contract assertions.
- `compileall` covers the new package source directory.
- All 12 gates pass (11 existing + 1 new).

- V2 gate count is currently 11 (Phase 38 added the `router-service` gate). Phase 39 adds a 12th `codex-backend` gate.
- `scripts/run_v2_gates.py` defines gates at lines 49-142. The `_gates()` function returns a tuple of `Gate` namedtuples.
- `codex_backend_src` path: `repo_root / "packages" / "backends" / "codex" / "src"`.
- The `contract-test-suite` gate PYTHONPATH (line 115) must include `codex_backend_src` so contract tests can import `inkstatute_backends_codex`.
- The `compileall` gate (lines 122-140) must include `"packages/backends/codex/src"`.
- The SAFETY-02 contract-count freeze tests at `packages/contract-test-suite/tests/test_contract_count_freeze.py` assert `BACKEND_ADAPTER_METHOD_COUNT = 9` and `ADAPTER_CAPABILITY_SET_FIELD_COUNT = 14` — these must remain green (no contract drift).
