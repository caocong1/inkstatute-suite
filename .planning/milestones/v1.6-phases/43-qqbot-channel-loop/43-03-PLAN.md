# Plan 43-03 — Feature Flag Default-Off + V2 Gate Integration + Contract Freeze Verification

## Goal

Verify that `qqbot_channel_enabled` defaults to `False` and that the QQBot adapter refuses ACK and delivery when the flag is off. Then integrate the QQBot channel into the V2 gate suite by adding a new `qqbot-channel` gate (14 → 15 gates), adding `channel-core/src` to the PYTHONPATH of the `wecom-service` and `contract-test-suite` gates, and updating `compileall` to include the new package source directories. Finally, verify that the contract freeze is not violated — `ChannelAdapter` still has 6 methods, `FeedbackSource` still has 4 values, and no files in `packages/platform-contract/`, `packages/platform-runtime/protocols.py`, or `packages/platform-runtime/src/platform_runtime/feature_flags.py` have been modified during Phase 43.

This plan satisfies:
- QQBOT-04: `qqbot_channel_enabled` defaults to `False`; QQ Bot feedback maps to existing `FeedbackEvent.source` enum values.
- SAFETY-04: all M2 feature flags (including `qqbot_channel_enabled`) default to `False`.
- GATE-01: V2 gate suite includes a new gate for the qqbot package, with all existing gates staying green.
- SAFETY-02: contract-count assertion test confirms `ChannelAdapter` Protocol method count is unchanged (6).
- SAFETY-06: contract freeze baseline hash test confirms no `packages/platform-contract/` schema files modified.

## Context

- Plan 43-01 (Wave 1) created the `packages/channel-core/` shared package and `packages/channels/qqbot/` package with `QQBotChannelAdapter`. Plan 43-02 (Wave 2) created the fixture-driven loop proof, idempotency tests, and feedback source mapping tests.
- The `qqbot_channel_enabled` feature flag already exists with default `False` in `packages/platform-runtime/src/platform_runtime/feature_flags.py:23`. Phase 43 does NOT modify `feature_flags.py` (contract freeze).
- The current V2 gate suite has 14 gates (defined in `scripts/run_v2_gates.py`). The gates are: `platform-contract`, `wecom-service`, `hermes-contract-layer`, `conversation-read-view`, `skill-registry`, `router-service`, `codex-backend`, `provider-model-backend`, `admin-console-api`, `feedback-service`, `phase7-privacy-boundary`, `contract-test-suite`, `v2-acceptance-traceability`, `compileall`.
- The `wecom-service` gate PYTHONPATH is `(wecom_src, platform_src, contract_src, platform_runtime_src)`. After Wave 1 extraction, wecom-service imports from `channel_core`, so `channel_core_src` must be added.
- The `contract-test-suite` gate PYTHONPATH includes many package sources. After Phase 43, `channel_core_src` and `qqbot_src` must be added for cross-package contract tests.
- The `compileall` gate compiles all package/service source directories. `packages/channel-core/src` and `packages/channels/qqbot/src` must be added.
- Contract freeze tests already exist: `packages/contract-test-suite/tests/test_contract_count_freeze.py` (asserts `CHANNEL_ADAPTER_METHOD_COUNT = 6`, `BACKEND_ADAPTER_METHOD_COUNT = 9`, `ADAPTER_CAPABILITY_SET_FIELD_COUNT = 14`) and `packages/contract-test-suite/tests/test_contract_freeze.py` (SHA-256 baseline hash comparison for 31 contract surface files). These tests must pass unchanged after Phase 43.
- Contract freeze (SAFETY-02, SAFETY-06): No changes to `packages/platform-contract/` or `packages/platform-runtime/protocols.py` or `packages/platform-runtime/src/platform_runtime/feature_flags.py`.
- Privacy: No literal secrets in plan or test files. Use `REDACTED` or short placeholders (< 12 chars).
