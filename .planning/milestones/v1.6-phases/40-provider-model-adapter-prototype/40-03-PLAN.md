<objective>

   - Import: `unittest`, `platform_runtime.output_boundary` (`BoundaryAction`, `DefaultAssistantOutputBoundary`), `wecom_service.output_policy` (`apply_output_policy`).
   - Define `NOISE_FIXTURES` as a list of `(backend, noise_text, expected_boundary_action, expected_policy_action, leaked_patterns)` tuples covering both Codex and provider_model noise:
     - **Provider model noise:**
       - `("provider_model", "model: gpt-4 generated this response", BoundaryAction.BLOCK, "block", ["gpt-4"])` — model name leakage, hard-blocked by `provider_leak` rule.
       - `("provider_model", "Error from gpt-4: rate limit exceeded", BoundaryAction.BLOCK, "block", ["gpt-4"])` — model name in error, hard-blocked by `provider_leak`.
       - `("provider_model", "api key invalid for provider", BoundaryAction.BLOCK, "block", [])` — API error, hard-blocked by `api_error` rule.
       - `("provider_model", "rate limit exceeded, retrying after 30s", BoundaryAction.REWRITE, "rewrite", ["rate limit"])` — rate-limit notice, rewritten by `rate_limit_notice` rule.
       - `("provider_model", "too many requests, please slow down", BoundaryAction.REWRITE, "rewrite", [])` — rate-limit variant, rewritten.
       - `("provider_model", "function call: get_weather(args={\"city\": \"HK\"})", BoundaryAction.BLOCK, "block", ["function call"])` — function call trace, hard-blocked by `function_trace` rule.
       - `("provider_model", "tool output: {\"result\": \"sunny\"}", BoundaryAction.BLOCK, "block", ["tool output"])` — tool output dump, hard-blocked by `function_trace`.
       - `("provider_model", "token usage report: 1234 tokens used", BoundaryAction.BLOCK, "block", ["token usage"])` — token usage report, hard-blocked by `function_trace`.
       - `("provider_model", "context window length exceeded", BoundaryAction.REWRITE, "rewrite", [])` — context window, rewritten.
       - `("provider_model", "insufficient quota for this month", BoundaryAction.BLOCK, "block", [])` — quota error, hard-blocked by `api_error`.
     - **Codex noise:**
       - `("codex", "codex thread started, turn.completed", BoundaryAction.ALLOW, "allow", [])` — Codex thread trace in business content (allowed if it's part of legal content — the boundary doesn't block "codex" or "thread" as words).
       - `("codex", "function_call_result: {\"output\": \"...\"}", BoundaryAction.BLOCK, "block", ["function_call_result"])` — function call result, hard-blocked by `function_trace`.
       - `("codex", "token_usage: {\"input\": 100, \"output\": 50}", BoundaryAction.BLOCK, "block", ["token_usage"])` — token usage, hard-blocked by `provider_leak` (matches `token[_\s-]?usage`).
       - `("codex", "rate limit retry in 60 seconds", BoundaryAction.BLOCK, "block", [])` — rate limit retry, hard-blocked by `api_error` (matches `rate limit retry`).
     - **Common noise (both backends):**
       - `("both", "traceback: RuntimeError at line 42", BoundaryAction.BLOCK, "block", ["traceback"])` — stack trace, hard-blocked by `debug_trace`.
       - `("both", "api_key=REDACTED", BoundaryAction.BLOCK, "block", ["api_key"])` — secret-like, hard-blocked by `secret_like`.
   - Test class `OutputBoundaryBackendNoiseTests(unittest.TestCase)`:
     - `setUp`: `self.boundary = DefaultAssistantOutputBoundary()`.
     - `test_provider_model_noise_blocked_or_rewritten_by_boundary`: for each provider_model fixture, call `self.boundary.apply("channel", text=noise_text)`, assert `decision.action == expected_boundary_action`. For BLOCK: `decision.visible_text is None`. For REWRITE: `decision.visible_text` is not None and does not contain any `leaked_patterns`. For ALLOW: `decision.visible_text == noise_text`.
     - `test_codex_noise_blocked_or_rewritten_by_boundary`: same for codex fixtures.
     - `test_common_noise_blocked_or_rewritten_by_boundary`: same for common fixtures.
     - `test_provider_model_noise_blocked_or_rewritten_by_output_policy`: for each provider_model fixture, call `apply_output_policy(noise_text)`, assert `decision.action == expected_policy_action`. For block: `decision.visible_text is None`. For rewrite: `decision.visible_text` does not contain any `leaked_patterns`. For allow: `decision.visible_text == noise_text`.
     - `test_codex_noise_blocked_or_rewritten_by_output_policy`: same for codex fixtures.
     - `test_no_backend_noise_reaches_visible_text`: for all BLOCK and REWRITE fixtures, assert that `leaked_patterns` do not appear in the visible text (if any). For BLOCK, visible_text is None. For REWRITE, check each leaked pattern is absent.
     - `test_model_name_gpt4_never_in_visible_output`: specifically assert that `"gpt-4"` never appears in any visible_text output for any fixture that contains `"gpt-4"` in the input.
     - `test_rate_limit_notice_is_rewritten_to_owned_notice`: for rate-limit fixtures that get REWRITE, assert the visible text is the owned service notice (check it's not the original text and does not contain "rate limit" or "retrying").
</action>
