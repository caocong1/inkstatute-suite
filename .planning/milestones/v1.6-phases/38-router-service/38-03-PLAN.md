# Plan 38-03 — V2 Gate Integration and Contract Freeze Verification

## Objective

Integrate the new `router-service` package into the V2 gate suite by adding a dedicated gate to `scripts/run_v2_gates.py`, updating the `compileall` gate to include the new source directory, adding the router-service source path to the `contract-test-suite` and `hermes-contract-layer` gate PYTHONPATHs, and updating the gate-count assertion from 10 to 11. Verify that all 11 gates pass green and that the SAFETY-06 contract freeze is not violated.

## Context

- Depends on Plan 38-01 (router-service package, RouterPort, RouterService, RULE strategy) and Plan 38-02 (SKILL strategy, mapper injection, None fallback) — all source and test files must exist.
- The V2 gate suite currently has 10 gates in `scripts/run_v2_gates.py` (lines 64-135). Phase 37 added the 10th `skill-registry` gate. This plan adds an 11th `router-service` gate.
- The gate-count assertion at `packages/contract-test-suite/tests/test_audit_v2_requirements.py:436` currently asserts `len(gate_names) == 10` — must be updated to 11.
- The `router-service` gate needs PYTHONPATH including `packages/router-service/src` (for `inkstatute_router_service`), `packages/platform-contract/src` (for `platform_contract` dependency), and `packages/skill-registry/src` (for `inkstatute_skill_registry` dependency used by SKILL strategy tests).
- The `hermes-contract-layer` gate needs `packages/router-service/src` and `packages/skill-registry/src` added to its PYTHONPATH so mapper injection tests can import `RouterPort` and `SkillRegistryPort`.
- The `compileall` gate must include `packages/router-service/src`.
- The `contract-test-suite` gate PYTHONPATH must include `router_service_src` so contract tests can import the router-service package if needed.
- Contract freeze test at `packages/contract-test-suite/tests/test_contract_freeze.py` compares schema file hashes against a v1.5 baseline — must stay green (no `packages/platform-contract/` modifications in Phase 38).
