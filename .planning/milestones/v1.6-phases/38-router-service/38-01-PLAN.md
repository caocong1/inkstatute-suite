# Plan 38-01 — Router-Service Package, RouterPort Protocol, RouterService, and RULE Strategy

## Objective

Create the `packages/router-service/` library package with the `RouterPort` Protocol, `RouterStrategy` enum (RULE, SKILL), the `RouterService` class, and the RULE strategy (keyword/regex intent classification). This plan delivers the ROUTER-01 core (injectable standalone router library producing `RouteDecision` events) and the RULE half of ROUTER-02 (intent classification via keyword/regex producing normalized `RouteDecision` records).

## Context

- `RouteDecision` already exists and is FROZEN at `packages/platform-contract/src/platform_contract/events.py:206-222` — no schema changes permitted (SAFETY-06 contract freeze).
- `RouteMode` enum exists at `packages/platform-contract/src/platform_contract/enums.py:164-168` with values: `MATCHED`, `SIMPLE_QA`, `SKIPPED`, `ZERO_MATCH`. RULE and SKILL are NOT new `RouteMode` values — they are router-service-internal strategies (`RouterStrategy` enum) that map onto the frozen `RouteMode` outcomes.
- `RouterPort` Protocol does NOT exist yet — must be created in this package, following the `SkillRegistryPort` pattern from `packages/skill-registry/src/inkstatute_skill_registry/registry.py:16-28`.
- The inline router is in `services/hermes-contract-layer/src/hermes_contract_layer/mapper.py` — `map_agent_end_context()` produces a `route_decision` dict (lines 92-117) via `_route_mode()` (lines 230-238). The standalone router must produce dicts with the same JSONL shape.
- `router_service_enabled` feature flag already exists at `packages/platform-runtime/src/platform_runtime/feature_flags.py:20` (default `False`) — no changes needed to `feature_flags.py`.
- The router must be a library package (NOT an HTTP service). Dependency graph: `hermes-contract-layer → router-service → {platform-contract, skill-registry}`. No circular imports.
- Package pattern follows `packages/skill-registry/` — `pyproject.toml`, `src/inkstatute_router_service/`, `tests/`.

6. Create `packages/router-service/src/inkstatute_router_service/service.py` with:
   - `from __future__ import annotations`
   - `from typing import Any, Mapping, TYPE_CHECKING`
   - `from platform_contract import RouteDecision, RouteMode`
   - `if TYPE_CHECKING:` block importing `from inkstatute_skill_registry import SkillRegistryPort` (avoids hard runtime dependency)
   - `from .strategies import RouterStrategy`
   - `from .classifier import classify_intent`
   - `ROUTER_SERVICE_VERSION = "0.1.0"` module-level constant
   - `class RouterService:` with docstring explaining it is stateless with two strategies (RULE, SKILL).
     - `__init__(self, skill_registry: "SkillRegistryPort | None" = None, strategy: RouterStrategy = RouterStrategy.RULE) -> None:` stores `self._registry = skill_registry` and `self._strategy = strategy`
     - `def decide(self, context: Mapping[str, Any]) -> RouteDecision:` — dispatches to `self._decide_skill(context)` if `self._strategy == RouterStrategy.SKILL`, else `self._decide_rule(context)`.
     - `def _decide_rule(self, context: Mapping[str, Any]) -> RouteDecision:` — RULE strategy: extract `message = context.get("message")`, call `classify_intent(message)`. If intent found and `self._registry` is not None, call `self._registry.search(category=intent)` — if results, pick first, set `mode=RouteMode.MATCHED`, `primary_skill=descriptor.skill_id`, `confidence=0.7`, `required_tools=list(descriptor.required_tool_refs)`, `matched_rule=f"rule:{intent}"`. If intent found but no registry or no results, `mode=RouteMode.SIMPLE_QA`, `confidence=0.5`, `primary_skill=None`. If no intent found, `mode=RouteMode.ZERO_MATCH`, `confidence=0.0`, `primary_skill=None`. Build and return a `RouteDecision` dataclass with `route_decision_id`, `turn_id`, `created_at` derived from context (use `context.get("route_decision_id", "")`, `context.get("turn_id", "")`, `context.get("created_at", "")`), `metadata={"router_strategy": "rule", "router_service_version": ROUTER_SERVICE_VERSION, "classified_intent": intent}`.
     - `def _decide_skill(self, context: Mapping[str, Any]) -> RouteDecision:` — SKILL strategy stub for this plan: if `self._registry` is None, return `RouteDecision(mode=RouteMode.ZERO_MATCH, ...)` with `metadata={"router_strategy": "skill", "router_service_version": ROUTER_SERVICE_VERSION}`. If registry is not None, check `context.get("skill_id")` — if present, call `self._registry.get_skill(skill_id)`, if found return `mode=RouteMode.MATCHED`, `primary_skill=descriptor.skill_id`, `confidence=1.0`, `required_tools=list(descriptor.required_tool_refs)`. If not found or no skill_id, return `mode=RouteMode.ZERO_MATCH`, `confidence=0.0`. Full SKILL strategy with `search()` is implemented in Plan 38-02. This stub is sufficient for RULE strategy tests.
     - Helper: `def _build_decision(self, context, mode, primary_skill, confidence, required_tools=None, matched_rule=None, reason=None, metadata_extra=None) -> RouteDecision:` constructs the frozen dataclass with all fields populated from context defaults plus the provided values.
