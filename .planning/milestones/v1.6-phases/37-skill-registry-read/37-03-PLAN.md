# Plan 37-03 — V2 Gate Integration and Contract Freeze Verification

## Objective

Integrate the new `skill-registry` package into the V2 gate suite by adding a dedicated gate to `scripts/run_v2_gates.py`, updating the `compileall` gate to include the new source directory, and adding the skill-registry source path to the `contract-test-suite` gate's PYTHONPATH. Verify that all gates (including the new one) pass green and that the SAFETY-06 contract freeze is not violated.

## Context

- Depends on Plan 37-01 (package structure, mapper, registry) and Plan 37-02 (API handler, discovery endpoint, feature flag integration) — all source and test files must exist.
- The V2 gate suite currently has 9 gates in `scripts/run_v2_gates.py`. This plan adds a 10th gate (`skill-registry`) and updates two existing gates (`compileall`, `contract-test-suite`).
- The `skill-registry` gate needs PYTHONPATH including `packages/skill-registry/src` (for `inkstatute_skill_registry`) and `packages/platform-contract/src` (for `platform_contract` dependency). The API tests also need `packages/platform-runtime/src` (for `RuntimeFeatureFlags`).
- Contract freeze test at `packages/contract-test-suite/tests/test_contract_freeze.py` compares schema file hashes against a v1.5 baseline — must stay green (no `packages/platform-contract/` modifications in Phase 37).
