<objective>
Add the policy-driven rolling summary pipeline layer on top of the existing RollingSummaryRecord and InMemoryRollingSummaryStore.

Purpose: long-running conversations need a trigger+producer pipeline that decides *when* to summarize and *how* to produce a safe summary ref — without ever embedding raw legal/customer text.
Output: RollingSummaryPolicy (thresholds), RollingSummaryTrigger (evaluation), RollingSummaryProducer (record creation), SummaryPrivacyError (fail-closed), and tests.
</objective>

<constraints>
- Do NOT change RollingSummaryRecord or InMemoryRollingSummaryStore in context_assembler.py.
- Do NOT change DefaultRunRuntime, WeCom channel, or ContextAssembler constructors.
- RollingSummaryProducer must accept source_refs as its primary input, not raw text strings.
- Privacy rejection must be recursive (same pattern as _validate_candidate in memory.py).
- New module is rolling_summary.py — keep context_assembler.py unchanged.
- All SQL/raw text checks use parameterized patterns, no eval or exec.
</constraints>

## Task 21-01-01: Create rolling_summary.py with SummaryPrivacyError and RollingSummaryPolicy

Create `packages/platform-runtime/src/platform_runtime/rolling_summary.py`.

**SummaryPrivacyError**: subclass `ValueError`, message includes the offending key.

**RollingSummaryPolicy** (`@dataclass(frozen=True, slots=True)`):
- `max_turn_count_trigger: int = 20` — trigger after this many turns
- `budget_pressure_threshold: float = 0.80` — trigger when estimated_tokens / budget_tokens >= this
- `require_source_refs: bool = True` — if True, producer fails closed on empty source_refs
- `allow_raw_text_in_metadata: bool = False` — must remain False; enforced by producer
- `min_summary_ref_prefix: str = "summary://"` — producer rejects refs not starting with this

**FORBIDDEN_SUMMARY_KEYS**: same set as `_FORBIDDEN_SUMMARY_KEYS` from context_assembler.py (extract to a constant shared within the module).

## Task 21-01-02: Add RollingSummaryTrigger

**RollingSummaryTrigger** — stateless, callable object or plain class:

```python
@dataclass(frozen=True, slots=True)
class RollingSummaryTrigger:
    policy: RollingSummaryPolicy

    def should_trigger(
        self,
        *,
        turn_count: int = 0,
        estimated_tokens: int = 0,
        budget_tokens: int = 0,
        task_completed: bool = False,
        explicit_request: bool = False,
    ) -> tuple[bool, str]:
        """Return (should_trigger, reason_code). reason_code is one of: turn_count, budget_pressure, task_completion, explicit_request, none."""
```

Logic:
- `explicit_request=True` → `(True, "explicit_request")`
- `task_completed=True` → `(True, "task_completion")`
- `budget_tokens > 0 and estimated_tokens / budget_tokens >= policy.budget_pressure_threshold` → `(True, "budget_pressure")`
- `turn_count >= policy.max_turn_count_trigger` → `(True, "turn_count")`
- else → `(False, "none")`

## Task 21-01-03: Add RollingSummaryProducer

**RollingSummaryProducer**:

```python
class RollingSummaryProducer:
    def __init__(self, policy: RollingSummaryPolicy | None = None, *, clock: Any | None = None) -> None: ...

    def produce(
        self,
        *,
        scope: SessionScope,
        session_id: str,
        summary_ref: str,
        source_refs: tuple[str, ...] = (),
        task_intent_refs: tuple[str, ...] = (),
        user_constraint_refs: tuple[str, ...] = (),
        unanswered_question_refs: tuple[str, ...] = (),
        artifact_refs: tuple[str, ...] = (),
        outcome_refs: tuple[str, ...] = (),
        text_sha256_16: str | None = None,
        text_length: int = 0,
        metadata: dict[str, Any] | None = None,
        existing: RollingSummaryRecord | None = None,
    ) -> RollingSummaryRecord:
```

Producer behavior:
1. Validate `summary_ref` starts with `policy.min_summary_ref_prefix` → raise `SummaryPrivacyError("summary_ref")` if not
2. If `policy.require_source_refs` and `source_refs` is empty → raise `SummaryPrivacyError("source_refs")`
3. Recursively validate `metadata` for forbidden keys (same pattern as memory privacy) → raise `SummaryPrivacyError(key)` if found
4. Compute `created_at` from existing record if provided, else use clock
5. Compute `updated_at` from clock
6. Return new `RollingSummaryRecord(scope=scope, session_id=session_id, summary_ref=summary_ref, ...)`

**Merge behavior when `existing` is provided**: keep `created_at` from `existing`, update all other fields from the new call.
