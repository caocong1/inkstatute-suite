Add MemoryOrchestrator — a standalone class that composes MemoryStoreAdapter + InMemoryRollingSummaryStore + ContextAssembler to produce a bounded ContextBundle with recalled memory/summary refs and MemoryUse evidence.

DefaultRunRuntime and WeCom channel constructors must remain unchanged.
</objective>

<constraints>
- Do NOT change DefaultRunRuntime.__init__, WeCom channel, or ContextAssembler.
- MemoryOrchestrator is standalone; hosts inject it optionally.
- Isolation check: query tenant_id/workspace_id must match scope; raise OrchestratorIsolationError otherwise.
- MemoryUse evidence: use store.record_memory_use() if available (SQLiteMemoryStore), else skip silently for InMemoryMemoryStore (which lacks the method).
- No raw legal/customer text in MemoryUse records.
</constraints>

## Task 22-01-01: Create memory_orchestrator.py with OrchestratorIsolationError and MemoryOrchestratorPolicy

**OrchestratorIsolationError**: subclass `ValueError`.

**MemoryOrchestratorPolicy** (`@dataclass(frozen=True, slots=True)`):
- `max_memory_refs: int = 8` — max memories to pass to ContextAssemblyInput
- `max_recent_turn_refs: int = 12`
- `max_artifact_refs: int = 8`
- `max_feedback_correction_refs: int = 6`
- `memory_search_text: str = ""` — default empty, orchestrator passes this to MemoryStore.search
- `record_memory_use: bool = True` — if True, record MemoryUse evidence for each selected memory

## Task 22-01-02: Add MemoryOrchestrator class

```python
class MemoryOrchestrator:
    def __init__(
        self,
        *,
        memory_store: MemoryStoreAdapter,
        summary_store: InMemoryRollingSummaryStore | None = None,
        context_assembler: ContextAssembler | None = None,
        policy: MemoryOrchestratorPolicy | None = None,
        clock: Any | None = None,
        id_factory: Any | None = None,
    ) -> None: ...

    def recall_and_assemble(
        self,
        *,
        scope: SessionScope,
        session_id: str,
        turn_id: str,
        current_turn_ref: str,
        current_turn_text: str | None = None,
        recent_turn_refs: tuple[str, ...] = (),
        artifact_refs: tuple[str, ...] = (),
        feedback_correction_refs: tuple[str, ...] = (),
        output_policy_ref: str | None = None,
        run_id: str | None = None,
        now: str | None = None,
    ) -> ContextAssemblyResult:
```

**recall_and_assemble behavior**:
1. Build `MemoryQuery(tenant_id=scope.tenant_id, workspace_id=scope.workspace_id, user_id=scope.user_id, session_id=session_id, text=policy.memory_search_text, now=now or _clock_now())`
2. Validate query matches scope — raise `OrchestratorIsolationError` if mismatch
3. Call `memory_store.search(query)` → take up to `policy.max_memory_refs` results by relevance
4. Retrieve rolling summary via `summary_store.get(scope, session_id)` if store provided
5. Build `ContextAssemblyInput(..., memory_refs=selected_memory_refs, rolling_summary=summary, ...)`
6. Call `context_assembler.assemble(input)` → `ContextAssemblyResult`
7. If `policy.record_memory_use=True` and `memory_store` has `record_memory_use` method, call it for each selected memory
8. Return result
