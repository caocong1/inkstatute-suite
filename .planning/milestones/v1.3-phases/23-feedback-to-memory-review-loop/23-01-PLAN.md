<objective>
Add the human-review layer that sits between FeedbackLearningPolicy (which produces pending MemoryCandidates) and the durable memory store. Phase 23 implements the review decision types, an in-memory review queue, and the decider that promotes or blocks candidates.
</objective>

<constraints>
- Do NOT change FeedbackLearningPolicy, InMemoryMemoryStore, SQLiteMemoryStore, or MemoryOrchestrator.
- FeedbackLearningPolicy.learn() already produces MemoryCandidates — Phase 23 adds what happens next.
- routing_candidates (from FeedbackLearningResult) must never be auto-approved; ReviewDecider raises ReviewDeciderError on any non-defer decision for them.
- Tombstoned candidates produce a MemoryRecord with status="tombstoned"; the store prevents future recall.
- No raw legal text — all candidates and reviews must carry source_refs only.
</constraints>

## Task 23-01-01: Create memory_review.py with MemoryCandidateReviewAction and MemoryCandidateReview

**MemoryCandidateReviewDecision** (`@dataclass(frozen=True, slots=True)`):
- `review: MemoryCandidateReview`
- `promoted_memory_record: MemoryRecord | None = None`
- `promotion_status: str = "pending"` — one of: `promoted`, `rejected`, `tombstoned`, `deferred`, `already_resolved`

## Task 23-01-02: Add InMemoryMemoryCandidateReviewStore

Thread-safe in-memory queue for pending and resolved candidates:

```python
class InMemoryMemoryCandidateReviewStore:
    def queue(self, candidate: MemoryCandidate) -> None: ...
    def queue_many(self, candidates: Iterable[MemoryCandidate]) -> None: ...
    def get_pending(self, *, tenant_id: str, workspace_id: str | None = None) -> tuple[MemoryCandidate, ...]: ...
    def get(self, candidate_id: str) -> MemoryCandidate | None: ...
    def resolve(self, candidate_id: str, review: MemoryCandidateReview) -> None: ...
    def get_reviews(self, candidate_id: str) -> tuple[MemoryCandidateReview, ...]: ...
    def list_resolved(self, *, tenant_id: str) -> tuple[MemoryCandidate, ...]: ...
```

- `queue` and `queue_many`: idempotent on `candidate_id`
- `resolve`: moves candidate from pending → resolved; subsequent calls return `already_resolved` via the decider

## Task 23-01-03: Add MemoryCandidateReviewDecider

```python
class MemoryCandidateReviewDecider:
    def __init__(
        self,
        *,
        memory_store: InMemoryMemoryStore | SQLiteMemoryStore,
        review_store: InMemoryMemoryCandidateReviewStore,
        clock: Any | None = None,
        id_factory: Any | None = None,
    ) -> None: ...

    def decide(
        self,
        *,
        candidate_id: str,
        action: MemoryCandidateReviewAction,
        reviewer_id: str | None = None,
        rejection_reason: str | None = None,
        edited_summary: str | None = None,
    ) -> MemoryCandidateReviewDecision:
```

Behavior:
1. Load candidate from review_store; raise `ReviewDeciderError("candidate_not_found")` if missing
2. Check if already resolved → return `MemoryCandidateReviewDecision(review=..., promotion_status="already_resolved")`
3. Guard routing candidates: if candidate.proposed_action == "review_route_or_skill_candidate" and action is not `defer` → raise `ReviewDeciderError("routing_candidate_cannot_be_auto_approved")`
4. Build `MemoryCandidateReview(review_id=..., candidate_id=..., action=action, ...)`
5. Call `review_store.resolve(candidate_id, review)`
6. Dispatch on action:
   - `approve`: create MemoryRecord from candidate; call `memory_store.upsert(record)`; `promotion_status="promoted"`
   - `reject`: `promotion_status="rejected"`
   - `edit`: create MemoryRecord with edited_summary; call `memory_store.upsert(record)`; `promotion_status="promoted"`
   - `tombstone`: create MemoryRecord with status="tombstoned"; call `memory_store.upsert(record)`; `promotion_status="tombstoned"`
   - `defer`: `promotion_status="deferred"`; candidate remains in pending queue (do NOT resolve)

**Approve/edit/tombstone MemoryRecord fields** from candidate:
- `memory_id`: new generated id
- `tenant_id`, `workspace_id`: from candidate
- `scope`: candidate.proposed_scope
- `sensitivity`: candidate.proposed_sensitivity
- `status`: "active" for approve/edit, "tombstoned" for tombstone
- `source_refs`: candidate.source_refs
- `summary`: `edited_summary` if provided else candidate.summary
- `subject`: candidate.subject or ""
- `raw_payload_ref`: candidate.raw_payload_ref
- `confidence`: candidate.confidence
- `related_user_id`: from candidate metadata "user_id" if present
