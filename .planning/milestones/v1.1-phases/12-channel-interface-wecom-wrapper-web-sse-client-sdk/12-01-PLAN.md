# Plan 12-01 - WeCom ChannelAdapter Wrapper

## Objective

Create a concrete WeCom `ChannelAdapter` wrapper around the existing sanitized WeCom service primitives, behind a default-off flag.

## Threat Model

<threat_model>
<risk id="T-12-01-regression" severity="high">Wrapper work could regress the existing WeCom service. Mitigation: do not move service code; import stable primitives and run existing service tests.</risk>
<risk id="T-12-01-backend-coupling" severity="high">Channel adapter could call Hermes or another backend directly. Mitigation: tests/source scan reject backend imports in channel package.</risk>
<risk id="T-12-01-secret-leak" severity="high">Wrapper config could store WeCom token/AES keys. Mitigation: config stores secret refs only.</risk>
</threat_model>

## Artifacts This Phase Produces

- `WeComChannelConfig`
- `WeComChannelAdapter`
- WeCom channel wrapper tests
