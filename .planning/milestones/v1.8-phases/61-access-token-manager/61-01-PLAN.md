<objective>
Create `token_manager.py` with transport injection (Protocol + Fake + lazy urllib) and `TokenManager` cache/auto-refresh logic, plus lifecycle unit tests that prove acquire → cache → 60s pre-expiry refresh → invalidate using an injectable monotonic clock.

Purpose: EGRESS-01 requires QQ Bot access tokens via `appId + clientSecret → POST /getAppAccessToken`, cached with response `expires_in` TTL (typically 7200s), and auto-refreshed 60s before expiry. This plan delivers the production module and lifecycle coverage; Plan 02 adds concurrent single-flight, error handling, and wecom-import isolation.

Output: `token_manager.py` (`TokenTransport`, `FakeTokenTransport`, `UrllibTokenTransport`, `TokenError`, `TokenManager`) and `test_token_manager.py` (lifecycle + import-safety tests).
</objective>
