<objective>
Implement the platform-runtime vision router that makes routing decisions on image-bearing turns according to operator policy, with fail-closed InkStatute-owned notices and output-boundary-safe error paths.

Purpose: VIS-02, VIS-03, and VIS-04 require a runtime routing decision on image-bearing turns: multimodal main if `supports_vision`; else vision→main mix when a vision model is configured; else fail-closed with an InkStatute-owned notice. Text-only turns must never invoke the vision model. Contract/audit evidence must stay reference-first (no raw image bytes). Vision/provider error paths must pass through the assistant output boundary without leaking provider stack traces or gateway meta. This plan implements the pure decision function — it does not call the vision model, resolve secrets, or make network calls. The Hermes adapter and runtime integration consume this decision to dispatch the actual model calls in a downstream wiring step.

Output: `vision_router.py` with `VisionRouter`, `VisionRoutingDecision`, and `VisionRoute`, public re-exports, and comprehensive tests.
</objective>
