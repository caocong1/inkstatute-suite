<objective>
Implement the admin-console-api vision config endpoint and confirm vision probe integration with Phase 77 routing_mode validation.

Purpose: VIS-01 requires an operator-facing API surface for vision routing configuration. Phase 76 already created the `vision` section in `CONFIG_SECTIONS` and the `_SECTION_ALLOWED_KEYS` for vision, and the probe handler already supports `target=vision`. Plan 77-01 added `routing_mode` enum and completeness validation to `validate.py`. This plan wires the vision GET/PUT endpoint to emit routing_mode metadata for the SSR consumer, normalizes empty-string vision fields to None, and confirms the existing vision probe path works after a Phase 77 routing_mode save. This plan does not introduce a new probe route, new network behavior, or runtime routing logic.

Output: Vision section GET/PUT metadata, empty-string normalization, vision probe integration test, and green API tests.
</objective>
