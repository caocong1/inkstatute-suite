# Phase 78.1 Plan 02: build_vision_resolver and backend support

**Provide the resolver builder and backend capabilities so services can inject a production-ready vision routing pipeline.**

## Performance

- **Duration:** ~30 min
- **Tasks:** 3
- **Files modified:** 21
- **Files created:** 3

## Accomplishments

- Created `packages/operator-config/src/inkstatute_operator_config/vision_resolver.py` with `build_vision_resolver` and `VisionResolver`.
- Added `build_vision_resolver` to `operator-config` `__init__.py`.
- `build_vision_resolver` loads `OperatorConfigStore` when `store.path.is_file()`, falls back to a default fail-closed document, maps catalog `provider_id` to vendor `kind` via the provider registry, and looks up `supports_vision` in the built-in catalog.
- Supports `backend` and `vision_runner` injection: backend `supports_vision=False` overrides catalog to false; vision pair requires `vision_runner`.
- Added `packages/operator-config/tests/test_vision_resolver.py` covering missing store, multimodal main, provider registry mapping, vision_then_main, missing runner, backend override, and real store round-trip.
- Added `supports_vision: bool = False` to `AdapterCapabilitySet` and updated `agent_adapter_manifest.schema.json`.
- Updated `ProviderModelBackendConfig` and `HermesBackendConfig` with optional `supports_vision`.
- Wired `supports_vision` into `provider_model_prototype_capabilities`, `hermes_oneshot_capabilities`, and `codex_prototype_capabilities`.
- Updated `ProviderModelBackendAdapter` and `HermesBackendAdapter` to pass `vision_decision` metadata through to `run_metadata` and `AgentResult.metadata`.
- Added image attachment support to `OpenAIClientRunner._build_messages` using `image_url` parts, no raw bytes.
- Added `packages/backends/provider_model/tests/test_openai_runner.py` covering text-only, image with text, image-only, and mime-type detection.
- Updated contract freeze tests and baseline hashes to reflect the expanded `AdapterCapabilitySet` and schema.

2. **Task 2: supports_vision capabilities** — agent_adapter, adapters, manifests.
3. **Task 3: OpenAIClientRunner image support** — image_url parts and tests.
