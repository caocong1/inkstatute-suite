# Phase 78.1 Plan 01: Wire VisionRouter into DefaultRunRuntime

**Make `DefaultRunRuntime` the consumer of `VisionRouter` for image-bearing turns.**

## Performance

- **Duration:** ~20 min
- **Tasks:** 1
- **Files modified:** 2
- **Files created:** 1

## Accomplishments

- Extended `DefaultRunRuntime.__init__` with optional `vision_resolver` and `vision_runner` arguments.
- Rewrote `create_run` to call `vision_resolver(req)` before `backend.submit_run()` and branch on `VisionRoute`.
- Implemented `FAIL_CLOSED` as a synthetic `Run` with `AsyncTaskState.FAILED`, `AgentResultStatus.FAILED`, `ReplyType.TEXT`, and the InkStatute-owned `FAIL_CLOSED_NOTICE` after `DefaultAssistantOutputBoundary.apply`.
- Implemented `MULTIMODAL_MAIN` and `TEXT_ONLY` by attaching a JSON-serializable `vision_decision` metadata record and calling the main backend.
- Implemented `VISION_THEN_MAIN` by calling `vision_runner.submit_run`, reading the vision result, stripping attachments, combining the vision description into `turn.content`, and submitting a new `RunRequest` to the main backend.
- Added `packages/platform-runtime/tests/test_run_runtime_vision.py` with tests for all four routes, missing runner fallback, and vision-runner failure.
- Confirmed `packages/platform-runtime/tests/test_vision_router.py` and `packages/platform-runtime/tests/test_run_runtime_lifecycle.py` still pass.
