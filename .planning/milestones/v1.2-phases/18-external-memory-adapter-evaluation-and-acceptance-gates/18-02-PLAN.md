## Objective

Create contract-suite evidence that Mem0/Zep-style adapter evaluation can be tested using only synthetic refs and local fixtures.

- Keep required five platform events schema-valid.
- Use only `fixture://`, `memory://`, `feedback://`, `adapter://`, hashes, IDs, statuses, and decision labels.

### 18-02-T2: Add focused tests

Create `test_phase18_external_memory_adapter_acceptance.py` to assert:

- Existing schema validator accepts the fixture.
- All adapter manifests are sanitized and refs-only.
- Mem0/Zep decisions are not default legal paths.
- Live legal gates include privacy, deletion/export, tenant isolation, data residency, security/secrets, and human review.
- Recursive privacy scans reject raw payload keys, token-like values, internal paths, Hermes meta/gateway/user command strings, and unreviewed legal-skill auto-modification claims.
