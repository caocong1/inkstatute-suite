<objective>
Create the platform-native long-term memory retrieval foundation for Phase 17.

Purpose: hosts need a small privacy-safe runtime support store that can persist, filter, and retrieve reusable memory refs for future context assembly without storing raw legal/customer conversations or introducing an external memory system.
Output: a stdlib-only memory module, public exports, and focused tests for LTM-03 and LTM-04.
</objective>

<constraints>
- Keep all code in `packages/platform-runtime`; do not create a service, database, queue, vector store, network client, Hermes integration, WeCom coupling, external memory adapter, or AI classifier.
- Use only Python stdlib and existing `platform_contract` dataclasses/enums.
- Store and return `MemoryRecord` copies. Do not mutate caller-owned records or return internal store objects.
- Reject exact `raw_payload` and full-text payload field names in metadata, industry context, and query inputs while allowing `raw_payload_ref`, `fixture://`, hashes, IDs, and refs.
- Treat legal-specific facts as metadata or industry context refs only; do not add legal-only top-level fields.
</constraints>
