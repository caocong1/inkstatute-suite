# Plan 19-01: WeCom session runtime E2E closure

## Objective

Close the v1.2 audit's critical WeCom session runtime wiring gaps without adding a new service process or coupling the WeCom package to Hermes internals.

## Tasks

1. Runtime create-run handoff
   - Update `WeComSessionRuntime.handle_turn()` so `CONTINUE_SESSION` and `START_NEW_SESSION` decisions call `runtime.create_run()`.
   - Replace the request session id with the resolved decision session id.
   - Add privacy-safe metadata refs for session decision, current turn, raw payload, and context assembly.
   - Preserve existing `resume_interrupt()` and active-task fast-path behavior.

2. Service ingress orchestration helper
   - Add a pure helper that accepts a sanitized WeCom callback plus injected runtime/session dependencies.
   - Normalize the callback with `normalize_wecom_turn()`.
   - Build `SessionScope`, `RunRequest`, and idempotency key.
   - Invoke `WeComSessionRuntime.handle_turn()`.
   - Export the helper from `wecom_service`.

3. Tests and evidence
   - Extend session runtime tests for continue, start-new, duplicate create-run idempotency, and active-task no-run preservation.
   - Add ingress helper tests for callback-to-runtime wiring, clarification resume, and context metadata refs.
   - Run focused service tests.
